# 角色剧本写作规范 v2（故事本）

> v1 写成了"人物设定说明书"，不合格。v2 必须是真正的剧本杀角色剧本：**讲故事**。
> 参考对象：《青楼2》《水镜八奇》《搞钱2》这类城限欢乐/阵营机制本的角色本写法。

## 一、什么是合格的角色剧本

1. **第一人称"我"讲故事。** 玩家拿到本子，读的是"我"的一生、"我"的秘密、"我"今晚为什么站在这里。不是说明书，不是档案表。
2. **用场景和对话推进，而不是罗列事实。** 每段重要往事都要写成一个**有画面的场景**：时间、地点、天气、气味、谁说了什么话、我心里怎么想。关键人物之间要有**来回的对白**。
3. **欢乐本的口吻。** 主角有鲜明的嘴脸和口头禅，内心独白里要有**吐槽、自嘲、反差笑点**（例如：皮拉提骂政敌时锅糊了、烦高在暴风里护发、麦克播一边装粗人一边在心里背亚里士多德、建国钱看什么都先算赔率）。政治讽刺对着权力游戏本身。
4. **情绪有起伏。** 欢乐为主，但每个人至少有一处**走心的瞬间**（遗憾、愧疚、孤独、被利用的痛），让人读完会心一软。
5. **每章结尾留钩子。** 每一幕的故事结尾停在一个悬念或一个让人坐立不安的念头上。
6. **规则不进故事。** 故事里不出现"真阵营""民调−3""F-xx""机制""规则卡"这类词。机制统一放在每幕最后的**【本幕任务】页**，并且那一页也要写得简洁有角色口吻。
7. **信息纪律不变**：只写这个角色此刻应当知道的事（以 v1 本子与设计圣经的信息分布为准）。他人秘密、沼泽名单、阵营人数、DM机密，一个字都不能写进去。

## 二、每本结构（Markdown，一级标题自动分页）

```
# 第一幕 · 新年筹款晚宴
（开篇一句话引子，可用一句台词或一个画面）
## 一、xxxx（章节小标题，有文学性，如"锅铲与麦克风"）
……故事……
## 二、……
……（共4–6章：我的出身与成名路 → 改变命运的往事（场景＋对白）→ 我与几位关键人物的纠葛（各写成小场景）→ 我心底的秘密（写成一段不敢对人说的回忆）→ 今晚：我走进骑墙大酒店）
## 【本幕任务】
> **【我想要的】** 用角色口吻写三星目标（简洁，含判定标准）
> **【我的本事】** 技能卡（照设计圣经数值，一句话说明用法）
> **【今晚要做的3件事】** ……
> **【小提示】** 表层秘密、小目标、签名台词、演法要点（3–5条）

# 第二幕 · 超级星期二之夜
（承接上一幕：两次活动之间这两个月里"我"身上发生了什么，新的回忆与新得知的事，用场景写）
## ……
## 【本幕任务】

# 第三幕 · 同夜党代会
## ……（卧底的第二幕/第三幕里，君子协定写成一段"我收到一份抄件"的场景，原文作为信件引用；其他人在同一位置是一段等长的"党内法律顾问给我的八卦备忘"场景）
## 【本幕任务】

# 终幕 · 摇摆之夜
## ……（大选前夜的独白与回忆，情绪收束）
## 【终局任务】
```

## 三、篇幅（以汉字计）

- 第一幕故事 9000–12000 字（另加任务页约 800 字）
- 第二幕、第三幕故事各 3500–5000 字
- 终幕故事 2500–3500 字
- 8 位角色同幕字数差 ≤20%；第二幕"协定原文／法律顾问备忘"段落字数差 ≤10%

## 四、事实来源（必须遵守，不得自创冲突设定）

- 本角色 v1 本子：`docs/jubensha/phase3/_archive/characters-v1/<文件名>`——事实、时间、信息边界已按设计圣经整理好，**以它为事实底稿**，改写成故事。
- 设计圣经：`docs/jubensha/phase1/02-characters-relations.md`（人物、技能、三星、表层秘密、小目标、三件事卡）、`03-truth-timeline.md`（事件与信息分布）、`01-core-concept.md` 附录A（规则口径）。大文件先 grep 再按章节读。
- 出品人裁决：梅戏的真相题题面为"沼泽成员都有谁（写出全部名字）"，任何本子都不得出现泄露沼泽人数的说法。

## 五、写入方式

覆盖写入 `docs/jubensha/phase3/characters/<文件名>`。分段落盘：先 Write 写第一段，之后用 Bash `cat >> 文件 <<'EOF_SEG'` 追加，每次 ≤4000 字。写完一章就落盘。
