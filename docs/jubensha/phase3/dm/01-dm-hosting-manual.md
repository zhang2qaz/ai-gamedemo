# 开本前：DM与场控须知

> 本册是《摇摆！》DM主持手册的**上册·流程与主持**。拿着本册和下册，DM可以独立开本。
> 本册写"什么时候、谁、做什么、说什么"；九页账本正文、DM机密册、真相题标准答案、结局文案都在**下册**，本册需要时写"见下册第X部分"。
> 规则口径唯一依据是规则冻结表F-01～F-23。本册与之冲突时，以冻结表为准。

## 一、本册怎么读

**符号约定**
- 引用块里以"🎙 贾不睡："开头的，是DM照念或照着改说的主持词。DM换成别的身份（拍卖师、律所执行人、九老会等）时，开头仍写"🎙 贾不睡："，括号里注明口吻。

- 以"【场控】"开头的是场控（副DM）的动作。

- 下册第三部分：机密道具文本（交权书摘要卡、复盘信封：计划书与交权书草稿）
- 下册第四部分：真相题标准答案与逐题确证条件
- 下册第五部分：结局文案（主结局、附加段、个人结局卡、通用尾声）

|---|---|---|

**NPC清单**（主DM至少要演出5种声线，建议每种配一件道具）：贾不睡（话筒）、拍卖师（拍卖槌）、钱钱委员会主席（名牌）、照妖镜鉴定师（放大镜）、律所执行人（黑框眼镜、文件夹）、九老会（黑袍）、吵架委员会主持人（关麦铃）、叉叉网（手机念稿）、州务卿（帽子，用于抽签）。

## 三、能力要求与上岗（F-22）

**硬性要求（达不到不得开本）**
1. 8人、7人局全程必配场控。6人局可以单DM，但必须使用"单DM替代包"，并且DM本人已取得单DM资格。
2. 主DM与场控都要通过分岗上岗考核：
   - 笔试20题（规则12、裁决8），85分合格；
   - 信息隔离情景题5道，对4道合格；"泄露暗信息"类答错一票否决；
   - 以玩家身份玩一次、观摩一次、带本老师监督主持一次后，方可独立开本；名场面校准录像完成前，以"主创组现场带本"替代。
3. **场控实操限时**：第三周8信封速算＋开票表≤6分钟；摊牌开封＋机密册8页同构更新＋报备回执装封≤8分钟；回执与邮包装封（8人份，含誊抄与选版）≤5分钟且零差错；收入信封装填（含草根、匿名、7人补偿、报备保证金扣减、听众来信补偿）≤3分钟且零差错；超级星期二开标≤4分钟；269令牌按周表发放≤1分钟；欠条袋预清点≤5分钟。
4. **主DM实操限时**：盲盒开标≤2分钟；F0换将全流程（含两张票同窗、恢复表决权、照念换将卡）≤3.5分钟；F5八州开票（含跟跟开场）≤10.5分钟；269唱票主持≤7分钟。
5. **单DM资格**：场控与主DM全部实操都通过，并在带本老师监督下以单DM身份完成一局6人局。
6. 终局规则讲解≥9分钟、分层进行；每轮速算≤5分钟并行（第三周≤6分钟）；十月惊奇检查表与机密册零失误。

**能力画像（建议）**：主持过阵营本或机制本；能在主播、拍卖师、法官、律所执行人几种口吻之间切换；先裁定、后讨论；表情不泄密。

## 四、场地（F-22第2款）

- **标准**：1个主场＋2个可关门的私聊空间；或4个彼此相距≥4米的区，配白噪音。
- 四个走廊区命名为：东厅、西厅、自助餐区、露台。每区同时只容1组。
- **只有一个房间时**：用桌角四区立牌，走廊同时谈话降到3组。
- **设备**：投屏设备或便携照片打印机1台（每期午夜合影）；没有设备时用拍立得。
- 主场需要：8个座位配8块桌面隔板；公示台（场控坐镇）；公开状态板；终局地图海报从第1期起就挂在墙上；音响（片头曲、雨声、BGM、离婚律师事务所电话铃）。

## 五、开本条件（开门前逐条打勾）

1. □ 人数确定为6、7或8人，已取对应色标套件（●8白／●7黄／●6绿）。
2. □ 8/7人局：场控到岗。6人局单DM：单DM替代包在手（自助登记簿、预印计数板、勾选栏台本卡），DM持单DM资格。

4. □ 机密册：人数页齐全，真阵营封袋已核（8人驴心3／象心3／沼泽2；7人3／2／2；6人2／2／2），觉醒卡2张在册。

8. □ 三枚见证人印章：辣椒印、麦克印在各自角色包；手稿印在手稿盒。

## 八、信息纪律（每次开本前默念）

1. 真阵营、卧底、沼泽成员姓名与人数，第9页发布（或复盘）之前，一个字不说，一个眼神不给。
2. 第2期听证之前，DM嘴里不出现"自动""定时""删不掉""死人开关""两头账本"。
3. 同一动作全员同时做：拆信封、写数、封口、交回，一律喊口令。任何人的信封都不提前、不延后、不单独收。
4. 私下问DM的问题（党鞭点票、事实核查、开盒、对镜头说话的追问）一律写纸条回答，纸条答完收回。
5. DM宣读的结果只说规定的那几个字："一致／不一致""领先／胶着""确有其言"。不加解释，不加语气。
6. 玩家逼问"你刚才为什么笑"，统一回答：🎙"本台主持人表情不代表本台立场。"
