# 全员演绎 · 序幕 ·《今夜不睡》开播

*（片头曲起。灯光扫过墙上的选举人团地图，中间八个摇摆州闪着黄灯。贾不睡端着一杯咖啡走到台前。）*

**旁白**：Y年1月19日晚，钢铁州铁锅城，骑墙大酒店宴会厅。门楣上挂着一条红蓝各半的横幅："两党都欢迎，账单都一样。"今晚的东家，是已故说客游游·两头吃的遗产基金会。死人请客，活人吃饭。

**贾不睡**：晚上好，欢迎收看《今夜不睡》大选特别季！我是贾不睡，名字就是我的工作纪律。今晚台上八位嘉宾：四位想当总统，四位想决定谁当总统。掌声欢迎！

**全体**：（鼓掌）今——夜——不——睡！

**贾不睡**：按老规矩，嘉宾们先对着镜头打个招呼。蓝胸牌，从这边来。

*（皮拉提举着一把锅铲站起来，像在直播间开场。）*

**皮拉提**：家人们！皮拉提来了！今晚不炒菜，今晚炒选情！锅都热了，你还凉着？

**烦高**：（先摸一下鬓角，再找到镜头，微笑）各位晚上好。宴会厅的空调风有点大，不过请放心——风再大，发型不乱。

**下木**：（笑眯眯，声音不高）下木，驴友党党鞭。管点票，管纪律。大家不用紧张，我这个人不记仇。（停顿两秒）我记账。

**梅戏**：梅戏，驴友党通讯总监，前调查记者。贾老师，我刚才那句自我介绍能引用吗？能？好。我手上有个独家——下次告诉你。

**贾不睡**：本台已经等了八年了，梅总监。红胸牌！

**麦克播**：（对着领带夹上的麦克风，嗓门把吊灯震得一晃）老铁们！麦克播！《三小时不聊正事》今晚搬进宴会厅！本段由壮壮蛋白粉赞助——喝了它，吵架不累！就"今晚吃什么"这个问题，这事儿咱展开聊三小时！

**贾不睡**：节目组只给了你三十秒。

**麦克播**：行，那我压缩一下，两小时五十九分。

**半步爹**：（先看了一眼左右，才慢慢站起来）大家好，我是……啊，不用鼓掌，不用鼓掌。总统今晚在官网卖纪念帽，抽不开身，派我来跟大家问好。我一直就在您身后半步。

**建国钱**：（把西装前襟一掀，内衬印着巨大的二维码）都是朋友！扫一扫，加个好友！今晚的酒水，驴友党那半边是我赞助的，大象党那半边也是我赞助的。两边押，才叫稳。

**狗登罗**：（站得笔直，像在宣誓作证）狗登罗，大象党首席选举律师。今晚在座的各位，我都查过了。（顿）他是干净的。——我说的不是你。

**麦克播**：我也没问你！

**狗登罗**：你三十秒的开场白里提了我三次。

**麦克播**：那是节目效果！

**旁白**：这对前夫前妻在节目里互骂了五年，收视率全台第一。导播在后台比了一个心。

**贾不睡**：好，下面请两党各用一句话，向全国观众介绍一下自己的党。驴友党先。

**皮拉提**：驴友出发！

**梅戏**：出发去哪儿？

**下木**：我们开了四个小时的会。

**烦高**：（摸鬓角）结论是，下周再开一次。

**贾不睡**：非常驴友党。大象党，去年那顶写着"第三届"的纪念帽，你们要不要向全国观众道个歉？

**半步爹**：（看了一眼狗登罗）我们大象党……

**狗登罗**：从不道歉。

**麦克播**：我们只"重新解释"！那顶帽子印的不是"第三届总统"，是"第三届……观众朋友抽奖活动"！

**建国钱**：顺便说一句，押宝网上"那顶帽子什么时候下架"的盘口，现在一赔四十，欢迎下注。

*（灯光一暗。场边推上来一只三层蛋糕，顶上插着一把巧克力做的锅铲，蜡烛摆成"34"。）*

**贾不睡**：本台还得到消息：今天正好是一位嘉宾的生日！

**皮拉提**：哎呀！家人们，三十四了！谢谢谢谢！我离总统的年龄门槛还差——（伸出手指要数，又缩回去）算了，不数了，数了有人要记。

**狗登罗**：（已经掏出了笔）记了。

**下木**：年轻人，锅可以热，账不能乱。生日快乐。（翻开小本子）这蛋糕是谁出的钱，我也顺手记一下。

**建国钱**：我出的！左边一半是驴友党口味，右边一半是大象党口味。中间那层夹心——（拍拍胸口）是我。

**烦高**：（往蜡烛的反方向退了半步，护住头顶）吹蜡烛这种事，我就在精神上支持一下。

**梅戏**：州长，"精神上支持"这句能引用吗？明天的标题我都想好了。

**半步爹**：（小声）……对了，其实我的生日是明天，零点一过就是。没事没事，大家先吃蛋糕，先吃。

**皮拉提**：副总统，您说什么？大点声，我直播间的家人们听不见！

**半步爹**：（看了一眼身后，身后没人）……没什么。

**全体**：（敷衍地拍手）生——日——快——乐——

**旁白**：每个人的座位卡里都夹着一张拍卖目录。台前摆着三只一模一样的盲盒，目录上只写了三件遗物：回忆录手稿（附律所寄存物一件）、第18洞记分卡、播客嘉宾谢礼。哪只盒子装哪一件，没人知道。

**麦克播**：播客嘉宾谢礼？那肯定是给我的！整个大选季谁的播客最大？

**梅戏**：回忆录手稿，我倒想看看他回忆了谁。

**建国钱**：三只盒子我都想要。可惜规矩是一人最多一只——这年头，连盲盒都限购。

**贾不睡**：还有一件事。一个月前，两头吃先生在第18洞倒下。法医报告只附了一句话："死者在读一张卡片时突发不适，卡片事后未找到。"本台悬赏：那张卡片是什么？谁递给他的？谁把它拿走了？

*（全场安静一秒。八个人同时伸手去端水杯。）*

**烦高**：（喝水的时候也没忘了对着镜头）这个问题，很值得深思。

**下木**：（对着空气，像在跟看不见的观众说话）你们注意到没有？刚才所有人同时口渴了。

**狗登罗**：律师建议：在座各位，今晚说话前先想三秒。

**贾不睡**：最后一条风声：节目组听说，今年每到政治大日子的午夜，叉叉网一个叫"@午夜账房"的账号，就会贴出一页账本。第一页——就在今晚零点。

**全体**：（齐声）今晚零点？！

**皮拉提**：好啊！谁的账，谁自己端！我的锅从来不怕人看！

**烦高**：零点？我十一点就得回房间定型，四十分钟，一分钟都不能少。

**半步爹**：零点……（看了看表，又看了看大家）……好的，好的。

**建国钱**：押宝网"第一页写的是谁"的盘口已经开了！八个名字，外加一个"其他"！

**狗登罗**：提醒一下，零点以后说的每一句话，都算明天的证词。

**梅戏**：那我现在说的算今天的，对吧？我有个独家——

**全体**：下次告诉你！

**贾不睡**：离零点还有几个小时，今晚的节目单很满：竞选广告、公开打赏、遗产拍卖、盲盒暗拍。不过开场之前，先请驴友党党鞭按座位点名。被点到的，站起来，二十秒，说名号、身份、签名台词。

**下木**：（慢条斯理地翻开那本小本子，抬眼扫了全场一圈）点到谁，谁起立。我不记仇。

**全体**：（齐声）你记账！

**下木**：（微笑）第一位——

*（灯光打到第一位嘉宾身上。DM宣布：党鞭点名开始。）*
