# 全员演绎 · 第二幕 · 超级星期二之夜

*（宴会厅一角拉起一条手写横幅："钱钱委员会临时办公点（停摆期间借用）"。桌上六个座牌，三蓝三红，中间一盏没插电的台灯。大屏幕上，三个州的地图在闪：冲浪州、孤星州、烤肉州。）*

**旁白**：Y年3月7日，超级星期二。全国多个州同一天初选开票。钱钱委员会总部因为政府停摆断了电，六位委员抱着文件夹，借了骑墙大酒店宴会厅的一个角落办公。三比三，永远打平。

**贾不睡**：欢迎回来！今晚叉叉网热搜前十，有九条是在座各位，第十条是"贾不睡的咖啡续了第几杯"。答案是：第八杯。

**全体**：（齐声）你被叉了！

**贾不睡**：先说上回。一月那个午夜，"@午夜账房"真的发了第一页，皮议员的厨房上了热搜。皮议员，有什么想对观众说的吗？

**皮拉提**：（锅铲往桌上一拍）家人们，该说的我那天晚上都说了。我就再说一句：锅是热的，骂人的话每一句都是我自己炒的！今晚超级星期二——锅都热了，你还凉着？

**麦克播**：我的节目连播了六期《厨房之谜》，每期三小时，收听量破纪录。皮议员，我得谢谢你，你是我今年最好的赞助商。

**皮拉提**：那你把广告费分我一半！

**麦克播**：我给你流量，你给我锅，这叫合作共赢，这事儿咱展开聊三小时。

**狗登罗**：（头也不抬）他说的"合作共赢"，意思是他赢。

**贾不睡**：好了好了。全国观众今晚最关心的问题只有一个：那一页，到底是谁发的？

*（八个人同时看向别人，没有一个人看向自己。）*

**梅戏**：先声明，不是我。我有独家，向来都是"下次告诉你"，从来不当天发。

**建国钱**：押宝网"谁是泄密者"的盘口已经开了！八个名字加一个"其他"。目前赔率最低的是……（扫了一圈）……不能说，说了影响盘口。

**下木**：（对着空气，慢悠悠地）他们都在看我。因为我知道每个人的老底。可是知道和说出来，是两门手艺。我只练前一门。

**半步爹**：（先看左边，再看右边）那天零点，我刚好满五十八岁……没人记得。所以请大家放心：一个连生日都没人记得的人，发什么都不会有人看。

**烦高**：（摸鬓角）我从不发帖。发帖要低头看手机，低头会乱发型。

**麦克播**：我要是泄密，就在自己节目里泄，展开聊三小时，谁会只发一页？

**狗登罗**：这一点我可以作证。他写东西从来超不过三行，剩下的全是语气词。

**皮拉提**：等一下！我是被曝光的那个人，我是受害者！受害者也要被审？

**贾不睡**：钱钱委员会说了：一律审。今晚他们就在这个角落开听证——反正他们的总部也没电。

**贾不睡**：说回正事。今晚三个州同时开票：冲浪州、孤星州、烤肉州。驴友党这边，州长对议员。

**烦高**：冲浪州是我的主场。那里的浪我都见过，这点票算什么。（门口一阵穿堂风吹过，他纹丝不动）

**皮拉提**：州长，冲浪州的年轻人都在看我直播。您见过的浪，是二十年前的浪。

**烦高**：（对着镜头微笑，慢半拍）年轻人，浪是会回来的。发型不会。

**贾不睡**：大象党这边，副总统对播客之王。

**半步爹**：孤星州的选民说，他们喜欢稳重、不抢镜的人。……他们说的是不是我，我得先问问总统。

**麦克播**：烤肉州的老铁们听好了！烤肉要慢火，选举要大嗓门！副总统连"我"字都不敢说，你让他怎么当总统？

**狗登罗**：顺便通知一下，你上周在孤星州的集会被投诉了。罪名：噪音扰民。

**建国钱**：三个州，两个党，四位候选人，我一共押了十二份。不管今晚谁赢，胜选派对上都有我。都是朋友！

**下木**：烤肉州的代表我个个都认识。各位放心，我只点票，不点菜。

**梅戏**：超级星期二的结果我已经拿到了——

**贾不睡**：开票还没结束呢！

**梅戏**：所以是下次告诉你。

**贾不睡**：万一今晚输了，两党有预案吗？驴友党先说。

**下木**：有。开会讨论输的原因，会期四周。

**皮拉提**：第五周开会讨论，上一个会为什么开了四周。

**贾不睡**：大象党？

**狗登罗**：大象党从来不输。

**半步爹**：（看了一眼狗登罗，跟着点头）我们只是……

**麦克播**：重新解释了胜利！

**建国钱**：押宝网已经替两党各开了一个盘：驴友党"会开到第几周"，大象党"会把输解释成什么"。两边押，才叫稳。

**贾不睡**：投票站关门前最后十秒，请各位给选民喊一句口号！

**下木**：投票要早，点票要准，账要记清。

**梅戏**：投给谁都行，出了投票站别急着走，留个电话，我回头采访你。

**半步爹**：请投给……（回头看了一眼，身后没人）……请投给我。这句话我练了七年。

**烦高**：（对镜头）风再大，发型不乱；票再少，微笑不散。

**建国钱**：投给谁都行！押宝网同步开盘，扫码下注，童叟无欺！

*（大屏幕一闪，叉叉网的推送声"叮"了八下。每个人手边都多了一张扣着的新卡。）*

**旁白**：开票还要等几个钟头。可在《今夜不睡》，开票之前，先开直播。每个人手里都捏着几张关于别人的"可靠消息"——真的假的，照妖镜说了算；锤还是洗，观众说了算。

**烦高**：（把那张卡扣得更紧了一点）我先声明，我手里这张，和发型无关。

**皮拉提**：我这张是热的，刚出锅！

**梅戏**：我这张能引用吗？……算了，我自己引用。

**下木**：（把卡收进小本子里夹好）先记下，回头再算。

**半步爹**：（小声）我能……空过吗？

**狗登罗**：可以。空过也会被记录。

**建国钱**：谁想出价收我这张，私聊。

**麦克播**：老铁们！今晚的扒马褂直播间——

**贾不睡**：——由本台主持！欢迎来到"扒马褂直播间"！规矩照旧，爆料人请念——

**全体**：（齐声）"据可靠消息……我不评论，我只是转发！"

*（灯光转红。DM宣布：扒马褂直播间开张，从民调最低的嘉宾开始。）*
