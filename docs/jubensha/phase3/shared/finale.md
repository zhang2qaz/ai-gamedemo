# 全员演绎 · 终幕 · 摇摆之夜

*（宴会厅的灯全部换成了红蓝两色。墙上那张选举人团地图被放大到占满整面墙，中间八个摇摆州还亮着黄灯。正中摆着一张辩论台，台上放着一只铜铃，铃上贴着标签："吵架委员会·关麦专用"。）*

**旁白**：Y年9月底，离大选日还有六个星期。骑墙大酒店还是那座骑墙大酒店，横幅还是那条横幅："两党都欢迎，账单都一样。"只是今晚，账单终于要结了。

**贾不睡**：欢迎回到《今夜不睡》大选特别季最终期——《摇摆之夜》！一月到现在，本台一期没落，一秒没睡。我的咖啡已经从杯换成了桶。

**全体**：（鼓掌）今——夜——不——睡！

**贾不睡**：先看地图。全国五百三十八张选举人票，拿到二百七十张当选。大部分州早就定了颜色，剩下八个州在摇摆。各位，摇摆是什么感觉？

**皮拉提**：像我的锅！左边一颠，右边一颠，菜还没出锅，人先晕了！锅都热了，你还凉着？

**烦高**：（摸鬓角）摇摆嘛，要看定力。地图可以摇，发型不能摇。

**麦克播**：摇摆州的老铁们！你们知道你们现在多值钱吗？每一个摇摆州选民，都是一个三小时播客的题目！这事儿咱展开聊三小时——一个州三小时，八个州就是二十四小时！

**狗登罗**：节目组只给了你二十四秒。

**麦克播**：你怎么连这都要管！

**建国钱**：押宝网八个摇摆州全部开盘！每个州两个颜色，我每个颜色都押了。不管地图最后是什么颜色，都是我喜欢的颜色。两边押，才叫稳。

**半步爹**：钢铁州是我的家乡……（看了看左右）……我是说，钢铁州的选民一直很稳重。他们会做出正确的选择。至于哪个是正确的，我就不抢先说了。

**梅戏**：我也是钢铁州人。我只说一句：钢铁州的结果，我有个独家——

**全体**：下次告诉你！

**梅戏**：……大选夜告诉你。这次是真的。

**下木**：（翻开小本子，对着空气）八个州，六个星期，五种资源，无数张欠条。各位，我不记仇——但今晚，所有人的账都会对上。

**贾不睡**：好，在进入正式流程之前，吵架委员会委托本台做一次辩论彩排。规则只有一条：不许说别人的名字。谁说了，就——

*（贾不睡拿起铜铃，"叮"地摇了一下。）*

**全体**：关——麦——！

**贾不睡**：题目：请用一句话，夸一夸在座的某一位。不许说名字。皮议员先来。

**皮拉提**：我想夸那位嗓门比我还大的先生。是他让我知道，原来这世上真有人比我还能说。

**麦克播**：谢谢！那我也夸那位拿锅铲的女士！她就是——皮……

*（叮！）*

**贾不睡**：关麦！说了名字！

**麦克播**：我就说了一个字！

**狗登罗**：一个字也是呈堂证供。

**烦高**：（摸鬓角，对着镜头）我欣赏那位西装上印着二维码的先生。他让每一套西装，都有了存在的意义。

**建国钱**：谢谢！我夸在座的每一位——都是朋友！都是用户！扫一扫，下注八折！

**下木**：（笑眯眯）我夸那位全场最年轻的女士。年轻真好。年轻的人，账还少。

**梅戏**：我夸那位律师。全场只有她记得比我还全。……这句能引用吗？

**狗登罗**：不能。另外，我拒绝夸任何人。律师的赞美，按小时收费。

**半步爹**：我……我想夸那位……（看了看左右，又看了看身后）……那位声音很大的先生。我站在他身后半步，耳朵到现在还嗡嗡的。

**贾不睡**：彩排通过，算是。真正的辩论里，说一次名字，风向就推给对手一格。各位，记牢了。

**贾不睡**：再说说接下来六个星期。驴友党，你们准备好了吗？

**下木**：准备好了。我们为了"怎么准备"开了六个星期的会。

**皮拉提**：所以我们什么都没准备，但是会开得非常团结！

**贾不睡**：大象党呢？

**狗登罗**：大象党从不准备。

**麦克播**：我们事后重新解释！

**半步爹**：（跟着点头，慢了半拍）……对，重新解释。

**贾不睡**：不管在不在票上，最后六个星期，每个人都还有活儿干。各位打算干什么？

**烦高**：保持微笑，保持体面，保持发型。三件事，一件都不能少。

**下木**：数票。我这辈子只干好了一件事，就是数。

**梅戏**：跑街头采访。每个选民我都问一句：您投给谁？能引用吗？

**半步爹**：我打算……（犹豫了一下）往前站一站。半步也行。

**建国钱**：两边站台，两边捐款，两边合影。照片我都想好了：左脸给蓝的，右脸给红的。

**旁白**：六个星期里，会有一场辩论之夜，两页午夜账本，一个总有人倒霉的十月。大选日零点，还有最后一页。照妖镜实验室已经提前把鉴定结论印好了，只有一种措辞："大概率是真的。"

**建国钱**：十月惊奇的盘口我也开了。热门选项是"某人的发型出事"，一赔三。

**烦高**：（微笑，一动不动）风再大，发型不乱。

**麦克播**：一赔三？我押十块！

**皮拉提**：我押二十！

**烦高**：……各位，我还在这儿。

**梅戏**：州长，这句能引用吗？

**贾不睡**：最后提醒一句。今晚先开票，定谁当选；开完票，再翻卡，定谁赢。刚才欢呼的人可能当场判负，刚才哀嚎的人可能是赢家。没有人出局，没有人能提前回家——这一点，和真正的政坛不一样。

**下木**：（合上小本子，对着空气）这才是最好看的部分。

**狗登罗**：律师提醒：你们签出去的每一张欠条，大选夜都会回来找你。

**建国钱**：都是朋友！大选夜的派对，两党的会场我都订好了，大选夜见！

**半步爹**：（慢慢站起来，往前走了半步，又停住）……大家，大选夜见。

**皮拉提**：家人们，最后六个星期！锅都热了——

**全体**：你还凉着？！

*（灯光一暗，只剩地图上八盏黄灯。场控把一只只收入信封放到每个人面前。）*

**贾不睡**：今晚我们只问两件事：谁当选？赢的，到底是谁的人？隔板后面，三——二——一——拆！

*（DM宣布：摇摆之夜开场。）*
