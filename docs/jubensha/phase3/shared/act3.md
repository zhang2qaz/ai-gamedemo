# 全员演绎 · 第三幕 · 同夜党代会

*（宴会厅被一排自助餐台从中间隔成两半。东厅挂满蓝气球，西厅挂满红气球。餐台正中立着一块牌子："本区域中立，请勿在此拉票。"牌子底下，两党代表正抢着同一盘炸鸡翅。）*

**旁白**：Y年8月14日。两党全国代表大会同一夜在骑墙大酒店开幕：驴友党在东厅，大象党在西厅，中间只隔着一张自助餐台。今晚唱名、提名、选搭档。全国观众只想知道一件事：散场的时候，谁的名字会印在选票上。

**贾不睡**：欢迎回来！本台今晚第一次同时直播两场党代会。导播说两边的掌声太像，他已经分不清哪边在鼓掌了。

**全体**：（东西两半同时鼓掌，又同时停下，互相瞪了一眼）

**贾不睡**：先说上回。三月那个午夜，"@午夜账房"一口气又发了两页，还附赠了一份律所公告。两位当事人有什么要说的吗？

**麦克播**：（清了清嗓子）不予置评。——老铁们，这是我这辈子说过最短的一句话，请记住这个历史时刻。

**建国钱**：我也不予置评。都是朋友，都是朋友。

**狗登罗**：作为律师，我建议两位以后继续保持这个长度。

**麦克播**：你管我说多长！

**贾不睡**：好的，我们来看东厅。驴友党今晚的会议议程有多长？

**下木**：（翻开小本子）四十七页。第一项议程是"讨论今晚的议程"。

**梅戏**：第二项是"讨论第一项为什么讨论了这么久"。这句能引用。

**皮拉提**：家人们，东厅的空调坏了，三千个代表挤在一起，跟我直播间的弹幕一样热！锅都热了，你还凉着？

**烦高**：（摸鬓角，对着镜头）空调坏了，正好考验一位领导人的定力。我已经站了两个小时，发型没有动过一毫米。

**贾不睡**：再看西厅。大象党今晚的会场布置得非常……隆重。

**半步爹**：（从一根巨大的红气球后面探出半个身子）谢谢。这些气球是总统亲自挑的颜色。他今晚在白房子看直播，嘱咐我站得离镜头……近一点。

**麦克播**：近一点？副总统，你往前走半步，就是镜头了！

**半步爹**：（往前迈了一步，又退回来半步）……习惯了。

**狗登罗**：大象党今晚没有议程。我们只有结论，议程事后补。

**建国钱**：两厅的炸鸡翅都是我赞助的。东厅原味，西厅辣味，中间那盘——（指着餐台）两边都能夹，所以最先被抢光。两边押，才叫稳。

*（东厅和西厅同时伸出两双筷子，夹住了同一只鸡翅。两人对视三秒，各自松手。）*

**旁白**：这是今晚两党第一次，也可能是最后一次，在同一件事上达成共识：谁都别想独吞。

**贾不睡**：今晚的流程很简单：唱名，提名，选搭档。每党九十票，过四十六票拿提名。各位，请对自己的代表们说一句话。

**下木**：各州代表团注意：唱到你们州的时候，声音洪亮，数字清楚。数错一票，我记一辈子。

**下木**：（转过头，对着空气）唱名的妙处在于，每个人都得当众大声说出自己站哪边。至少，是嘴上。

**皮拉提**：我的代表都是我直播间的家人，喊"皮拉提"的那种！一喊就到，一到就投！

**烦高**：我的代表都是冲浪州的老乡，交情比发胶还牢。

**麦克播**：我的代表都是听了我三年节目的老铁！三年，每期三小时，算下来他们听我说话的时间比听他妈说话还长！

**半步爹**：我的代表……（掏出手机，照着屏幕念）"感谢各位一直以来的支持，总统向大家问好。"（往下划了划）……就这一句。

**梅戏**：我不是候选人，所以我没有代表。但我有每一个代表的电话。

**狗登罗**：我也不是候选人。我有每一个代表的档案。

**建国钱**：我也不是候选人。我有每一个代表的……（把西装一掀）……二维码。都是朋友！

**贾不睡**：唱名之后是搭档。节目组给每位提名人准备了一张"求婚卡"，当众点名，对方三十秒内答复。本台提醒：可以跨党，无代价。

**全体**：（齐声，东西两厅同时）跨党？！

**下木**：（对着空气，笑了一下）你们看，刚才那一秒，两边的人都在偷看对面。

**皮拉提**：求婚我熟！我直播间每天都有人求婚！……不过都是给锅铲的。

**烦高**：（整理领带）搭档如婚姻，讲究的是体面。最重要的是，合影的时候不能挡我的发型。

**麦克播**：谁要跟我搭档，先说好：节目我一个人讲，三小时，你负责点头。

**狗登罗**：（头也不抬）上一个跟你搭档的人，点了五年头，颈椎出了问题。

**梅戏**：我先说好：谁求婚，我都要第一个拿到独家。下次告诉你们是谁。

**半步爹**：（小声）八年前，我也是这样被求婚的……我当时说的是"好的，好的"。

**建国钱**：押宝网已经开出"谁跟谁搭档"的盘口，一共二十八种组合，我每一种都押了一点。

**贾不睡**：今晚最后一项：资格诉讼。年龄、州籍，任何人都可以告，费用两块钱。本台已经听说，有人律师袍都穿好了。

**狗登罗**：（把一份文件在桌上磕整齐）我只陈述事实：宪法写的是"年满三十五岁"。我查过了——

**皮拉提**：（锅铲一举）你查过了，我活过了！有本事法庭上见！

**烦高**：（摸鬓角）我五十二岁，冲浪州州长，资格无可挑剔。真要告我，只能告我的发型太完美。

**全体**：（东厅）吁——（西厅）噢——

**梅戏**：（飞快地记）"你查过了，我活过了"，这句能引用吗？庭审记录是公开的，我带了三支笔。

**皮拉提**：随便引！不收版权费！

*（灯光一收，只剩桌面一盏灯。场控把每个人的第三册翻到封底，那里贴着一只鼓鼓的密封袋。）*

**旁白**：唱名还没开始。可在唱名之前，每个人都要先做一个决定——一个不能告诉任何人、只能写进信封里的决定。

**贾不睡**：各位，请把第三册封底那只密封袋拿出来。（停顿）别撕！谁也别撕。等我口令，全员同时撕封。

**麦克播**：老铁们，我宣布：这是本节目开播以来，第一个我不能剧透的东西！

**梅戏**：（把袋子贴到耳边听了听）没声音。……这是我拿到过的第一份，连"下次告诉你"都不能说的东西。

**烦高**：（对着镜头）风再大，发型不乱。袋子再鼓，表情不动。

**半步爹**：（看了看左右，发现所有人都在看自己的袋子）……这一次，没人在我前面。

**建国钱**：这个袋子，押宝网开不了盘。

**下木**：（合上小本子）好了。这一页，不记。

**贾不睡**：三——（全场八只手同时捏紧袋口）——先别急。撕之前，我先把规矩讲清楚。

**全体**：（齐齐松了一口气）呼——

*（DM宣布：摊牌信封与押宝单环节开始，先讲解，后撕封。）*
