# 第三阶段写作规范（角色本／DM手册／公共物料）

## 唯一依据
- `docs/jubensha/phase1/01-core-concept.md` 附录A《规则冻结表》F-01～F-23：全本唯一规则口径，冲突时以它为准。
- `02-characters-relations.md`：人物、生日、技能文案、三星、表层秘密、小目标、三件事卡、关系、戏份矩阵。
- `03-truth-timeline.md`：事件、日期、九页账本正文、第18洞、**§5信息分布表（谁在何时知道什么）**、真相题。
- `04-flow-and-mechanics.md`：前三期流程与规则；`05-finale-election.md`：终局；`07-conditional-hotline.md`：午夜热线。
- 不要读 `_process/`。文件很大：先 `grep -n "^#"` 看目录，再按章节 Read(offset,limit)。

## 信息纪律（最重要）
- 角色本只写该角色在该时点**应当知道**的内容（按03§5与02秘密分层）。只有DM知道的事实，一个字都不能进角色本。
- 不得出现真阵营人数、沼泽成员名单、他人的真阵营或秘密（本人已知的除外）。
- 卧底和非卧底的同一册，字数差≤10%（全员同构）。第2册双签规则段落：两名卧底印规则原文；其余六人在同一位置印等长的"党内法律顾问备忘"。

## 篇幅（每人，8人标准版）
- 第1册（开局＋第1期）：6000–8000字；第2、3册各≤3500字；第4册（终局个人本）≤3000字。
- 各角色同册字数差≤20%。

## 角色本结构（Markdown约定，排版程序据此分页）
- 文件开头不写封面（封面由排版程序生成）。
- 每册以一级标题开始，排版时自动分页：`# 第1册 · 新年筹款晚宴（1月19日）` / `# 第2册 · 超级星期二之夜` / `# 第3册 · 同夜党代会` / `# 第4册 · 摇摆之夜（终局个人本）`。
- 第1册必须包含：①"阅读须知"（本册何时读、禁止给别人看）；②你是谁（第二人称"你"，有画面感的人物小传，含命名梗、出生日期、州籍）；③你的过去（个人时间线，只写你知道的）；④你认识的人（对其余7人的看法，只写你所知的表面与私下关系）；⑤你的秘密（按你知道的层级）；⑥你的目标（三星，写清判定标准）；⑦技能卡（照02与F-10原文）；⑧本期3件事卡、打赏小目标、表层秘密提示；⑨演法提示与台词样例（签名台词＋3句）。
- 第2–4册：本期新得知的信息（按03§5）、本期任务与决策提示、本期3件事卡、名场面提示与台词模板。
- 卡片用引用块：首行写 `**【技能卡】名称**`、`**【3件事卡】第1期**` 等，排版会渲染成卡框。
- 可插入 `<div class="pagebreak"></div>` 强制分页。不要用HTML以外的特殊语法。

## 文风
- 简体中文，欢乐、有画面、好读，讽刺对着权力游戏本身。不出现任何真实政治人物姓名，不出现AI模型名。
- 规则性内容用短句、编号；叙事用第二人称。

## 写入方式
- 分段落盘：先 Write 写第一段，之后用 Bash `cat >> 文件 <<'EOF_SEG'` 追加，每次≤4000字。写完一段立刻落盘。
