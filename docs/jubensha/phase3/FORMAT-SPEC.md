# 《摇摆！》剧本杀剧本标准格式规范（最高优先级）

> 出品人指令：现在的文本不像正常的剧本杀剧本。以下是剧本杀行业通行的角色本格式，**8本角色本必须逐字遵守同一套结构、同一套标记**，任何本子不得自创版式。

## 一、整本结构（每个角色本完全相同的骨架）

```
（封面：排版程序生成）

# 剧本须知
（统一的一页，8本一字不差，见第四节模板）

# 角色信息
（统一表格：姓名｜性别｜年龄｜身份｜所属党派（胸牌）｜性格关键词｜外号｜签名台词）
（人物关系简表：你眼中的其余7人——一句话印象，只写你知道的）

# 第一幕 · 新年筹款晚宴
（幕首提示框，见第三节）
## 【我的故事】
## 【全员演绎】序幕 · 《今夜不睡》开播
## 【我的时间线】
## 【本幕情报】（可公开的／必须隐藏的／可以撒谎的）
## 【本幕任务】
（幕尾止读标记，见第三节）

# 第二幕 · 超级星期二之夜
（同上结构；【我的故事】只写两幕之间发生的事与我新得知的事）

# 第三幕 · 同夜党代会
（同上结构）

# 终幕 · 摇摆之夜
（同上结构；【本幕任务】改名【终局任务】）

# 结局（由DM宣布后才可翻开，封口页）
（本角色的个人结局分支，按DM宣读的结局编号阅读）
```

## 二、各区块写法

| 区块 | 写法 | 篇幅 |
|---|---|---|
| 【我的故事】 | 第一人称"我"，场景＋对白，欢乐口吻；**只写过去与幕间发生的事，不写桌上将要发生的反应与结果** | 第一幕 5000–7000 字；其余每幕 1500–2500 字 |
| 【全员演绎】 | 8本里是**同一份台本**（由 `phase3/shared/` 统一提供），排版时自动插入；本人台词自动加粗高亮。角色本里只写一行占位：`<!--演绎:序幕-->` 等 | 每场 5–8 分钟 |
| 【我的时间线】 | 表格：时间｜地点｜我做了什么｜谁能证明／谁看见了。第一幕写人生关键节点＋"第18洞那天""1月19日当晚"；之后每幕写本幕关键时段 | 10–20 行 |
| 【本幕情报】 | 三栏：✅可以公开说的／⛔必须隐藏的（被问到怎么圆）／🎭可以撒谎的方向 | 每栏 3–6 条 |
| 【本幕任务】 | 编号短句，玩家看得懂，不出现任何F编号、规则术语缩写；含"本幕必须找谁聊、问什么、藏什么、拿到什么" | ≤400 字 |

## 三、统一标记（必须原样使用）

**幕首提示框**（每幕第一行）：
```
> **【第X幕 · 标题】** 阅读时长约 N 分钟｜请在DM宣布"开始阅读"后再翻开本幕
```

**幕尾止读标记**（每幕最后一行，原样）：
```
<div class="stop">■ 第X幕 完 ■<br>请停止阅读，合上剧本，等待DM指示</div>
```

**结局封口页**：
```
<div class="stop">■ 以下为结局 ■<br>未经DM宣布，严禁翻阅</div>
```

**全员演绎占位**（排版时替换为共享台本）：
```
<!--演绎:序幕-->   <!--演绎:第二幕-->   <!--演绎:第三幕-->   <!--演绎:终幕-->
```

## 四、《剧本须知》模板（8本一字不差）

1. 本剧本只属于你一个人。游戏全程不得把剧本给任何人看，也不得照着剧本原文念给别人听（演绎台本除外）。
2. 剧本分为四幕和一个结局。**只能阅读DM允许的那一幕**；看到"请停止阅读"标记时必须停下，合上剧本。
3. 【我的故事】是你的记忆，你可以选择说、不说、或者说一部分。【本幕情报】里标为"必须隐藏"的内容，被问到时请用你自己的方式圆过去。
4. 你可以撒谎，但不能修改剧本里写明的事实去欺骗DM。
5. 遇到【全员演绎】时，请等DM带领全员一起朗读，轮到你的台词（加粗部分）时请大声、带感情地演出来。
6. 有任何不清楚的地方，请举手问DM，不要私下翻规则书。

## 五、DM手册对应要求

- DM上册每一幕开头写明：发哪一幕、阅读时长、何时宣布"开始阅读"、何时组织【全员演绎】（DM担任旁白）、何时进入公聊/私聊/搜证/机制环节。
- DM手册收录全部4场演绎台本的完整版（含旁白与舞台提示）。
