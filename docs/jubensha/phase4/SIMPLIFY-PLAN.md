## 一、保留的核心（卖点不动）

1. **8个政客、两个党、三种心**：胸牌（驴友党／大象党）与真阵营（驴心3／象心3／沼泽2）的双层结构。
2. **午夜账本**：每幕结尾放出账本页，当事人当众狡辩，这是全剧固定的高潮节拍。
3. **两名卧底与沼泽上线**：烦高、半步爹为卧底，上线都是沼泽。
4. **大选夜**：先开票定谁当选，再翻心定谁赢。
5. **一个核心悬念**，全程只追这一件事：
   > **"两头吃死在第18洞的那天，到底发生了什么？账本是谁在发？"**
6. 走心点（第9页是写给皮拉提的信）和午夜热线（条件触发平衡小游戏，出品人已定）。

## 三、胜利条件（简化）

| 心 | 胜利条件 |
|---|---|
| 驴心 | 当选总统的心是驴心 |
| 象心 | 当选总统的心是象心 |
| 沼泽 | 游戏结束时，两名沼泽合计持有**当选总统亲笔签的欠条≥3张** |

- 沼泽胜利与两党胜负**互不影响**（可以同时赢）。删除"坐庄""垂帘""惨胜""被套牢"。
- 欠条：每人开局3张空白欠条，写"欠××一次"并签名即生效；可白送、可交易；**兑现方式只有一种**：持有人可在任一次投放时要求立据人按自己指定投放1资金。
- 全员同一套真相题（4问，统一判分，按意思判）：①账本是谁在发 ②第18洞递出卡片的人 ③捡走交权书的人 ④沼泽是谁。答对数换星，替代原来各人不同的真相题。

## 八、文本改写规则

1. 每本 ≤2.2万字：第一幕6000（故事约4500）、第二三幕各3500、终幕2500，其余是角色信息和任务。
2. **故事只写"桌上用得到"的东西**：每一段回忆都要变成一个能问的问题、一个能藏的秘密或一个能交易的筹码；用不上的删。
3. 每幕故事必须带一条指向第18洞的新线索。
4. 禁止复述DM已公开的内容；禁止预写桌上会发生的结果。
5. 演绎台本必须接住刚读完那一幕的情绪和新信息；只演公开信息，不泄露私密任务。
6. 每句梗的笑点不能依赖对美国政治的了解。
