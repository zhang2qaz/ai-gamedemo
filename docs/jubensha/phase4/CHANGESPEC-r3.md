# 《摇摆！》玩家规则书

## 开场节目单

《今夜不睡·大选特别季》，主持人贾不睡（DM）。

第六十一届大选年，现任总统金大嗓两届任满，人人都觉得自己行。一个月前，跨党老说客游游·两头吃在第18洞读一张卡片时倒下了。今年起，每逢政治大日子的午夜，网上会多一页署名“账房”的《账本》，第一页就在今晚；被点名的人得当众狡辩。

**今晚嘉宾**

- 大象党：05麦克播（得克萨斯·播客之王）、06半步爹（宾夕法尼亚·副总统）、07建国钱（内华达·“两边押”的老板）、08狗登罗（佛罗里达·永远站着的律师）

## 片头规则

**怎么赢**：当选总统的心是哪种，哪种心就赢；另外，两名沼泽手里加起来有当选总统亲笔签的欠条≥2张，沼泽也赢。

> 例：大象党的人当选总统，可他的心是驴心，那么驴心赢，胸牌不算数。

**三条铁律**：只在走廊交易（饭点可以聊，不能交易）；能转手的只有资金和欠条；嘴上答应的不算，当面交到手才算，DM不登记。

**技能**：每人1个，用法、次数、费用见角色本「我的底牌」。

**黑料**：片头每人2张，写着别人的丑事，有真有假，只你能看；第二幕扒马褂时用，不能交易。

**收入**：第二幕、第三幕、终局开场，每人领2＋民调的一半（向下取整）资金。

**真相题**（答题卡）：①账本是谁在发 ②第18洞递出卡片的人 ③第18洞捡走那两页纸的人 ④沼泽是谁。第二幕起随时交，只能交一次，最晚在终局第三轮和钱一起装进信封。一题写“A或B”算错；④有几个写几个，写全才对，不算“A或B”；答案是你自己就写自己，照样算分。过关：①必须答对，另外三题再对两题；个别角色更严，见「我的底牌」。

**星星**（最多3颗）：你的心赢了；真相题过关；演出你的名场面（见「我的底牌」；原句一字不差，可以看着念）。

**十个词**
- **胸牌**：公开的党，驴友党或大象党，每党4人。
- **心**：只有你知道的阵营：驴心想让驴心的人当总统，象心想让象心的人当总统，沼泽两党都不帮、只想收当选总统的欠条；心不一定和胸牌一致。
- **资金**：钱，有多少可以保密。
- **民调**：0—10的人气，夹在桌前，人人看得见。
- **欠条**：每人开局3张空白的，签上角色名才算数；谁拿着归谁，能转手、能撕，签名的人不能拒绝、不能收回。终局时，拿着它的人可以要签名的人从自己的钱里拿出1资金，投到指定的州和提名票上，用完撕掉。散场作废。
- **账本页**：每幕午夜放出的一页《账本》，共九页。
- **锤·洗**：账本页点名的人狡辩60秒，其余人闭眼出拳头（锤）或手掌（洗），锤比洗多，他民调−1（民调已是0或在终局，改交1资金）。
- **走廊**：自由私聊、交易的时间。
- **提名票**：第三幕每党选出的“总统候选人＋副手”。
- **摇摆州**：终局要抢的5个州。

## 第一幕规则卡　新年筹款晚宴

**你要做什么**：演广告挣钱，拍遗物拿线索。

**怎么做**
1. 竞选广告：轮流演60秒广告，唱、跳、喊口号都行。八条演完再一起闭眼，DM念到谁，喜欢就竖拇指。
2. 遗产拍卖：DM先念8件遗物的目录，再逐件举起。每人在桌下把钱攥进拳头（不要就攥空拳），DM数三、二、一，同时张开，出得最多的拿走，钱交DM，其余收回。不到起拍价算没出，一件最多出5，同价猜拳。每人最多拍2件。
3. 走廊15分钟。午夜念账本第1、2页，锤或洗。

**结果**
- 广告：0个拇指得0资金，1—2个得1，3—4个得2，5个以上得3。
- 拍卖：线索只有你能看，可以念、可以给人看，不能转手；附带的空白欠条能转手；有的遗物让技能多用1次。没人出价就流拍。

> 例：金笔起拍1。张开拳头，烦高3，建国钱2，其余空拳。烦高交3资金，拿金笔和1张空白欠条，建国钱收回2。

## 第二幕规则卡　超级星期二

**你要做什么**：用黑料扒别人，翻线索，给本党同伴塞钱。

**怎么做**
1. 扒马褂：你有2张写着别人的黑料，有真有假。从01起转两圈，每圈念1张或说“过”。被念到的人马上选：认、辩、喊假。
2. 搜证：民调低的先，每人翻1张线索卡。公开卡当众念；私密卡只有你看，可以撒谎；私密卡的地点或正文写着你的名字、职务或你的州，必须当众念。线索卡能给人看，不能转手。
3. 初选：在纸条上写本党另一个人（不能写自己），信封里至少装1资金，交DM。
4. 走廊10分钟。午夜念账本第3、4页。

**结果**
- 认：民调−1；第一圈认的，再从手里挑1张黑料给念卡的人（不能挑写着他名字的），他第二圈可以念。
- 辩：说30秒，其余人闭眼出拳头（不信）或手掌（信），不信多，你民调−2。
- 喊假：DM查。卡是真的，你民调−2；是假的，念卡的人民调−2。
- 初选：钱归被写的人。每党收到钱最多的人是初选第一名（平局民调高的胜，再平编号小的胜），第三幕提名时最后发言、平票时胜出。

> 例：梅戏写“皮拉提”装3，下木写“皮拉提”装1。皮拉提收到4，是驴友党初选第一名，4资金归她。

## 第三幕规则卡　同夜党代会

**你要做什么**：选出本党的提名票，再接一通热线。

**怎么做**
1. 提名：每党4人各讲30秒，初选第一名最后讲。DM数三、二、一，4人同时指本党一人（可以指自己）。
2. 求婚：被指最多的人从本党另外3人里点一个当副手，说一句求婚词。对方可以拒绝（不上票的人终局能撑场）；第三个被点到的必须答应。
3. 拆信：每人拆一只信封，看60秒，在卡底两个格子里勾一个交回。多数人勾哪个都没有影响；有人的心可能就此改变，改了只有他自己知道。
4. 搜证同第二幕。走廊13分钟。
5. 午夜热线：DM接4通荒诞来电，每通由提名票上一人和对面党不在提名票上的一人各答20秒。
6. 午夜念账本第5、6页。

**结果**
- 提名平票：初选第一名在里面就他胜，否则民调高的胜。两张提名票到终局不再改。
- 热线：每通答完，其余6人闭眼，拳头投提名票上的人，手掌投另一位，多的民调＋1。热线结束，DM背面朝上发给每人一张小卡，只能口说、不能给人看。卡上写着“已到账”的，终局开场DM会私下把钱给你；没写的就没有钱。你什么都不用交。
- 梅戏、狗登罗查到的，是那人此刻的心。

> 例：某党指完，两人各被指2次，其中一人是初选第一名，他当候选人，再向另一人求婚。

## 终局规则卡　摇摆之夜

**你要做什么**：抢摇摆州，让你想要的人当总统。

**怎么做**
1. 辩论：3道题，每题两张提名票各答45秒（两人自己分，每题换先答，到点就停）。不在提名票上的4人同时指赢的那张，多的一方两人民调各＋1，一样多不加。
2. 三轮投钱抢州：第一轮内华达6分，第二轮威斯康星10分、密歇根15分，第三轮佐治亚16分、宾夕法尼亚19分。两党开局各236分，先到270分的当选。每轮按顺序：
   - 走廊3分钟；
   - 第二、三轮，不在提名票上的4人按编号，给开票前落后的那张票各放一块“2”字圆片撑场，州自己选；
   - 拿欠条的人在背面写州和提名票交DM，签名的人当场掏1资金投进去（没钱就下一轮再用）；用掉的撕掉，不再算沼泽的账；
   - 每人往信封里装钱交DM，纸上写清每州给哪张提名票多少，钱和合计一样。
3. 第二轮后念第7、8页。答题卡最晚随第三轮的钱交；收完信封，每人一句话猜两位总统候选人的心（不计分），再念第9页、开票。

**结果**
- 每州钱多的拿下（撑场每块算2，欠条每张算1）；相等时民调和高的拿下，再相等猜拳。
- 当选总统、副总统先翻心，其余人按编号翻；说“沼泽”的两人最后摆出当选总统签的欠条。

> 例：宾夕法尼亚，驴友党那张装钱15；大象党那张装钱14＋欠条1张＝15。相等，大象党民调和12比10高，拿下19分。

### 1.1 一个人就能开
本本单DM即可开，不需要助手。你同时是主持人、管钱的（收入、拍卖款、技能费、补偿都从你手里进出）、计时员、记账员。照下面五条做：
1. **民调你不用记**：民调牌摆在每位玩家桌前，人人看得见，变动时让玩家自己拨。
2. **余额你不用记**：资金是实物筹码，各人自己数。有人问还剩多少：“您数一数，本台不记账。”你只在台账第2栏给半步爹每幕多给的那1资金打勾，防漏发。

4. **欠条你不用登记**：欠条是实物，谁拿着归谁；只有终局有人用欠条、以及翻心时，你才经手实物。
5. **你只记一份台账**（两张A4，见1.5）：闭眼举牌时每个人的选择、私下结果、卧底决定、终局每州的合计，以及你当场判过的口径。

**三句守口令**：私下的话走到他身边低声说，绝不夹在对全桌的话里；当众不说任何人的钱数、技能名（本人当众发动时除外）、剩余次数，看钱只私下看、只答够或不够；宣布口径只说规则，不带人名和技能名。
