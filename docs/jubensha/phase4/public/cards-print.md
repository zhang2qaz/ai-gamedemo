# 《摇摆！》印刷卡面册

> 印厂与DM专用，**不发玩家**。所有文字以 docs/jubensha/phase4/BIBLE.md 为准；本册只收需要印刷的四类卡面：拍品卡、投放单、欠条、真相题答题卡。
> 线索卡、黑料卡、账本页、密件、听众来信等DM物料的正文，见DM手册，不在本册。

## 印制总表

| 物料 | 尺寸 | 正反 | 8人局 | 7人局 | 6人局 | 备注 |
|---|---|---|---|---|---|---|
| 拍品卡 | 90×130mm | 双面 | 8 | 8 | 6（删拍品5、7） | 正面拍卖时出示，背面只给得主看 |
| 投放单 | 90×130mm | 单面 | 每人每轮1张，共24 | 21 | 18 | 三轮三种版式，另备每种4张 |
| 投放信封 | 110×160mm | — | 24 | 21 | 18 | 不透光，封口不需胶 |
| 欠条 | 63×88mm（扑克牌） | 双面 | 27（开局24＋拍品3） | 24 | 20（开局18＋拍品4的2张） | 另备6张 |
| 真相题答题卡 | 90×130mm | 单面 | 8 | 7 | 6 | 另备2张 |

## 一、拍品卡（8张）

**正面统一版式**（拍卖时DM举起出示）：
```
┌──────────────────────────┐
│  两头吃遗物 · 拍品〔编号〕    │
│                          │
│       〔拍品名〕            │
│                          │
│  得到：〔类别〕              │
│  起拍：〔起拍价〕资金          │
│  每次至少加1 · 10秒无人加价成交 │
└──────────────────────────┘
```

**背面**（成交后交给得主；线索类只给得主看，可口述或出示，不能转手）：

| 编号 | 正面：拍品名／得到／起拍 | 背面正文 |
|---|---|---|
| 拍品1 | 第18洞记分卡／线索／2 | 第18洞记分卡。最后一组四人：两头吃、下木、建国钱、半步爹。<br>（卡背角落小字）按本会惯例，同组最年轻者扶旗杆。 |
| 拍品2 | 回忆录手稿第12章／线索／2 | "我雇人从不用自己的名字。我的司机、厨子、园丁，都挂在我的管家公司绿茵名下。" |
| 拍品3 | 老G的谢礼卡／线索／2 | "谢谢三小时陪我聊中道。我停下的那天，闹钟会替我把话说完。——G" |
| 拍品4 | 雪茄盒／2张空白欠条／2 | 得主当场领取2张空白欠条（随卡发放）。 |
| 拍品5 | 金笔／1张空白欠条／1 | 得主当场领取1张空白欠条（随卡发放）。 |
| 拍品6 | 老座钟／技能多用1次／3 | 你的技能可以多用1次。（半步爹：任选一幕，技能多用1次。） |

## 二、投放单样张（三轮三种版式）

版式统一，只改轮次与州名。填写后连同等额资金封进投放信封交DM。

**第一轮**
```
┌────────────────────────────────┐
│  摇摆之夜 · 投放单 · 第一轮              │
│  投放人：＿＿＿＿＿＿                    │
│                                │
│  州            驴友票    大象票         │
│  内华达（6）    ＿＿      ＿＿           │
│                                │
│  合计＿＿资金 ＝ 信封内资金               │
│  可以投0 · 可以投给任何一张提名票          │
└────────────────────────────────┘
```

**第二轮**：州栏改为两行——威斯康星（10）、密歇根（15）。

**第三轮**：州栏改为两行——佐治亚（16）、宾夕法尼亚（19）；底部加印一行粗体：
"**真相题答题卡还没交的，现在一起封进信封。**"

DM计算栏（印在投放单背面，DM用）：
```
州＿＿＿＿   驴友票：暗投＿＋兑现＿＋站台＿×2＋民调加成＿＝＿＿
             大象票：暗投＿＋兑现＿＋站台＿×2＋民调加成＿＝＿＿
```

## 三、欠条样式

**正面**（签名即生效）：
```
┌─────────────────────┐
│        欠  条           │
│                     │
│  欠 ＿＿＿＿＿＿ 一次     │
│                     │
│  立据人签名：＿＿＿＿＿＿   │
│                     │
│  谁拿着，就归谁。          │
└─────────────────────┘
```

**背面**（兑现时由持有人填写，交DM）：
```
┌─────────────────────┐
│  兑  现                │
│                     │
│  州：＿＿＿＿＿＿          │
│  投给：□驴友票  □大象票    │
│                     │
│  立据人当场交DM 1资金，     │
│  由DM替他投入。           │
│  兑现后由DM撕掉。          │
└─────────────────────┘
```

印制要求：纸张选可签字的哑光卡纸；正面底纹为淡绿色票据纹，四角编号不印（防止识别来源）。拍品4、5所附欠条与开局欠条完全相同。
