## 二、装钱单样张（三轮三种版式）

版式统一，只改轮次与州名。填写后连同等额资金封进装钱信封交DM。

**第一轮**
```
┌────────────────────────────────┐
│  摇摆之夜 · 第一轮 · 我往信封里装了多少      │
│  我是：＿＿＿＿＿＿                      │
│                                │
│  州          驴友党提名票  大象党提名票   │
│  内华达（6分）    ＿＿        ＿＿         │
```

**第二轮**：标题改"第二轮"，州栏改为两行——威斯康星（10分）、密歇根（15分）。

**第三轮**：标题改"第三轮"，州栏改为两行——佐治亚（16分）、宾夕法尼亚（19分）；底部加印一行粗体：

## 三、欠条样式

**正面**（签名即生效）：
```
┌─────────────────────┐
│        欠  条           │
│                     │
│  欠 ＿＿＿＿＿＿ 一次     │
│                     │
│  签名：＿＿＿＿＿＿＿＿     │
│                     │
│  谁拿着，就归谁。          │
└─────────────────────┘
```

**背面**（终局使用时由持有人填写，交DM）：
```
┌─────────────────────┐
│  请签名的人投1资金        │
│                     │
│  州：＿＿＿＿＿＿          │
│  投给：□驴友党提名票      │
│        □大象党提名票      │
│                     │
│  签名的人从自己的钱里     │
│  当场掏1资金给DM投进去；   │
│  他没钱，本条还给持有人，   │
│  下一轮再用。             │
│  用完撕掉，不再算沼泽的账。  │
└─────────────────────┘
```

印制要求：纸张选可签字的哑光卡纸；正面底纹为淡绿色票据纹，四角编号不印（防止识别来源）。拍品4、5所附欠条与开局欠条完全相同。
