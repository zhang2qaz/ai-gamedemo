# 《摇摆！》玩家规则书

## 开场节目单

《今夜不睡·大选特别季》，主持人贾不睡（DM）。

第六十一届大选年，现任总统金大嗓两届任满，人人都觉得自己行。一个月前，跨党老说客游游·两头吃在第18洞读一张卡片时倒下了。从那天起，每逢政治大日子的午夜，网上就多一页署名"账房"的《账本》，被点名的人得当众狡辩。

**今晚嘉宾**
- 驴友党：01皮拉提（纽约·炒菜骂人的网红议员）、02烦高（加利福尼亚·发型不乱的州长）、03下木（俄亥俄·端保温杯的党鞭）、04梅戏（伊利诺伊·"下次告诉你"的通讯总监）
- 大象党：05麦克播（得克萨斯·播客之王）、06半步爹（宾夕法尼亚·副总统）、07建国钱（内华达·"两边押"的老板）、08狗登罗（佛罗里达·永远站着的律师）

**今晚节目**（约6小时）：片头 → 第一幕 新年筹款晚宴 → 第二幕 超级星期二 → 饭点30分钟 → 第三幕 同夜党代会 → 终局 摇摆之夜 → 复盘。全程无人出局。

今晚只追一件事：**两头吃死在第18洞的那天，到底发生了什么？账本是谁在发？**

## 片头规则

**怎么赢**：当选总统的心是哪种，哪种心就赢；另外，两名沼泽手里加起来有当选总统亲笔签的欠条≥3张，沼泽也赢。

> 例：大象党的人当选总统，可他的心是驴心，那么驴心赢，胸牌不算数。

**三条铁律**：只在走廊交易（饭点可以聊，不能交易）；能转手的只有资金和欠条；嘴上答应的不算。

**技能**：每人1个，写在角色本里；没写次数的，全场1次。

**收入**：第二幕、第三幕、终局开场，每人领2＋民调的一半（向下取整）资金。

**真相题**：①账本是谁在发 ②第18洞递出卡片的人 ③第18洞捡走那两页纸的人 ④沼泽是谁。第二幕起随时交，只能交一次，最晚在终局第三轮和钱一起装进信封。一题写"A或B"算错。过关：①必须答对，另外三题再对两题；个别角色更严，以角色本为准。

**星星**（最多3颗）：你的心赢了；真相题过关（门槛见角色本）；演出你的名场面。

**十个词**
- **胸牌**：公开的党，驴友党或大象党，每党4人。
- **心**：只有你知道的阵营：驴心想让驴心的人当总统，象心想让象心的人当总统，沼泽两党都不帮、只想收当选总统的欠条；心不一定和胸牌一致。
- **资金**：钱，有多少可以保密。
- **民调**：0—10的人气，夹在桌前，人人看得见。
- **欠条**：写上"欠××一次"并签名的卡，每人开局3张空白的；终局时，拿着它的人可以要签名的人从自己的钱里拿出1资金，投到指定的州和提名票上，用完撕掉。
- **账本页**：每幕午夜放出的一页《账本》，共九页。
- **锤·洗**：账本页点名的人狡辩60秒，其余人闭眼出拳头（锤）或手掌（洗），锤过半，他民调−1。
- **走廊**：自由私聊、交易的时间。
- **提名票**：第三幕每党选出的"总统候选人＋副手"。
- **摇摆州**：终局要抢的5个州。

## 第一幕规则卡　新年筹款晚宴

**你要做什么**：演广告挣钱，拍遗物拿线索。

**怎么做**
1. 竞选广告：轮流演60秒广告，唱、跳、喊口号都行。其余人闭眼，喜欢就竖拇指。
2. 遗产拍卖：DM逐件举起8件遗物，从起拍价开始，谁都能喊价，每次至少加1；10秒没人加就成交，钱交给DM。每人最多拍2件。
3. 走廊15分钟。午夜念账本第1、2页，锤或洗。

**结果**
- 广告：0个拇指得0资金，1—2个得1，3—4个得2，5个以上得3。
- 拍卖：拍到线索的，只有你能看，可以念、可以给人看，不能转手；有的遗物是空白欠条，有的让你的技能多用1次。没人出起拍价就跳过。

> 例：金笔起拍1。烦高喊1，建国钱喊2，烦高喊3，10秒没人加。烦高交3资金，多拿1张空白欠条。

## 第二幕规则卡　超级星期二

**你要做什么**：用黑料扒别人，翻线索，给本党同伴塞钱。

**怎么做**
1. 扒马褂：你有2张写着别人的黑料，有真有假。从01起转两圈，每圈念1张或说"过"。被念到的人选：认、辩、喊假。
2. 搜证：民调低的先，每人翻1张线索卡。公开卡当众念；私密卡只有你看，可以撒谎；私密卡上写着你的名字，必须当众念。线索卡能给人看，不能转手。
3. 初选：在纸条上写本党另一个人（不能写自己），信封里装任意资金（可以是0），交DM。
4. 走廊10分钟。午夜念账本第3、4页。

**结果**
- 认：民调−1，再从手里挑1张黑料给念卡的人（不能挑写着他名字的），他第二圈可以念。
- 辩：说30秒，其余人闭眼出拳头（不信）或手掌（信），不信多，你民调−2。
- 喊假：DM查。卡是真的，你民调−2；是假的，念卡的人民调−2。
- 初选：钱归被写的人。每党收到钱最多的人是初选第一名（平局民调高的胜，再平编号小的胜），第三幕提名时最后发言、平票时胜出。

> 例：梅戏写"皮拉提"装3，下木写"皮拉提"装1。皮拉提收到4，是驴友党初选第一名，4资金归她。

## 第三幕规则卡　同夜党代会

**你要做什么**：选出本党的提名票，再接一通热线。

**怎么做**
1. 提名：每党4人各讲30秒，初选第一名最后讲。DM数三、二、一，4人同时指本党一人（可以指自己）。
2. 求婚：被指最多的人从本党另外3人里点一个当副手，说一句求婚词。对方可以拒绝；第三个被点到的必须答应。
3. 拆信：每人拆一只信封，看60秒，在卡底两个格子里勾一个交回。多数人勾哪个都没有影响；有一两个人的心可能就此改变，改了只有他自己知道。
4. 搜证同第二幕。走廊13分钟。
5. 午夜热线：DM接4通荒诞来电，每通由提名票上一人和不在提名票上的一人各答20秒。
6. 午夜念账本第5、6页。

**结果**
- 提名平票：初选第一名在里面就他胜，否则民调高的胜。两张提名票到终局不再改。
- 热线：其余6人同时指答得好的那位，多数的民调＋1。热线结束，DM背面朝上发给每人一张小卡，只能口说、不能给人看。卡上写着给你钱的，终局开场DM会私下把钱给你；你什么都不用交，也不用做。
- 梅戏、狗登罗查到的，是那人此刻的心。

> 例：大象党指完，麦克播、半步爹各被指2次，半步爹是初选第一名，他当候选人，再向麦克播求婚。

## 终局规则卡　摇摆之夜

**你要做什么**：抢摇摆州，让你想要的人当总统。

**怎么做**
1. 辩论：3道题，两张提名票各答45秒。不在提名票上的4人同时指向赢的那张提名票，多的一方两人民调各＋1，2比2都不加。
2. 三轮投钱抢州，每个州有分数：第一轮内华达6分，第二轮威斯康星10分、密歇根15分，第三轮佐治亚16分、宾夕法尼亚19分。两党开局各有236分，先到270分的那张提名票当选。每轮：
   - 走廊3分钟；
   - 不在提名票上的4人，各在本轮一个州的一张提名票上放一块写着"2"的圆片撑场，算2资金；
   - 拿欠条的人在背面写州和提名票交DM，签名的人当场掏1资金给DM投进去；他身上没钱，欠条还给你，下一轮再用。用掉的欠条撕掉，不再算沼泽的账；
   - 每人往信封里装钱交DM，在DM发的纸上写清每个州给哪张提名票多少，信封里的钱要和纸上的合计一样。
3. 第二轮后念账本第7、8页；第三轮收完信封念第9页，再开票。

**结果**
- 每个州，谁投的钱多谁拿下这个州的分（撑场每块算2资金，欠条每张算1）；相等时两人民调加起来高的提名票拿下，再相等猜拳。
- 当选总统和副总统先翻心，再全员翻心。

> 例：宾夕法尼亚，驴友党提名票＝装钱13＋撑场1块＝15；大象党提名票＝装钱12＋欠条1张＋撑场1块＝15。相等，大象党民调12比10高，拿下19分。
