# 《摇摆！》玩家规则书

## 开场节目单

> 《今夜不睡·大选特别季》　主持人：贾不睡（DM）

晚上好，不睡的观众们！第六十一届大选年开锣，现任总统金大嗓两届任满，人人都觉得自己行。今晚来了8位政客：胸牌两个党，心思三种，总统只有一个。

还有件小事：一个月前，跨党老说客游游·两头吃在第18洞读一张卡片时倒下了。从那天起，每逢政治大日子的午夜，网上就多一页他的《账本》。被点名的人，得当众狡辩。

**今晚嘉宾**
- 驴友党：01皮拉提（边炒菜边骂人的网红议员）、02烦高（发型二十年没乱的州长）、03下木（端保温杯的党鞭）、04梅戏（永远"下次告诉你"的通讯总监）
- 大象党：05麦克播（一开口三小时的播客之王）、06半步爹（永远在总统身后半步的副总统）、07建国钱（外号"两边押"的老板）、08狗登罗（永远站着的选举律师）

**今晚节目**（约6小时）
1. 片头：发本，讲一页规则
2. 第一幕 新年筹款晚宴：演广告、拍遗物
3. 第二幕 超级星期二：扒马褂、搜证、初选
4. 饭点30分钟：可以聊，不能交易
5. 第三幕 同夜党代会：选提名票、接热线
6. 终局 摇摆之夜：辩论、三轮投放、开票、翻心
7. 复盘：真相、结局、评星

全程无人出局。每人1个技能、1页账本、1个名场面。今晚只追一件事：**两头吃死在第18洞的那天，到底发生了什么？账本是谁在发？**

## 片头规则（一页）

### 你的心写在你的角色本里
胸牌公开，决定你属于哪个党、能上哪张提名票。心保密，决定你怎么赢。胸牌和心不一定一致；每种心各有几人，不公开。

| 心 | 怎么赢 |
|---|---|
| 驴心 | 当选总统的心是驴心 |
| 象心 | 当选总统的心是象心 |
| 沼泽 | 游戏结束时，沼泽合计持有当选总统亲笔签、未兑现的欠条≥3张 |

- 沼泽和两党可以同时赢。
- 当选总统本人若是沼泽：驴心、象心改看副总统的心；沼泽这局赢不了（自己签的欠条不算）。

### 三种资源
- **资金**：筹码。开局数额见角色本。第二幕、第三幕、终局开场各领一次收入：2＋民调÷2（向下取整）。身上有多少钱可以保密。
- **民调**：0—10，摆在桌前。账本页、扒马褂、热线、辩论会改变它。它决定收入，终局还给你的提名票加成。
- **欠条**：实物卡，见下。

### 欠条
- 每人开局3张空白欠条。写上"欠××一次"并签上自己的角色名即生效，签名的人叫立据人。
- 可白送、可交易、可转手，谁拿着归谁。
- **只有一种兑现**：终局任一轮投放时，持有人把欠条交DM，背面写明"哪个州、投给哪张提名票"；立据人当场交DM 1资金，DM替他投进去。兑现后欠条撕掉。立据人身上没钱，本轮兑现不了，欠条退回。

### 交易三条铁律
1. 只在走廊里交易。饭点可以聊，不能交易。
2. 能转手的只有资金和欠条。民调、线索卡、黑料、技能都不能转手。
3. 规则只认欠条：嘴上答应的，不算数。

### 技能
每人1个，全场限用1次，用法见角色本。

### 十个词
| 词 | 意思 |
|---|---|
| 胸牌 | 公开的党籍：驴友党或大象党，每党4人 |
| 心 | 保密的阵营：驴心、象心、沼泽 |
| 资金 | 筹码 |
| 民调 | 0—10的人气 |
| 欠条 | 签了名的"欠你一次" |
| 账本页 | 每幕结尾午夜放出的《账本》，共九页；第1—8页各点名一人 |
| 锤·洗 | 账本页审判：被点名者狡辩60秒，其余人闭眼举牌，拳头＝锤，手掌＝洗，DM只报票数。锤过半，民调−1；平票按洗 |
| 走廊 | 私聊时段，交易只在这里 |
| 提名票 | 第三幕选出的"总统候选人＋副手"，每党一张 |
| 摇摆州 | 终局要抢的5个州 |

## 第一幕规则卡　新年筹款晚宴（75分钟）

**流程**：阅读18分钟 → 演绎6 → 竞选广告15 → 遗产拍卖12 → 走廊12 → 午夜：账本第1、2页

### 60秒竞选广告
- **你能做**：轮到你时，演一条60秒的竞选广告，唱、跳、喊口号都行。
- **怎么做**：你演完，其余人闭眼，喜欢就竖大拇指。
- **结果**：DM数拇指，从银行发资金：0个得0，1—2个得1，3—4个得2，5个以上得3。

### 遗产拍卖
遗嘱写明：晚宴照办，遗物照拍。8件全部明拍，一轮拍完。

| 拍品 | 你会得到 | 起拍 |
|---|---|---|
| 1 第18洞记分卡 | 线索 | 2 |
| 2 回忆录手稿第12章 | 线索 | 2 |
| 3 老G的谢礼卡 | 线索 | 2 |
| 4 雪茄盒 | 2张空白欠条 | 2 |
| 5 金笔 | 1张空白欠条 | 1 |
| 6 老座钟 | 你的技能多用1次 | 3 |
| 7 旧推杆 | 你的技能多用1次 | 3 |
| 8 最后一条短信 | 线索 | 2 |

- **怎么做**：DM按编号逐件出示。从起拍价开始，谁都能随时喊价，每次至少加1。10秒没人加价就成交，钱交银行。
- 没人出起拍价就流拍，不再回拍。每人最多拍到2件。
- **结果**：线索拍品只给得主看，得主可以口述或出示，但不能转手。欠条拍品就是多几张你能签的空白欠条。

### 走廊（12分钟）
随便找人聊，资金和欠条在这里交易。

### 午夜
DM念账本第1、2页，各审一人：狡辩60秒，其余人锤或洗。

> **小例子**：金笔起拍1。烦高喊1，建国钱喊2，烦高喊3，10秒没人吭声。烦高交3资金给银行，多了1张空白欠条——签给谁、换什么，他说了算。

## 第二幕规则卡　超级星期二（75分钟）

**流程**：领收入 → 阅读12 → 演绎6 → 扒马褂20 → 搜证10 → 初选8 → 走廊10 → 午夜：账本第3、4页

从本幕起，可以随时交真相题卡（见终局规则卡）。

### 扒马褂
- 开局每人2张黑料，都写着别人的名字。有些黑料是伪造的：你不知道手里那张的真假，当事人自己有数。
- **怎么做**：从DM左手边起轮流，转两圈；每圈打1张（念出卡面）或说"过"。
- **当事人三选一**：
  - **认**：民调−1，并从自己手里赔1张黑料给爆料人（没有就不赔）。
  - **辩**：辩解30秒，其余人（含爆料人）闭眼举牌，拳头＝不信，手掌＝信，DM只报票数。不信多于信，当事人民调−2；否则无事。
  - **喊假**：DM当众查真假。卡是假的，爆料人民调−2；卡是真的，当事人民调−2。
- 赔来的黑料可以在第二圈打。结束后，没打的黑料交回DM。

### 搜证
- 8张线索卡背面朝上，摆在8个地点牌上。按民调从低到高（同分时编号小的先），每人选1个地点、翻1张。
- **公开卡**：当众照念。**私密卡**：只有你看，可以转述，也可以撒谎。
- 私密卡的地点或正文写着你自己的名字时，必须当众照念。
- 线索卡可以出示，不能转手。

### 初选
- 每人1只信封、1张选票。选票写本党另一人的名字（不能写自己），信封里装任意资金（可以是0），封好交DM。
- DM按党开封，当众报每人收到多少，钱归被写的人。
- 每党收到最多的人＝临时领跑者。平局比民调，再平编号小的胜。
- 领跑者只有一个好处：第三幕提名时最后发言，平票时胜出。

> **小例子**：梅戏写"皮拉提"塞3资金，下木写"皮拉提"塞1，皮拉提写"梅戏"塞0。DM报：皮拉提收到4，全党最多，成为驴友党领跑者，4资金归她。

## 第三幕规则卡　同夜党代会（70分钟）

**流程**：领收入 → 阅读12 → 演绎6 → 提名与搭档15 → 党代会密件5 → 搜证8 → 走廊10 → 午夜热线5 → 午夜：账本第5、6页

### 提名与搭档
1. **演讲**：每党4人各说30秒"我为什么该上提名票"，领跑者最后。
2. **投票**：DM数"三、二、一"，本党4人同时指向本党一人（可以指自己）。
3. **结果**：得票最多的是本党总统候选人。平票时，领跑者在其中就领跑者胜；否则民调高的胜；再平编号小的胜。
4. **求婚**：总统候选人从本党另外3人里点一人当副手，当众说一句求婚词。对方可以拒绝，再点下一人；第三个被点到的必须答应。
5. 两组"总统候选人＋副手"就是两张提名票，到终局不再改。另外4人是票外玩家，终局每轮各放1枚站台。

### 党代会密件
- 全员同时拆一只同款信封，读60秒，在卡底勾选，折好交回DM。每个人动作完全一样。
- 信里写了什么、你勾了什么，只有你知道。密件可能改变某些人的心；凡是查心的技能，查的都是"当下的心"。

### 搜证
同第二幕，换一批新的8张。

### 午夜热线
- DM接4通荒诞来电。每通由1名提名票成员和1名票外玩家作答，各用角色口吻即兴20秒；配对抽签，每人恰好答一次。
- 其余6人举手选更好的回答，多数者民调＋1；平票都不加。
- 热线结束，每人收到一封"听众来信"。来信只能口述，不能出示；信里说的事，DM在终局开场兑现。

> **小例子**：来电："我家猫在你们辩论时睡着了，这算不算选民意愿？"麦克播和烦高各答20秒，6人举手，4人选烦高，烦高民调＋1。

## 终局规则卡　摇摆之夜（60分钟）

**流程**：领收入 → 阅读8 → 演绎5 → 总统辩论10 → 第一轮 → 第二轮 → 账本第7、8页 → 第三轮 → 账本第9页 → 开票 → 翻心

### 州表
| 地盘 | 选举人票 | 开州 |
|---|---|---|
| 驴友党基本盘 | 236 | — |
| 大象党基本盘 | 236 | — |
| 内华达 | 6 | 第一轮 |
| 威斯康星、密歇根 | 10、15 | 第二轮 |
| 佐治亚、宾夕法尼亚 | 16、19 | 第三轮 |

合计538，270当选，即先在摇摆州拿到34票。拿下一州＝拿走它全部的票。不会平票，第三轮前不会定局。

### 总统辩论
DM念3道题，每题两张提名票各答45秒，驴友票先答，下一题换先手。票外4人同时举手选胜方，胜方两人各民调＋1；2:2都不加。

### 每轮五步
1. **走廊3分钟**：私聊、交易。
2. **站台**：票外4人按编号，各把1枚站台当众放到本轮一个州的一张提名票上。
3. **兑现欠条**：见片头规则。
4. **暗投**：全员在投放单上写"本轮每个州：给驴友票几、给大象票几"，把等额资金封进投放信封交DM。可投0，可投任一张票。
5. **开州**：DM报每州两张票的票力和胜负，不报谁投了多少。

### 票力
**票力＝暗投资金＋兑现资金＋站台×2＋民调加成**
- 民调加成：开每州时，比两张提名票的民调和（总统候选人＋副手），高的一方该州＋2；相等不加。
- 票力相同：两位总统候选人猜拳一次定胜负。

### 真相题
①账本是谁在发　②第18洞递出卡片的人　③捡走交权书的人　④沼泽是谁
- 每人1张答题卡，第二幕起随时可交，只能交一次；最晚在第三轮暗投时封进投放信封。
- 按意思判，错字不扣分；一题写两个答案算错。第9页在截止后才念。

### 开票与翻心
DM宣布当选的正、副总统 → 两人翻心，判驴心、象心 → 清点沼泽手里的总统欠条 → 公布真相题 → 评星。

**星级**（每人最多3颗）：你的心赢了（以翻心时为准）／真相题过关（门槛见角色本）／完成角色本里的名场面（DM判定）。

> **小例子**：宾夕法尼亚，驴友票＝暗投13＋站台2＝15；大象票＝暗投11＋兑现1＋站台2＋民调加成2＝16，大象票拿走19票。
