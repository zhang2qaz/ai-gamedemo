## 一、开本前

### 1.1 一个人就能开
本本单DM即可开，不需要任何助手。你同时是主持人、银行、计时员、记账员。为了忙得过来，记住四件事：
1. **民调你不用记**：民调牌摆在每位玩家桌前，人人看得见，变动时让玩家自己拨。
2. **资金你不用记**：每人身上多少钱对别人保密，你也不必知道；终局他们自己把钱封进信封。
3. **欠条你不用登记**：欠条是实物，谁拿着归谁；只有终局有人用欠条、以及翻心时，你才经手实物。
4. **你只记一张台账**（见1.5）：闭眼举牌时每个人的选择、私下结果、卧底决定、终局每州的算钱。

玩家读本的时间就是你的准备时间：照下一张流程卡把物料摆好。

### 1.5 DM台账（开本前抄在一张A4上）
1. **闭眼举牌记录**：一行一次（第1—8页的锤／洗；扒马褂里每一次"辩"的信／不信），八列是01—08，每格记"锤／洗"或"信／不信"，最后一格记结果。下木的技能会来问这里。
2. **技能**：八行，记每人用了几次、何时、结果。拍品6、7的得主在这里标"多1次"。
3. **名场面**：八行，判定完成就打勾（判定口径见5.9）。
4. **卧底**：烦高　坚守／倒戈；半步爹　坚守／倒戈 → 算出现在驴心几人、象心几人。
5. **关键结果**：两党初选第一名；两张提名票（总统＋副手）；热线判定（H1／H2／H3）。
6. **终局算钱表**：五个州各两行（驴友票／大象票），三格：信封里的钱、欠条（每张1）、撑场（每枚2），加总；另记开票那一刻两张票的民调和，钱相等时用。
7. **真相题**：八行，①②③④对错，是否得星。

## 三、片头与四幕

### 3.0 片头（10分钟）

**第1步　开播（1分钟）**
> 晚上好，欢迎收看《今夜不睡·大选特别季》！我是贾不睡。第六十一届大选年，现任总统金大嗓两届任满，人人都觉得自己行。今晚8位政客：胸牌两个党，心思三种，总统只有一个。今晚只追一件事：两头吃死在第18洞的那天，到底发生了什么？账本是谁在发？

**第2步　发本（2分钟）**
按1.3"片头"一行发。说："第一幕册先别翻开。"

**第3步　讲规则（5分钟）**　让大家翻到规则书「片头规则」，你照念：
> 第一，**胸牌**公开，就是你别在胸前的党：驴友党或大象党，每党4人，决定你能上哪张提名票。**心**保密，写在你的角色本里：驴心、象心或沼泽。胸牌和心不一定一致；每种心有几个人，不公开。
> 第二，怎么赢，就一句话：当选总统的心是哪种，哪种心就赢；另外，沼泽手里有当选总统亲笔签的欠条3张以上，沼泽也赢。
> 第三，只有三种东西：**资金**是筹码，身上多少可以保密；**民调**0到10，摆在桌前，决定你每幕领多少收入；**欠条**，每人3张，写上"欠谁一次"、签上你的角色名就生效，谁拿着归谁。欠条只有一个用处：终局拿着它，可以让签名的人替你投1资金。
> 第四，交易三条铁律：只在走廊里交易；能转手的只有资金和欠条；嘴上答应的不算数，只认欠条。
> 第五，每人1个技能，次数和用法见角色本；没写次数的，全场限用1次。
> 最后，全程无人出局。每人1个技能、1页账本、1个名场面。

**第4步　答疑（2分钟）**　只答规则，不答剧情。然后：
> 请翻开第一幕册。12分钟，读到"演绎"提示就停。

常见问题：
- **"我能告诉别人我的心吗？"**——能说，也能说谎。嘴上说的都不算证据。
- **"角色本能给别人看吗？"**——不能，只能口述。线索卡和拍品卡可以出示。
- **"各种心各几个人？"**——不公开，这就是游戏。

### 3.1 第一幕　新年筹款晚宴（72分钟）

**流程卡**

| 项 | 内容 |
|---|---|
| 发哪一幕 | 第一幕册（片头已发） |
| 阅读 | 12分钟 |
| 何时演绎 | 读完立即演，序幕，6分钟 |
| 主机制 | 遗产拍卖，12分钟 |
| 小游戏 | 60秒竞选广告＋打赏，15分钟（在拍卖之前） |
| 走廊 | 15分钟 |
| 账本审判 | 午夜：第1页皮拉提、第2页麦克播，12分钟 |
| 收尾 | 休息10分钟 |

**第1步　阅读（12分钟）**
- 有人举手，你走过去轻声答，只答规则。
- 你趁机核对：拍品卡按1—8叠好，空白欠条3张备好；台账抄好。
- 第10分钟提醒："还有两分钟。"

**第2步　演绎（6分钟）**　发序幕台本，每人演自己的角色，你演贾不睡和旁白。演完收回台本。

台本：shared/prologue.md。发8份给玩家，你拿另备的那份念贾不睡和旁白；演完连同你那份一起收好。

**第3步　60秒竞选广告＋打赏（15分钟）**
> 每位嘉宾给自己打一条60秒竞选广告，唱、跳、喊口号都行。演完，其余人闭眼，喜欢就竖大拇指。拇指越多，筹得越多。从01皮拉提开始。

- **玩家做**：按编号01→08轮流演，60秒到你喊停。
- **你结算**：每条演完说"请闭眼"，数其余7人的拇指，说"请睁眼"，当众只报"得几资金"：0个得0，1—2个得1，3—4个得2，5个以上得3，从银行发。台账不用记拇指。
- **常见问题**：
  - 演的人自己不竖。每人对每条广告最多竖一次。
  - 可以短于60秒，不能超。
  - 半步爹在本幕任何一次发钱时都可以说"跟"（见1.6）。

**第4步　遗产拍卖（12分钟）**
> 遗嘱写明：晚宴照办，遗物照拍。8件全部明拍，一轮拍完。我举一件，从起拍价开始，谁都能随时喊价，每次至少加1。我数10秒没人加价就成交，钱当场交银行。没人出起拍价就流拍，不再回拍。每人最多拍到2件。

- **你做**：按编号举起拍品卡正面，念"拍品×，××，得到××，起拍×"。有人喊价就复述最高价，静下来后数"十、九……一，成交"。
- **结算**：得主当场交钱；你把拍品卡交给他（线索类只给他看，背面正文见5.4）；拍品4附2张、拍品5附1张空白欠条；拍品6、7的得主在台账"技能"栏标"多1次"。
- **常见问题**：
  - **同时喊同一个价**：你先听到的人算；分不清就让两人猜拳。
  - **成交了付不出钱**：这件改由出价第二高的人按他的最后出价成交；没有第二人就流拍。以后此人喊价前，你可以要他先亮钱。
  - **拍到的线索能给别人看吗**：能出示、能口述，不能转手。

**第5步　走廊（15分钟）**
> 走廊开放15分钟。随便找人聊，资金和欠条只在这里交易。有当众技能要发动的，现在举手。

- 先处理举手的当众技能，再开始计时。你坐在桌前等人来办私下技能（开盒、党鞭点票）。
- 结束前2分钟喊："还有两分钟。"时间到："走廊关闭，请回座。"走廊外的交易无效，你看到就让双方退回。

**第6步　午夜：账本第1、2页（12分钟）**
这是全剧固定的高潮节拍。**统一审判流程只写在这里**，第二幕、第三幕、终局的午夜都照此执行：
1. 灯光调暗。你念页眉"账本·第N页（共九页）"和正文（正文见5.3）。
2. 当事人起立狡辩60秒，你计时。可以沉默，60秒照计。
3. > 请其余各位闭眼，举手：拳头是锤，手掌是洗。三、二、一。
   你逐人记进台账第1栏，然后："请放下，睁眼。"
4. 当众只报票数，例如"四锤三洗"，**不报名单**。

- 签名的人说身上没钱：他私下把钱袋给你看，确实没有，这张欠条退回持有人，下轮再说。
- 一个人一轮可以用多张。用掉的欠条不再计入沼泽胜利。

每一轮你做：
1. 发本轮投放单和信封，计时走廊3分钟。
2. 撑场：按编号叫不在提名票上的人，各自当众把撑场筹码放上州板。
3. 欠条：问"有用欠条的吗？"逐张处理。
4. 收钱：收齐8只信封。拆信封，数钱，对单子，填台账第6栏。
5. 开票，照念格式：

## 六、裁决原则与FAQ

### 6.1 裁决原则
1. 规则卡与本手册冲突，以本手册为准；都没写的，按"对谁都一样、最快能继续"判，判完当众说一遍，此后全场照此。
2. 一切闭眼举牌只报票数，不报名单。
3. 只认实物：嘴上答应不算；走廊外的交易无效，退回。
4. 不公开任何人的心、资金、技能剩余次数和私下结果。
5. 不解释账本，不答剧情，不暗示真相；名场面复盘才公布。
6. 角色本、来信只能口述；线索卡、拍品卡可以出示。能转手的只有资金和欠条。
7. 发现漏拨民调、发错钱，当场更正；已结束的环节不翻案。
8. 时间优先：超时按第二节的顺序砍。

### 6.2 FAQ
1. **欠条"欠××"一栏空着算吗？**签了名就生效，空栏持有人可自己补填。没签名的是空白欠条，不算数。
2. **空白欠条能送人吗？**能。收到的人签上自己的名，签名的人就是他。
3. **当选之前签的欠条算收账吗？**算，只看签名的人最后是不是当选总统。
4. **用欠条时，签名的人能拒绝替人投吗？**不能。
5. **能在饭点谈好、走廊再交割吗？**能。谈不禁止，交割只在走廊。
6. **发胶能先声明"要是被锤就用"吗？**不能，下降宣布时当场说。
7. **半步爹跟领，一次收入发8个人算几次？**他只跟一次，领1资金，本幕次数就用掉了。
8. **终极特稿、背调能查同一人两次吗？**能，每次各算一次。
9. **三小时连麦能问什么？**只问已经发生的事，是非题。不能问心，也不能问等于问心的事（"你是卧底吗""你的心和胸牌一致吗""你是沼泽吗""你是不是两头吃的学生"），不问打算。违规你驳回让他重问，不算用掉。被问的人答"是""否"，确实不知道可答"不知道"；答案与机密附录相反时，你当众更正。
10. **开盒看到的能说出去吗？**能说，也能撒谎，卡不能拿走。
11. **卧底倒戈后能再倒回来吗？**不能，只决定一次。
12. **真相题交了能改吗？**不能，只能交一次。
13. **名场面差一点（比如锤票刚好过半）算吗？**不算，条件全满足才给星。
14. **当选总统的心是沼泽怎么办？**沼泽赢，驴心、象心都输。不看副总统。
15. **热线时要交欠条吗？**不用。热线全程玩家什么都不交，听众来信只按你手上的信息判。
16. **某州两边的钱一样多？**比两张提名票的民调和（总统候选人＋副手），高的拿下；再一样，两位总统候选人猜拳。民调在终局只有这一个作用。
