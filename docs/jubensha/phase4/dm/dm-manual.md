## 一、开本前

### 1.1 一个人就能开
本本单DM即可开，不需要助手。你同时是主持人、管钱的（收入、拍卖款、技能费、补偿都从你手里进出）、计时员、记账员。照下面五条做：
1. **民调你不用记**：民调牌摆在每位玩家桌前，人人看得见，变动时让玩家自己拨。
2. **余额你不用记**：资金是实物筹码，各人自己数。有人问还剩多少："您数一数，本台不记账。"你只在台账第2栏给半步爹每幕多给的那1资金打勾，防漏发。
3. **交易你不经手**：走廊里两人当面互给，交到对方手里就算成；你不登记、不担保、不代转。有人来请你确认："当面给了就算，没给就不算。"
4. **欠条你不用登记**：欠条是实物，谁拿着归谁；只有终局有人用欠条、以及翻心时，你才经手实物。
5. **你只记一份台账**（两张A4，见1.5）：闭眼举牌时每个人的选择、私下结果、卧底决定、终局每州的合计，以及你当场判过的口径。

**三句守口令**：私下的话走到他身边低声说，绝不夹在对全桌的话里；当众不说任何人的钱数、技能名（本人当众发动时除外）、剩余次数，看钱只私下看、只答够或不够；宣布口径只说规则，不带人名和技能名。

玩家读本的时间就是你的准备时间：照下一张流程卡把物料摆好。

### 1.5 DM台账（开本前抄在两张A4上）
1. **闭眼举牌记录**：一行一次（第1—8页的锤／洗；扒马褂里每一次"辩"的信／不信），八列是01—08，每格记"锤／洗"或"信／不信"，最后一格记结果。下木的技能会来问这里。
2. **技能**：八行，按1.6"次数"列预印格子：半步爹那行预画"第一幕□ 第二幕□ 第三幕□ 终局□"，钱发到手就打勾；其余各1格，用一次划一格，旁边记何时、结果。拍品6、7的得主加1格（半步爹加"多1次□"）。
3. **名场面**：八行，判定完成就打勾（原句、时机和判定通则见5.9）。半步爹在第6页之前说出第18洞的事，不打勾，说出的信息照常有效。
4. **卧底**：烦高　坚守／倒戈；半步爹　坚守／倒戈 → 算出现在驴心几人、象心几人。
5. **关键结果**：两党初选第一名；两张提名票（总统＋副手）；热线判定（H1／H2／H3）。
6. **终局算钱表**（单独放第二张）：五个州各两行（驴友票／大象票，即驴友党提名票／大象党提名票；当众一律说全称），三格：信封里的钱、欠条（每张1）、撑场（每块2），加总；另记开票那一刻两张提名票的民调和，钱相等时用。只记每州两张票的合计，不抄装钱单。
7. **真相题**：八行，①②③④对错，是否得星（①错就不得星；下木、建国钱、半步爹须4问全对）。

**时钟怎么走**（全本只写这一处）：只记一个数：比时刻表快几分钟还是慢几分钟，各段钟点不必对表。
- **快了**：直接进行下一项。只有同一幕里还没开始的下一次走廊可以加时，一幕合计最多5分钟；超出的、后面隔着休息或饭点的、在终局的，一律让后面整体提前，休息、饭点照原分钟，终局每轮走廊固定3分钟。
- **慢了**：任何环节超时（含拍卖、读本）都算慢了。按下面顺序挑还没进行的项砍，砍够分钟数就算追上，砍的是靠后的项也算，当下照常进行：
  1. 复盘③"第9页的信"整段不念（开票前已经念过一遍）。
  2. 竞选广告每条从60秒改为30秒。
  3. 演绎只念旁白、贾不睡的台词和全体齐声那一句；其余玩家台词不演；标【可删】的不念。
  4. 总统辩论从3题减到2题。
  5. 第三幕热线跳过公开部分（隐藏部分照发）。
  6. 最后才砍走廊：每次最多减3分钟。
- 扒马褂落后时，把"辩"的辩解从30秒改为20秒。
- 终局的三轮、最后猜心、第9页、开票、翻心一样都不能砍（最后猜心和你算两州同时进行，本来就不另占时间）。

**第6步　走廊（10分钟）**　同第一幕第5步。

**第7步　午夜：账本第3、4页（9分钟）**　按第一幕第6步的统一审判流程。念完：
> 饭点30分钟。可以聊，不能交易，不能发动技能。

**第2步　演绎（5分钟）**

**第3步　总统辩论（10分钟）**　把5张辩论题卡洗乱，背面朝上，翻最上面3张，按翻出的顺序念。照念：
> 首场总统辩论！三道题，一题一题来。每道题，两张提名票各有45秒，两个人谁说、各说多少，自己商量。第一题驴友党提名票先答，第二题大象党先答，第三题再换回驴友党；后答的可以接前面的话。45秒一到我喊"停"，没说完的半句不算。三题答完，不在提名票上的各位，我数"三、二、一"，同时指向你觉得赢了的那张提名票。

- **你做**：每段只掐一个45秒，两人怎么分你不管。喊"开始"后5秒没人开口，按6.3④点名，计时照走；副手可以全程不开口，由总统候选人答。到点就喊"停"。
- **结算**：指得多的一方，两人民调各＋1；一样多都不加。没指、指两张的不算票（1比0也算多）。
- **常见问题**：
  - **三题能一起答吗**：不能，一题一题来。
  - **超时了**：喊停就停，不扣任何东西。
  - **评委能指自己党的票吗**：能，指哪张都行。

辩论题（洗乱后翻3张，两党对等）：
1. 如果你当选，上任第一天做的第一件事是什么？不许说"开会"。
2. 用一句话说出对面提名票一个你真心佩服的优点。
3. 选民说"两党都一样"，请用45秒证明你们至少有一点不一样。
4. 你们的承诺里，哪一条最可能做不到？
5. 如果账本有第十页，你希望上面写的是你的哪件事？

**第4步　三轮投放（每轮8分钟）**
先照念一次：
> 三轮，每轮四件事。第一，走廊3分钟，可以交易。第二，撑场：从第二轮起，开票前分数落后的那张提名票，由不在提名票上的4位按编号各放一块写着"2"的圆片，算2资金——必须放，只能放在落后的那张票上，放本轮哪个州自己选；第一轮两边同分，不撑场。第三，手里有欠条的，在背面写州和提名票交给我，签名的人当场从自己的钱里掏1资金给我投进去；他身上没钱，欠条还给你，下一轮再用；用掉的欠条撕掉，不再算沼泽的账。第四，每人往信封里装钱，在我发的纸上写清每个州给哪张提名票多少，信封里的钱要和纸上的合计一样，可以投0，可以投任何一张提名票。然后我开票：每个州，谁投的钱多谁拿下这个州的分——撑场一块算2，欠条一张算1。两边一样多，两张提名票比民调，总统候选人加副手，高的拿下；再一样，猜拳。我只报两边各多少，不报谁投了多少。

**用欠条只写在这里**：
- 持有人把欠条交给你，背面写好"哪个州（只能是本轮的州）、投给哪张提名票"。
- 签名的人当场交你1资金，你把这1资金记进该州该票的"欠条"格，然后撕掉欠条。
- 签名的人说身上没钱：他私下把钱袋给你看，确实没有，这张欠条还给持有人，下一轮再用。
- 一个人一轮可以用多张。用掉的欠条不再计入沼泽胜利。
- 背面以交给你时写的为准；签名的人事先写好的，持有人可以划掉重写。
- 第三轮签名的人仍然没钱，或者持有人不用：欠条留在持有人手里，翻心时照算沼泽的账。

每一轮你做：
1. 发本轮装钱单和装钱信封，问一句"有当众技能要发动的，现在举手"，处理完开始计时走廊3分钟。第一轮开场按6.3①点歌；第三轮开场按6.3⑤照念"最后一轮"那句。走廊中有人要当众说话（名场面、当众技能），喊"全桌停一下"，说完继续，计时不停。
2. 撑场：第一轮跳过。第二、三轮先报一句"现在落后的是××党提名票"，再按编号叫不在提名票上的人，各自当众把圆片放到落后那张票本轮某个州的格子里。
3. 欠条：只问一句"用欠条的，举手。"没人举手就过；有人举手，按上面"用欠条只写在这里"逐张处理。
4. 收钱：收齐信封，照念"导播点票，请各位稍候。"全桌等你约2分钟（含在本轮5分钟里）。逐只数钱，和装钱单的"合计"对一下（对不上按钱算，见常见问题），把每州两张票的钱加总记进台账第6栏；装钱单不抄，用回形针夹好。
5. 开票，照念格式：
> 内华达：驴友党提名票×，大象党提名票×。内华达6分，归——××党提名票！目前驴友党×分，大象党×分。

两边一样多：民调和高的那张票拿下，你报一句"一样多，比民调，××党提名票高"；民调和也一样，两位总统候选人当众猜拳一次，胜者拿下该州。

- **第二轮开票后**：按第一幕第6步的统一审判流程念第7、8页（6分钟），再开第三轮。念第7页前照念一句："终局里被锤，不掉民调，改交1资金。"
- **第三轮**：走廊开始前提醒："真相题答题卡还没交的，这一轮跟钱一起装进信封，过了这轮作废。"收信封后，先抽出答题卡放一边，转到第四节4.1：全桌做"最后猜心"，你趁这2分钟算佐治亚、宾夕法尼亚，**先不报**。
- **常见问题**：
  - **信封里的钱和装钱单对不上**：按钱算。多装的退回；少装的，从装钱单上数额最大的那一格往下扣，扣到相符。
  - **撑场能放下一轮的州吗**：不能，只能放本轮要开的州；放下不能挪。
  - **投完剩下的钱有用吗**：没有任何用处，鼓励全部投出去。
  - **撑场能不放，或者放在领先的那张票上吗**：不能。每人必须放，只能放在落后的那张票上，只选州。

## 六、裁决原则与FAQ

### 6.1 裁决原则
1. 规则卡与本手册冲突，以本手册为准；都没写的，按"对谁都一样、最快能继续"判，判完记进台账第8栏，当众说一遍（只说规则，不带人名、技能名），此后全场照此。
2. 一切闭眼举牌只报票数，不报名单。
3. 只认实物：嘴上答应不算；钱和欠条当面交到对方手里才算成交，你不登记、不担保；走廊外的交易无效，退回。
4. 不公开任何人的心、资金、技能名（本人当众发动时除外）、技能剩余次数和私下结果。
5. 不解释账本，不答剧情，不暗示真相；名场面复盘才公布。
6. 角色本、热线小卡、没打出的黑料只能口述；线索卡、拍品卡、交权书卡可以出示。能转手的只有资金和欠条。
7. 发现漏拨民调、发错钱，当场更正；已结束的环节不翻案。
8. 时间优先：超时按第二节的顺序砍。
9. 私下的话私下说：走到他身边低声说，绝不夹在对全桌的话里；看谁的钱都私下看，只答够或不够。

### 6.2 FAQ
1. **欠条"欠××"一栏有什么用？**写不写都行，写了也不限定谁用：谁拿着，谁用。签上角色名才算数；没签名的空白欠条不算任何人的账，谁拿到都能自己签，签的人就是欠的人。
2. **欠条能转手、能撕吗？**能。拍品4、5附的空白欠条和开局的一样。拿着的人可以撕掉，撕了作废。
3. **签名的人能拒绝、作废或收回吗？**不能。转了几手，都是签名的人掏钱；想拿回来，只能在走廊里换回来。
4. **当选之前签的欠条算收账吗？**算，只看签名的人最后是不是当选总统。没用掉的翻心时照算，没签名的不算。
5. **能在饭点谈好、走廊再交割吗？**能。谈不禁止，交割只在走廊：两人当面交到对方手里就算，你不登记、不担保。
6. **发胶能先声明"要是被锤就用"吗？**不能，下降宣布时当场说。
7. **半步爹的"身后半步"要他举手吗？**不用。你自动多给：第一幕结算他的广告时多1（0个拇指也给），之后每次发收入时多1。拍品6、7被他拍到，下一次再多给1。
8. **终极特稿、背调能查同一人两次吗？**能，每次各算一次。
9. **三小时连麦能问什么？**只问已经发生的事，是非题。不能问心，也不能问等于问心的事（"你是卧底吗""你的心和胸牌一致吗""你是沼泽吗""你是不是两头吃的学生"）；也不能直接问四道真相题的答案（"你递过卡片吗""你捡走那两页纸了吗""账本是不是两头吃发的"），只能问周边细节，比如时间、地点、物件（"那天你戴球帽了吗"）。不问打算。违规你驳回让他重问，不算用掉。被问的人答"是""否"，确实不知道可答"不知道"；答案与机密附录相反时，你当众更正。
10. **开盒看到的能说出去吗？**能说，也能撒谎，卡不能拿走。
11. **卧底倒戈后能再倒回来吗？**不能，只决定一次。
12. **真相题交了能改吗？**不能，只能交一次。
13. **名场面差一点（原句错字、不在写明时点）算吗？**不算。原句可以看着角色本念；锤票多少不影响名场面。
14. **当选总统的心是沼泽怎么办？**沼泽赢，驴心、象心都输。
15. **某州两边的钱一样多？**比两张提名票的民调和（总统候选人＋副手），高的拿下；再一样，两位总统候选人猜拳。民调在终局只有这一个作用。
16. **两头吃是被害、被下药，还是自杀？**都不是。法医结论是自然死亡（心脏病），这一句可以当众告诉全桌；别的不解释。
17. **散场时手里的欠条、没兑现的口头账怎么算？**都作废，不结算。
18. **有人中途离场？**他的资金、欠条交你保管，他签出的欠条照样有效；他的线索卡、拍品卡正面朝上摆桌边，谁都能看，不念；此后他不被问、不投票；已在提名票上的，提名票不变。锤洗照"锤比洗多"，撑场、辩论判票少一人照算。

### 6.3 冷场（只靠主持词，不加道具、不加人手）
走廊是全桌交换消息的唯一时段。冷场，是有人没人找、自己也不去找，或当众环节没人开口；拥堵，是一个人被围住。你只用下面的主持词，**不替人传话，不提示谁该问什么，不透露任何人的底**。

**① 走廊开场：点歌。** 宣布走廊开放后加一句：
> 本台点歌时间：××点给××，××点给××。被点到的两位，走廊里先聊一句，聊完随意。
