## 一、开本前

### 1.1 一个人就能开
本本单DM即可开，不需要任何助手。你同时是主持人、银行、计时员、记账员。为了忙得过来，记住四件事：
1. **民调你不用记**：民调牌摆在每位玩家桌前，人人看得见，变动时让玩家自己拨。
2. **资金你不用记**：每人身上多少钱对别人保密，你也不必知道；终局他们自己把钱封进信封。
3. **欠条你不用登记**：欠条是实物，谁拿着归谁；只有热线和翻心两个时刻需要你看实物。
4. **你只记一张台账**（见1.5）：闭眼举牌时每个人的选择、私下结果、卧底决定、开州计算。

玩家读本的时间就是你的准备时间：照下一张流程卡把物料摆好。

### 1.4 摆台
- DM坐长桌一端。玩家按编号**从你左手边起顺时针**坐：01皮拉提、02烦高……08狗登罗。凡是"从DM左手边起"的环节，就是从01开始。
- 桌中央：银行。搜证时在桌边摆8张地点牌，线索卡背面朝上压在牌下。
- 每人桌前：民调牌朝外，拨到开局值（5.1表）。
