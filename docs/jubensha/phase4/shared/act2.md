# 全员演绎 · 第二幕·超级星期二之夜

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，不算狡辩，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（骑墙大酒店大堂，电视墙上一排州名在跳票数。）*

**旁白**：Y年3月7日，超级星期二，全国多个州在同一天初选。一月那晚零点，"@午夜账房"真的发了：第一页写一位厨子，第二页写一位粗人。从那天起，在座每个人都多了一个习惯——零点前，先看手机。

**贾不睡**：欢迎回来！先说上回。皮议员，账房说您的狗"选票"，项圈牌背面刻着三个字。哪三个字？

**皮拉提**：（比出三根手指）不、告、诉。

**建国钱**：押宝网"项圈三个字"的盘口已开，热门是"投我吧"，一赔二。

**贾不睡**：再说粗人。麦克播先生，原来您是哲学博士？

**麦克播**：（清嗓子）账房写的，我一个字都不认。（顿）……亚里士多德也不认。

**贾不睡**：账房还给博士留了一句："我很喜欢和你聊天。"是谁这么喜欢和您聊天？【可删】

**麦克播**：（嗓门小下去）……我的听众，都喜欢和我聊天。【可删】

**贾不睡**：全国观众最关心的问题来了：这两页，到底是谁发的？

**下木**：（慢悠悠）知道和说出来，是两门手艺。

**烦高**：（对着镜头微笑）我从不发帖。发帖要低头，低头会乱发型。

**半步爹**：一个总站在后面的人，发什么都没人看。所以……不是我。

**梅戏**：这个问题我记下了。下次告诉你。【6人局跳过】

**狗登罗**：律师不猜。【7、6人局跳过】

**贾不睡**：说回初选。开票之前，两党有预案吗？驴友党？

**下木**：有。输了就开会讨论原因，会期四周。

**贾不睡**：大象党？

**麦克播**：大象党没有预案。预案是给会输的人准备的。

**建国钱**：两边的庆功宴，都是我订的。【可删】

**旁白**：开票还要等几个钟头。可在《今夜不睡》，开票之前先扒马褂。每人手里两张关于别人的"可靠消息"，有真有假——真假只有当事人自己心里清楚。

**贾不睡**：请各位把那两张卡拿出来。爆料人念卡，当事人听好：认，辩，还是喊假？全体——三、二、一！

**全体**：我只是转发！

*（灯光转红。DM宣布：扒马褂开始。）*
