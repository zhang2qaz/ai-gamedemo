# 全员演绎 · 第二幕·超级星期二之夜

*（骑墙大酒店大堂，电视墙上一排州名在跳票数。台前摆着一口铁锅，锅底朝上。）*

**旁白**：Y年3月7日，超级星期二，全国多个州在同一天初选。一月那个零点，"@午夜账房"真的发了：第一页写一位厨子，第二页写一位粗人。从那天起，在座每个人都多了一个习惯——零点前，先看手机。

**贾不睡**：欢迎回来！先说上回。皮议员，您那口"妈妈传下来的铁锅"，本台今晚替您带来了。（把锅翻过来）价签还在。

**皮拉提**：（一把抢过锅）家人们，锅是租的，影棚也是租的！可骂人的话，每一句都是我自己炒的！

**梅戏**：我只关心一件事：账房说你的狗"选票"，项圈牌背面刻着三个字。哪三个字？

**皮拉提**：（比出三根手指）三个字——不、告、诉。

**梅戏**：好，这句能引用。

**建国钱**：押宝网"项圈三个字"的盘口已开，目前热门是"投我吧"，一赔二。

**贾不睡**：再说粗人。麦克播先生，原来您是哲学博士？

**麦克播**：（清嗓子）老子没念过几天书——（全场盯着他）……念了九年。论文写亚里士多德。行了吧！

**狗登罗**：顺便更正：我们俩在节目里互骂，是合同约定。每季度至少六次，广告五五分成。

**麦克播**：你怎么当众念合同！

**狗登罗**：这季度还差两次。刚才这句算一次。

**贾不睡**：账房还给博士留了一句："我很喜欢和你聊天。"全国观众都想知道，是谁这么喜欢和您聊天？

**麦克播**：（嗓门第一次小下去）……我的听众，都喜欢和我聊天。

**贾不睡**：那么全国观众最关心的问题来了：这两页，到底是谁发的？

*（八个人同时看向别人，没有一个人看向自己。）*

**下木**：（对着空气，慢悠悠）他们都在看我。因为我知道每个人的老底。可知道和说出来，是两门手艺。

**烦高**：（对着镜头微笑）我从不发帖。发帖要低头，低头会乱发型。

**半步爹**：一个总站在后面的人，发什么都没人看。所以……不是我。

**建国钱**：押宝网"谁在发账本"的盘口也开了，八个名字，外加一个"其他"。目前赔率最低的是……不能说，说了影响盘口。

**贾不睡**：说回初选。开票之前，两党有预案吗？驴友党？

**下木**：有。输了就开会讨论原因，会期四周。

**皮拉提**：第五周，讨论上一个会为什么开了四周。

**贾不睡**：大象党？

**狗登罗**：大象党没有预案。预案是给会输的人准备的。

**半步爹**：（慢半拍点头）……对，我们只准备了庆功宴。

**建国钱**：两边的庆功宴，都是我订的。两边押，才叫稳。

**贾不睡**：今晚本台的初选规矩也不一样：选票上不许写自己，钱只能塞给本党的别人。

**烦高**：（慢半拍）也就是说……想当领跑者，得先让同事心疼你。

**麦克播**：那我完了。我的同事只心疼她自己的耳朵。

**狗登罗**：我的耳朵，按合同另计。

*（电视墙"叮"了一声。每人手边多了两张扣着的卡。）*

**旁白**：开票还要等几个钟头。可在《今夜不睡》，开票之前先扒马褂。每人手里捏着两张关于别人的"可靠消息"，有真有假——真假只有当事人自己心里清楚。

**烦高**：（把卡扣紧）我先声明，我手里这张，和发型无关。

**梅戏**：我这张能引用吗？……算了，我自己引用。

**半步爹**：（小声）我能……说"过"吗？

**下木**：可以。"过"，也会被所有人记住。

**麦克播**：老铁们！扒马褂直播间，今晚咱展开扒三小时！

**贾不睡**：——由本台主持！从我左手边开始，爆料人念卡。当事人听好：认，辩，还是喊假？

**全体**：（齐声）据可靠消息——我不评论，我只是转发！

*（灯光转红。DM宣布：扒马褂开始。）*
