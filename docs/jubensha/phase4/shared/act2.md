# 全员演绎 · 第二幕·超级星期二之夜

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，不算狡辩，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（骑墙大酒店大堂。电视墙一半红一半蓝，各州的初选票数在跳。）*

**旁白**：3月7日，超级星期二，十几个州在同一天初选。一月新年晚宴那晚，零点一到，"@午夜账房"真的贴出了账本：第1页写一位厨子，第2页写一位粗人。从那以后，在座各位睡前都要先看一眼手机。

**贾不睡**：欢迎回到《今夜不睡》！先说上一期被写到的两位。皮议员，账房说您那口"我妈传下来的铁锅"，锅底价签还没撕。听说这一个多月，粉丝往您国会办公室寄了四十三口锅？

**皮拉提**：（掰着手指数）四十三口！里头还有一口柴火灶的大铁锅，邮费比锅还贵。家人们，别寄了，再寄我办公室就改卖锅了！

**贾不睡**：账房那一页还写了：您那条狗"选票"，项圈牌背面刻着三个字。哪三个字？

**皮拉提**：（比出三根手指）不、告、诉。

**建国钱**：（看了一眼手机）押宝网"项圈三个字"的盘口，热门是"投我吧"，一赔二。

**贾不睡**：再说粗人。麦克播先生，账房说您是名校的哲学博士。第二天中午，您还真加播了一期？

**麦克播**：加播了！我当着全国听众把两页账本从头念到尾，念完告诉他们：老子没念过几天书！（顿）……那个希腊老哥的书，不算。

**贾不睡**：账房还给博士留了一句："我很喜欢和你聊天。"是谁这么喜欢和您聊天？

**麦克播**：（嗓门小下去）……我的听众，都喜欢和我聊天。

**贾不睡**：全国观众最关心的问题来了：这两页，到底是谁发的？

**烦高**：（对着镜头微笑）我从不发帖。发帖要低头，低头会乱发型。

**半步爹**：一个总站在后面的人，发什么都没人看。所以……不是我。

**梅戏**：（在采访本上记了一笔）这个问题我记下了。下次告诉你。【6人局跳过】

**狗登罗**：（看着别处）律师不猜。【7、6人局跳过】

**贾不睡**：党鞭，您呢？麦克播先生一月在节目里放过话：下一页要是写到您，他请全国听众喝枸杞。

**下木**：（举了举保温杯）账本不是我发的。枸杞是我发的：今天上午，驴友党每人一包。超级星期二，保温要紧。

**麦克播**：（愣了一下）老抠门，你抢我的单！……行，大象党那份，我请！【可删】

**贾不睡**：票还在跳，开票还得等几个钟头。本台老传统：开票之前，先扒马褂。各位兜里揣着的、关于别人的"可靠消息"，可以掏出来了。全体，三、二、一！

**全体**：我只是转发！

**贾不睡**：第一位，请！

*（灯光转红。）*
