# 全员演绎 · 终局·摇摆之夜

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，不算狡辩，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（骑墙大酒店宴会厅。今晚的灯全是红蓝两色。整面墙是一张大选地图，只剩五个州还亮着黄灯。正中并排摆着两张辩论台。）*

**旁白**：10月，首场总统辩论之夜。今晚本台一口气播两档：先播首场总统辩论，再直接连播大选开票。八月党代会那天零点，"@午夜账房"贴出了两页：一页写一位发型永远不乱的州长，一页写一位总站在半步之后的人。两页挨着贴在网上，转发量破了纪录。

**贾不睡**：欢迎回到《今夜不睡》大选特别季最终期《摇摆之夜》！地图上只剩五个州还在摇摆。先说八月那两页。州长，账房说您每月一号给一位"老朋友"写近况。那位老朋友是谁？

**烦高**：（笑容一动不动）……下次告诉你。

**贾不睡**：州长，这句是梅总监的口头禅。【6人局跳过】

**梅戏**：（举起手）版权费，下次再收。【6人局跳过】

**麦克播**：我们党的发言人说得好："连对面的州长都每月回我们元老家吃饭，说明我们党的牛排好。"【可删】

**贾不睡**：再说另一页。副总统，三十一年前，您是宾夕法尼亚驴友党青年团主席？

**半步爹**：……年轻人，谁还没穿错过几件衣服。

**皮拉提**：这旧队服烧得真干净，我锅底都没刷这么干净！【可删】

**贾不睡**：账本只剩最后几页了。还没被写到的人，自己心里有数。

**狗登罗**：（拉开椅子，想了想，又站直了）没上账本，不等于干净。【7、6人局跳过】

**下木**：（放下保温杯，没有压低嗓子）我那一页，我等着。

**贾不睡**：今晚辩论，两党准备得怎么样？

**麦克播**：（对着手机）各位听众，驴友党准备了一百个口号，到现在还在投票选用哪一个！

**下木**：（抿一口保温杯）投到第四十个了。【可删】

**皮拉提**：大象党也准备好了，提词器擦得锃亮。这回可别再把"此处停顿，等待掌声"也念出来！

**建国钱**：（一手一瓶香槟）两党的庆功派对，我都订好了。今晚谁赢，我都开香槟。

**贾不睡**：最后一期，最后一次。全体，三、二、一！

**全体**：今夜不睡！

*（灯光一暗，只剩地图上五盏黄灯。）*

**贾不睡**：请两张提名票上台！首场总统辩论，三、二、一，开始！
