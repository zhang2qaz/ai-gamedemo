# 全员演绎 · 终幕·摇摆之夜

*（宴会厅的灯全换成了红蓝两色。整面墙是一张大选地图，只剩五个州还亮着黄灯：内华达、威斯康星、密歇根、佐治亚、宾夕法尼亚。正中并排摆着两张辩论台。）*

**旁白**：大选前一个月，首场总统辩论。本台今晚一口气直播到底——先辩论，再连播大选夜开票。八月那个零点，"@午夜账房"又发了两页：一页写一位发型永远不乱的州长，一页写一位总站在半步之后的人。两页挨着贴在网上，转发量破了纪录。

**贾不睡**：欢迎回到《今夜不睡》大选特别季最终期——《摇摆之夜》！两党开局各有236分，先到270分的当选，只剩这五个州还在摇摆。

**麦克播**：五个州！一个州聊三小时，十五个小时，正好一期！

**狗登罗**：节目组给你十五秒。

**麦克播**：你这季度骂我的次数，早就超额了！

**狗登罗**：超额部分，按合同另计。

**贾不睡**：先说上回。州长，账房说您每月和父亲吃一次饭，每月一号还给一位"老朋友"写近况。

**烦高**：（对着镜头，笑容一动不动）和父亲吃饭，是孝道；给老朋友写信，是礼貌。风再大，发型不乱。

**梅戏**：州长，那位老朋友是谁？这句我想引用。

**烦高**：……下次告诉你。

**梅戏**：那是我的台词！

**贾不睡**：副总统，三十一年前，您是宾夕法尼亚驴友党青年团主席？

**半步爹**：（往身后看了一眼）……年轻人，谁还没穿错过几件衣服。

**皮拉提**：家人们！副总统当年还是我们驴友党的人！这旧队服烧得真干净，我锅底都没刷这么干净！

**建国钱**：（一掀西装，二维码闪了一下）押宝网五个摇摆州全部开盘。每个州两种颜色，我每种颜色都押了。两边押，才叫稳。

**贾不睡**：九页账本已经发了六页。在座还没被写到的，只剩两位。

*（全场目光齐刷刷转向两个人。）*

**狗登罗**：（站得更直了）律师提醒：没上账本，不等于干净。（顿）不过我查过了，我是干净的。

**下木**：（抿一口保温杯，笑眯眯）我不急。账，总是最后才结。

**贾不睡**：今晚辩论，两党准备得怎么样？驴友党？

**皮拉提**：我们准备得非常民主——

**梅戏**：——我们准备了一百个口号，正在投票选哪一个。

**贾不睡**：大象党？

**麦克播**：我们准备了两套答案：一套给支持者听，一套给我妈听。

**半步爹**：（慢半拍点头）……对，第二套比较厚。

**贾不睡**：不在提名票上的四位，请举手！各位也别闲着——每一轮，都能给一张提名票撑一次场，一下顶两块钱。撑哪个州、哪张提名票，全看各位。

*（DM临场点名举手的四位。）*

**举手的四位**（齐声）：撑哪边，看谁给得多！

**贾不睡**：最后提醒两件事。第一，两头吃死在第18洞的那天到底发生了什么，账本到底是谁在发——答案请写好，最晚第三轮往信封里装钱时一起交上来。第二，今晚先开票，定谁当选；再翻心，定谁真赢。欢呼的人可能当场判负，哀嚎的人可能才是赢家。

**下木**：（合上小本子，对着空气）这才是最好看的部分。

**建国钱**：两党的庆功派对我都订好了，今晚谁赢都开香槟。

**半步爹**：（慢慢站起来，看了看身后，又坐下）……大家，今晚见分晓。

**皮拉提**：家人们，最后五个州！锅都热了——

**全体**：你还凉着？！

*（灯光一暗，只剩地图上五盏黄灯。）*

**贾不睡**：请两张提名票上台——首场总统辩论，三、二、一，开始！

*（DM宣布：总统辩论开始。）*
