# 全员演绎 · 终局·摇摆之夜

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，不算狡辩，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（宴会厅的灯全换成了红蓝两色。整面墙是一张大选地图，只剩五个州还亮着黄灯。正中并排摆着两张辩论台。）*

**旁白**：Y年10月。今晚本台一口气播两档：先播首场总统辩论，再直接连播大选夜开票。八月那晚零点的两页，各位刚才都听过了：一页写一位发型永远不乱的州长，一页写一位总站在半步之后的人。两页挨着贴在网上，转发量破了纪录。

**贾不睡**：欢迎回到《今夜不睡》大选特别季最终期——《摇摆之夜》！只剩五个州还在摇摆。

**麦克播**：五个州！一个州聊三小时，十五个小时，正好一期！

**狗登罗**：节目组给你三十秒。【7、6人局跳过】

**贾不睡**：州长，账房说您每月一号给一位"老朋友"写近况。那位老朋友是谁？【可删】

**烦高**：（笑容一动不动）……下次告诉你。【可删】

**贾不睡**：州长，这句有版权的。【可删】

**贾不睡**：半步爹副总统，三十一年前，您是宾夕法尼亚驴友党青年团主席？【可删】

**半步爹**：……年轻人，谁还没穿错过几件衣服。【可删】

**皮拉提**：家人们！这旧队服烧得真干净，我锅底都没刷这么干净！【可删】

**建国钱**：押宝网五个摇摆州全部开盘。每种颜色，我都押了。

**贾不睡**：九页账本已经发了六页。还没被写到的，只剩两位。

**狗登罗**：（站得更直）没上账本，不等于干净。【7、6人局跳过】

**下木**：（没压嗓子）……我那一页，我等着。

**贾不睡**：今晚辩论，两党准备得怎么样？

**皮拉提**：驴友党准备了一百个口号，正在投票选哪一个。

**麦克播**：大象党准备了两套答案：一套给支持者听，一套给我妈听。

**半步爹**：（慢半拍点头）……第二套比较厚。【可删】

**贾不睡**：今晚先开票，定谁当选；再翻心，定谁真赢。欢呼的人可能当场判负，哀嚎的人可能才是赢家。

**建国钱**：两党的庆功派对我都订好了，今晚谁赢都开香槟。【可删】

**皮拉提**：家人们，最后五个州！锅都热了——

**贾不睡**：全体——三、二、一！

**全体**：你还凉着？！
