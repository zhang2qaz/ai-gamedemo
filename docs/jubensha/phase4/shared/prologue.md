# 全员演绎 · 序幕·《今夜不睡》开播

*（DM用：标【可删】的句子，超时时不念；标【7、6人局…】【6人局…】的句子，人少时按标注处理。）*

*（片头曲起。宴会厅门楣上挂着一条红蓝各半的横幅："两党都欢迎，账单都一样。"贾不睡端着一杯咖啡走到台前。）*

**旁白**：Y年1月19日晚，骑墙大酒店，新年筹款晚宴。今晚的东家，是一个月前去世的跨党老说客游游·两头吃。遗嘱写明：晚宴照办，遗物开拍。死人请客，活人吃饭。

**贾不睡**：晚上好，欢迎收看《今夜不睡·大选特别季》！我是贾不睡，名字就是我的工作纪律。今晚八位嘉宾，四位想当总统，四位想决定谁当总统。驴友党，先打招呼！

**皮拉提**：（举着锅铲站起来）家人们！今晚不炒菜，今晚炒选情！锅都热了，你还凉着？

**烦高**：（先找到镜头，再微笑）各位晚上好。宴会厅的空调风有点大，不碍事——风再大，发型不乱。

**下木**：（端着保温杯，笑眯眯）下木，党鞭。大家别紧张，我这个人不记仇。（抿一口）我记账。

**梅戏**：梅戏，通讯总监。贾老师，我手上有个独家——下次告诉你。【6人局跳过】

**贾不睡**：本台等这个"下次"，已经等了八年。大象党！【可删】【6人局只念"大象党！"】

**麦克播**：（嗓门把吊灯震得一晃）老铁们！麦克播！就"今晚吃什么"这个问题，这事儿咱展开聊三小时！

**狗登罗**：（站得笔直）节目组给了你三十秒。狗登罗，大象党首席选举律师。在座各位我都查过了——他是干净的。（顿）不是说你。【7、6人局跳过】

**麦克播**：我也没问你！【7、6人局跳过】

**半步爹**：（先看左右，才慢慢站起来）大家好……不用鼓掌，不用鼓掌。总统今晚有事，派我来问好。我一直就在您身后半步。

**建国钱**：（一掀西装，内衬印着巨大的二维码）都是朋友！今晚驴友党那半边的酒是我请的，大象党那半边也是我请的。两边押，才叫稳。

**贾不睡**：两党各用一句话介绍自己。驴友党？【可删】

**梅戏**：我们为这一句话，开了四个小时的会。【6人局改由下木说】

**贾不睡**：大象党？【可删】

**狗登罗**：大象党从不道歉。【7、6人局跳过】

**麦克播**：我们只"重新解释"！

**贾不睡**：说正事。一个月前，两头吃先生在佛罗里达一座球场的第18洞倒下，那天是他78岁生日。法医报告只附了一句："死者在读一张卡片时突发不适，卡片事后未找到。"和他同组打球的，就有在座的副总统。

*（全场安静一秒。八个人同时伸手去端水杯。）*

**半步爹**：（水洒了一点）……打球的人，眼睛是盯着球的。

**烦高**：（喝水时也对着镜头）这个问题，很值得深思。

**下木**：（对着空气）你们注意到没有？刚才所有人同时口渴了。

**建国钱**：押宝网"卡片上写了什么"的盘口……算了，这个不开。死者为大。

**贾不睡**：本台悬赏：那张卡片是什么？谁递给他的？谁把它拿走了？还有一条风声——今年每逢政治大日子的午夜，网上一个叫"@午夜账房"的账号就会贴出一页账本。第一页，就在今晚零点。

**全体**：（齐声）今晚零点？！

**皮拉提**：谁的账谁自己端！我的锅从来不怕人看！

**麦克播**：零点？我节目正好零点开播，直播读账本，展开聊三小时！

**烦高**：零点我得回房间定型。四十分钟，一分钟都不能少。

**半步爹**：（看了看表，又看了看大家）……好的，好的。

**狗登罗**：律师提醒：零点以后说的每一句话，都算明天的证词。【7、6人局跳过】

**梅戏**：那我现在说的还算今天的。我有个独家——【6人局跳过】

**全体**：下次告诉你！【6人局跳过】

**贾不睡**：离零点还有几个钟头。按遗嘱，今晚要拍遗物——不过开拍之前，每位嘉宾先给自己打一条60秒竞选广告。观众闭眼竖拇指，拇指越多，筹得越多。

**皮拉提**：拇指？我直播间最不缺的就是拇指！

**狗登罗**：提醒一句：竖拇指不记名。所以，别指望谁会承认。【7、6人局跳过】

**全体**：（齐声）今——夜——不——睡！

*（灯光打到第一位嘉宾身上。DM宣布：竞选广告开始。）*
