# 全员演绎 · 序幕·《今夜不睡》开播

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（骑墙大酒店宴会厅。门楣上挂着红蓝各半的横幅："两党都欢迎，账单都一样。"嘉宾在台前的长桌后坐成一排，镜头的红灯亮了。）*

**旁白**：1月19日，星期三晚上，骑墙大酒店，新年筹款晚宴。东家游游·两头吃是跨党的老说客，人称"沼泽俱乐部"的老大，一个月前去世了。他在遗嘱里留了一句附言："新年晚宴照办，加拍遗物。"所以今晚请柬照发，酒照倒，两党的人都来了。

**贾不睡**：镜头切进宴会厅！今晚这张长桌上，有人想当总统，有人想决定谁当总统，还有人两样都想。驴友党，先打招呼！

**皮拉提**：（从包里抽出锅铲，举过头顶）家人们！今晚不炒菜，炒选情！锅都热了，你还凉着？

**烦高**：（先找镜头，再微笑）晚上好。这边空调风有点大。不碍事，风再大，发型不乱。

**下木**：（端着保温杯，笑眯眯）下木，党鞭。别紧张，我这个人不记仇。（抿一口）我记账。

**梅戏**：（翻开采访本，看了一眼，又合上）梅戏，通讯总监。贾老师，我有个独家，下次告诉你。【6人局跳过】

**贾不睡**：大象党！

**麦克播**：（举着手机，冲屏幕那头的听众）各位听众，麦克播！今晚这事儿，咱展开聊三小时！

**狗登罗**：（站着，没坐）狗登罗，大象党首席选举律师。在座各位，我都查过了。（指向半步爹）他是干净的。（转向麦克播）你，还在查。【7、6人局跳过】

**半步爹**：（撑着伞，慢慢站起来）大家好……总统今晚有事，让我替他来问个好。（说完，往后退了半步）……习惯了。

**建国钱**：（一掀西装，内衬印着二维码）都是朋友！今晚两边的酒，都是我请的。两边押，才叫稳。

**贾不睡**：说正事。一个月前，两头吃先生在佛罗里达一座球场的第18洞倒下，那天是他78岁生日。法医报告只附了一句："死者在读一张卡片时突发不适，卡片事后未找到。"和他同组打球的，就有在座的副总统。

**半步爹**：（手一抖，杯里的水洒了一点）……打球的人，眼睛是盯着球的。

**建国钱**：（掏出手机，想了想，又揣回去）押宝网"卡片上写了什么"的盘口……算了，这个不开。死者为大。

**贾不睡**：本台悬赏：那张卡片是什么？谁递给他的？谁把它拿走了？还有一条风声：每逢政治大日子的午夜，一个叫"@午夜账房"的账号会贴出一页账本。第一页，就在今晚零点。

**麦克播**：零点？好！明天中午我加播一期，把这页账本给听众从头念到尾！

**烦高**：账本你们先看。零点我得回房间定型，四十五分钟，一分钟都不能少。【可删】

**皮拉提**：（锅铲往桌上一拍）账本？来！我的锅，从来不怕人看！

**下木**：（抿一口保温杯）皮议员，冷静一点。【可删】

**贾不睡**：离零点还有几个钟头。开拍遗物之前，每位嘉宾先给自己打一条竞选广告。全体，跟我喊，三、二、一！

**全体**：今夜不睡！

**贾不睡**：第一条广告，皮议员，请！

*（灯光打到皮拉提身上。）*
