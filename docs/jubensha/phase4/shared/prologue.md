# 全员演绎 · 序幕·《今夜不睡》开播

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（片头曲起。宴会厅门楣上挂着红蓝各半的横幅："两党都欢迎，账单都一样。"）*

**旁白**：Y年1月19日晚，骑墙大酒店，新年筹款晚宴。东家是一个月前去世的跨党老说客游游·两头吃。遗嘱写明：晚宴照办，遗物开拍。死人请客，活人吃饭。

**贾不睡**：晚上好，欢迎收看《今夜不睡·大选特别季》！我是贾不睡，名字就是我的工作纪律。今晚八位嘉宾，四位想当总统，四位想决定谁当总统。驴友党，先打招呼！【7人局念"七位嘉宾"，6人局念"六位嘉宾"，后半句不念】

**皮拉提**：（举起锅铲）家人们！今晚不炒菜，炒选情！锅都热了，你还凉着？

**烦高**：（先找镜头，再微笑）晚上好。空调风有点大——不碍事，风再大，发型不乱。

**下木**：（端着保温杯，笑眯眯）下木，党鞭。别紧张，我这个人不记仇。（抿一口）我记账。

**梅戏**：梅戏，通讯总监。贾老师，我有个独家——下次告诉你。【6人局跳过】

**贾不睡**：大象党！

**麦克播**：老铁们！麦克播！今晚吃什么，咱展开聊三小时！

**狗登罗**：（站得笔直）狗登罗，大象党首席选举律师。在座各位我都查过了——他是干净的。（顿）不是说你。【7、6人局跳过】

**半步爹**：（慢慢站起来）大家好……总统今晚有事，派我来问好。我一直在他身后半步。

**建国钱**：（一掀西装，内衬印着二维码）都是朋友！今晚两边的酒，都是我请的。两边押，才叫稳。

**贾不睡**：说正事。一个月前，两头吃先生在佛罗里达一座球场的第18洞倒下，那天是他78岁生日。法医报告只附了一句："死者在读一张卡片时突发不适，卡片事后未找到。"和他同组打球的，就有在座的副总统。

**半步爹**：（水洒了一点）……打球的人，眼睛是盯着球的。

**建国钱**：押宝网"卡片上写了什么"的盘口……算了，这个不开。死者为大。【可删】

**贾不睡**：本台悬赏：那张卡片是什么？谁递给他的？谁把它拿走了？还有一条风声——每逢政治大日子的午夜，一个叫"@午夜账房"的账号会贴出一页账本。第一页，就在今晚零点。

**麦克播**：零点？我节目正好零点开播——直播读账本！

**烦高**：零点我得回房间定型。四十五分钟，一分钟都不能少。【可删】

**皮拉提**：谁的账谁自己端！我的锅，从来不怕人看！

**贾不睡**：离零点还有几个钟头。开拍遗物之前，每位嘉宾先给自己打一条竞选广告。全体，跟我喊——三、二、一！

**全体**：今夜不睡！

*（灯光打到第一位嘉宾身上。DM宣布：竞选广告开始。）*
