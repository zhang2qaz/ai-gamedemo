# 全员演绎 · 第三幕·同夜党代会

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，不算狡辩，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（两党会场同在一座城，中间只隔一条街。大屏上滚着一行广告："定时公开·不可撤销至尊版——连我们自己都删不掉。"）*

**旁白**：那是三月的事。现在是Y年8月14日，两党全国代表大会同一夜开幕。三月那晚零点，"@午夜账房"又发了两页：一页写两边押的人，一页写一位记者。从那一页起，全国都知道了——账本是一台定时器在发。替谁发，账房没写。【6人局把"又发了两页：一页写两边押的人，一页写一位记者"念成"又发了一页，写两边押的人"】

**贾不睡**：欢迎回来！建国钱先生，滚动字幕那句广告词，是您写的吧？【可删】

**建国钱**：（干笑）写的时候，我觉得这是卖点。【可删】

**麦克播**：老铁们，我就问一句：这台定时器的第1号客户到底是谁？我家电饭煲也能定时，它算不算嫌疑人？

**贾不睡**：五月，两头吃先生下葬，本台也去了。门口最大的两只花圈挨着站——一只驴友党党鞭办公室，一只开盒智能。

**下木**：（抿一口保温杯）花店摆的。

**建国钱**：都是朋友。

**贾不睡**：再说记者。梅总监，"周四先生"是谁？【可删】【6人局跳过】

**梅戏**：账房说得对，我只是没问。这一次，我会问。【可删】【6人局跳过】

**贾不睡**：九页账本，已经发了四页。还没被写到的各位，今晚睡得着吗？【可删】

**皮拉提**：被写过的人反而轻松了！家人们，我最近睡得可香了！【可删】

**半步爹**：我……一般是站着睡的。在总统身后站久了，习惯了。【可删】

**贾不睡**：今晚要定提名票，还要"求婚"：请一位同党当副手。各位有什么要求？

**皮拉提**：求婚我熟！我直播间天天有人求婚——求的是锅铲。

**麦克播**：谁跟我搭档，先说好：节目我一个人讲三小时，你负责点头。

**烦高**：搭档如婚姻，讲究体面。合影的时候，别挡我的发型。

**狗登罗**：婚前协议，我来起草。【7、6人局跳过】

**半步爹**：（小声）八年前，我也被求过一次婚。我说的是："好的，好的。"【可删】

**建国钱**：押宝网"谁跟谁搭档"的盘口，每一种我都押了一点。【可删】

**贾不睡**：两边会场，给自己的人喊一声——三、二、一！

**全体**：选我选我！

*（灯光打到讲台上。DM宣布：提名演讲开始。）*
