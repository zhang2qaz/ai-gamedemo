# 全员演绎 · 第三幕·同夜党代会

*（DM用：标【可删】的句子，超时时不念；标【7、6人局…】【6人局…】的句子，人少时按标注处理。）*

*（两党会场同在一座城，中间只隔一条街。台上的大屏一分为二：一半是蓝气球，一半是红气球。屏幕下方滚着一行广告："定时公开·不可撤销至尊版——连我们自己都删不掉。"）*

**旁白**：Y年8月14日，两党全国代表大会同一夜开幕。三月那个零点，"@午夜账房"又发了两页：一页写两边押的人，一页写一位记者。从那一页起，全国都知道了——账本是一台定时器在发。替谁发，账房没写。【6人局把"又发了两页：一页写两边押的人，一页写一位记者"念成"又发了一页，写两边押的人"】

**贾不睡**：欢迎回来！本台今晚同时直播两场党代会。先请出今晚最尴尬的嘉宾——建国钱先生，滚动字幕那句广告词，是您写的吧？【可删】

**建国钱**：（干笑）"连我们自己都删不掉。"……写的时候，我觉得这是卖点。都是朋友，都是朋友。

**狗登罗**：另外，押宝网有十一个小号，挂在您司机名下。【7、6人局改由贾不睡说】

**建国钱**：那叫对冲！我的司机也是朋友！

**麦克播**：老铁们，我就问一句：这台定时器的第1号客户到底是谁？我家电饭煲也能定时，它算不算嫌疑人？

**皮拉提**：（锅铲一挥）电饭煲不电饭煲的，先把今晚的提名管好！锅都热了，你还凉着？

**贾不睡**：五月的葬礼，本台也去了。门口最大的两只花圈挨着站——一只驴友党党鞭办公室，一只开盒智能。

**下木**：（抿一口）花店摆的。

**建国钱**：都是朋友。

**梅戏**：这句我想引用：死人请客，活人站队。【6人局跳过】

**狗登罗**：律师提醒：花圈不构成证据。【7、6人局跳过】

**贾不睡**：再说记者。梅总监，"周四先生"是谁？【可删】【6人局跳过】

**梅戏**：（深吸一口气）我没见过他，也没问过他。账房说得对，我只是没问。（顿）……这一次，我会问。【6人局跳过】

**麦克播**：账房最后那句，"新人选站到了总统身后半步"——副总统，这说的不就是您？【6人局跳过】

**半步爹**：（往身后看了一眼，身后没人）……我只是被选中的那个。被选中，不犯法吧？【6人局跳过】

**狗登罗**：不犯法。我查过了。【7、6人局跳过】

**贾不睡**：九页账本，已经发了四页。在座还没被写到的，还有四位。各位，今晚睡得着吗？【可删】

**皮拉提**：被写过的人反而轻松了！家人们，我最近每晚都睡得可香了！

**烦高**：睡得着。睡前我会把发型固定好，账本再厚，也压不乱。

**下木**：（抿一口保温杯）我睡得很好。记账的人，睡前都对过账。

**半步爹**：我……一般是站着睡的。在总统身后站久了，习惯了。

**贾不睡**：好，镜头切到驴友党会场。今晚的议程有多长？【可删】

**下木**：（翻开小本子）四十七页。第一项：讨论今晚的议程。

**梅戏**：第二项：讨论第一项为什么讨论了这么久。这句能引用。【6人局跳过】

**贾不睡**：镜头切到大象党会场？【可删】

**狗登罗**：大象党没有议程。我们只有结论，议程事后补。【7、6人局改由麦克播说】

**烦高**：（对着镜头，慢半拍）听说两边会场的空调都坏了。正是考验一位领导人定力的时候——风再大，发型不乱。

**贾不睡**：今晚流程很简单：每党四人各讲三十秒"我为什么该上提名票"，然后同时伸手，指出本党的总统候选人。候选人再当众"求婚"，请一位同党当副手。

**皮拉提**：求婚我熟！我直播间天天有人求婚——求的是锅铲。

**麦克播**：谁跟我搭档，先说好：节目我一个人讲三小时，你负责点头。

**半步爹**：（小声）八年前，我也被求过一次婚。我当时说的是："好的，好的。"

**建国钱**：押宝网"谁跟谁搭档"的盘口，一共……（掰手指）不管几种，我每一种都押了一点。

**烦高**：搭档如婚姻，讲究的是体面。合影的时候，别挡我的发型。

**下木**：（合上小本子，笑眯眯）我只提醒一句：今晚每一根伸出去的手指，我都记着。

**全体**：（两边会场同时）吁——

**贾不睡**：三十秒演讲，初选第一名最后一个讲。第一位，请上台！

*（灯光打到讲台上。DM宣布：提名演讲开始。）*
