# 全员演绎 · 第三幕·同夜党代会

*（括号里是动作，不念；道具没有就比划。台词都是戏：不算规则，不算交易，不算狡辩，名场面原句在这里说了也不算。齐声句等贾不睡数"三、二、一"。【可删】超时不念，问句和答句一起删；【7、6人局…】【6人局…】按标注念。）*

*（两党会场同在一座城，中间只隔一条街。《今夜不睡》的直播车停在这条街正中，车前摆着一排高脚凳。街口的大屏上滚着一行广告："定时公开·不可撤销至尊版——连我们自己都删不掉。"）*

**旁白**：8月14日，两党全国代表大会同一天晚上开幕。三月超级星期二那天零点，"@午夜账房"又贴了账本。写建国钱的那一页里有一笔：开盒智能卖一款定时器，叫"定时公开·不可撤销至尊版"，把内容交给它，到点就替你发出去。它上线第一周就来了一位"第1号客户"，账本就是它替这位客户发的。第1号客户是谁，账房没写。

**贾不睡**：欢迎回来！建国钱先生，街口大屏上那句广告词，账房说是您写的？

**建国钱**：（干笑）写的时候，我觉得这是卖点。

**麦克播**：卖点归卖点。我就问一句：这台定时器的第1号客户，到底是谁？

**建国钱**：客户信息，保密。（顿）这也是卖点。

**贾不睡**：说到不露名字的人。梅总监，账房说，八年前给您递料的那位"周四先生"，您从来没问过他是谁？【6人局跳过】

**梅戏**：账房说得对，那时候我只是没问。（翻开采访本）现在在问。【6人局跳过】

**贾不睡**：第1号客户叫什么，本台查不到。开盒智能这几个字，本台倒是五月见过。两头吃先生下葬，老先生遗嘱里交代过："等大家忙完初选再来送我，别耽误正事。"本台也去了。灵堂门口最大的两只花圈挨着摆：一只落款驴友党党鞭办公室，一只落款开盒智能。

**下木**：（抿一口保温杯）花店摆的。

**建国钱**：都是朋友。

**贾不睡**：账本还有一多半没发。还没被写到的各位，今晚睡得着吗？【可删】

**皮拉提**：被写过的人反而轻松了！我最近睡得可香了！【可删】

**半步爹**：我……一般是站着睡的。在总统身后站久了，习惯了。【可删】

**贾不睡**：今晚两边会场都要定提名票，还要"求婚"：请一位同党当副手。各位对另一半有什么要求？

**皮拉提**：我就一个条件：跟我搭档，得会刷锅。

**麦克播**：谁跟我搭档，先说好：节目我一个人讲三小时，你负责点头。

**狗登罗**：婚前协议，我来起草。【7、6人局跳过】

**烦高**：（理了理鬓角）合影的时候，你站我右边，把左侧四十五度留给镜头。

**半步爹**：（小声）八年前，我也被求过一次婚。我说的是："好的，好的。"

**贾不睡**：两边会场，替自己喊一声！三、二、一！

**全体**：选我选我！

**贾不睡**：驴友党会场，请第一位上讲台！

*（灯光打到讲台上。）*
