## 2. 真相（简化版）

### 2.1 一句话真相
两头吃的两个学生——驴友党党鞭**下木**和大象党金主**建国钱**——想逼老师交出沼泽俱乐部三十年的家当。他们在老师生日球局的第18洞递上一份"交权书"，老师读完倒地，死于心脏病。可老师早在一年前就发现了他们的计划，给自己设了一个**死人开关**：九页账本加密托管，他一停止每周签字，账本就在每个政治大日子的午夜逐页公开。**账本是死人在发。**

### 2.2 前因（只留桌上用得到的）
- **两颗种子**：两头吃定下计划，在两党各种一颗"种子"。三十年前，下木把驴友党青年团主席**半步爹**送进大象党；二十年前，建国钱把大象党元老之子**烦高**送进驴友党。种子只认上线，以为上线代表"真正的本党"：半步爹以为下木代表驴友党，烦高以为建国钱代表大象党。种子不知道上线属于沼泽。
- **交权书**：前年11月，建国钱用自家开盒智能的写作助手起草交权书，把分享链接发给下木；这一版的分享链接默认公开，被搜索引擎收录。两头吃每周五都会把学生和种子的名字搜一遍，就这样看到了草稿。
- **死人开关**：前年12月，两头吃以自己私人全资的家政公司**绿茵管家服务有限公司**的名义，买下开盒智能新品"定时公开·不可撤销至尊版"，成了它的第1号客户；又在守口如瓶律所签下定时公开托管合同（起草人是狗登罗，她只见过代理人，不知委托人是谁）。九页账本是他亲笔写的。触发条件：委托人死亡，或连续两周漏签每周一的"生存确认"。此后一年他每周一签字，签名只写一个"游"字，最后一次是Y−1年12月13日。
- **心脏**：两头吃三年前装过心脏支架，医生不让他打球，他照打。读到交权书草稿后，他定下一条：学生哪天当面把交权书递上来，他就不再去签字——活着，两周后账本照发；倒下，当天就发。所以最后一次签字时他说"周六更快"、把下周的薄荷糖先给出去，是在等学生，不是知道自己会死。周六倒下是心脏病，不在他的计划里。
- **第一笔钱**：皮拉提第一次竞选时，有83人各捐199美元，雇主都是绿茵管家。钱是两头吃出的，他从没向她收过账。

### 2.4 账本的发布路径

### 2.6 真相题：标准答案与统一判分
- **提交**：每人1张真相题卡，可从第二幕起随时交，只能交一次；最晚在终局**第三轮往信封里装钱**时一起装进装钱信封。第9页在截止之后才念。
- **判分**：按意思判，错别字不扣分；一题写两个候选答案（"A或B"）按错判。
- **计星**：①必须答对，另外三题再对两题＝真相星1颗。下木、建国钱开局已知②③④，半步爹亲眼见过第18洞、第三幕又从信封得知沼泽，这三人须**4问全对**才得星。

## 3. 阵营与胜利

### 3.1 胸牌与心
- **胸牌**（公开）：驴友党或大象党，决定你能上哪张提名票。每党4人。
- **心**（保密）：驴心／象心／沼泽。玩家只在自己的角色本里读到自己的心。规则书不公开各心人数。
- 8人局开局：**驴心3（皮拉提、梅戏、半步爹）／象心3（烦高、麦克播、狗登罗）／沼泽2（下木、建国钱）**。
- 每党4人＝忠诚候选人＋对面派来的卧底＋忠诚幕僚＋沼泽：驴友党＝皮拉提、烦高（卧底）、梅戏、下木（沼泽）；大象党＝麦克播、半步爹（卧底）、狗登罗、建国钱（沼泽）。

### 3.2 胜利条件
| 心 | 胜利条件 |
|---|---|
| 驴心 | 当选总统的心是驴心 |
| 象心 | 当选总统的心是象心 |
| 沼泽 | 当选总统的心是沼泽；或游戏结束时，两名沼泽合计持有**当选总统亲笔签的欠条≥3张** |

- 一句话：**当选总统的心是哪种，哪种心就赢；另外，两名沼泽手里加起来有当选总统亲笔签的欠条≥3张，沼泽也赢。**
- 当选总统的心是沼泽时，沼泽直接获胜，驴心、象心都输。
- 沼泽的收账胜利与两党胜负互不影响，可以同时赢。用掉的欠条已撕掉，自然不计。
- 判定顺序：DM宣布当选总统与副总统 → 两人翻心，按总统的心判胜 → 清点沼泽手中的总统欠条，判沼泽 → 开真相题 → 评星。

### 3.3 卧底：单人倒戈
- 卧底只有两人：**烦高**（驴友党胸牌，象心，上线建国钱）、**半步爹**（大象党胸牌，驴心，上线下木）。
- 第三幕"卧底信封"环节，全员同时拆信封（第10节）。卧底得知"你的上线是沼泽"，**单人**决定一次：
  - **坚守**：心不变；
  - **倒戈**：心改为胸牌所在一方（烦高变驴心；半步爹变象心）。
- 在卡上勾选、折好交回DM，不公开，无任何代价。两名卧底的决定互不影响，结果可能是3:3、4:2或2:4。
- 终极特稿、背调查的都是"当下的心"：倒戈后的卧底查出来是"一致"。

### 3.4 欠条
- 每人开局3张空白欠条。写上"欠××一次"并签上自己的角色名，即生效。
- 欠条可白送、可交易、可转手，谁拿着就归谁。只能在走廊里交易，饭点不可交易。
- **唯一用法**：终局时，拿着欠条的人可以要签名的人从自己的钱里拿出1资金，投到指定的州和提名票上。终局任一轮，持有人把欠条交给DM，背面写明"在哪个州、投给哪张提名票"；签名的人当场掏1资金给DM，DM替他投进去，然后撕掉欠条。签名的人身上没有资金时，这张欠条本轮用不了，还给持有人，下一轮再用。
- 用掉的欠条不再计入沼泽胜利。所以沼泽手里的总统欠条，最好一张都别用。
- 遗产拍卖里另有3张空白欠条（拍品4、5；6人局只有拍品4的2张）。

### 12.2 穷举验证
脚本（python3，已运行）：
```python
from itertools import product
SAFE_D, SAFE_R = 236, 236
STATES = [('内华达',6),('威斯康星',10),('密歇根',15),('佐治亚',16),('宾夕法尼亚',19)]
TOTAL = SAFE_D + SAFE_R + sum(v for _,v in STATES); WIN = TOTAL//2 + 1
ties = dwin = early = 0
for bits in product([0,1], repeat=5):
    d = SAFE_D + sum(v for (_,v),b in zip(STATES,bits) if b); r = TOTAL - d
    ties += d == r; dwin += d > r
    d2 = SAFE_D + sum(v for (_,v),b in zip(STATES[:3],bits[:3]) if b)
    r2 = SAFE_R + sum(v for (_,v),b in zip(STATES[:3],bits[:3]) if not b)
    early += d2 >= WIN or r2 >= WIN
print('分数总数', TOTAL, '当选线', WIN)
print('穷举组合', 32, '平票', ties, '驴友票胜', dwin, '大象票胜', 32-dwin-ties, '前两轮后已锁定', early)
```

### 12.4 每一轮的五步
1. **走廊3分钟**：自由私聊，可交易资金和欠条。
2. **撑场**：不在提名票上的4人按编号顺序，各把1块写着"2"的撑场圆片当众放在本轮要开的一个州、某一张提名票上。每块算2资金。
3. **用欠条**：见3.4。签名的人交的1资金算进指定州、指定提名票。
4. **往信封里装钱**：全员（包括提名票上的人）在装钱单（DM发的纸）上写清每个本轮州给哪张提名票多少，把等额资金一起装进装钱信封交DM，信封里的钱要和纸上的合计一样。可以投0，可以投给任何一张提名票。
5. **开票**：DM算出每个本轮州两张票各得多少资金，当众报两边的数和谁拿下，不报谁投了多少。

### 12.5 每个州谁拿下
- **谁在这个州投的钱多，谁拿下**：信封里的钱＋欠条（每张算1资金）＋撑场（每块算2资金）。
- **相等时**：两张提名票比民调和（总统候选人＋副手，按开票那一刻），高的拿下；再相等，两张票的总统候选人当众猜拳一次（石头剪刀布），胜者拿下。这是民调在终局的唯一作用。

### 12.6 总统辩论（小游戏，10分钟）
