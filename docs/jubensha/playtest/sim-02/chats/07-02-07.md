# 私聊7（第三幕走廊）：烦高 × 建国钱

**烦高**：（左脸朝你，站在柜台侧边，一只手护着左边头发，声音压低）钱老板，最后一次走廊，我只问一个问题，问完要不要谈条子，看你答得怎么样。**押宝网上那个"加州明年是否开征冲浪板税"一赔七的盘口，是谁开的？**——这件事今晚这间屋里，只有写信的人和收信的人知道。我不跟你吵，二十年了，我就想听你自己说一句：我每月一号那封"近况"，到底送上过哪张桌子。
你要的签名条我心里有数：我现在是提名票上的人，我签一张"欠建国钱一次｜烦高"，值多少你比我会算。我刚才在台上当众说了"上了票欠条不往外签"，要我为你破这个例，得拿真东西来换：**第一，那天第18洞从草上捡走、揣进怀里的那两页纸，现在在哪、写的什么；第二，冲浪板税那句实话。**两样都实在，签名条我再跟你谈数目；只给一样，咱俩还是"只碰过杯"。另外提醒你一句——最年轻的那位扶的旗杆，这话今晚已经不止我一个人知道了，你先想好怎么答，再开口。

**建国钱**：（左右看一眼，解开西装扣子，两边衣襟一摊，内袋朝他翻出来——空的）烦议员，先给你看一样不要钱的：内袋，空的。纸不在我身上，你刚才那句"揣进怀里"，过期了。
第一样，冲浪板税——**是我开的。**四月一号你那封近况，我当天下午挂上押宝网，一赔七。你写信试我，我上钩了，这账我认，不赖。二十年的信，有的我自己看，有的我卖了——我是开盘口的，消息到我手上就是行情。可你也翻翻你自己的账：你竞选账上四成，是从内华达三家信箱公司进来的——那三个信箱的钥匙，在我兜里。你的信卖出去的钱，一大半又回了你的信封。这叫对冲，不叫出卖。
第二样，两页纸。在，是我捡的。旗杆也是我扶的——四十六，最年轻，半步爹满场在送这句，不值钱了，我自己认，省得你拿它吓我。纸现在锁在一个只有我开得开的柜子里，不在会所、不在水塘、不在我身上。写的什么，先给你一行订金：**老头的东西，两页，第二页底下签字栏是空的——他没来得及签。**剩下的字，看你的笔。
开数：**三张**。两张"欠建国钱一次｜烦高"，一张"欠下木一次｜烦高"——党鞭往你信封里那三块真金白银，你台上自己认的，他托我来收这个情，跑腿费我收过了，你别问。三张DM桌前当面交，我当场把第一页写的什么一句一句说给你；第二页，等你当选那天我再跟你讲。
嫌多我让一步：两张——一张归我，下木那张不能少。再往下砍就不用谈了：你出去说咱俩只碰过杯，我出去说冲浪板税是用户自己开的，谁也不欠谁。哦对，上回你欠我的那个打听露台的人名，顺手搭上。还剩几分钟，走不走？

**烦高**：（没看那个空内袋，手指在柜台上点了三下，像在数钱）钱老板，冲浪板税你认了，旗杆你也认了，这两句我收下，记你个"认账"。内华达那三个信箱——你要捅出去，押宝网那个一赔七的盘口也得跟着见报，咱俩一根绳上的，这把刀你别往我这边比划。
数目我算过了，我给你个实数，不来回拉锯：**一张**。"欠建国钱一次｜烦高"，DM桌前现签现交。下木那份情，**我拿现钱还，2资金，DM桌前你代收也行、他自己来也行**——名字我不往外写第二张，我在台上说过的话，破一回是给你面子，破两回我这张票就不值钱了，对你也不值钱。再搭上你要的那个人名：打听露台的，是**半步爹**——你自己说的，他满场在送你的话，这名字现在也不值钱，算我两清。
条件也一句：签字之前，第一页你在DM桌前**一句一句念完**，再告诉我第二页是个什么东西——遗嘱、合同、还是给谁的信，就要个名目，不要字。念完我签；念一半，我把笔收回兜里，咱俩照旧"只碰过杯"。一张加两块现钱加一个名字，换一页半——这是我今晚最大方的价，走不走你定。

**建国钱**：（把西装扣子扣回去，笑一下，伸出一根手指晃了晃）一张。行，烦议员，你这价我认——我是开盘口的，一赔一的单子也接，只要它真。下木那2块现钱我代收，他自己不来，我一块不少转他手里，跑腿费已经收过了，不再抽你的。半步爹这名字，收下，算你两清。
但念法得说清楚，省得到了桌前你把笔收回去：纸不在我身上，我念的是我脑子里那一页，**一句一句、意思不走样，字不保证一个标点不差**——你要原件，原件那天谁都拿不出来。第二页的名目我现在就先给你，算我也出点诚意：**那不是遗嘱，也不是谁写给谁的信——是一份"交接"，老头签了，手里的东西就算交出去了。签字栏空着，所以到今天什么都没交出去。**谁写的、交给谁，第一页上有，桌前念给你。
交割这么办：DM桌前，你先把条子写好，"欠建国钱一次｜烦高"，州和票那两格空着别填，**压在你手底下，笔别放**；我念第一页，念完你手一松，2块现钱跟条子一块推过来。我念一半你收笔，我也认；你念完不松手，我出去就说冲浪板税是烦议员自己下的注。走，现在就去，别让下一位排在咱们前头。
