# 私聊6（饭点）：下木 × 建国钱

**下木**：（端着饭盒挪到你旁边那张空桌，背对大家，筷子拨着青菜）师弟，饭点不让过手，我就来对三笔账，嘴上对，不动钱。第一笔，你那页账本，六锤一洗——那一只手掌是我的。外头问起来我说我锤了，"十一个小号谁看了不恶心"，咱俩照旧是死对头。第二笔，口径得对齐，梅戏在追咱俩：你报第十八洞那组人时嘴滑喊了我半声"师……"，我替你圆成"**师爷**"——三十年前老驴友管党鞭叫师爷，你嘴急老毛病；她还问我怎么知道短信原文，我说是**拿一条消息跟你换着看了一眼原卡**，换的什么不说。谁问你，你就照这两句，一个字别多。她今晚盯的是"周四"，也盯"一块儿去"这半句，我把她往周四上引了，你那半句自己收好，别再在人前说漏。第三笔才是正事：你那页写"至尊版上线第一周来了第1号客户，账本就是它发的"。师弟，我不问你知不知道是谁，我替你算：账房那个号前年十二月注册，咱俩那张纸是前年十一月签的，差一个月。老头读了四十秒说"你们终于来了"——他不是在等咱俩，他是早把账锁好了在等。九页，八个人，多出来那一页我猜就是第十八洞，翻出来那天咱俩一个递一个捡，谁都跑不了。所以我要你一句准话：你卖锁的，后台能不能看出第1号客户锁了几页、哪天开？看不出来也行，咱俩现在就得定个说法——那页要真出来，我说"贺寿卡夹了退休建议"，你说什么？还有烦高，初选我往他信封里装了三块，开封烦高收了三，数对得上，你第三幕一开就去告诉他"党鞭给的情"，第一张"欠下木一次"签给我。我四张空白条子一张还没撒出去，撒了第一个告诉你，咱俩合起来数到三就收手——这条我认。（把饭盒盖一扣，嗓门拔高）押宝网的饭也是拿小号押来的吧？咽得下去？

**建国钱**：（不回头，掰开一次性筷子，两根互相刮毛刺）师兄，三笔我一笔一笔回，回完我也要开价，饭点不动钱，动嘴总行。第一笔，那只掌我记你账上，算你先付了一成，外头你照锤，我照骂。第二笔，"师爷"我认，可你晚了一步：皮拉提也揪了我那半声，我当时跟她圆的是"失礼了"——她说第三幕要当众问你听没听过"失礼"。咱俩合一个版本：我嘴急想喊"师爷"，一想当着电视喊对家党鞭师爷太失礼，咽回去了。两句都对，谁问都这么接。烦高那边我圆的是"死对头说急了"，也不冲突，你别再加第四版。第三笔，后台的事，实话给你：锁几页我看不到，内容我看不到，我卖的就是"连我们自己都删不掉"。但开锁那天，我花了一张条子买到了——不是十二月十八，是**十二月二十一，周二**。往前倒两周是十二月七号，那天起就没人给它报平安了，老头倒下前十一天。所以你算对了一半：他不是在等咱俩，他是早停了报平安，等着账自己出来。几页、谁是下一页，我真不知道，谁说知道谁在骗你。这条我不白给——你去礼品部翻的那堆没取的卡，看见什么原样说给我，咱俩扯平。那页要真出来，我的说法是：旗杆倒了我去扶，风把白信封刮下坡，我追两步没够着，进水塘了——跟我那天跟你说的一字不差，你也别改词，你就说"贺寿卡夹退休建议"，咱俩谁也没看清里头。还有一笔你得知道：你那颗种子在漏水。半步爹跟皮拉提说扶旗杆的是我、离洞最近的是我；皮拉提还捏着一张露台照片，果岭边一个背影弯腰捡东西。照片第三幕走廊我拿短信换来看一眼，背影是谁我第一个告诉你。你说封口费你出你谈——那就赶紧谈，别等他把你也说出去。烦高我认：第三幕一开我就去说"党鞭给的情"，第一张"欠下木一次"归你，第二第三归我；你四张条子撒出去报我，数到三收手，这条我也认。（把筷子往饭盒上一拍，嗓门比他还高）我押宝网的饭是小号押来的，你那保温杯里的威士忌是党费打的吧？咱俩谁也别嫌谁咽不下！
