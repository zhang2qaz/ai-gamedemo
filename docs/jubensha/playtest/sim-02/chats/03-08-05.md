# 私聊（终局第三轮走廊）：狗登罗 × 麦克播

**狗登罗**：（把公文包立在两人中间挡住视线，压低声音）就五分钟，我只谈账。驴友267，我们236，佐治亚16加宾州19刚好271——两州必须全拿，丢一个就结束，所以"全压宾州"这条路已经没了，钱得两头放。我手里还剩5，你报个实数，别再像内华达那样"放1"装0。我的提议：我宾州大象3、佐治亚大象2；你按你余额同样拆，宾州多放。第二件，建国钱兜里那张"别人签的名"留到宾州——要是驴友的人签的，宾州驴票白送1，你去问他收不收你的现钱买回来，我出1跟你分摊，前提是关门前当着DM的面交割。第三件，真相题卡今轮必须封进信封，我第③格还空着：第18洞扶旗那个人，你那边——老G的热线里——有没有提过谁跟他一起去棕榈湾打球？你给我一个名字，我把留着没说的那一条也给你。

**麦克播**：（把公文包往旁边一推，凑过去，嗓门压到一半——对我来说已经是耳语了）行行行，五分钟，我三十秒说完——你知道我三十秒就是三分钟。实数：**8**。没装，没藏，内华达那回欠你的我今晚用诚实还，诚实在我体系里排中间，今晚往前挪一格。拆法：**宾州大象5、佐治亚大象3**，加你的宾3佐2——宾州咱俩8，佐治亚5。第二件我不干，听我算：建国钱那张条子，咱俩掏2块买回来，宾州驴少1票；同样2块直接塞信封，宾州象多2票——买条子是花两块办一块的事，这买卖他赚咱亏，让他留着自己掏钱去，签名人掏的是他自己腰包，他要真扔驴那边，他自己也薄一块。省下的1块你加宾州。第三件，名字我没有，热线上他一个名字都没报过，这个我不编——但我有原话，独家，录播没播的：他最后一次上节目前说，"**下周我生日，两个学生陪我打最后一组，一个替我扶旗，一个给我递卡。**"最后一组四个人，老头自己不算，剩下木、半步爹、建国钱——三个人里两个是学生，一个不是。半步爹那条"第12洞除你皆其学生"的传闻你也听过，我押**半步爹是那个不是学生的**，那扶旗、递卡就是下木和建国钱各一个；同组最年轻扶旗——建国钱自己说他扶的旗，这回他可能没撒谎，那**递卡的就是下木**，周四先生，记账的人。好，我给完了，轮到你：帽檐上那两个数字加一个日期，还有你留着没说那一条，一口气倒给我，我好封信封。
