# 私聊4：建国钱（07）× 狗登罗（08）

**建国钱**：（2:16，柜台立牌摆正，那张线B6卡背面"12/21 周二 后✓"朝下压在掌心）狗律师，又是我——上一单两清，账上我认。这单我先报数再开口：老先生是12/18周六走的，触发日是12/21周二，死人不会晚三天才算死，所以不是"死了就开"那条，是另一条。往前数十四天，12月7号。你不用点头，我自己的机器，日志我回去会翻。我今天要买的是后面那截：触发是12/21，账本却是今晚1/20零点才上墙——**中间这三十天的延时是谁设的？还有没有第二批，下一页几点出？**墙上每多一页，我押宝网就得重开一次盘，这个对我值钱。
出价两样，你挑：①拍品8"最后一条短信"，全场就我手里有，原文一字不差念给你——发信人那栏被撕了，可里面有日子、有"几个人"，你当律师的一听就知道那天谁在老先生门口排队；②你要是不要情报要货——麦克播是咱大象党初选第一，提名最后说话、平票他赢，你们俩刚在DM桌前互封完，你手里要是还压着他签的别的条子，我收，**一张两块现钱**，今晚柜台最高价。再附一口小单：短信我也能单卖，**一块钱**现钱，不要条子——你只认欠条，我只认筹码，各让半步：钱给我，原文给你。

**狗登罗**：（2:17，站着，手插西裤兜没掏出来）先纠正你的算术，这句白送：12月7号是**周二**，不是周一。你按"两周没报平安"倒推，起点就得落在周一上——你这个日历拿反了，回去翻日志之前先翻日历。条款是哪条我上一单就说过不卖，今天也不卖。
你要买的那截，我如实答：**三十天延时谁设的、有没有第二批、下一页几点出——我不知道。**这不是推辞，是条款：合同里写了"起草人回避"，内容那部分我没看，这一点你柜台上那张副联也能证明，起草人栏只有我名字，别的都不归我管。你问机器的事，该问造机器的人——也就是你。
所以①②我都接不了：情报我没有，麦克播签的别的条子我也没有，刚才DM桌前当众撕的是我签给他的，不是他签给我的。
我只做你那口小单，但加两个条件，按DM口径来：一、DM说过拍品卡**能出示**——我不听念，我要**看卡**，你压在掌心我看完就还，不碰、不拿；二、我看完当场给你**1资金**，看之前不给。看见卡上"几个人"那一栏要是被你手指挡着，算没看，钱不给。你同意，就现在把卡翻过来。

**建国钱**：（2:18，嘴角一撇，把手掌从卡上挪开半寸又压回去）狗律师，你那句白送的我退回去——我从头到尾只说了"12月7号"，没说过周一，你纠的是你自己脑子里那个数。不过日历我收下了：周二倒推周二，正好十四天，一天不差，谢谢你帮我对账。
行，三十天延时你不知道、条子你也没有，那今天就做小单。条件我认，但柜台规矩也得有一条：**钱先放桌上，压在我立牌底下，我不收；卡翻过来你看，看完我拿钱，你拿眼福。**你不碰卡，我不碰钱，谁也不吃亏。卡两面都给你看，我手指头全拿开——也省得你说"几个人"那栏被我挡了：没那一栏，上面是两个字"我们俩"，你自己数。
看完别急着走，再白搭你一句，算我请：起草人回避我信，可**签委托、交钱、按月点"我还活着"的那只手**总得有人见过吧？绿茵管家是谁上门办的，男的女的、几个人来的——你不用答我名字，就告诉我是"一个人"还是"两个人"。答了，下一单我按八折给你。来吧，翻了。（把拍品卡正面、背面依次摊在桌上，双手离开桌沿）

**狗登罗**：（2:19，从西裤兜里抠出一枚筹码，弯腰——没弯下去，改成伸长胳膊——塞进立牌底下）12月7号那句我收回，你确实只说了日子，没说周一，是我替你多想了一步，这条记你账上。
钱压好了，**1资金**，从这一秒起不归我，也还不归你，等我看完。（俯身盯卡，正面看完，抬手示意翻面，背面看完，直起腰）看完了，两面都看了，手指没挡，这单两清——你拿钱。我不复述卡上任何一个字，你也别在外头说"狗登罗看过短信"，看过不等于认了。
你白搭那句，我答一半：律所前台登记的是"绿茵管家"派来的**一个人**，代理人身份，签委托、交定金都是他。男的女的、长什么样、后来"我还活着"是谁来点的——不在这一半里，那是下一单，八折的话你先报价。还有，"按月"是你说的，我没说过，别记我账上。
