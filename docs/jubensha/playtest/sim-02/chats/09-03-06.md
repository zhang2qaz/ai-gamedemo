# 私聊9：下木 × 半步爹

**下木**：（这回是我走到他椅子边，没让他站，自己拉了把椅子挨着坐下，保温杯放在两人中间，声音压到只有他听得见）辩论你指了皮拉提，一样是驴友那张，谢了。就两件事，我说完你答，答完我还得去接烦高的热线。第一件，你上回问我递的到底是什么，我拿"贺卡""退休建议"糊弄你两回——今晚我照实说：信封里是"Happy 78"卡，卡里夹两页纸，是一份交接书，请老先生把他手里管了三十年的生意、签字权、账本，交出来，退休。上面有我的签名。他读了四十来秒，说"你们终于来了"，就倒了。这是我欠你的实话，就这一回，出了这把椅子我不认。第二件，换你一句实话：那天果岭上，弯腰把信封和那两页纸塞进西装里的那只手——是不是建国钱？你不用说名字，是，你就把手放到保温杯上；不是，就别动。还有，内华达这轮你那块"2"，放驴友那张，烦高和皮拉提，你辩论都指过他们了，不算我逼你。

**半步爹**：（盯着保温杯看了好几秒，手慢慢放上去，没拿开）……嗯。（声音很小）那个"2"，我本来就打算放驴友那张，不是因为你说。……老木，你那两页纸上，签名就你一个吗？

**下木**：（看着他的手在杯子上，没动，过了两秒才把杯子往自己这边挪回来）……就我一个。党鞭的字，一个就够分量。（停一下，声音更低）他弯腰捡，不是因为上面有他的名字，是因为他比我先看明白那两页纸值钱——这事我自己去跟他算，你别碰，也别跟梅戏、别跟任何人提今天这把椅子上的话。你那块"2"，后面两轮也照这么放，你说不是因为我，那就更好，记你自己的账。（站起来拍了下他肩膀）生日快乐，五十八了，老实孩子。我去接热线了。

**半步爹**：（他已经站起来了，我才开口，声音小得差点听不见）……老木。今年……我没给你写近况。以后也不写了。（低头看自己的手）那个"2"……我放我自己的。你别再寄卡了。
