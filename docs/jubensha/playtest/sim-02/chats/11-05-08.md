# 私聊 11：麦克播 × 狗登罗（终局第二轮走廊）

**麦克播**：（一屁股坐下，帽子往桌上一扣，先举手投降）先自首，律师别记笔录——内华达我说"放1我出"，信封里装的是0。打开一看大象2，就建国钱那块圆片，咱俩一个子儿没进，我猜你也是等我先掏，对吧？行，这口锅我背，节目里我管这叫"战略性哑火"。但你听我算完这笔账就知道哑得值：驴那边开出20，撑场6加条子1，**他们自己往信封里塞了13块钱**，就买了6分。他们现在242，还差28；咱236，差34。
（掰手指）剩下四个州：威斯康星10、密歇根15、佐治亚16、宾州19。我算了三遍——**密歇根咱拿下，251，接下来只要宾州一个就是270整**；而驴那边没了密歇根，威斯康星加佐治亚才26，凑不够28，他们也必须拿宾州。等于宾州一局定生死。密歇根要是丢了，咱就得宾州加佐治亚两个全拿，那就是做梦。所以我的提案就一句：**这轮威斯康星一分不放，全压密歇根大象。**
我出多少你说个数——我家底两位数，这轮我打算往密歇根装**7**，留的全给宾州；你个位数，密歇根跟1到2就行，剩下的连同兑我帽檐那张"宾"的1块，全攒宾州。
三件事你这三分钟替我办：一，建国钱那块内华达放了大象，按你说的"第二轮走廊付第一轮那块"——这1块你付了没有？付的时候让他这轮圆片放**密歇根大象**，别放威斯康星。二，扶旗那格你说问完建国钱告诉我，现在问完了吧？三，DM刚才嘴里漏的那个余额，你离得近，听见是谁、多少没有？别跟我讲律所不出具——这是对手的家底，不是你客户的。

**狗登罗**：（站着，没坐，公文包立在脚边）先更正笔录：内华达你说"放1我出"，记录在案，结果是0——这不是战略性哑火，这是违约，我记下了，不追究。你的账我核过，没错：密歇根拿下，宾州就是一局定生死。威斯康星一分不放，我同意。
你那三件事，按顺序答。
一，建国钱那块我**不付**。4:30DM裁定：我跟他那单没有两人一起到桌前交割，**不执行**。他第一轮那块"白放、记账"，DM当场说了不记、不算交易。我付了就等于自己承认一笔DM都不承认的账。这轮我可以再找他，条件不变：他当众放了密歇根大象，我第三轮走廊付1；不先付。另外他刚在走廊想让你签"欠建国钱一次"，说"收藏不投"——**沼泽的收法**。他后来撤了单，但我还是给你一条法律意见：今晚谁递过来空着州票的条子，你一个字都别签。
二，扶旗那格：建国钱自己说的原话，"第18洞那天我扶着旗杆，就在洞边，没别人"。他说的，我没核实。我手里有一样东西跟这句对不上——帽檐上两个数字，外加一个日期。**你先给我一个名字**：每周一零点打你热线、第一句"今天果岭很快"、去年12月中以后再没打来的那个老听众，是谁。你说名字，我给你数字和日期，当场，现在。
三，DM当众说了"不算公开信息、别外传"，那就是规则。我不转述。律所不出具不是因为客户——是因为DM说了。
钱：我这轮密歇根大象跟**2**，你的7照装，别再写一个装一个。另外——我手里建国钱签的那张条子，**这轮就用在密歇根大象**。第三轮他兜里要是空了，条子退回来，没有第四轮，就是废纸。宾州那份我另外攒：信封里的，加上专兑你帽檐那张"宾"的1块，不动。

**麦克播**：（帽子从桌上拿起来，又扣回去）行，违约记下了，大律师不追究，我节目里给你播一期《论前妻的宽宏大量》。钱的事定了：**密歇根大象我装7，你装2，建国钱那张条子在欠条环节当众砸密歇根**——咱这边10块起步，建国钱圆片要是也放象就是12。威斯康星一分不放。空着州票的条子——放心，我三张空白欠条揣兜里揣到发霉，一个字不签，这事上我比你还律所。
（压低嗓门，这辈子头一回压低）按我的规矩该你先说——不过12月13日你早就点过头了，那一格之后是空的，算你已经先说了一半。剩下一半我认。名字给你：**游游·两头吃**。Golf的G，六年，每周一零点准时打进来，第一句"今天果岭很快"，跟我吵亚里士多德吵到天亮。最后一通**12月13号周一凌晨零点四十**，挂电话之后录音里还有4秒，他自言自语一句——"天一亮，还得去签个字。"12月20号那周一，线没亮。（敲桌子）好，我说完了，一个字没少。现在轮你：**帽檐上那两个数字、那个日期，当场，现在。**念完你顺手告诉我一句——那顶帽子是谁的？是不是第18洞那天扶旗那人头上的？要是建国钱说"扶旗杆、没别人"跟你那日期对不上，那就是他撒谎，我第三轮就不指望他那块圆片了，宾州得多压。

**狗登罗**：（还是站着，从公文包内袋抽出一张折好的便签，没递，照着念）名字收到，"游游·两头吃"，记录在案。你多给了一句"天一亮，还得去签个字"——我不欠你找零，但我按原价多付一格，算律所的诚信溢价。
第一，**数字是"18"**。每周一来我们律所签字的那位老先生，帽檐绣的就是"18"，帽子侧面一棵棕榈树——棕榈湾会员帽，打满一百场才发。
第二，**日期是去年12月13日，周一**。前台录像里他最后一次来签字，就是那天上午。你那通电话凌晨零点四十挂的，"天一亮还得去签个字"——他说到做到，签完了。下一个周一，12月20日，前台没人来，你那条线也没亮。两边对得上，一天不差。
你问帽子是谁的。我只出具我看过的东西：会所监控我放大过，第18洞扶旗那人，帽檐也是棕榈树加"18"。是不是同一顶、是不是同一个人，录像上看不见脸，**我不出具结论**。但建国钱跟我说"旗杆是我扶的、没别人"——他要是没有那顶一百场的帽子，这句话就有问题。你自己判断，第三轮宾州多压，我不反对。
钱照刚才定的：密歇根大象，你7我2，建国钱那张条子欠条环节当众砸密歇根。威斯康星一分不放。还有——你帽檐那张"宾"，第三轮我那1块已经单独装好了，不用催。散会，到点了。
