# 私聊 2：麦克播（05）× 狗登罗（08）

**麦克播**：（把胸兜里那张四折餐巾纸掏出来一角晃了晃，又塞回去，嗓门压到七十分贝）前妻同志，上回的账两清，这回是第二幕的新单子，我说快点儿，三件。第一件，初选：大象党报上我第一、半步爹第二，这回塞钱写名字是暗的，我不能写自己——我写你，装一块；你写我，装一块，谁也不亏，就是一票换一票，跟上回那张条子一个性质，生意，不是表态。你要嫌半步爹憋着的钱多不敢站队，你就当是投资，五月一号续约的时候我节目给你涨价。第二件，问你一句话，私下问，外头我一个字都不提：二月第二个周三选题会，你说过一句"账房懂合同"，说完翻文件翻得跟洗牌似的——我认识你十年，你翻文件快就是说多了。我不问账房是谁，我就问：十二月二十一号"自己动了"的那个东西，是不是一份**按页、按日子往外发**的东西？是，你点头；不是，你摇头；不知道，你就说"起草人回避"，我也认。第三件，老头子七十八岁生日那天想收什么礼，你听他提过没有？——这三件你挑着答，我拿一样硬货换：我手里有一盘老G的录音，里头有一句是他亲口说他自己是什么人，跟"打球"有关，你点完头我贴你耳朵说。别跟我说附件三，今天收费我认，我按句付。

**狗登罗**：（没接餐巾纸，站着，手指在桌面上点了三下，一件一件）三件，我按条款回。
第一件，初选。你说"谁也不亏"，这句不成立。规则卡原文：收到钱最多的是第一名，"平局民调高的胜"——你民调4，我3，咱俩互装一块，一比一平局，第一名是你，我白垫一块给你当垫脚石。所以这单不是一票换一票，是我替你买第一名。我可以买，但要加价：**你把我上回签的那张欠条还我**——当面撕或者交回我手里都行。条子回来，我纸条写"麦克播"，装1，你写"狗登罗"，装1。条子不回来，我装0，写谁不告诉你。还有一句丑话：信封是暗的，DM不当众拆明细，咱俩谁少装一块谁都查不出来，所以我要你同意走DM——交信封前一起举手请DM记一笔"05、08互写、各装1"，他核了再算，不核咱就当没谈。
第二件，你问的那个"东西"是不是按页、按日子往外发——起草人回避。（停两秒）这是你自己给的选项，我选它，不算不答。我只补一句公开的：账本第二页落款是"下回聊聊"，下回。你自己数。
第三件，老头七十八岁想收什么——我没听他提过，不编。这件我不收你钱。
所以你那盘录音，我答了一件半，你按句付：贴耳朵，一句，他说他自己是什么人。说完咱们外头接着骂，五月一号的涨价写进续约意向书，口头的不算。

**麦克播**：（"啧"了一声，手掌在桌上一拍又收住，音量自己拧回七十分贝）行，狗大律师，算账算到我民调上去了——4比3平局我吃第一，你说得对，这单是你替我买第一名，我认，老子做生意不赖秤。条子我还你，但得按你的规矩来，你的规矩我也加一条：交信封之前咱俩一起举手请DM记"05、08互写、各装1"，**DM点头记上了，我当场把你签的那张条子撕给你看**；DM说这种事他不记、不核，那这单作废，条子还在我胸兜里，咱俩谁也不装，各写各的，回头也别说我没诚意。成不成，就这一句。
第二件你选"起草人回避"——好，你这回避回避得比点头还响。"下回聊聊"，下回，我会数，一页一个日子，第二页是我，下回是谁、哪天，我自己盯，不再问你，省得你又翻文件洗牌。第三件你说没听过不编，我信，这件不收钱也是你的规矩，我记下了。
录音，一句，我按句付，现在付。（凑过去，压到四十分贝）三年前，周一零点，他原话："打球的老先生，其实只有一个，就是我。四个人一组，我出钱，他们出汗。"——就这一句，第二句我不卖，别问。
（退回来，嗓门复位）续约意向书我写，"涨价"两个字我亲手写，数字写"待议"——你教我的。出了这门你照骂，我照骂，明天节目第一句我已经备好了。走，找DM去。

**狗登罗**：（听完那句录音，没点头也没摇头，掏出笔在自己手背上记了"一组四人"四个字，又用袖口盖住）录音收到，一句，两清。
你加的那条我接受，我复述一遍，免得到时候各说各的：一、交信封之前，咱俩一起举手请DM登记"05、08互写、各装1"；二、DM点头记上，你当场把我签的那张欠条撕了，撕完我们各自装；三、DM说不记不核，整单作废，条子留你那儿照旧有效，各写各的，谁也不欠谁一块。三条，少一条都不算。
续约意向书写"待议"——行，这两个字是我发明的，我认。但你记着，"待议"的意思是"我还没答应"，五月一号我还是要坐下来谈的。（顿了一下）……站着谈。
走吧。出了这门，你嗓门开到九十，我回你一百。
