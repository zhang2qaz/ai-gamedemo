# 私聊（终局第3轮走廊）：下木 × 建国钱

**下木**：（拎着保温杯坐到你柜台边，背对全桌，声音压到只有你听得见）师弟，五分钟，我只说要紧的，四件。第一件，你内袋那张"别人签名"的条子——谁签的？是烦高，你**千万别在宾夕法尼亚花**。驴友267，只差3分，佐治亚宾夕法尼亚随便拿一个就当选；你一花，条子撕了，翻心那一刻就少一张，咱俩白忙一晚上。留着它，比19分值钱。第二件，烦高跟我说他3:51在DM桌前掏了2块交你替我代收，DM台账上没有——他是在糊弄我，还是你俩背着我做了什么？一句话，我不追。第三件才是正事：咱俩现在一起去找烦高，你是他每月一号收信的老朋友，你开口他听。我兜里还有5块，全给他，他在我两张白条上签"欠下木一次"，加你那张就是三张，四点五十二前到DM桌前当面交割。他怕掏钱——你告诉他，这三张咱俩一张都不交DM兑现，他一分不出。第四件，皮拉提要来问你"Happy 78递之前拆没拆、夹没夹别的"，口径就一句：**卡里只有卡**，你说别的我就圆不上了。还有，纸——你答应过翻心前给我一句准话，就是现在了。（拧开保温杯，大声）看什么看，党鞭来跟对家要酒钱，不行啊？

**建国钱**：（手指敲着柜台，像在报价，声音压得比你还低）师兄，四件我按你的顺序回，一件一个价。第一件，烦高那张条，内袋，**宾州不花，攥到开票**——我当众喊"好钢留到宾州"是喊给全桌听的，宾州我会说"驴友稳了不必花"。第二件，没糊弄你：3:51烦高确实当着DM推了2块过来，说是还你那份情，DM台账记在我名下，是我拖着没转——这不叫背着你，叫我替你"保管"了两轮。等会儿一起去DM桌，我当面过给你，一分不抽。第三件，这单我劝你别做：烦高刚才私下已经跟我把话挑明了——"规则书上沼泽怎么赢你我都念过"，**开票前一张名字都不签**，还威胁我宾州要是拔他的条投大象，他就当众说"建国钱攥着烦高的条"。你拿5块去找他，钱他照收不收不知道，条子他肯定不签，反倒把你也送到他眼皮底下。他还追问"老头的两个学生是不是一个驴友一个大象"——我摇头，说另一个跟我坐大象党长桌。**你记住这口径**，别让他把你和半步爹对上。你那5块加我还你的2块，一共7块，砸进宾夕法尼亚驴友信封——烦高先得当选，他签的条才算账；当选以后、翻心以前，那才是收签名的时候，到时候他是总统，咱俩一个出钱一个出面，价钱我来谈。第四件，皮拉提来问，我就一句"卡里只有卡"，记住了。最后，纸，我给你准话：**没有水塘。那天旗杆一倒，第一个冲上去的是我，信封和两页纸我揣进了内袋，现在锁在骑墙大酒店我套房的保险柜里。第二页老头的签字栏是空的，他没签。**骗你是我不对，但纸一直在咱们手里，没丢。——我说了你想听的，你也给我一句：你撒出去的白条，到底谁签了？咱俩手里现在一共几张能算账的？（然后大声）酒钱？想得美，党鞭也得排队！

**下木**：（拧上保温杯，手指在柜台上点了两下，像在对账）师弟，先答你：我撒出去的白条，**一张都没人签**。四张空白还在我兜里，烦高两次都没签。所以咱俩能算账的，就你内袋那一张——一张。你的"当选以后、翻心以前再收"那套，我替你翻过规则书了：开票完就是"当选总统和副总统先翻心，再全员翻心"，中间**没有走廊**，DM刚才也说了关门后一路撑场、欠条、装钱、念第9页、开票。烦高一当选，他第一个翻心，咱俩连跟他说句话的空都没有。要收，就是这五分钟，过了四点五十二，沼泽这局就是一张纸。第二，你那2块——DM第一轮完了我当面问过，台账上3:51烦高没交给你任何东西。你别跟我说"保管"。现在跟我去DM桌前，你把2块过给我，我就当你没说过这句；过不了，我就知道烦高跟你是一伙对我的。第三，烦高那边我不跟你抬杠，你不去，我自己去：我出5块，加你那2块，7块，换他一张——就一张，签"欠建国钱一次"也行，签你名下，我不抢。他怕你宾州拔他的条？你当着他面把那张条子还给他看一眼再收回来，告诉他咱俩谁都不兑现。他要再不签，那就是他想让咱俩输——你是他上线，你心里该有数了。第四，纸的事，我记下了：保险柜，第二页老头没签。老头没签，那交权书就是废纸——那他"终于来了"等的是谁，你比我清楚。翻心以后，我要看那两页。（大声，拍柜台）行，排队就排队，酒钱我记账上，利滚利！

**建国钱**：（把计算器往你那边一推，屏幕上是个"2"）师兄，账不跟你吵——DM怎么跟你说的我不管，3:51烦高推过来那两块就在我信封里，现在就过：走，DM桌前，你点头我点头，**2块当场给你**，一分不抽，台账有没有那行，从这一刻起都有了。白条的事听明白了：咱俩手里能算账的就一张，没有中场走廊——行，那就按你的，这五分钟收。但我改一下你的价：烦高不缺心眼，缺的是宾州的钱，他怕的不是签名，是咱俩拿他的条子去兑现掏他的钱。所以咱俩**一起去**，我先把内袋那张当他面亮一下再收回，说"三张都不进DM的箱子"；你出5加我刚还你的2，我再添3——**10块现钱，换他两个签名**，一张"欠下木一次"，一张"欠建国钱一次"，钱他自己装宾州驴友信封，等于我们替他买当选。他十块都不收，那就是他想看咱俩输，那时候我不护他了。还有，第8页我出的是手掌，那一掌算我先还你的利息。纸的事，翻心以后两页都给你看——老头"终于来了"等的是谁，我也想了一晚上，等完事咱俩对着那个空签字栏慢慢算。（大声，把计算器收回去）酒钱？利滚利我认，先付本金两块，走，去DM那儿当面清！
