# 私聊（终局第3轮走廊）：下木 × 建国钱

**下木**：（拎着保温杯坐到你柜台边，背对全桌，声音压到只有你听得见）师弟，五分钟，我只说要紧的，四件。第一件，你内袋那张"别人签名"的条子——谁签的？是烦高，你**千万别在宾夕法尼亚花**。驴友267，只差3分，佐治亚宾夕法尼亚随便拿一个就当选；你一花，条子撕了，翻心那一刻就少一张，咱俩白忙一晚上。留着它，比19分值钱。第二件，烦高跟我说他3:51在DM桌前掏了2块交你替我代收，DM台账上没有——他是在糊弄我，还是你俩背着我做了什么？一句话，我不追。第三件才是正事：咱俩现在一起去找烦高，你是他每月一号收信的老朋友，你开口他听。我兜里还有5块，全给他，他在我两张白条上签"欠下木一次"，加你那张就是三张，四点五十二前到DM桌前当面交割。他怕掏钱——你告诉他，这三张咱俩一张都不交DM兑现，他一分不出。第四件，皮拉提要来问你"Happy 78递之前拆没拆、夹没夹别的"，口径就一句：**卡里只有卡**，你说别的我就圆不上了。还有，纸——你答应过翻心前给我一句准话，就是现在了。（拧开保温杯，大声）看什么看，党鞭来跟对家要酒钱，不行啊？
