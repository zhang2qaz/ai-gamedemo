# 私聊1：下木 × 建国钱

**下木**：（拎着保温杯晃到柜台边，背对全桌，声音压得只有你听得见）师弟，外头我骂你那几句别往心里去，电视宿敌嘛，账要做平。就三件事，时间紧我直说。第一，那张纸——棕榈湾那天，真是被风吹进水塘了？你看着我说。第二，你兜里那张记分卡、那条短信，给我瞄一眼，我不白看：我这儿有四张空白条子，四个能上提名票的名字——皮拉提、烦高、麦克播、半步爹——咱俩分了收，谁收的都算咱俩的。半步爹和烦高我去，那俩跟我熟；麦克播和皮拉提你去，你有钱，我手里就剩五块，你别跟外人说。第三，烦高今晚七件拍品抢了六件，他是替你拍的，还是自己在查第十八洞？要是他自己在查，咱俩得先对口径。

**建国钱**：（手肘撑柜台，脸冲着账本，嘴几乎不动）师兄，先说结论：你那账分错了。第一，纸——吹进水塘了，我看着你说，吹进去了，水塘那天风多大你也在。这事别再问，问多了外人看出咱俩有话说。第二，卡给你"瞄"，不收你钱，自家人。记分卡正面就是四个人的岁数——老头78、你61、半步爹57、我46，你本来就知道，没新东西；短信我原样念给你："老师，周六见。我们俩一起来。"发信人那栏撕了。（压低）师兄，十二月十八号是周六。这条是不是你发的？要是你发的，这张卡得一直烂在我兜里，谁问都别认，"我们俩"三个字一算就算到咱俩头上。第三，烦高七件只拿了一个推杆，其余全是喊价抬价，他抬谁的价你心里有数——他在抬你的。他刚才盯我兜里的卡，冲我来的，所以**烦高归我**，我顺手应付他、顺便摸他底；你去半步爹和皮拉提——皮拉提刚播完揣着7块，正是能签条子的时候，你那张"不记仇只记账"的老脸她吃。麦克播也归我，他要拿"老G"换我念卡，我念正面岁数糊弄他。还有两句实话：一，我拍卖梭哈了，兜里是**零**，你别指望我垫钱，柜台是空架子，别说出去。二，四个人一人签一张没用——赢要**同一个当选的人**签够三张，现在谁上提名票都不知道。先别乱撒条子，今晚就收"人情"，让他们嘴上欠着；第三幕提名一出来，咱俩把手里空白条全砸到那一个人身上。行不行，点个头，然后骂我一句"奸商"再走，演给他们看。

**下木**：（拧开保温杯抿一口，眼睛看着别处，像在挑柜台上的毛病）短信不是我发的。我订的是一张"Happy 78"，当面递的，用不着先发短信报到——老头接卡说的是"我还以为你们今年忘了"，你记得吧？他压根没等我的短信。那"我们俩一起来"是谁跟谁，你心里比我清楚：你要说也不是你，那这屋里就还有一对"我们俩"，比咱俩早一步敲了老头的门。卡你揣好，别念，谁问都说正面就是岁数——这点我跟你一条心。纸的事我不问了，七成就七成，你记着我是信了你七成的。分工我认：烦高、麦克播归你，半步爹、皮拉提归我。但"先别撒条子"你算错一半——四个人里最后只有一个当选，我今晚先每人收一张，压中谁谁就已经欠咱一张，第三幕再补两张就够三张，比到时候临时求人便宜。我手里四张空白，你自己那三张也别赔给狗登罗，她在抢咱生意。你兜里是零我不说出去，我兜里是五你也别说。（把杯盖一扣，提高嗓门）——奸商！柜台上摆的全是假账！

**建国钱**：（啪地合上账本，冲外头翻了个白眼，嘴还是不动）行，奸商就奸商。三件事我收尾。一，老头那句话你记岔了——我站得比你近，他读完卡说的是"你们终于来了"，不是"忘了"。"终于"，师兄，意思是他在等人。等谁？短信那对"我们俩"。你说不是你，我信你——信你八成，比你给我那七成多一成，这账你欠我的。二，"每人先收一张"我让一半：你那四张撒半步爹、皮拉提，随你；烦高那张我来收，你别碰，他找你签你就推给我。麦克播我先不给条子，他兜里就剩一枚，签了也掏不出那1资金，空头条子我不收。三，半步爹你重点盘——拍卖他出到10，嘴里漏了一句"那是我的……那天的卡"，他那天跟老头之间有事。你去问他十二月中旬有没有给老头发过短信、跟谁一块儿去过。问出来，这一条就算你还我那一成。我那三张一张都不卖给狗登罗，我还想收她那两张雪茄盒的呢。去吧，骂大声点。
