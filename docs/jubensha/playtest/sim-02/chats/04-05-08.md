# 私聊（终局第三轮走廊·第二次）：麦克播 × 狗登罗

**麦克播**：（又从侧边挤过来，帽子摘了攥手里，嗓门这回是真压低了）别瞪我，账上一个字不改——宾州大象5、佐治亚大象3，我刚才在走廊角落里已经背着人把八块按两堆码好了，信封开出来少一块你当众念我。我回来就三件事，三件加起来不超过一分钟，你掐表。第一，DM刚才那串流程里有个"**最后指认**"——撑场、欠条、装钱、然后最后指认、然后第9页。我翻遍规则书没找着这四个字，指谁？指沼泽？指递卡的？还是又是提名那种伸手指人？你是律师，你那份规则卡上要有写，念给我；要是你也没有，咱俩先对好：只要是指"谁是沼泽"，咱俩一起指**建国钱**——他想让我签"欠建国钱一次"、收藏不投，刚才又当众挂牌收别人签名的条子，这就是沼泽的吃相。第二，平票：州里平了看两张提名票民调和，咱俩现在我4、你被锤掉一格，驴友那边烦高加皮拉提少说十往上——**平了就是输**，所以佐治亚、宾州都得多一块，不是平一块。你那3和2要是还有哪怕一块零钱没装，别留，留着没用，DM刚说的。第三，不是账：账本还剩最后一页，没被单独写过的人里有我。要是第9页念的是我——老G、热线、牛排馆后门那个"游"字——我那六十秒不打算再拍桌子说"老子念过菜谱"了，我想站着把那句实话说完。可那一说，蛋白粉那份合同第七条就算我违约，起草合同的是你们律所十四楼。所以我先问你一句，就一句：我要是在台上把粗人这身皮脱了，你那边扛不扛得住？你说扛不住，我就继续嚷嚷到五月一号。

**狗登罗**：（看了眼表，没坐）一分钟，我按条答。第一，"最后指认"四个字规则书里确实没有——但终局规则卡第3条原文："第三轮收完信封，**每人说一句四题答案（不计分）**，再念第9页、开票。"位置一模一样，夹在装钱和第9页中间，我按这条理解：就是每人把真相题四题答案说一句，**不计分**，不是提名那种伸手，也不加减民调。所以你说"一起指建国钱"，我可以说，反正我卡上第④题本来就写的他，已经封进信封了；但我不替你保证它有用——不计分的东西，指了也就是给账房听个响。我待会儿当众再问DM一遍"最后指认＝规则卡第3条那句话吗"，以DM口径为准。第二，平票：我没零钱了。五块全在单子上，宾州象3、佐治亚象2，一块没留，跟刚才说的一样，开封你可以数。第三——（停了两秒）你那份合同，第七条，我们律所十四楼起草的，我比你清楚：**今年五月一号已经到期了**。续约意向书在我公文包里，我写的"待议"，没签，你也没签。你现在没有合同可以违约。所以扛不扛得住这个问题不成立——没有需要我扛的东西。……（声音低一点）你要在台上说实话，就站着说完。我站过九个小时，站着说话不丢人。至于每周三，我到点了也会去，跟第七条没关系。就这些，时间到了。

**麦克播**：（愣了一下，把攥皱的帽子又展平）……五月一号。对，五月一号。我自己本子上写着呢，那天我还在你们楼下电梯口站了十四分钟——我刚才是嘴比脑子快，把"答应老G永远不说"那个约跟蛋白粉那个约搅成一锅了。行，律师说不成立就不成立，我认，这一条算我念错菜谱。最后指认我按你的口径：规则卡第3条那句，每人说一句四题答案，不计分，不伸手。我那一句就照咱俩信封里那份说——①老先生自己拧的闹钟，②递卡下木，③扶旗建国钱，④沼泽建国钱，一个字不加，不给账房多送料。你去问DM的时候我在旁边听，DM要是说不一样，咱俩当场再对一眼，不用再出来。钱：宾州大象五、佐治亚大象三，八块，码好了，平了就是输我也不留一块。最后一句不是账——第9页要是念到我，我就站着说完，不拍桌子；要是念的不是我，那句话我留到下个礼拜三，三点前到，不让你看表。（戴上帽子往回走）时间到，我闭嘴。头一回。

**狗登罗**：（看表，收起）四十秒，你超了，但"头一回"我记账上，算抵。口径对上了：最后指认＝规则卡第3条那句，四题答案各说一句，不计分；DM要是口径不一样，以DM为准，我当场举手问，你别抢话。我那份跟你一字不差：①老先生自己，②下木，③建国钱，④建国钱。钱：我信封宾州大象3、佐治亚大象2，五块，现在就封。——还有一条，作为你前任的法律顾问，免费：下礼拜三三点，迟到一分钟我照样走。去吧，站直了。
