# 私聊11：皮拉提 × 下木（终局第二轮走廊）

**皮拉提**：（拎着锅铲"否决"一屁股坐到下木旁边，压着嗓子但压不太住）党鞭！两件事，一件公的一件私的，三分钟我只占您一分半。公的：您那块"2"，这轮请放**密歇根·驴友党提名票**——密歇根15分是咱俩家的命门，威斯康星丢了能活，密歇根丢了今晚就凉。您放了，我当众喊一句"党鞭撑的"，功劳记您头上。私的——（锅铲往桌上轻轻一磕）去年十二月，党鞭办公室给老头寄没寄一张白的"Happy 78"？您上回在台上没答，我不怪您。我换个问法：老头倒下前二十分钟在第十七洞打过一个电话，说"**他们**说，到第十八洞再把礼物给我"——"他们"，是两个人。那天陪他走到十八洞的就您、半步爹、建国钱三个。您跟我说实话，那张白卡是谁从您办公室拿走、谁递到他手上的；我真相题那一栏就不写您名字，这句电话我今晚也烂在肚子里，不当众念。您要是说"记不清"——（咧嘴）那我就当您答了一半，剩下一半我自己填。

**下木**：（把保温杯往她锅铲旁边一推，声音比她还低）副总统，公的那件不用谈——密歇根驴友党那张，我本来就放，"党鞭撑的"这句您喊不喊都行，我不图功劳，图您欠我个面子。私的我给您全的，不给半个：白卡是我办公室订的，Happy 78，我亲手递到老头手上，没人从我那儿拿走，第十八洞一圈人都看见了，这个我上台也认。"他们"——老头叫了三十年，党鞭办公室在他嘴里就是"他们"，订卡的是我助理，递卡的是我，两个人，对得上吧？您想往建国钱、半步爹身上数，那是您的笔，我不拦，但别说是我讲的。我换您两样：一，第十七洞那通电话今晚烂在您肚子里，真相题别写我；二，您手里那张露台照片，弯腰那个背影，您认出是谁了没有？告诉我一个名字，我第三轮那块"2"也还放您这张票上。成交您就点个头，不成交——（笑）党鞭也只当您答了一半。

**皮拉提**：（盯着保温杯看了两秒，锅铲在手心转半圈，突然一拍大腿，又赶紧压住嗓子）党鞭！您这口供太利索了，利索得我都想给您鼓掌——助理订、您递，两个人，"他们"，严丝合缝。行，我点头。（真点了一下）第十七洞那通电话今晚我不当众念，真相题那栏——（手在胸口比了个拉链）我的笔我自己管，您放心。照片那个弯腰的背影，我给您一个名字，但我只说一遍，说完您别回头看人：**建国钱**。离旗杆最近、扔了旗杆冲上去的就是他，背影的肩膀跟他那身西装一个线条。（凑近）可我白给您这个名字，您得让我值：一，您那块"2"这轮**密歇根驴友**，下一轮**宾夕法尼亚驴友**，两轮都放，关门前我盯着您落桌；二，就一句——那张Happy 78，您递之前**拆没拆过、里面除了烫金字还夹没夹别的东西**？老头低着头念的是"你们终于来了"，那可不是贺卡上印的字。您答了这句，咱俩今晚就是一个锅里的人；您不答——（咧嘴，锅铲在桌上轻磕一下）我就当您答了一半，剩下那半我去问建国钱，他嘴可比您松。
