# 私聊8：半步爹 × 下木

**半步爹**：（走到绿萝边，没坐，站在他椅子侧面——不是身后——手攥着西装下摆，声音很小）老木……我就问一句，问完就走。（咽了一下）你是不是老先生的学生？

**下木**：（没抬头，拧开保温杯盖又拧上，指了指旁边那把椅子）坐下，站着更像有事。学生？（笑了一声）我是他饭友，欠他一顿牛排，这辈子还不上了。上回我说"学生给老师贺寿"，那是客气话，老人家七十八，谁不算他学生。……谁让你来问这句的？你今晚拆的那封信里写了？还是皮拉提问你的？跟我说是谁，我好知道风从哪边吹。（声音再压低）刚才狗登罗那三个字你别慌。"不一致"不分驴心沼泽，他也就知道个"不一致"。有人问你，你就一句："我的心埋在佛罗里达了。"多一个字都不说，让他们自己去猜你是哪一种——猜得越乱越好，别往驴友党那边猜就行。还有，你那块圆片，终局放驴友党，放烦高那张票上；这不是我要，是你自己的安全——大象党这回赢了，第一个要清理的就是刚被背调翻出来的人。生日红包那一块还给你留着，不用签条子了，什么时候想要，咱俩去DM桌前，当面给。

**半步爹**：（没坐，手还攥着下摆）……没人让我问。我自己想问的。（停了一下，声音更小）饭友……好，我记住了。圆片放哪儿……我、我到时候再看。红包——不签东西的话，那我收。现在就去DM那儿吧，我怕待会儿又不敢了。
