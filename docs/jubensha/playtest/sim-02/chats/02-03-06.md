# 私聊2：下木 × 半步爹

**下木**：（端着保温杯在绿萝边坐下，拍拍旁边那把椅子，嘴唇几乎不动）坐。别站我身后半步了，三十年了还这样，让人看见。先说句私事——再过三个多钟头你五十八，今年那张白卡我照样寄；广告那会儿我给你竖了拇指，你领的那三块里有我一块。好，正事，三件，时间紧。第一，第十八洞那天你站四米外，你看清了什么？我要听你眼睛看见的，不是台上那句"推杆线"。第二，师弟手里有条短信："老师，周六见。我们俩一起来。"发信人那栏撕了。是不是你发的？跟谁一块儿？跟我说实话，我替你瞒，外头谁问都是"不知道"。第三，（把一张空白欠条压在保温杯底下推过去）签个名，"欠下木一次"，条子我揣着，不到要紧时候不动。你拍卖冲了两回顶，麦克播又盯上你的推杆线，后面哪个走廊他一连麦就冲你来——到时候我替你挡；皮拉提手里那章回忆录念不念、念什么，我也替你去探。哪天我出了事，你安安静静当你的大象；哪天你出了事，老木在。签吧。

**半步爹**：（坐下，屁股只挨半个椅子，声音很小）……谢谢那一块。短信不是我发的，我没发过，真的。那天……我就看见老先生坐倒了，然后有只手把信封和那两页纸抓起来，塞进西装里了。特勤挡着我，没看清是谁的手。（停一下，低头）老木……那个白信封，跟你每年寄我的一样。是你的吗？……条子我先不签。我就剩四块了，我、我想想。

**下木**：（拧开保温杯喝一口，眼睛看着绿萝，不看他）白信封？学生给老师贺寿，一张生日卡。我这人就认白卡，三十年了你又不是不知道。卡里夹了两页退休建议——老人家七十八了，该歇了。就这些。（压低）但你刚才那句"有只手抓起来塞进西装里"，这个值钱，比你兜里那四块值钱多了。你记住：这话出了这个角落，只能是我替你说，你自己一个字都别往外吐——有人在外头说那纸是"被风吹进水塘"的，你一开口，就是当众打人家脸，人家手里有卡有短信，回头第一个收拾的是你。再帮我想一下，就一下：那只手是从哪边伸过来的？左边还是右边？袖子什么颜色，戴没戴戒指、手表？想不起来没关系，别瞎编，想起来了只告诉我。（手指在欠条上点了点，往他那边又推半寸）条子的事我知道你怕什么——怕到时候真要你掏钱。这样：今天你生日，我先给你一块，算老木的生日红包，你揣着；你在条子上签"欠下木一次"，往后真轮到这张条子，用的就是这一块，你一分自己的不动。四块还是四块，还多一个人替你挡麦克播。不亏。签了，咱俩今晚这角落里的话，都烂在肚子里。

**半步爹**：（手在膝盖上搓了两下，不敢看他）那只手……我真没看清。好像是……不，我不知道，我不瞎编。（小声）你说的我记住了，我不往外说。……红包我不要，条子今天也不签。不是不信你，老木，我、我就是怕。等我想明白了……我来找你。
