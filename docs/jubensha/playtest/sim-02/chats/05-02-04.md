# 私聊5：烦高 × 梅戏

**烦高**：（端着盘子坐到她旁边，左脸朝她）梅记者，饭点不能过手，我就来说说话，账留到第三幕走廊再结。先说一件，信不信由你：刚才第4页，我出的是掌。锤也锤不掉你，可我不想让"站在半步后面的人"看见一屋子都是拳头。我来问两件事。第一，你说"周四晚上谁不在家，你们自己想"，这话是说给全桌的，我想听你没说出口的那半句：你心里那位周四晚上固定不在家的，是不是就站在总统身后半步那位？你点头摇头都行，我不让你担名字。第二，件小事：党鞭办公室每年寄的那张白色烫金"Happy"卡，你今年是哪天收到的，卡里除了印的字，有没有人手写了一句？我那张写的是"风大，注意头发"。你告诉我，我第三幕走廊给你2资金，现钱，不打条子。另外，录影棚里我停的那一拍，你本子上记了一笔，我知道。那一拍跟今晚的事没关系，你别往家里挖，我就不往你"欠三百多次"那张卡上看。这个算我求你，不算交易。

**梅戏**：（往后靠了靠）第一个，摇头。我说的周四不是他，别往半步爹身上套。卡是3月1号到的，晚了一天，系统不认2月29，里面就印的"Happy 36"，没人手写——你那句"注意头发"我这张没有。2资金第三幕走廊记得给。你那一拍我不挖，我那三百多个下次你也别翻，就这样。

**烦高**：（点点头，把盘子往里推了推）行，摇头我收下，不往半步那位身上套。卡的事你答得干净，这2资金值，第三幕走廊一开我先找你，当面点给你，不拖到提名后。我那一拍你不挖，你那三百多次我不翻——这句我当成你我之间的规矩，不当买卖。再多说半句，不算价：提名前别给谁签名欠条，尤其是"卖锁不卖钥匙"那家。你民调0，条子比钱值钱，签出去就是给人家当筹码。周四那位，你哪天愿意说了，我这边也有一张有抬头的纸，可以一起对。

**梅戏**：嗯，条子我本来也没打算签。你那张有抬头的纸……我有个独家，下次告诉你。走廊记得先找我就行。
