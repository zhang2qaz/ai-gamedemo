# 私聊3：建国钱（07）× 狗登罗（08）

**建国钱**：（2:10，把柜台二维码立牌扣下，拿着一张私密卡背面朝上在手里转）狗律师，热线接通，我长话短说——我这人只做生意不聊天。三月午餐会我问你"能不能停"，你说停得了就是虚假宣传，我回去想了一个月，想明白了：那台机器是我家的，账本页尾那串签名末四位你自己去墙上看，0001——至尊版第1号客户。系统是我卖的锁，钥匙在你们律所。这个我先白送你，算开张见面礼。现在要价：我手里这张是律所寄存处的副联，起草人一栏写的是你名字，触发日一栏被人涂黑了。我就买那一栏——**哪天触发的**，是"委托人死了"那天，还是"两周没报平安"那天？你给我日子，这张卡我公聊不亮、谁问都说寄存处空的。另外两个小生意顺带问：你拍拍卖拍的那两张雪茄盒空白条，按一块一张我收；你要是手头紧，我也能给你签名条垫钱。还有——（压低声音）你那张律师执照的料我见过卡面，已经交回DM了，我嘴上有锁，锁是我卖的，钥匙你懂。说个价吧。

**狗登罗**：（站着，不坐，把他那张背面朝上的卡看了一眼又看回他脸）建国钱，先把账对清楚。你说的"见面礼"我收下，但我得复述一遍，免得以后你说我听错：机器是你家开盒的"定时公开·不可撤销至尊版"，账本页尾签名末四位0001=至尊版第1号客户，钥匙在我们律所——对吧？那我追问一句，算在见面礼里：**0001是机器编号还是客户编号？那一串签名，0001前面是谁的名字？**你卖的锁，买锁的人是谁你不会不知道。
第二，日子。你开的条件是"公聊不亮、谁问都说寄存处空的"——口头的我不认，我开局就说过，我只认欠条。你**签一张"欠狗登罗一次"给我**，州和票我自己填，我就当场告诉你哪天触发、写在你那张卡背面。条款是"死了"还是"两周没报平安"——那是律所业务，不卖，你拿到日子自己去对你机器的日志，你比我清楚它哪天开的口。
第三，空白条。不卖，一块、两块都不卖。规则书写得明白，沼泽要的是"当选总统亲笔签的欠条"，空白条在你手里一分钱不值，除非你打算拿去找人签——你一个开锁的，收那么多空白锁干什么？我先记下这个问题。
第四，执照。"考五次"那张是假的，谁念我当场喊假，DM查，念卡的人民调减二。你嘴上有没有锁随你，我这边不用钥匙。
还有——（压低）你那张卡上"起草人"写的是我，这是事实，我不否认；但你要是公聊亮出来，我就把三月牛排馆你问"能不能让它停一停"原话讲出来。你怕锁停不了，比我怕名字被念更怕。所以：一张签名条换日子，成交就伸手。

**建国钱**：（把卡收回内袋，柜台立牌又翻回来，二维码朝她）行，狗律师，你算账比我柜台的机器还快，我喜欢。先回你送的那问：0001是**客户编号**，不是机器编号——至尊版卖出去的第一单。签名那串前面写的是"绿茵管家服务有限公司"，就是你卡上那个委托方。后面是谁在出钱，说实话我没查——卖锁的不问人家开谁家门，问了就没下一单了。这条算我白送第二回，你记着，我这人送东西都有账。
执照那张你说假，那就假，我本来也打不了，今天当没见过。三月牛排馆那句"能不能停"——你讲出去，全桌只会问"那台机器是谁托管的"，第二句就问到"起草人"。咱俩一根绳，谁先松手谁先掉。所以都别亮，这个不用欠条，是算术。
正事：一张签名条换日子，**我认**。但我是做市的，一口价不接，加一个小点：日子写在我这张卡背面，**再在旁边打个勾或叉——触发日在12月18号之前，还是之后**。条款你不卖我不问，前后我自己会算。成交方式也按我柜台规矩，**一手交一手**：我把签好的"欠狗登罗一次"压在桌上，手指按着；你写完卡背，翻过来给我看，我手指一抬，条子归你。州和票你自己填，我兜里有钱我就掏，没钱它回你手里下轮再用——这你比我清楚，规则书第40行。
空白条你不卖就算了。我收空白条干嘛？倒卖啊，老狗——一张白纸在别人手里不值钱，在会找人签字的人手里就值。你要哪天想通了，价格还是一块，柜台常开。伸手吧。

**狗登罗**：（站着，从他按着的条子上看了一眼签名栏，确认是他亲笔、"欠"后面写的是"狗登罗"，州和票两栏空着）好，一手交一手。我先复述，省得以后你说我听错：你签"欠狗登罗一次"，州、票空着归我填；我在你那张卡背面写触发日，旁边打勾或叉——在12月18号之前还是之后。就这些，条款不在里面。
（拿笔，在他卡背面写"12/21 周二"，旁边写"后"，打勾，翻过来给他看）
你看清楚：日子写了，"之前之后"那个勾其实是白送的——日子摆在那儿，你自己会数，算你多收了一口价，我不计较。
（他手指一抬，我把条子收进西装内袋，没坐）另外"绿茵管家服务有限公司"我记下了，算你第二回白送，账上我认。牛排馆那句"能不能停"，我们说好都不亮——这句我也不用欠条，因为是你说的"算术"，我认算术。空白条柜台你常开，我不去。走了，外头还有人等我站着。
