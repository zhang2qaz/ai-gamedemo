# 私聊2（第二幕走廊）：下木 × 建国钱

**下木**：（端着保温杯靠到柜台另一头，跟你隔一个身位，眼睛看着绿萝）师弟，先还账：半步爹那边我问了，短信不是他发的，他咬得很死，"我没发过，真的"——你那一成我还上了，咱俩现在都是八成，扯平。再说三件，第一件是生意：你那颗种子今年打算走多远？他扒马褂第一张就点我保温杯，满桌七个人他偏挑我，是你授意演给外人看的，还是他已经不认上线了？他要真冲提名票去，咱俩那三张条子就得往他身上砸，你给我句准话，我初选好往他那儿装钱。第二件，（声音更低）那天从第十八洞走回会所，两百米，你一路右手按着西装内袋，服务生接外套你都不给——我当时没多想，今晚想起来了。还有人看见"一只手"把信封和两页纸塞进了西装。是谁看见的我先替你压着，没往外漏。我不跟你要那张纸，我就要你一句实话：纸在不在，在谁手里。你给我实话，我手里这个"看见的人"就永远不开口；你还跟我说水塘，那我就只能当那只手不是你的，去问问到底是谁的了。第三件，你广告上说"保温杯那位一赔五十"、梅戏念你那张两千万你喊假赢了两点、现在民调三块——外头都看着咱俩是死对头，正好。我这儿九块，别跟外人说，你要是真是零，初选我替你垫一块，条件是你那张记分卡和那条短信，今晚哪一刻都别在公聊亮出来。（拧上杯盖，提高嗓门）——拍个破记分卡出十一，钱多烧的！

**建国钱**：（拿抹布擦柜台，擦到你那头停住，眼睛看账本不看你）师兄，账我收了，八成对八成，扯平。不过半步爹那句"我没发过，真的"——做生意的都知道，带"真的"两个字的报价最不真。你问没问他那天**跟谁一块儿去的**？这半句才值钱，下回补上。
三件事，我一件一件回。
第一，种子。保温杯那张——**我让他点的**。七个人里挑你最安全：你掉两点，外头只会更信咱俩是死对头。准话给你：他冲驴友党提名票，线还在我手上，就是最近胃口大了，跟我讨价还价，签名条说"等提名出来再签"。你是驴友党，初选往他信封里装，装多少你定，**装完让他知道是党鞭给的情**——第三幕他上了票，咱俩手里的条子集中往他身上砸。但你别直接跟他聊老头、聊第十八洞，他今晚在到处问露台的事，问得比你还细。
第二，纸。我给你一句实话，先付一半：**纸不在水塘里。今晚也不在这间屋里，谁来搜我身都搜不着。**后一半——在谁手里——你拿"看见的人"的名字来换，一手交一手，这是我柜台的规矩，对你也一样。还有，师兄，"去问问到底是谁的手"这话别吓唬我：你要满世界问那只手，人家第一个反问的就是"那信封是谁递的"。咱俩一根绳上拴着，你拽我，你自己也往水里走。那个看见的人要什么价，告诉我，**封口费我出**，不用你垫。
第三，钱。零已经不是零了，领了点收入，够装我自己的信封。你那一块我心领——而且初选排在走廊前头，你这块钱现在递不过来，递过来DM也不认。别垫给我，**直接装进烦高信封**，比垫给我划算。记分卡和短信，公聊我一张都不亮，这条不要钱，白送你。
另外提醒一句：麦克播在公聊追"Happy 78"，追得很紧，问你点头摇头——**别点头也别摇头**，就说"一百多张卡，记不清"。他要是下一圈开"三小时连麦"点你，你得先想好怎么答"是或否"。
（把抹布一甩，嗓门提起来）九……就你那点养老钱，也配来我柜台砍价？保温杯拿好，慢走不送！

**下木**：（拧开保温杯抿一口，眼睛还是看绿萝，嘴唇几乎不动）好，八成对八成，账清了。半步爹那句"真的"我也听着别扭——不过师弟，你张口就问"跟谁一块儿去的"，我倒要先问你：短信上写的是"我们俩一起来"，没写"去"。你怎么就知道是两个人**一块儿去过**？这半句你要是心里有数，下回你先报，我再去补。
名字的事，不换。你那一半是"不在水塘、不在这屋"，等于告诉我"在别处"——我拿一个活人的名字换你一个"别处"，这买卖你在柜台上也不做。我只送你一句，白送：**看见的人不在果岭上。**那天果岭上就咱仨加一个倒下的，半步爹站那儿跟根旗杆似的，他眼睛只盯着老头，他那张嘴你也知道，三十年没说过一句整话。你别去碰他，碰了他吓得到处找人哭，反倒把咱俩都哭出来。封口费也不用你出，这人的价我来谈，你出钱就等于告诉人家这事跟你有关。
绳子是一根，这话我认。可绳子那头的纸在你手上，我就要你一句：**第三幕翻心之前，那两页纸不进任何一个外人的手、不进任何一张线索卡。**你点个头，咱俩就算重新拴紧了。
种子我听明白了：初选我往烦高信封里装，装完你去告诉他"党鞭给的情"。但你也给他带句话——他点我保温杯那一张，我认了掉一点，这一点我记在他账上；提名一出来，第一张"欠下木一次"签给我，不是签给你，这是规矩，替你干活的人先拿条子。麦克播那边我照你说的，"一百多张卡，记不清"，不点头也不摇头。他要真连麦点我，我也只答"是或否"，多一个字都不给。
（把杯盖拧死，往柜台上"咚"一墩，嗓门拔高）养老钱怎么了？养老钱也不往你这黑店里扔！你那记分卡留着当传家宝吧！

**建国钱**：（抹布在柜台上画圈，头都不抬）师兄，抠字眼抠到我柜台上来了。"我们俩一起来"——"来"的意思就是一块儿到，到之前总得一块儿出门吧？你读短信读成文言文了。我要真心里有数，还用得着派你去问半步爹？这半句你照样补，补回来算你的。
名字不换，行，柜台规矩是"不成交不强买"。"不在果岭上"这句我收下了——果岭外头站着的人，一只手都数得过来，我自己会算。你不让我碰半步爹，我不碰；但你也别拿"看见的人"当秤砣一直压我，这单你谈，谈不下来再来找我，钱我照出，不记你账上。
点头的事：我点。**第三幕翻心之前，那两页纸不进任何外人的手、不进任何一张线索卡、不上公聊。**这条我白给，因为本来就是我的打算——纸出去一张，咱俩谁都收不回来。
烦高那张条子，我让一步：**提名出来，第一张"欠下木一次"签给你**，我去跟他说"党鞭的情先还"。但我也要个对价——第二张、第三张往我这儿走，你别跟他另开价；还有你那四张空白条子，撒出去谁签了，回头告诉我一声，咱俩合起来数，别各算各的，数到三就收手。
（把抹布往桶里一摔，嗓门拔高）养老钱？你那点养老钱连我柜台的押金都不够！保温杯里装的什么自己心里清楚，下回别往我这儿凑！
