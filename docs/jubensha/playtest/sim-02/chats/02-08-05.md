# 私聊 2：狗登罗（08）× 麦克播（05）

**狗登罗**：（站着，把那张写了"未收费、无约束"的餐巾纸翻到背面，笔帽拔开，压在桌上）走廊了，DM说这儿的交易才算，所以这次收费。上回约定我复述一遍，你听着有没有漏字：你嘴对我耳朵说G的真名——三个字的那个，身份证上的，不是字母——我当场在这张纸背面写日子，写完纸归你。顺序不变，你先。另外加一条新的，单独计价：你说"老头子停下的那天，闹钟替他把话说完"——我想知道那个"话"是什么时候、从哪儿说出来的，你节目有没有收到过什么东西，信、录音、邮件，随便什么。你要是收到过，内容我不要，你只告诉我"收到没有、哪天收到的"，我拿雪茄盒里一张空白欠条换，我签名、欠你一次——初选那一票的州你填，钱我掏，就一票，不是表态，是生意。你要觉得这价低，现在说，过了这四句我不加价。

**麦克播**：（凑过去，手掌拢成喇叭贴她耳朵——这是我这辈子音量最小的一次，导播要在得哭出来）听好了，就说一遍：**游游·两头吃**。账单上那个"游"，是游游的游；那个"G"，是我们节目给他起的代号。（坐回去，声音恢复八十分贝）身份证我没见过啊，律师同志，我跟他吃了六年牛排，他签"永远匿名"，我又不是派出所——我知道的全名就这个，三个字你要是指"两头吃"，那就是它，多一个字我编都编不出来，编了你也不信。名字给了，该你写日子了，纸翻过来，笔你都拔了别浪费墨水。
第二单我接，价不嫌低，一票就一票：老实说——**截至今晚，没收到。**信、录音、邮件、快递、听众寄来的锦旗，都没有跟他沾边的；十二月二十号以后我那热线每周一零点照开，一次都没亮过。所以"闹钟"要么还没响，要么响到别人那儿去了——你那个"东西自己动了"的日子，要是在今天以后，那就对上了；要是在今天以前，那就说明它响了、但不是冲着我响的。这句我白送你推理，单子照收：雪茄盒那张，你签名、写"欠麦克播一次"，背面勾大象党提名票，州我先空着，等我看明白哪个州最缺那一票再填——DM要是说必须当场填，我就当场填。成交你就递过来，不成交，名字我也已经说了，老子不往回咽。

**狗登罗**：（听完，没动表情，笔尖在纸上停了两秒）"游游·两头吃"。我说的是"三个字"，你给了五个字加一个点——不过你说多一个字编不出来，这句我信，记录在案。（翻过餐巾纸，当着他的面写："12/21，周二。"——停顿，又在下面补一行小字："东西自己动的那天。"推过去，手指压着没松）日子在这儿。今天是一月十九，它在今天以前——按你白送我的推理，闹钟已经响过了，没冲你响。你自己琢磨它响到谁那儿去了，这句我也白送。（松手，纸归他）
第二单。（从雪茄盒里抽出一张空白欠条，正面写"欠 麦克播 一次"，签名"狗登罗"）规则书第一百一十六行：州和提名票是"拿欠条的人在背面写"，所以州你空着合规，DM不用当场填——但提名票这一栏我当着你面勾了〔大象党提名票〕，我签名的条子我不想看见它去给驴友党垫一块钱。你要是觉得我勾这一下违约，现在说，我们一起举手问DM：持有人能不能改签名人勾好的提名票。不说，就当你认了。（递过去）还有一条写给你听的，不写给你看：我身上的钱我不报数，轮到这张条子那一轮，我要是兜里空了，规则说条子退回你，下一轮再用——那不叫赖账，叫规则。成交。外面继续骂，我恨你恨得很专业。

**麦克播**：（一把把餐巾纸抽过来，对着灯看了三秒，叠成四折塞进衬衫胸兜，拍两下）十二月二十一，周二。他十八号倒下，二十号周一零点我那热线没亮，二十一号东西就自己动了——行，老头子连闹钟都定在我节目第二天，怕吵着我睡觉是吧。（接过欠条，正面背面各看一眼）勾大象党？不违约，正合我意，这一下你要不勾我还得自己勾，省我一笔墨水——不用举手问DM，认了。州我空着，等终局看哪个州缺这一块。你兜里空不空是你的事，空了条子回我手里，下一轮接着找你，这个我也认，规则就是规则，你们律师比我念得熟。（把欠条和谢礼卡叠在一起揣好）成交。"三个字"那事你记录在案就记录，我就知道这五个字加一个点，你要是哪天在哪张纸上看见他三个字的真名，记得也贴我耳朵说一声——这单下回算，我先欠着，不签条。出了这门老子照骂你，明天节目第一句："我前妻那个女人，嗓门比我还大。"
