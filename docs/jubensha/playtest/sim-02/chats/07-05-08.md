# 私聊7：麦克播（05）× 狗登罗（08）｜第三幕走廊

**麦克播**：（把帽子往DM桌角一扣当"成交章"，人靠在桌沿，嗓门压到深夜档）副手同志，正片上映，检票口到了。三件事，老规矩按顺序，我这回掐表，不超三分钟。
第一，交割。你饭点报的价——"欠麦克播一次"，提名票勾大象党，州我填——你那张空白条还在、你人也站在DM桌前了，条件全齐。签吧，当着DM，实物过手。我这边一张条子都不签给你，不是不信你，是我当了候选人，**我签出去的条子越少，这张票越干净**——你是律师，这条你比我懂。
第二，你刚才那发背调。半步爹"不一致"，你花零块钱查出来的东西，全桌都听见了，可只有你知道你**为什么偏偏查他**。驴心还是沼泽，DM不说，我也不问你猜哪个——我就问一句：你查他之前，心里押的是"一致"还是"不一致"？你押对了，说明你手里有我没有的东西，咱俩一张票，那东西我得知道个方向。
第三，拿货换货。（从内兜里摸出一张卡，压在帽子底下，只露半截给她看，"绿茵管家服务有限公司"那一行冲她）遗产基金会展位翻出来的，私密卡，我不念、不转手，你看这半截就够了——这家公司是谁全资的，你比我先知道，对吧？蓝夹子上那个"委托方"，就是老先生自己。我不问合同内容，起草人回避我认。我只要一个日子：**委托方最后一次跟你所里确认，是哪天？**是不是十二月十三号？你点头摇头、或者"回避"都行，但别说"寄存处是空的"——闹钟不放寄存处，这话我饭点说过了。
你回我这一句，我给你一句我刚拿到、全桌就我一个人有的东西：老先生最后一组，**谁扶的旗，谁递的卡**，我手里有一半的答案。你那份合同"下一页"什么时候响，你自己听着；这一半答案，够你提前半拍知道它冲谁响。

**狗登罗**：（站着，没碰你的帽子，从信封里抽出一张空白欠条按在DM桌上，笔帽咬掉）按顺序答，你掐表我也掐。
第一，交割。现在签：正面"欠麦克播一次"，签名狗登罗；背面勾**大象党提名票**，州空着归你填。——口径我先替你说清：规则书原文是"拿欠条的人在背面写州和提名票交DM"，所以我勾的那一格，严格讲是我的意思，不是锁。不过票上是你我两个人，你要拿它投驴友党，那是你自己拆自己的台，我不拦。DM，实物过手，请您看一眼：一张，签名，交给05。（递过去）
第二，我押的是**不一致**。证据是我举手的时候，筹码我按在桌底下没拿出来——你那会儿在看我，你看见了。为什么偏偏查他，律所业务不予置评。给你能用的结论，一句：终局他放的"2"、他手里谁的条子，**一块都别指望落在我们这张票上**。驴还是沼泽，DM不说，我也不猜给你听。
第三，（看了一眼帽子底下那半截，没伸手）签字簿是所里的文件，我不念、不出示，也不说它存在不存在。你问的是一个日子——这个我不回避。（点头，一下）**是十三号。**那一格之后，下一格是空的。
就这些。现在轮到你：谁扶的旗、谁递的卡，你那一半，原话给我。外加一个你可能顺手知道的：那天那组四个人里——老先生不算——**谁最年轻**？你说得出年龄更好，说不出给我个排序也行。

**麦克播**：（接过欠条，正反面冲DM亮一下，"DM您瞧好，欠麦克播一次、狗登罗签名、勾大象党、州空着"，折两折塞进帽檐里，跟那张便签挤一块）收了，副手同志，验货合格，这张我终局填州。下面我按你的顺序还你，掐表。
第一，原话，一个字不改：**"下周我生日，两个学生陪我打最后一组，一个替我扶旗，一个给我递卡。"**——老先生上节目前说的。我先自首：饭点我说"学生，零个"，那会儿我脑子里真是零；这句是今晚党代会信封塞到我手里我才对上号的，你骂我记性差可以，别说我那会儿诈你。四个人一组，老先生不算，剩三个，**两个是他学生**，一个扶旗、一个递卡，还剩一个是陪着出汗的。
再白送你一条规矩，球会的老规矩：**同组最年轻的扶旗杆**。所以你问谁最年轻——你跟我想到一块儿去了，谁最年轻谁扶旗，扶旗的就是倒下那会儿第一个扔了旗杆冲上去、从草上抓了东西按胸口的那位。（压低）这半句是露台上有人看见的，人我不报。
第二，年龄——我手里**没有**，不编。排序我只能给你个押注，不是证据：木老捧着保温杯管烦高叫"你年轻"，他不像最年轻的；剩半步爹和钱老板，我押**钱老板**。记分卡在他柜台，那上面要是印了生日或者差点，你比我会问。
最后，我拿你那个"十三号"算了笔账：十二月十三号是个**礼拜一**。礼拜一确认，下个礼拜一十二月二十号——老先生前一天已经倒了，没人签——第二天二十一号，周二，东西自己动了。对得严丝合缝。所以我就问一个，点头摇头：**你那份合同，是不是写的"每周一确认一次、漏一次就启动"？**再加半句，不回避也行：十三号那天来确认的，签的是不是**就一个字**？

**狗登罗**：（还站着，看了一眼表）收尾，两问两答，按你的顺序。
第一问，合同条款——"每周一确认、漏一次就启动"——**起草人回避**。不是摆架子：保密义务不因委托人死亡而终止，这句话是我亲手写进那份合同的，我不能第一个违约。你账算得对不对，我不点头也不摇头。只替你改一处笔误：老先生倒下是**十八号**，你那个算法里十八号是**礼拜六**，不是"前一天"。——差一天，记者稿子会被人抓的。
第二问，我点头，一下：**一个字。**哪个字不说；你要猜，自己猜，别当着全桌猜。
最后两条，算副手对候选人的交代，不收钱：
一，"两个学生、一个扶旗一个递卡"这句原话，我认你今晚才对上号，饭点那笔不追。但"最年轻"我自己去问，你别替我开口——钱老板那边是柜台，谁先开口谁吃价。
二，帽檐里那张条，州你终局再填，填之前跟我对一下。我在票上，没有"2"撑场，**我手里每一块钱、每一张条子都只往咱们这张票上走**——你也一样，别让任何人拿你的嗓门换他自己的条子。就这样，表到了。
