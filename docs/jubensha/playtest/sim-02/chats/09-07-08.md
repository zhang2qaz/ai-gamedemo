# 私聊9：建国钱（07）× 狗登罗（08）｜终局第一轮走廊·热线

**建国钱**：（4:24，热线接通，袖扣转半圈，两张空白欠条夹在指缝里像扑克牌）狗律师，DM又把咱俩连一根线上了——这叫天意，也叫一根绳。辩论我手指烦高，你别记仇：手指是民调，信封才是钱，金主从来两边押。今晚最后一个盘口，你只认欠条，我就拿欠条报价：**我再签一张"欠狗登罗一次"，州和票空着归你填**——加上你西装里我早先签的那张，等于两块真钱铁定落你们大象党，签名的人当场掏、DM亲手收，不用信我人品。换两样。第一，帽檐底下那位：你回头让麦克播给我签一张"欠建国钱一次"，州票空着——他嫌签多了票不干净，你就跟他说，我是收藏签名的，这张我**不拿去投**，攥着当纪念。第二样不算买卖，算我私人问的：**每周一去你们律所签那一个字的人，长什么样？最后那几个周一……他走路还稳吗？**你说"回避"我认；你要愿意说一句，上回说的八折不用了，我那张条子白签。

**狗登罗**：（站着，没碰你那两张牌）建国钱先生，先把条款拆开，一样一样过。第一样：拒绝，不议价。规则书写得很清楚，"用掉的欠条撕掉，不再算沼泽的账"——一张"不拿去投、攥着当纪念"的当选总统签名，在规则上正好就是沼泽要攒的那种。我不当这个中间人，麦克播那边我也会转告他"别签"。第二样：你的问题我可以答一句，但按我的收费顺序来——**你先说，第18洞那天你站在哪儿，旗杆是谁扶的。**你说了，我告诉你签字那人我看到的样子；"走路稳不稳"我不答，我只看签名，不看步态。还有，你说"两块真钱铁定"，这个"铁定"我不认：签名人当场掏钱，你身上的钱我看不见，第三轮你说没钱，条子退回就作废。所以我的还价是：新那张"欠狗登罗一次"你照签，州票空着我填；**今晚这一轮你的"2"当众放在内华达大象党提名票上**——当众放，我看得见，不用信你人品。先前说的"第二轮起每块事后付1，最多2"照旧有效。热线那几根手指的账，我这边不记。

**建国钱**：（把两张牌收回一张，剩一张在指缝里转）行，狗律师按小时收费，我按笔结。你问的我先付——**第18洞，我扶着旗杆，就在洞边。旗杆是我扶的，没别人。**就这一句，多的不送，弯腰没弯腰你别问，问了另算钱。现在轮到你：签那一个字的人，长什么样，你说一句就行，步态我不问了。麦克播那张我撤单，不要了——**但你也别去他那儿替我"转告别签"**，我撤了的单你还去拆，那叫收两遍钱。你的还价我接一半再加一点：新条照签，"欠狗登罗一次｜建国钱"，州票空着你填；内华达那块"2"，我**当众放你们大象票上**，你看得见，放下不挪。可撑场是真金白银的2块，不是人情——你那个"事后付1、最多2"从**这一轮就起算**，不等第二轮。成交就DM桌前现签现交；不成交，这根旗杆的事你当没听过。

**狗登罗**：（还是站着，从公文包里抽出一支笔，没打开包）好，你先付了，我按约定给一句：**每周一来签字的那个人，戴一顶棕榈湾的会员帽，帽檐压得很低，我从没看清过他的脸。**就这一句，结清。第二，麦克播那张你撤单，我记"撤单"——撤了的单不存在，我不会拿你的名字去他那儿说任何事；但我是他的选举律师，"今晚别给任何人签州票空着的欠条"是我对委托人的一般法律意见，不点名、不针对你，这个我照给，不算收两遍钱。第三，还价我接，条款我复述一遍，你说"是"就去DM桌前：①你现签一张"欠狗登罗一次｜建国钱"，州票空着，当场交到我手里；②这一轮你的"2"当众放在**内华达·大象党提名票**上，放下不挪；③付款"从这一轮起算"我同意——意思是：**第一轮这块，我第二轮走廊付你1资金；第二轮你的"2"再放大象票，我第三轮走廊再付1；总共最多2，第三轮那块不付。**付款永远在我看见圆片之后，不先付。你要是"从这一轮起算"指的是现在先付，那就不成交，旗杆的事我也当没听过——咱俩扯平。
