# 私聊4（终局第三轮走廊）：烦高 × 建国钱

**烦高**：（背对全桌，站在DM桌边上，左侧45度，声音压得只有你听得见）钱老板，最后五分钟，我不绕了，就一笔账。你内袋那张"欠建国钱一次｜烦高"，你自己说好钢留到宾夕法尼亚。现在267比236，驴友党差3分，佐治亚、宾州任拿一个就够——你那一块钢砸进去，改不了大局，只能让我当着皮拉提的面掏钱，坏我一顿饭。我出价：**2资金现钱，现在就去DM桌前，你把条子交出来当面撕，我当面给钱**，比你上回"一张付2"还公道。不卖也行，那你就当众说一句"这张投宾州驴友票"，我也认，钱我留着。两条你挑一条，别再跟我谈"再签两张"——开票前我一个名字都不签，皮拉提那边我也是这么答应的。另外，上回我问的那句你还没回：老头的两个学生，是不是一个在驴友党、一个在大象党？点头摇头都行，不收钱。

**建国钱**：（侧过身，手插西装内袋，像在摸烟）烦高，你这两条我都不挑。2块买我撕条子？这张纸在我这儿比2块值钱，撕了我就真成"只碰过杯"的了。当众喊"投宾州驴友"？那等于我花你1块钱、你当着皮拉提掏钱——你自己刚说这是坏你的饭。所以第三条：宾州欠条环节我当众说"不用，驴友稳了不必花"，条子攥到开票，你一分不掏、饭照吃，这是白送你的。——但我是做生意的，白送完了总得报个价，最后一次：下木和我凑**10资金现钱**，你在DM桌前签两张"欠××一次"，州票空着，签完这10块你转身就自己装进宾州驴友信封。你差3分，我们替你把宾州买稳——你签两个名字，换十块钱全砸在你自己身上。不签，我不怪你，前面那条照样白送。至于老头那两个学生——白问白答：**摇头**。不是一个驴友一个大象。驴友党桌上老头只放了你一颗，这句我上回说过，没改口。还有，"建国钱攥着烦高的条"这话你真要当众喊，先想想全桌听完第一个问的是谁——是问我，还是问你为什么给大象党金主签过条。咱俩这张纸，最好一起烂在内袋里。

**烦高**：（没转身，手指在DM桌沿上敲了两下，像在点钞）第三条我收下——宾州欠条环节你当众一句"不用，驴友稳了不必花"，这个人情我记在你名下，开票后还。但我照样在兜里留一块钱等着，钱老板别见怪，二十年了，我信你的回卡，不信你的内袋。十块钱那条，免了。你兜里一张，再加两张，正好三张——数到三这种账，我父亲教我的第一样东西。宾州差的那3分，我自己装，用不着你们俩替我买稳；十块钱要真想砸，你们自己去装驴友信封，我不拦，也不欠。两个学生那题，摇头我收到了，算你白送一回。最后一句：你那张纸，开票前你不拔，我就不喊；你拔了投大象，那就不是烂在内袋里，是烂在桌面上——我们一起烂。就这样，我回座了，关门前我谁都不再找。

**建国钱**：（把内袋里的手抽出来，空的，拍了拍西装前襟）行，二十年头一回有人数到三把我数退了，这笔我认栽。宾州那句"不用，驴友稳了不必花"我当众说，说话算数——你兜里那一块钱留着吧，留着也没处花。十块钱的单撤了，不加价、不改价，钱我自己看着装。最后一句是白送，不是报价：开票之后要是你当选，记得押宝网第一个给你道喜的是我，第一个找你谈"下一届"的也是我——那时候你签不签，我们再谈价。条子烂在我内袋，嘴烂在你肚子里，这笔账今晚就这么平。回座吧，烦总统。
