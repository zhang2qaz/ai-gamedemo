# 私聊11（终局第二轮走廊）：烦高 × 建国钱

**烦高**：（站到柜台侧边，左脸朝你，手插在西装口袋里没拿出来）钱老板，三分钟，我长话短说，两件事一个价。
第一件，旧账：3:51桌前DM一把就交割了，条子和两块钱都推过去了——你那第一页，我一句都没听着。我先松的手，这笔你欠我的，今晚还得还。不用全念，给我两样就行：**第一页是谁写的、要交给谁。**
第二件，二十年了，我就问一句，你照实说，不要钱：**我这二十年的近况，最后摆在了谁的桌上？**是老头的，还是你押宝网的柜台上？
然后是价：你兜里那张"欠建国钱一次｜烦高"，你说"好钢留到宾夕法尼亚"——我不等宾夕法尼亚了。**这一轮就用掉它**，威斯康星或者密歇根，投哪张票你自己写，我当场掏那1块；用掉之后我**再给你3资金现钱**，DM桌前交。一张条子，你本来只换得来我掏1块，现在换4块，比你押宝网一赔七的单子还稳。不用，咱俩就照旧"只碰过杯"——那页纸的账，我出门记在你头上。

**建国钱**：（把那张"欠建国钱一次｜烦高"从内袋抽出半截，在柜台上点了点，又插回去）烦议员，旧账我认——3:51 DM手快，我嘴还没张条子就推过来了，这页是我欠你的，现在补，**不收钱**。
第一页：主意是我出的，执笔的不是我，是老头的另一个学生；交给谁——**交给老头的两个学生**。老头在第二页一签字，他手里那本账就归那俩人。执笔那个名字我不卖，那是我欠别人的账，跟你那三个信箱一个道理，一根绳。
第二件，你问二十年的近况——我照实说：**一封没少，全锁在我内华达的铁皮柜里。押宝网柜台上只摆过一封，四月那封，你自己下的饵。**什么"大象党的长桌"，没那张桌子。看过你信的，就两个人：我，和老头。老头走了，现在就剩我一个。
然后是你的价，我不接——一张条子换4块，你是在花钱买我手里的刀。我反着开：**这张我不用，攥着**；攥在我兜里，它一块钱都投不到你对面去。你再签**两张一样的**"欠建国钱一次｜烦高"，州和票空着，**我付你3资金现钱**，现在就去DM桌前一手交钱一手交条——密歇根15分，你正缺子弹。嫌两张多，一张我付2，最低价。三张都在我兜里，我当众放话"建国钱手里的烦高条，只投驴友"。还剩两分多钟，走不走？

**烦高**：（手从口袋里拿出来，在柜台上按了按，没去碰你那张条子）第一页的账，我收下，两清——不收钱，这个情我记着。近况那句也收下：一封没少，铁皮柜里。行，二十年，我总算知道信落在哪儿了。
可钱老板，你这个价我算了三遍，怎么算都是你赚条子、我赚三块。三块钱我缺，可条子比钱贵——**今晚开票前，我一张名字都不再签，一张、两张，都不签。**规则书上沼泽怎么赢，你我都念过，你兜里那张已经是我能给的全部了。
你不用它，攥着，我不拦你；但我也不白陪你攥：宾夕法尼亚那轮你要拔，我那1块认，投哪张票我当场看着——投驴友，咱俩还是只碰过杯；投大象，我当着全桌把"建国钱手里攥着烦高的条"这句话说出来，大家自己算你兜里还有几张。
最后问一句，不讲价：**你说"老头的两个学生"——一个在驴友党，一个在大象党，是不是？**你点头摇头都行，这个我不记你账。

（走之前左手往鬓角抬了一下，又放下）时间到了，DM那边我就不去了。

**建国钱**：（把那张条子在内袋外头拍了一下，没拿出来，笑）不签就不签，烦议员算账比我们押宝网的精算师还细，我服。条子我攥着，宾夕法尼亚那轮我也不拔——**攥到开票**，你看着它一块钱都投不到你对面去，这总比你那3块钱值。
你最后那句——（摇头）**摇头。**不是一边一个。驴友党那张桌上，老头的人就一个，就是你这颗种子；另一个学生，跟我坐同一张长桌。你别往你们党里数，数错了伤和气。
白送你一句不记账的：密歇根我那"2"，放驴友票。你当选那天，咱俩再碰一杯——那时候你签名多值钱，我那时候再开价。
