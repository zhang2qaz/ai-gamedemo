# 私聊7（第三幕走廊）：下木 × 梅戏

**下木**：（端着保温杯在绿萝边上坐下，没看她，看着DM桌）梅记者，最后一趟走廊，我不绕。两件事。第一，你是查公司的行家——**"绿茵管家"是谁的公司？** 谁是实际老板、哪年注册、跟开盒智能什么关系，你知道多少说多少。我先放一块钱在桌上当车马费，你说的东西对得上，再加一块，现在当着DM交割。第二，你数了一晚上周四，我知道。我不跟你装：那个嗓子，我**知道是谁**。今晚绿茵管家你给我一句实话，散场前我还你半句——你那两通电话是从哪张桌子边上打出去的。买卖一手换一手，谁先抢跑谁亏。顺带一句：你热线连的是烦高，终局你那块撑场圆片要是放驴友党那张票上，小皮也在票上，你上副手那盏灯没白亮——驴友党赢了，你那篇"下次"的旧账，就再也没人有资格翻。行，就把手边那块拿走；不行，杯子推回来，我不怪你。

**梅戏**：（把那块钱拿过来）……行。绿茵是两头吃自己的，他家司机厨子园丁都挂它名下，就这么多，注册年份跟开盒那边我不知道。（停一下）你那半句别等散场，现在说吧——还有，你从哪听说绿茵的？圆片的事到时候再看。

**下木**：（拧开保温杯喝一口，还是没看她）"他家"——哪个他家？司机厨子园丁一个不落挂在一个壳底下，这得是人走了还想让家里灯照常亮的那种人。你点个头就行，**是不是佛罗里达那位老先生家**？你点头，第二块钱现在就放你手边；你摇头，这一块就当我请你喝的咖啡。从哪听说的——跟你的周四一样，记账的人嘴里漏的，谁我不说，你也不会把线人卖给我。半句我现在给，算我抢跑一步，你记着这个情：那两通电话，不是从记者室，也不是从大象党那边打出去的——**打电话的人图的不是钱，图的是让一个人往上挪一格。你数数八年前谁往上挪了，再数数他今晚坐哪张桌。**剩下半句，等你圆片落了地再说。

**梅戏**：（点了下头，把第二块钱也拢过来）……嗯，是他家。半步那个我听懂了。圆片我真没想好，到时候看吧。
