# 私聊5：狗登罗（08）× 麦克播（05）

**狗登罗**：（端着一杯冰水站到他椅子边，没坐，餐巾压在杯底）先把程序说清楚：DM刚宣布饭点**不能交易、不能过手**，所以今天我只报价不交货，咱俩说好的东西一律等第三幕走廊开表、到DM桌前交割才算数，饭点里谁点头都不构成承诺——这句你要是有异议现在说。
三件事，按顺序。
第一，你那三年热线。建国钱连麦答你的时候嘴里漏了半个字"师……"，全桌都听见了。我问你：老G在热线上有没有提过"学生""老师""徒弟"这类词？有没有说过他带过几个人、是谁？你只说"提过没有、几个"，名字你可以留到走廊再卖。
第二，梅戏刚才那句"周四晚上谁不在家"。咱俩是每周**三**对接，不在里头，这个我替咱俩先摘干净。你节目周四晚上有没有固定来电或者固定连线的嘉宾？八年前那段时间，有没有谁跟你说过"周四晚上有事"——你做了十年夜间节目，谁哪晚不在家你比电话局清楚。
第三，第三幕你是大象党初选第一，提名最后发言、平票你赢。我的票目前**待议**。你要是把第一、第二件答实了，第三幕走廊我当着DM签一张空白欠条给你，"欠麦克播一次"，提名票我照样勾大象党，州你填——一张，不加价。答得含糊，就当今天这顿饭我请你听我说话。
另外问一句不收钱的：你初选那一块写的是谁，我不问；但大象党有一块写给了半步爹——不是我，也不是你，对吧？

**麦克播**：（把牛仔帽往她那杯冰水旁边一扣，压低嗓门——对我来说压低等于正常人说话）程序没异议，律师说饭点不算数，那这顿饭就叫"预告片"，正片第三幕走廊上映，DM桌前检票。老规矩，按顺序。
第一，先更正一个数字：不是三年，是**六年**，每周一零点，您这前妻连我节目开播几年都记不住，合同第七条该加一款"复习义务"。答你的题：老G在热线上——**提过学生没有？没有。几个？零。**"学生""老师""徒弟"这三个词，六年里他一次没说过。他在电话里只叫我一个称呼，全国都当是损我，你知道是哪两个字。"师……"那半个字是建国钱嘴里漏的，不是我电台里漏的；B8那张"只教过两个学生"，我也在琢磨是谁，但我敢拍胸脯：那句话不是在我节目上说的。名字我不卖，因为我手里没有名字——没货不开价，这叫职业道德。
第二，周四。本台热线周一零点，周四晚上我没有固定连线嘉宾，八年前也没人跟我报备"周四有事"——我不编，编了第三幕被你当众背调，我丢不起这个人。但我送你一个思路，不收钱：梅戏那页写的是"一周后新人选站到了总统身后半步"。谁站过去了，大家都知道；**周四先生不是站过去的那个人，是替他打电话的那个人。**往"半步"身后再找半步。
第三，成交。第三幕走廊开表，DM桌前，你签一张空白欠条"欠麦克播一次"，提名票勾大象党，州我填。我认这个价，不加价也不砍价——今晚我第一次跟你谈生意不讨价还价，你记一笔。
附送那题：对。大象党写给半步爹那一块，**不是我**。我那块写的是谁你不问，我也不说——但DM报数你也听见了，你收到几块你心里有数。
最后我反问一个，不收钱也行：走廊开头你连麦接的是建国钱。他那张嘴今晚老往西装内袋上按，锁匠摸口袋，钥匙八成在里面。他热线上跟你说了什么——你挑一句不涉密的给我。还有，（声音真的低下来）"第1号客户"那份合同，是不是你所里起草的？点头、摇头，或者老规矩——起草人回避。我听得懂。

**狗登罗**：（把冰水杯从他帽子旁边挪开两寸，不让帽檐碰杯）六年，我记错了，这条我认，不用加"复习义务"——加了也是第七条附件，要双方签字，你签不起。
价格确认：第三幕走廊开表后，DM桌前，我签一张"欠麦克播一次"，提名票勾大象党，州你填。**这是第三幕的报价，不是饭点的承诺**——铁律三，嘴上说的不算，到时候我手里那张空白条还在、我人还站在DM桌前，就签。你今晚没砍价，我记一笔，也就记一笔。
你那"往半步身后再找半步"我收下了，不收钱的东西我一般不信，但这句我先记着。顺口追一句，也不收钱：老G六年只叫你一个称呼，你说"全国都当是损你"——那两个字，是不是跟"学生"那三个词沾边？你点头摇头就行，你刚才说他"一次没说过"，我是律师，我只认字面。
你要的两样：
建国钱那句不涉密的，给你一句他自己在午夜当着全桌说过的——"卖锁不卖钥匙"。你今晚听过了，我再说一遍不算泄密，也不算我给你什么。他私下跟我说的，我答应过人家不复述，你换成是你，你也希望我守这个。
第1号客户那份合同——（停一秒，没点头也没摇头）起草人回避。你听得懂，这三个字我只说一次，第三幕谁问我，我都说律所寄存处是空的。


**麦克播**：（把帽子往回拽了一寸，离你那杯冰水远点——行，律师的杯子也有安全距离）"起草人回避"，四个字我收下了，跟你一样，我也只听一次。第三幕谁问我，我就说今晚咱俩聊的是离婚财产里那台咖啡机归谁。
你追的那句，我按字面答，你是律师你只认字面，我是播客我只认录音：**摇头。**那两个字是毕业证上印的，不是课堂上点名用的。六年，他没叫过我一声"学生"，我也没叫过他一声"老师"——我们俩在电话里是抬杠的，不是上课的。B8那句"只教过两个学生"要是真有我一份，那他教我的方式就是每周一零点跟我吵架，这种学费，全德州就我一个人交得起。
价格不动：第三幕走廊开表，DM桌前，你手里那张空白条还在、你人还站在那儿，签"欠麦克播一次"，提名票勾大象党，州我填。你说"嘴上说的不算"，我同意——所以我今晚嘴上也不加任何东西，省得你第三幕说我加价。
最后一句不收钱，当饭后甜点：你那家律所，寄存处是空的，可**闹钟**不需要放在寄存处。老G给我的卡片上写"闹钟会替我把话说完"——你起草的那份合同要是还有"下一页"，什么时候响，你不用告诉我，你自己先听着点。我走了，帽子我拿走，冰水你自己喝。
