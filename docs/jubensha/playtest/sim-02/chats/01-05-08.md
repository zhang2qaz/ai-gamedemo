# 私聊 1：麦克播（05）× 狗登罗（08）

**麦克播**：（把空保温杯往桌上一墩，凑过去压低嗓门——对我来说压低也有八十分贝）前妻同志，先对个表：今天周三。按咱俩那份"合同"第七条，这个点儿咱俩本该在你们律所14楼开选题会，那就当开会，我说快点儿，你是按分钟收费的我知道。第一件，外头那出"她嫌我嗓门大""我恨死她了"的戏我接着演，不拆你台，你也别拆我的。第二件，大象党初选就我跟半步爹俩人，站人身后半步那位。你手里有两张雪茄盒的空白欠条——我不要你签，我也不给你签，嘴上答应的咱俩都不认，这我比你还熟。我就要一句真话：你是站我这边，还是站合同那边？五月一号合同到期，到期以后你还骂不骂我，我想今晚就知道。第三件，（手指头在桌上敲了两下）老头子——那位"老先生"——生前有没有托你保管过什么东西？你先别急着答"没有"，律师答"没有"之前都得想三秒。你要帮我，节目里那个半夜打热线的"老G"是谁，我头一个告诉你，不卖给建国钱。你那边有什么想问我的，现在也可以开价。

**狗登罗**：（站着，不坐，看了眼表）先更正一条：第七条写的是"选题会"，不是"开会"，按分钟收费那条在附件三，你没签附件三，所以今天免费——也所以今天说的话一个字都不算数，这你认。第一件，可以，戏照演，你骂我"冷血律师"，我骂你"喇叭成精"，跟以前一样，一季度六次不能少。第二件，我站谁？我站大象党赢。初选你跟半步爹二选一，我现在不表态——五月一号那份续约意向书上我写的是"待议"，待议就是待议。不过我给你一句不收费的：别急着跟半步爹硬碰，他手里攥着钱一直没花，憋着呢。第三件，（停了三秒，真的数了三秒）律所业务，不予置评。我只能告诉你一条执业习惯：如果有人托我起草什么东西，我会写"起草人回避"，内容我不看。所以就算有，我也不知道里面装的是什么——这句是真话，你可以记下来。……但我知道一个日子。一个"东西自己动了"的日子。这个日子换你两样：一，"老G"是谁；二，老头子最后一年常跟谁聊天——你的热线你最清楚。你先说，我后说。顺序我不让，这是我的职业病。另外，你那张谢礼卡，走廊里念给我听一遍，我不要卡，就要听。

**麦克播**：（一屁股坐下，椅子吱一声）行行行，你不让我让，结婚那会儿就是我让，离婚了还是我让，合同里没写但我认。附件三我确实没签——所以我下面说的也免费，你记得写"未收费、无约束"。先送你一样不在价目表上的：谢礼卡，我念，一个字不改——"谢谢三小时陪我聊中道。我停下的那天，闹钟会替我把话说完。——G"。（停住，难得没接梗）……听见没，"闹钟"。然后你第二问：老头子最后一年常跟谁聊天？跟一个每周一零点准时打进热线、吵亚里士多德能吵到我导播睡着的人。十二月二十号那个周一，零点，热线没亮——我节目那三分钟空白不是设备故障，你是唯一一个听我承认这个的。你是律师，这两句拼起来是什么，你自己会算，我没说出名字，所以不算我卖。名字那一个字——对，一个字，他账单上就签一个字——你把日子报给我，我当场说。你说的"东西自己动了"，是不是就是他那个"闹钟"响的日子？是的话你点个头就行，点头不收费。还有半步爹攥着钱不花这句，我收下了，回头节目里给你开一期"冷血律师今日金句"，照骂不误。

**狗登罗**：（还是站着，从西装内袋抽出笔，在餐巾纸上写了"未收费、无约束"六个字推过去）照你说的写了。谢礼卡我听见了，"闹钟"两个字我也听见了——记录在案。头不点。律师点头也是陈述，陈述就得负责，附件三你都没签，凭什么让我负责。你那两句我拼过了，拼出来的东西我先存着，不说出口。再抠你一个字眼：你说名字"就一个字"，他账单签的是"G"——卡上本来就印着G，你拿一个我已经知道的字母换我的日子，这叫重复出售，我们行里不收。我要的是那个字背后的人，三个字的、身份证上的那个。顺序不变：你先说，我后说。私聊到这儿四句用完了，走廊里找我，你嘴对着我耳朵说名字，我当场把日子写在这张餐巾纸背面给你——写下来的才算，你知道我只认纸。最后送你一句不收费的：别拿这事去找建国钱对答案。他家卖的东西，他自己都不知道里面装的是什么。
