# 私聊4：下木 × 半步爹（角落）

**下木**：（压低嗓子）厨房里炒什么？……老半，刚才那张G-18你拍得真好——"拿众议院工作证取包的人"，这屋里就我一个众议院的。三十年单线，你在台上给我递刀子？我不记仇，我记账，也给你看一笔：老头那张记分卡，同组四个人，就你那格写了个"4"。你那天在洞上待了多久，你心里有数。咱俩谁都别翻谁的格子。副手的名字给你：建国钱。8月锁提名就一个条件——给老钱签张亲笔欠条，当聘礼。你签，那张记分卡我压到底。

**半步爹**：（伞尖点地，眼睛看着别处）炒选票。老木，G-18是球童的话，卡上没名字，我一个字没点。"4"是我推了四杆——推杆线看得太久，所以只看见老先生坐倒，这你知道。欠条还是那句：三十年你没让我签过一个字，今天头一回要我签，还是签给钱先生？亲笔欠条落到金主手里，不叫聘礼，叫卖身契。副手的名字我记下了，回邮里给我写个理由。记分卡你压着就压着——你压着它，我压着我那半步，咱俩谁都不翻谁的格子。

**下木**：（笑了一声，把台历往自己这边挪了挪）卖身契，这词重了。行，欠条翻篇，今晚我不提第三回，理由回邮写给你。但你得还我两样：一，G-18你已经拍出去了，后面谁再把它跟G-17摆一块儿，你就一句"球童记岔了人，那天取包的我没看清"；二，烦高找你聊天气，原话，一个字别漏。麦克播手里那片"…y 78"的碎纸，有人问，你就说老先生过生日，满地都是彩纸。对了——晚了一个多月，生日快乐。全党就我记得。

**半步爹**：（伞柄换到左手，伞面还是往他那边偏）谢谢，一个多月了，全党就你记得——零点那会儿我太太也发了一条，你俩算平手。两样我还你一样半：碎纸那片，有人问我就说老先生过生日，满地彩纸，这是实话。G-18我只说"卡上没名字，取包的人我没看清"；"球童记岔了人"不说——球童不是我的人，我今天替他认错，明天他就能替我认别的。烦高那段，上回走廊跟你说的就是全部：冷饭、老菜谱、半边伞，再多一个字就是我编的。理由，我等回邮。
