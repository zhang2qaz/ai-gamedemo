# 私聊第2轮：狗登罗（08）× 梅戏（04）

**狗登罗**：（站着，红领带一压，声音放低）梅记者，开门见山：B盒归你，恭喜。手稿我不要，那是你们记者的饭碗。但手稿里夹着的那件东西，是守口如瓶律所的寄存物，所有权在律所，拍卖行把它连盒一起卖了，程序上本来就有瑕疵。我不跟你打官司，按市价买回来：现钱3块，这一轮就去公示台登记，转让存根我来填，你只签个名。不卖也行，提醒你一句：那东西在不懂它的人手里是块铁，在想用它的人手里是把刀——建国钱刚才私聊已经在打听它了。价钱可以谈，你开个数。

**梅戏**：（把信封往怀里一收）狗律师，您这"所有权在律所"说得漂亮，可您律所自己的信写的是"此章已登记在您本人名下，仅限本人使用"——律所亲手登记给我的，怎么转头就成了拍卖行卖错了？再说规则写的是手稿印"按卡牌一换一"转让，现钱3块填得进存根吗？我不急着卖。您真想要，拿三样东西来换：第一，这东西是哪天、谁塞进我封好的箱子的；第二，它说的"用途另行公告"到底是什么；第三，您那句"他是干净的"，他是谁。三样说清楚，我给您优先权，谁出价我先问您。建国钱爱打听，让他打听去。

**狗登罗**：（还站着）你抠得对，现钱不能单独换卡——但规则写了资金赠予可以跟卡牌交易同时办。我改价：一换一，我给你一张黑料卡，当事人是你发小皮拉提，糊锅那段；再在公示台记账赠你2块。这张卡在你手里，就没人能拿它打她。你三问我答一个半：一，12月22日律所按委托人生前指示寄出，前台存根钉着，你自己去搜。二，我只说一句：它不能删任何东西、不能改任何东西，只能让某样东西晚点出来，而且一枚没用。三，"他是谁"——律师特权，你拿刀架我脖子上我也不说。成交就填存根；不成交，求你一件事：别卖给建国钱。

**梅戏**：（笑了一下，信封没松手）"一枚没用"——狗律师，您这句比前面那一串都值钱。一枚没用，说明得凑好几枚，说明您手里或者您眼里已经有别的了。您拿皮拉提的黑料来换，这一手挺毒：我收了算护她，不收就像我不管她死活。可这章是"让某样东西晚点出来"，我宁可它在我手里晚，也不想它在您手里晚。今晚不卖，不卖您，也不卖建国钱，这句我可以给您。等律所公告了用途咱们再谈价。那张黑料您先揣着，真拿出来打她，我这本采访本可是写得满满的。
