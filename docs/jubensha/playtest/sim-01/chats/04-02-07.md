# 私聊 4：烦高 × 建国钱（第2期走廊）

**烦高**：（摸鬓角，笑，背对着人）钱先生，又是我找您——拼图那张G-19您白出，人情我替冲浪州记着。就问三句。头一句：上回暗号您只接半句，这角落没第三双耳朵，下半句现在补上，我那笔账就销。第二句：您见谁都说"都是朋友"，我想问问，指的是哪种朋友？一起打第18洞那种，还是每月一号收信那种？第三句：认亲那张，您没写我——是忘了，还是故意的？桃子州我照旧揣着，一个字没动。

**建国钱**：（低头擦杯口，不看他）下半句我这辈子只在纸上回——你认旗那天起，嘴上那半句就作废了；谁在角落里张嘴就接得溜，你才该跑。"都是朋友"是哪种？Y-20年4月17号，周四，你第一封信落款那种；骰子州那三家给你的发胶钱，也是那种。认亲那张我故意空着：台上那么多眼睛，下木一点票，冲浪州跟金主连着线就挂出来了，不写是护你。现在谈买卖：你医院那张下张私密卡，原文念给我；我回你二月信里那句"账本是谁"——比听证上多半句。桃子州，照旧别动。

**烦高**：（摸鬓角，笑）四月十七号，周四——这个对上了，我认。暗号您不接，我记成您纸上欠我半句。医院那张G-06我原样念：心内科门诊，去年十一月，"储备极差，避免急性情绪刺激"；页边是他自己的字："知道了。球照打，他们总会来的。"实话说，狗登罗、麦克播、梅戏都看过，不值钱，我先付。轮到您——"账本是谁"后面那半句，我要原话，别转述。桃子州揣着，旗没到不落。

**建国钱**：（把杯子放下，声音压到杯沿底下）原话，就这一句，听完烂肚子里："账本不是人在写，是一把到了点自己会开口的锁在写；上锁的那个人，十二月十三号以后再没签过字。"——所以别找人，找人找不着。添头一句：下一页要是写到冲浪州，你先别认别辩，等我纸上的旗。这半句咱俩两清；纸上欠你那半句，跟第二张⛳18一起回。还有，你那张G-06页边那行字，别给第五个人看了，回头我按押宝网挂牌价买断。
