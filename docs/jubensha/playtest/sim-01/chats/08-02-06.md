# 私聊 8：烦高 × 半步爹（饭点，角落）

（记录说明：半步爹被叫到时本文件不存在，烦高的第1句未见记录；以下从半步爹这句开始。）

**半步爹**：（端着汤碗，半步站到他侧后）饭点，什么都不过手，我就问不答也行。第一，超级星期二我守了，皮拉提那边一分没填——您那边，麦克播那一州是谁填的，您心里有数就行。第二，伞还在梅戏手里，饭后要回来，那个信号照旧。第三，我得先算清一笔：两份一起拆了，您转驴、我转象——转过去以后，咱俩手里那张"怎么算赢"的纸还作不作数？您那本里要是写了，透半句；我这本没写，我不动笔。

**烦高**：（摸了下鬓角，背对大厅舀汤）一，大象那边我一分没填，信封里只有冲浪州我自己两块，麦克播那州谁填的我真不知道。二，伞的事我对不上——咱俩说好的是您抬帽檐，伞是哪天加的？饭后别换信号，换了我就当没约过。三，我那本也没写转过去怎么算赢，只写了"两人同时转入胸牌那边"，所以我按字面算：转了我就是真驴，您是真象，十一月各凭本事。这个我饭后要当面问DM，问清了再动笔，三块钱不能押在一句"大概"上。还有——党鞭刚才在饭桌问我"老半聊没聊到第18洞"，您掂量。
