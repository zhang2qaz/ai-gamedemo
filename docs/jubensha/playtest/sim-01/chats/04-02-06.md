# 私聊 4：烦高 × 半步爹（终局F1走廊·第2沙漏，角落）

**烦高**：（背对公示台，先摸了下鬓角）老半，长话短说，三分钟后就封信封了。您那页念的是"旗子插在哪儿，他的球就往哪儿推"——您收的条子右下角，是不是一面小旗、旁边带个数？您先报数，对上了，我把第18洞我知道的那半张给您，咱俩一人半张，凑一张指认卡，谁都不白交。还有一笔账：我现在是票外的人，桃子州我替红票加三、砸蓝票二。您是西厅的竞选经理，您手里那几块，往哪个州、哪张票上使？

**半步爹**：（伞收着靠在腿边，这回没往谁那边偏）右下角是一面小旗，旁边一个"18"，三十年没换过号——我先报了。您那张要也是18，那咱俩的近况是寄进同一只信箱，回卡片的是同一只手。您那半张现在给我：纸上写的什么，还是谁递出去的，一句就够，我好填卡。钱的事——我牌子挂红，是西厅的经理。桃子州您砸您的，我不跟着砸，也不拦。剩下那几块我攥着，等第二周钢铁州开门，那是我爹交了三十年会费的工会。

**烦高**：（摸鬓角，笑了一下）18，对上了，咱俩是一个信箱。那我那半张直说：旗杆是建国钱扶的；两头吃最后半句"……来了"——这句是麦克播转给我的，源头就是您。所以我那半张，一半是您自己的话，我不跟您装大方。我的推法：他第18洞读的就是一张小旗卡，扶旗的手、回卡的手，八成是一只手。指认我往建国钱写，您自己掂量。钱的事我只求一句：钢铁州开门那周，您那几块别落蓝票，落红票我欠您一个人情。还有，"…y 78"这几个字您见过没有？

**半步爹**：（把收着的伞往自己腿边拢了拢）"…y 78"？那天是老先生七十八岁生日，蛋糕上、餐巾上、球童帽檐上全是78，我一个看推杆线的人，分不清是哪张纸上的。指认您往哪儿写是您的事，我不替您掂量，也不抄您的。钱——您那句人情我记下了，可钢铁州开门那周往哪落，我得先看第一周开出来的风向，不给您写条子，也不哄您说一定落红。一个信箱里出来的两个人，往后各寄各的近况吧。
