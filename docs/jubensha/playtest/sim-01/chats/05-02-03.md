# 私聊5：烦高 × 下木（F2 第二周走廊·第1沙漏）

**烦高**：（摸鬓角，笑）下木，饭桌上你问我"大象怕什么"，我欠你半句，今天来还账。不过先算一笔：我现在是独立参选人，蓝票上坐的是皮拉提和梅戏——翻你台历、把你锤到2的，头一个就是梅戏。你那几块钱再往蓝票里投，等于给记你账的人发工资。铁锈带钢铁、轮胎、奶酪，你钱打算落哪州、哪张票？你要是红票压一州，或者干脆攥着不投，我把下半句告诉你，再把第18洞旗杆那边我拼出来的东西给你。你先报州，我后开口。


**下木**：（拿筹码敲桌沿）你先报州我后开口——三十年都是别人先开口，我后记账。行，给你半个州：钢铁州十九票，这周我一块钱不往蓝里扔，攥着。轮胎、奶酪我不保证。你先把"下半句"和旗杆那边拼出来的东西说一句，我掂掂分量；分量够，奶酪我也攥着。还有，五点半你把梅戏的特稿往"周四晚上十点那位"身上拨——这笔我记着呢，今天你这句话，算不算还账？另外问一句：旗杆这俩字，你从谁嘴里听来的？

**烦高**：（摸鬓角）半个州换半句话，公道。旗杆不是谁嘴里听来的——会所露台那张G-14是我亲手翻的，公开卡："钱先生一直扶着旗杆，老先生倒下前回头看了旗杆一眼。"我再白送你一截：老先生最后半句是"……来了"。谁来了，你记账的人自己掂。五点半那笔，算还一半——你被锤是举牌不记名，梅戏那一嗓子可是记名的。暗号下半句我照旧压着：奶酪州你不光攥着、是往红票落，下周我当面补齐，一个字不少。钢铁州攥住，我信你三十年没换的号码。

**下木**：（把筹码收回兜里）"来了"——老人家七十八，那天谁走过去他不说"来了"？球童端水也是"来了"。倒是你那张卡写得明白：扶旗杆的是钱先生，回头看旗杆，那就是看钱先生。我那会儿在果岭边扶人，离旗杆远着呢，这句你记清楚，别往我这儿拨第二回。账这么结：钢铁我攥着，奶酪我也一块不进蓝——但红票我不落，驴党党鞭往红里砸钱，明早就上公示台，你我都难看。下半句你压着吧，我这把年纪，大象怕什么，我比你早知道三十年。
