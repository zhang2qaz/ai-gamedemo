# 私聊8：烦高 × 麦克播（F4 第三周第2沙漏）

**烦高**：（摸鬓角，背对公示台）博士，最后一笔账，算给你听：摇摆州九十四张，过四十八。咱们锁了骰子加奶酪十六，还差三十二——钢铁十九加桃子十六正好三十五，够了。仙人掌、烤肉别撒钱，撒匀了哪州都是胶着。我剩的两块全进钢铁红，最后一枚分票砸钢铁蓝。你和狗律师手上还剩几块？录音那张留到现在，就砸桃子蓝。再提一句：下木刚在我这儿起了上半句暗号，还要我把旗杆那半句烂掉——他名录上挂着号，你别跟他对暗号，欠条袋冻结前一张都别签。

**麦克播**：（帽子不在头上，只好摸后脑勺）账你算得比我节目三小时还清楚，我认。交底：我兜里**零**，狗律师也**零**——钢铁四块上周就填完了。录音那张？上周已经砸了钢铁蓝，别指望。咱俩这周只剩站台，原本都站钢铁；我改站**桃子红**，钢铁留给她，一人一州，跟你钢铁红两块、桃子背书刚好凑上。下木那半句我不接，他名录上挂着号，我连鸡翅骨都不递他。欠条袋我交空的，狗律师也空的。就一句：你那枚分票砸钢铁蓝，别手滑砸到别处。

**烦高**：（摸了下鬓角，笑得有点僵）博士，你这账有一处得改：桃子背书我早用完了，手上一张都没有。所以桃子红只剩你一个人站台，薄得很——我不骗你，桃子十六张我现在不敢算进来。那就别两头撒：钢铁我两块红、分票砸钢铁蓝、狗律师站钢铁红，三样叠一州，钢铁十九先吃稳。桃子你照站，算白捡，赢了是运气，输了别怪账。分票我砸钢铁蓝，不手滑，你放心。欠条袋我也交空的。一句话：今晚不是比谁铺得广，是比谁哪一州没漏。

**麦克播**：（把手从后脑勺放下来，压低嗓子）行，桃子背书没了，账我改。可你自己那笔账也得认一句：钢铁十九吃稳了才三十五，没桃子过不了四十八——桃子放弃，等于整场放弃。所以我照站桃子红，不挪。钢铁归你两块红加分票砸蓝，再加狗律师站台，我回头就跟她说"钢铁你一个人顶"。博士最后跟你交个实底：我欠条袋交空的，下木那半句我烂在肚子里。分票要是手滑了，三小时节目我专门聊你——这回我一句正事都聊。
