# 私聊2：下木 × 半步爹（角落）

**下木**：厨房里炒什么？……嗯，炒选票。老半，长话短说。第18洞那天的说法咱俩得对齐：大家排队给老师贺寿，你在看推杆线，一抬头老师坐下了，我离得近扶了一把——就这些，"卡片"俩字谁都别提。麦克播说过零点要来问你，你就一句"生日不谈丧事"。还有，烦高约你"聊天气"，别单独去，那孩子跟咱不是一路。钢铁州那19票我替你记着，回头签张欠条给我，算党费，8月那一步我保你。生日快乐，零点后见。

**半步爹**：炒选票——三十年了，您还是先把洋葱圈推过来。口径我记住了：我看推杆线，一抬头老先生坐下了，您扶了一把，别的我没看见，也没什么可提的。烦高那孩子刚才问我"大象怕什么"，我没答上来；您说不是一路，我就不往他伞底下站。欠条的事容我缓缓——钢铁州那6块是我自己攒的工资，签了名的纸落到谁手里都是把柄，单线的规矩还是您定的。零点后您先告诉我"8月那一步"是哪一步，我回邮里一句近况都不少写。

**下木**：（把洋葱圈推过去）规矩是我定的，你守得对，欠条先欠着，欠我一句话就行。8月那一步：象党提名锁死在你名下，副手人选我来塞，你到时只管点头。细的零点后回邮里写。烦高问你"大象怕什么"——他在试你是不是那边的老人。下回他再问，你就说"不知道，我属驴"，别接茬。他今晚还跟你说了啥？一个字一个字告诉我，回邮里写也行。

**半步爹**：（把洋葱圈掰一半推回去）欠您一句话，我认。烦高没说几句：先问我第18洞那天心里怎么想，我说看推杆线；他自己说他家灶上"只炒冷饭，老菜谱，口味改不掉"，又说往后钢铁州下雨，他替我撑半边伞——我说雨大了再说，没应。就这些。"我属驴"那句我就不说了，象党副总统嘴里冒出这仨字，明早就上梅戏的头版。副手人选您塞谁，零点后回邮里先给我个名字，我再点头。生日的事，谢您记着。
