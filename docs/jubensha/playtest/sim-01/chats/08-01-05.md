# 私聊 8：皮拉提 × 麦克播（饭点，角落）

**皮拉提**：（端着餐盘挤过来，叉子当话筒戳到他鼻尖）麦博士——哦不对，麦大嘴，饭点不许交易，我就动动嘴。三件事。一，律所说三枚章，你一枚我一枚，你前妻一枚没有却满场替人跑腿，替你跑的吧？你想压第几页，今天当面说；谁敢压第九页，在我这儿就等于自报沼泽。二，我党代会零票我认，可规则卡写搭档能跨党、不花钱——你西厅要是拿下提名，求婚卡上写寿星的名字，我给你的节目当三个月嘉宾。三，上回你那句"大象怕什么"，后半句到底是啥？你说全了，我也说全。

**麦克播**：（拿鸡翅骨当话筒回戳过去）寿星，三件事按顺序回。一，我那枚章零点前谁也不借，第九页该见光就见光——谁找我压第九页，我比你先喊沼泽；我前妻跑的是她自己的腿。二，求婚卡写你我乐意，可你今天才三十四，副总统得三十五，DM一判不合格我白烧一次求婚。你先问清"年龄合格"按哪天算，再谈三个月嘉宾；另外你那枚章零点后只跟我盖，不跟建国钱、下木坐一张桌。三，口令？上回我先开的口，这回寿星先把"厨房里炒什么"下半句说全。

**皮拉提**：（啪一声把叉子拍桌上）麦大嘴你作业没做！规则书第15条白纸黑字：按**就职日**算——明年一月二十号我三十五岁零一天，差一天，也是够！合格，你那张求婚卡烧不了。你牛仔州我大苹果州，也不撞州。章的事我改一半：建国钱、下木连章都没有，我不跟他们坐一桌，这条答应你；"只跟你盖"不行——第九页谁都别压，压七还是八，申请书念给我听，我点头才落章。口令？傻了吧，上句是问的人说，下句是答的人接——我问过了，你没接。你先把"大象怕什么"下半句说全，我再考虑把锅掀开给你看。

**麦克播**：（把鸡翅骨插回餐盘）行，第十五条我服，差一天也是够——求婚卡上寿星的名字我先留着，三个月嘉宾一期不能少，第一期就聊"差一天"。章按你的来：零点后谁想压七压八，申请书先念给咱俩听，两人都点头才落章，第九页谁也别碰。口令嘛——寿星，"大象怕什么"是我上回问你的，你原样问回来，那叫鹦鹉学舌，不叫对暗号。你家锅掀不掀随你，我这下半截，留到就职典礼那天站台上说给你听。
