# 私聊7：烦高 × 下木（F4 第三周走廊）

**烦高**：（摸鬓角，这回没笑）下木，第9页一念，你跟建国钱排在一行，装不熟也没用了。我不翻旧账，算最后一笔：皮拉提当众说"你们的汤自己热"，蓝票上去，你三十年的账一个字兑不了；红票上去，门至少还开着。上周你说红票落钱"明早上公示台"——DM六点十二说过，投放永远不报谁投的，公示台只记赠予。最后一周没播报没锁票，你剩的钱往钢铁或桃子红票里落，暗号下半句我今天当面还你。给我一个州名就行。


**下木**：（压低嗓子，背对公示台）上周我说的是"红票不落"，不是"明早上公示台"——你这账记岔了，不过岔了我不计较。州名给你：**钢铁**。我剩的钱往钢铁红里落，数别问，开票自己看。下半句你留着，我早会了；我换另一样：第18洞那根旗杆、"……来了"那半句，从今晚起烂在你肚子里，梅戏、狗登罗问起，你就说球童看错了。第9页说种子的名字他带走了——带没带走，你我都别去翻。成不成，点个头。

**烦高**：（摸鬓角，笑了半下）账我记岔了，认。头我点——旗杆那半句，从这儿起我嘴里只有"球童看错了"，第9页那一行我也不翻。可你说下半句"早会了"，那你得让我听一耳朵：上半句你来起，我听对了，才算咱俩是一个灶上的。钢铁红票我记下了，开票那天钢铁要是蓝的赢了，我不找你算账，只是以后这条走廊，你我就当没站过。

**下木**：（拿手指在桌面上敲两下，声音压到只够你听）行，我起，你听着：大象怕什么？——下半句别出声，在肚子里接上就算对上了；你嘴里念出来，就是你当着我认了你那张胸牌底下是什么颜色，这个我不逼你。一个灶上的，记账不用写字。钢铁红我说落就落；钢铁要是蓝的赢了，走廊你可以当没站过，可旗杆那半句你还是得烂着——那是你的命，不光是我的。散吧，背对着走。
