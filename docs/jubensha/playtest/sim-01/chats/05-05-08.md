# 私聊第5轮（终局F2走廊第1沙漏）：麦克播 × 狗登罗

**麦克播**：（帽檐一压，蹲到角落）律师，先谢你那笔锁票钱，骰子州落袋了，数我不问，账记心里。说正事：铁锈带三个州，我手里还攥着张轮胎州大锅饭背书，夹红+3，我钱跟着压轮胎；钢铁十九票最大，你能往钢铁红票填几块？上周我跟对面约了互不砸，这周解禁——那段"选民就是流量"的录音，砸钢铁蓝还是奶酪蓝，你定。再两件私事：第七页，我跟对面那位把它摁到明年了，别问我为啥挑七。还有，你今晚当众念合同，掌心写"18"和"5/1"，啥意思？

**狗登罗**：（站着，看表，没看他）钢铁红票我填4，兜里就这些，站台也站钢铁，跟你轮胎背书错开。录音砸钢铁蓝，十九票砸大不砸小——先问DM录音算不算黑料卡、打不打得着那张票，别砸空。第七页我不问，记账：欠你一页。另一枚章是谁的？梅戏答应盖前喊我一声，我要知道她守没守信。掌心：18是作业，交了；5/1是你说合同到期那天。写了又划掉——不知道这礼拜三还算不算例会。帽子礼拜三还你，你准点，我不早到。

**麦克播**：（把帽子摘下来，扣进她手里）另一枚是皮拉提的，她跟我同按的。梅戏没盖，所以她没欠你那声招呼——这名字你烂肚子里，DM公告只报页码。钢铁红你填4，我轮胎背书夹+3、兜里剩的全压轮胎，奶酪先放；录音我先找DM问打不打得着蓝票，打得着就砸钢铁蓝，十九票砸大不砸小，听你的。帽子别礼拜三还了，你先戴着。合同五一到期了，礼拜三不算例会，算我请你吃饭。我就问一句，不按合同条款问：你站我这边，是真心，还是习惯？

**狗登罗**：（帽子攥在手里，没戴，也没坐）皮拉提……行，这名字我烂肚子里。梅戏没盖，那她没欠我。钢铁红4，签字算数，我现在就去填。你那个问题——合同条款里没有这一条，所以我按律师的规矩答：习惯是真的，真心也是真的，这两样我分不开，十年了，我自己也没查清楚。帽子我先戴着。礼拜三那顿饭，你准点，我也准点——不早到了。
