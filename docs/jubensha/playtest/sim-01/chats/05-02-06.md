# 私聊 5：烦高 × 半步爹（第2期走廊第2轮）

**烦高**：（摸鬓角，笑）副总统，上回您说雨真下大了再说谁撑哪半边——今晚雨够大了。不聊天气，聊点旧事：下木党鞭刚才当众叫您"咱青年团出来的老相识"，我好奇，您当年在青年团里，当的是什么主席？再问个不相干的：两个人守一头鹿，有一个跑去追兔子，您说那头鹿最后归谁？您答得上，往后有一夜要交信封，咱俩谁都不必白交那份钱；答不上，就当我研究发型研究糊涂了。


**半步爹**：（伞柄斜靠在两人中间，声音放低）主席？下木记性好，我只记得那年给一屋子人倒过茶。鹿我答得上：一个跑去追兔子，鹿就谁也得不着，追兔子的那位拎只兔子回家，守鹿的那位白蹲一夜；两个人都守到天亮，鹿才算两人的。可守之前，我得知道对面蹲的是不是同一头鹿。你那本老菜谱，你入门那天——是哪个周四，几月几号？你说得出那个日子，那一夜的信封我跟你一块儿交；说不出，咱俩接着聊天气。还有，这话别让党鞭听见，有人叮嘱过我离你远点。

**烦高**：（摸鬓角，没笑）同一头鹿，我信。日子给您——四月十七，周四，书房，有人跟我说"你是唯一的一颗种子"。年份您自己算，算对了说明您那本菜谱跟我是一个灶上的。"唯一"这俩字我记了二十年，今晚看来是骗人的。礼尚往来：您的周四，或者您的周五，几月几号？还有，叮嘱您离我远点的那位——是不是总说"都是朋友"的那位？您点个头就行。信封那夜，咱俩同一刻递，谁先递谁吃亏，谁都别先。

**半步爹**：（伞柄往他那边推了半寸，眼睛看着别处）书房、周四——我那四个字不是在书房听的，是在酒馆，配半个洋葱圈，比你早十年。所以"唯一"骗的不止你，骗咱俩的多半是同一张嘴。我的日子今晚不给：我那张纸上那格是涂黑的，你报什么我都只能信，咱俩扯平。叮嘱我的不是"都是朋友"那位——那位只管两边押。摊牌夜同一刻递，谁都不先；可递之前，"过去以后站哪边"这笔账，我得自己再算一遍。
