# 私聊第4轮：梅戏（04）× 狗登罗（08）（F1走廊投放合一·第2沙漏）

**梅戏**：（把采访本合上夹在胳膊底下，压低声音）狗律师，就三分钟，我不绕。第一，壮壮蛋白粉的钱是从哪个账户汇的——厂家对公户，还是某个邮政信箱？你速记卡上写了个"5/1"又划掉，那是你俩"互骂合同"签字那天吧，蛋白粉那份是不是同一天的？第二，你背调建国钱"不一致"，那你晚宴上说的"他是干净的"肯定不是他——是谁？我拿一样东西换：你那张"三百字免责声明"的黑料在我手里，答得实在，今晚我不拿它打你。最后随口一问——厨房里炒什么？

**狗登罗**：（站着，没接她递来的笔）梅记者，规矩先说：您那张"免责声明"黑料，报编号——当事人是我的H08在我自己手里，DM登记过户的。您那张真有，再谈打不打。实话部分：蛋白粉的钱走哪个户我没经手，我只审条款；5/1就是三方协议签字日，就一份，第2页早公开了。第二问：八年前那句"他是干净的"，您第4页的线人报完一周后上来的是谁，您比我清楚，我不替您念名字。厨房炒什么，规则书上没这道菜，暗号我不对。我要换的：您那枚手稿章跟谁盖之前，先喊我一声。

**梅戏**：（不掏卡，只报数）H32，第3册附袋DM亲手发的，卡面当事人写的就是您，"签名后面三百字免责声明，比正文还长"。您手里那张H08要也是这句，那就是一桩黑料印了两张，回头咱俩一起找DM对。"一周后上来的是谁"我听懂了：八年前给半步爹做背调、写"干净"的是您。那我再问一句：您怎么知道我采访本第4页记的是线人？还有三方协议，厂家是谁牵的线？答实在了，盖章前我先喊您一声。只是喊一声，不问您同不同意。

**狗登罗**：（看了眼表，没坐）第4页是账本8/15零点当众落的，全场都听DM念过"线人"俩字，这不叫我知道，叫我识字。厂家谁牵的线——合同上没有牵线人那一栏，纸上没有的我不答，答了就是编。H32跟H08撞车这事，散场前咱俩一起举手找DM，谁的卡是印错的谁认，在此之前您别打，我也不拿H28打您——对等。"喊一声"我收下，记住是盖之前，不是盖完。最后送您一句不要钱的：您第4页那位周四先生，今晚还在这屋里打着球，您采访本上那个问号，别只画在一个人名字后面。
