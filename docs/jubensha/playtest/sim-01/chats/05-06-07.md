# 私聊5：半步爹 × 建国钱（F2第二周走廊·第1沙漏）

**半步爹**：钱先生，借您一步，就两句，说完我就回伞底下。头一句是送您的：狗登罗在找第18洞"弯腰捡信封"的人，摸到旗杆边上来了——我跟她讲的是，您那天两只手一直攥着旗杆，从老先生坐倒到医生上果岭，没腾出来过。第二句是问您的：八年前七月十九号上午，有人打电话催背调，"都是朋友，别拖"——那电话是您自己想打的，还是周四陪您打网球那位让您打的？您给我句实话就行。钢铁州是我老家，这周我自己守门口，您也别往我老家撒红钱；咱俩谁都不用签条子。

**建国钱**：旗杆那句我收下，算我欠您一瓶——两只手攥旗杆，这话以后我也这么说，一个字不改。电话那句我给实话：我自己打的，没人让。那礼拜押宝网开了"谁补老汤的位"，我押您，赔率最肥，背调拖过盘口关门我就白押了。打网球那位连我押谁都不知道，别往他身上记。钢铁州我不碰，红钱我撒轮胎、奶酪。换您一句：您手里要是有麦克播或狗登罗签的条子，我三块收，现钱，不问来路。

**半步爹**：条子我手里一张没有，我这人不签也不收，这门您敲错了。倒是您急着三块收麦克播、狗登罗的条子——收的是谁的账，我不问，也不传。那瓶酒我记下了，可您这句实话我得退回半句：押宝网是您家开的，庄家押自己的盘，还怕盘口关门？赔率最肥那天您敢押，兜里得先揣着张名单。谁给的我不问。就一句：这礼拜老木找过您没有？您不吭声，我就当找过。

**建国钱**：找过——周四照打，他照输我一瓶，打完骂我"吸血鬼"，跟电视上一个味儿，这算不算"找"，您自己记。名单那句您说对一半：庄家兜里揣的不是名单，是赔率表，谁背调干净我押谁，那年全场就您最干净，用不着谁递。您不收条子，那咱换样东西：钢铁州我说不碰就不碰，您第二周轮胎州也别站台，咱俩各守一亩地，谁也不踩谁的苗。那瓶酒，开票那晚我亲手给您开。
