# 私聊 2：烦高 × 建国钱（第1期走廊第2轮）

**烦高**：（摸鬓角，压低声音，笑）钱先生，我知道您那张卡上写着"别找我"——可第2轮了，咱俩再绕着走，倒像是约好的，干脆碰一杯。就三句，说完我走。头一句：大象怕什么？第二句：半步爹那边有自己的菜谱，拿"厨房里炒什么"试我，周四他不认，说是周五——那不是咱们这条线，您心里有个数。第三句：A盒归了您，我不问里头是什么，只问一句：那东西会不会落到我头上？我兜里不宽，帮不上钱；能帮的是桃子州那张背书，终局往哪边落，您给句话。

**建国钱**：（不看他，盯着手里的香槟杯）大象怕什么？怕老鼠，更怕账对不上——下半句我不在走廊里接，你懂规矩。半步爹那道菜我记下了，周五不是咱们的灶，别跟他对。A盒里那张东西印了四个名字，没有你，落不到你头上，我拿它压箱底。桃子州那张背书你先揣着，谁出价都别卖；终局我给你递一张⛳18，旗朝哪边，你就往哪边落。交换就一样：半步爹约你"聊天气"，到底聊了什么，下个月一号的近况里多写一行。
