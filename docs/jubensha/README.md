# Ascham工作室 · 美国竞选城限欢乐阵营本 —— 创作总流程

> 品类：纸质实体 / 城限 / 欢乐 / 阵营（机制驱动）/ 本格
> 人数：6–8人（8人满配，6、7人可适配）　时长：7–8小时
> 题材：当代美国政坛 · 《纸牌屋》式权谋 · 终局大机制为竞选美国总统
> 玩法参考：《青楼2》《水镜八奇》《搞钱2》的机制精神（只做移植，不照抄）
> 核心玩家：城限阵营本中度玩家

本目录是整个剧本从零到发行的工作区。下面是把"一个优质剧本的创作流程"拆成的阶段和具体动作，每个阶段写明产出物和验收标准。

## 第一阶段：顶层设计（当前阶段）

顶层设计是整个项目里最难、改动成本最高的一步：世界观、阵营、人物关系网、真相因果链、流程骨架和终局大机制都在这里定下来，后面的环节都在它上面展开。所以这一阶段用"多路竞稿 → 多视角评审 → 合成 → 对抗审查 → 修订"的方式做，不靠单稿一次写成。

### 1A 研究与概念竞稿

1. **三路研究**（`phase1/_process/research-*.md`）
   - 参考作品机制拆解：《青楼2》《水镜八奇》《搞钱2》，每条信息标注可信度，并给出移植到竞选题材的转化方案
   - 美国政坛素材库：当下政治生态（只用作映射底色）、总统选举全流程硬知识、《纸牌屋》权谋套路、讽刺梗、虚构化命名
   - 玩家画像与产品规范：中度城限阵营玩家画像、欢乐技法、弹性人数、长本节奏、DM能力惯例、城限物料规范
2. **四路独立概念竞稿**（`phase1/_process/concept-A~D.md`），每路主攻一个方向：
   - A 权谋反转派：人物网与多层反转驱动
   - B 机制博弈派：统一资源经济，各幕机制联动
   - C 阵营拉扯派：明暗阵营、双面间谍、转阵营与平衡
   - D 欢乐讽刺派：表演环节、名场面、讽刺梗
3. **三视角评审**：玩家体验与欢乐度 / 逻辑严谨与反转质量 / 机制可玩性与落地，逐维打分并提出嫁接建议
4. **合成核心方案 v1**（`phase1/01-core-concept.md`）：选定基底方案，嫁接其他方案的长处，修掉评审指出的问题

### 1B 深度设计与对抗审查

5. **故事圣经**（拆为两份并行撰写）：`phase1/02-characters-relations.md`（8个角色完整设定、8×8关系矩阵、反转阶梯、戏份矩阵）与 `phase1/03-truth-timeline.md`（真相总时间线、死人开关与九页账本、第18洞、信息分布表、"为什么不"压力测试、真相题）
6. **流程与机制**（`phase1/04-flow-and-mechanics.md`）：分幕流程与时间预算、每幕机制规则骨架、资源经济、角色技能、6/7/8人适配
7. **终局竞选大机制**（`phase1/05-finale-election.md`）：竞选各阶段的规则、选举人团计票、与前几幕资源的接口、边界情况、DM主持要点、DM能力画像与硬性要求、结局矩阵
8. **五维对抗审查**：因果逻辑 / 阵营平衡 / 体验节奏 / 反转戏剧性 / DM与纸质落地，每条问题分级并附修复方案
9. **修订与一致性校验**：统一修订计划 → 分文件修订 → 跨文件一致性校验 → 复审，直到没有致命问题为止
10. **顶层设计圣经定稿**（`phase1/README.md`）：一页纸总纲 + 各文件索引 + 留给第二阶段的问题清单

### 第一阶段验收标准

- 真相因果链中的每一环都能回答"为什么"和"凭什么做得到"，没有"作者需要所以发生"的情节
- 8个角色之间每一对都有实质关联，反转不少于8个，每个反转都有铺垫和揭示时机
- 阵营结构在6、7、8人下都成立，没有必胜策略、造王者问题，也没有人过早出局
- 每一幕都写清楚玩家在做什么、要做哪些决策、资源怎么流动，总时长核算在7–8小时
- 终局竞选大机制写到能想象实际怎么玩的程度，DM能力要求明确
- 名字好记、欢乐、自带人设，不使用真实政治人物的姓名
