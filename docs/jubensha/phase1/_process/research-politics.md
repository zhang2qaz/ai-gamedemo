## B. 美国总统选举全流程硬知识（游戏机制依赖，务必准确）

### B1. 时间线总览（以一个"总统大选年"为例）
| 阶段 | 时间 | 关键事实 |
|---|---|---|
| 隐形初选 | 选前1–2年 | 抢金主、抢幕僚、抢背书；成立探索委员会 |
| 初选/党团会议 | 选举年1月–6月 | 各州自定日期与规则；"超级星期二"（3月初十几州同日） |
| 党代会 | 7–8月 | 正式提名总统候选人与副总统搭档；通过党纲 |
| 大选辩论 | 9–10月 | 通常2–3场总统辩论+1场副总统辩论 |
| 提前投票/邮寄 | 9月下旬起（各州不同） | 2020/2024年约半数以上选票在选举日前投出 |
| 选举日 | 11月第一个星期一之后的星期二 | 2028年为11月7日 |
| 州认证 | 11月–12月上旬 | 《选举计票改革法》（ECRA 2022）：州须在选举人投票日前6天发出确认证书 |
| 选举人投票 | 12月第二个星期三之后的第一个星期二 | 各州选举人在本州首府投票 |
| 国会计票 | 次年1月6日 | 副总统主持，**仅为程序性角色**（ECRA明确）；异议需每院1/5议员联署 |
| 就职 | 次年1月20日正午 | 宪法第20修正案 |

### B2. 初选与党团会议
- **初选（Primary）**：州政府主办的投票。类型：封闭式（仅本党注册选民）、开放式（任何人可选一党投）、半开放式、"丛林初选"（加州等州级选举，所有候选人同场，前二晋级——注意**总统初选不用丛林制**）。
- **党团会议（Caucus）**：党组织主办的集会式选择，公开站队、多轮游说。爱荷华共和党仍以党团会议开局；民主党2028已将爱荷华移出早期州。**"站角落、被拉人"的现场形式天然适合剧本杀。**
- **代表票（Delegates）**：
  - 民主党：各州按得票**比例分配**，门槛15%（低于15%不得代表）。2024年约3,900+承诺代表，首轮需承诺代表过半（约1,976）。
  - 共和党：各州自定，**大量"赢者通吃"或"超过50%通吃"**州；2024年共2,429名代表，需1,215。
- **超级代表（民主党"自动代表"）**：党内要员（国会议员、州长、DNC委员等，约700+）。**2018年改革后，第一轮投票不得投票**；若首轮无人过半，进入"竞争性党代会/经纪人党代会（brokered convention）"，第二轮起超级代表加入，承诺代表也逐步"松绑"。共和党无同等机制（仅有每州3名党委成员作为代表，多数受约束）。
- **承诺代表的约束**：民主党代表"凭良心反映选民意志"，规则上非绝对法律约束；共和党多州规则要求首轮按结果投票。
- **退选与代表**：候选人退选后，其代表可"释放"给他人——**"把我的代表卖给你"是天然交易机制**。

### B3. 党代会与副总统搭档
- 党代会议程：资格审查（credentials，可挑战代表资格）→ 规则委员会 → 党纲 → 唱名投票（roll call，各州依次报票，常有"把最后一票让给家乡州"的仪式）→ 提名演讲 → 副总统提名 → 接受提名演讲。
- **副总统搭档**：惯例由总统提名人"指定"，党代会形式上投票通过。历史上1956年民主党曾开放代表票自由选副手。选择考量："平衡票"（地域/年龄/派系/性别）、"不抢风头"、"背景审查（vetting）"——**背调没做干净是经典丑闻起点**（1972年副手因精神病史被换下仅18天）。
- 宪法第12修正案：总统与副总统**不能来自同一州**的选举人（严格说是：一州选举人不得同时投票给两位本州居民）——2000年切尼因此把住所从得州迁回怀俄明。**可做"搭档必须跨州"规则。**
- 若提名人在党代会后退选/死亡：由**全国委员会（DNC/RNC）**按党章补选，而非重开党代会（2024年民主党换将发生在党代会前，通过"虚拟唱名"完成）。

### B4. 辩论
- 传统主办：**总统辩论委员会（CPD，1987起，两党合办的非营利机构）**。入场门槛：全国5家民调平均≥15%、且在足以赢得270票的州具有选票资格。**→ 第三党几乎永远进不了辩论台。**
- 2024年两党候选人绕开CPD，直接与电视网（如6月CNN、9月ABC）约辩，规则包括：**不讲话时静音麦克风**、无现场观众、不得携带笔记、主持人可现场事实核查（争议点）。
- 形式：主持人提问式、市民大会式（town hall，观众提问）、开场陈述/结辩。
- 辩论影响：通常改变1–3个百分点；但**单场灾难性表现可导致退选**（2024年6月）。

### B5. 选举人团（Electoral College）
- 总数 **538**（众议员435 + 参议员100 + 华盛顿特区3），胜选需 **270**。
- 2024/2028使用2020人口普查分配：加州54、得州40、佛州30、纽约28、宾州19、伊利诺伊19、俄亥俄17、佐治亚16、北卡16、密歇根15、亚利桑那11、威斯康星10、内华达6、缅因4、内布拉斯加5。
- **赢者通吃**：48州+DC。**例外：缅因（4票=全州2+两个国会选区各1）与内布拉斯加（5票=全州2+三个选区各1）**按"国会选区法"分票。2024年内布拉斯加第2区（"蓝点"）投民主党、缅因第2区投共和党。**→ 一个城市选区的1票可能决定总统，非常适合做"最后1票"戏剧点。**
- 缅因州总统选举使用**排序复选制（ranked choice）**。
- **不忠选举人（faithless elector）**：选举人违背承诺投票。2016年有7名（史上最多一次）。**2020年最高法院"Chiafalo v. Washington"案一致裁定州可惩罚或替换不忠选举人**；约三分之二的州有约束法律，部分州会当场作废其投票并替换。**→ 游戏中"策反选举人"必须设计成高成本/大概率失败/仅限无约束州。**
- **269:269平局或无人过270**（宪法第12修正案"条件性选举"）：
  - 新一届国会（1月3日就职后）于1月6日计票后进行；
  - **众议院选总统**：在得票前三名中选；**每州代表团一票**（州内议员先内部投票决定本州一票），需**26州过半**；代表团平票则该州弃权；
  - **参议院选副总统**：在副总统得票前二名中选；**每位参议员一票**，需全体参议员过半（51票）；
  - 若至1月20日众院仍未选出总统、而参院已选出副总统 → **副总统当选人代理总统**；若都没选出 → 按《总统继任法》由众议院议长代理（需辞去议员）。
  - 历史：1800年（杰斐逊）、1824年（亚当斯，"腐败交易"传说——第四名候选人议长克莱支持亚当斯后被任命为国务卿）。**"1824腐败交易"是绝佳剧情原型：议长卖票换国务卿。**
  - 《纸牌屋》第5季正是用"选举受阻→众院僵局→参院选出副总统代理总统→摇摆州重投"做终局，可借鉴（见C节）。

### B6. 竞选财务（2025–26周期限额，FEC通胀调整）
| 捐款方 → 接收方 | 限额 |
|---|---|
| 个人 → 候选人 | **每次选举3,500美元**（初选、大选分别算，即一周期7,000） |
| 个人 → 全国党委（DNC/RNC等） | 每年44,300美元 |
| 个人 → 党委特别账户（建筑/重新计票/党代会） | 每账户每年132,900美元 |
| 个人 → 普通PAC | 每年5,000美元 |
| 多候选人PAC → 候选人 | 每次选举5,000美元 |
| 个人/公司/工会 → **超级PAC** | **无上限**（2010年"联合公民案"+SpeechNow案） |
| 501(c)(4)"社会福利组织" | 无上限，**无需公开捐款人**（"黑钱"主通道） |
- **协调禁令**：超级PAC只能"独立支出"，不得与候选人竞选团队协调（"不得共享策略、不得按候选人要求投放"）。现实漏洞："红盒子"（候选人网站公开发布"希望看到什么广告"）、共享供应商、前幕僚过去主持PAC。**→ 天然的"打擦边球/被抓包"机制。**
- 外国人（非绿卡）任何形式的选举捐款均**违法**；以他人名义捐款（"稻草人捐款"）违法。
- 公共资金：总统竞选可申领公共资金但须接受支出上限，主要候选人自2008年起基本放弃。
- FEC：6名委员，同党不得超过3人 → **常年3:3僵局**（现实中AI广告规则即因此搁浅）。
- 现实规模：2024周期总统竞选+外部支出合计数十亿美元；加密货币PAC 2024周期约2.9亿，2026年加密+AI两大PAC已花超1亿。

### B7. 民调与误差
- **误差范围（MoE）**：样本约1,000人 → 约±3个百分点（95%置信），**两人差距的误差约为单人误差的近2倍**。"领先2分=统计平手"。
- 注册选民（RV）vs 可能选民（LV）口径不同；加权（教育程度为2016后关键权重）。
- 系统性误差：2016、2020年低估共和党；2024年整体偏差较小但仍略低估。
- 民调汇总/预测模型/预测市场（2024起美国预测市场合法化扩张，2026年被媒体大量引用）。
- "内部民调"多为竞选团队选择性发布，常用来"造势"。

### B8. 十月惊奇（October Surprise）
定义：选前数周爆出、来不及澄清的重磅事件。经典：1980年人质谈判传闻；2004年本·拉登录像；2016年"好莱坞通道录音"+联邦调查局局长重启邮件调查信；2020年"笔记本电脑"事件。**原则：时机>内容**——发太早会被消化，发太晚媒体来不及发酵。**→ 游戏中可做"爆料时机"博弈：越晚越猛但越可能在提前投票中失效。**

### B9. 提前投票/邮寄选票
- 各州差异巨大：有的州全邮寄（如科罗拉多、华盛顿等），有的州严格限制。
- 计票顺序导致"红色海市蜃楼/蓝色转移"：现场票先计 or 邮寄票先计，导致选举夜领先者反转。**→ "选举夜假象"可做DM演绎的大反转桥段。**
- 邮寄选票"治愈"（ballot curing，签名不符可补正）、截止日（邮戳日 vs 到达日）因州而异。

### B10. 重新计票与争议
- 规则因州而异：例如宾州差距≤0.5%自动重计；亚利桑那≤0.5%自动；佐治亚≤0.5%候选人可申请；威斯康星≤1%可申请（≤0.25%免费）；密歇根差距≤2,000票自动。
- 重计通常只改变几十到几百票（2000年佛州最终差距537票，最高法院"布什诉戈尔"终止重计）。
- 选举诉讼、认证拖延、"替代选举人名单"（2020年）——ECRA 2022已收紧：每州只认州长签发的唯一证书。

### B11. 交接期
- 选后至1月20日约11周；GSA"确认"（ascertainment）启动交接资源；《总统过渡法》；内阁提名需参院确认；**"跛脚鸭"期间的特赦**（离任总统大规模特赦是现实高频梗）。
- 总统继任顺序：副总统→众议院议长→参议院临时议长→国务卿……（《纸牌屋》主角正是从党鞭→副总统→总统，全程"未经选举"上位。）
- **宪法第22修正案**：总统最多当选两届（"再选第三届"是现实中的高热度梗，游戏中可讽刺）。

### C3. 可移植权谋套路清单（20条）
1. **违约之仇**：被许诺的位子给了别人 → 开局"被背叛"动机卡，第一幕就有"讨债"目标，人人有怨气、开局即有戏。
2. **制造空缺**：不直接抢位，而是让在位者"自愿"离开 → 机制"体面下台"：凑齐3张"压力牌"可逼某NPC/玩家职位下台，空位重新拍卖。
3. **扶植傀儡再引爆**：先帮你，再毁你 → "投资-收割"机制：你可以给别人投资，持有其"黑料期权"，在终局前任意时刻行权。
4. **泄密换曝光**：政客给记者独家，记者给政客版面 → "新闻交易所"：情报换热度点数，双向互惠也双向要挟。
5. **黑料保险箱**：手握对方把柄不用，只为确保对方忠诚 → "把柄"卡默认扣着不出，出了就失去控制力（使用即贬值）。
6. **替罪羊链条**：丑闻沿着指挥链往下推 → "甩锅接力"：爆雷时可将黑料传给下属/盟友，但对方可拒收并反咬（拍桌名场面）。
7. **金主双押**：富豪同时给两边捐 → 金主胜利条件是"无论谁赢都欠我"，在阵营本里制造"不站队的第三极"。
8. **说客的佣金**：促成交易就抽成 → 中立角色：撮合任意两人交易可获佣金，鼓励全场流动、防挂机。
9. **党鞭点票**：投票前挨个"数人头"、承诺换票 → "点票环节"：记票员角色可在正式投票前私下收"承诺"，承诺可被违背但违背公开后掉信用。
10. **议程封杀**：不让法案上会场比否决更有效 → "议长之锤"：控制议程的角色可决定哪些提案进入投票。
11. **以恐惧动员**：制造/夸大危机为自己加分 → "危机卡"：可以把一个事件升级成全国危机，所有人必须表态（站队即暴露）。
12. **夫妻权力合伙**：家庭即政治联盟 → "搭档绑定"：两人共享部分资源与胜利条件，但各有一个不可告人的个人目标。
13. **搭档要价**：克莱尔要副总统位 → 副总统人选拍卖：候选人用"承诺/资源/政策"竞标搭档，搭档可坐地起价、临阵改投。
14. **背调炸弹**：搭档背景没查干净 → "背调翻牌"：党代会前每位搭档翻一张"历史卡"，可能是光环也可能是雷。
15. **把对手的武器夺来**：抢走对方的旗舰政策据为己有 → "政策偷取"：别人打出的政策卡可被支付成本"抄作业"，原作者获得一半收益（窃取也有回报，减少挫败）。
16. **选举受阻与重投**（S5终局）：部分州结果作废、重投 → 终局大机制"重投州"：DM指定1–2个州在最终轮重新竞争，全场所有资源向这两州集中。
17. **众院条件性选举**：没人过270，就到众院按州代表团投票 → 第二终局：269:269时，进入"每州一票"的代表团游说，**原本的小角色瞬间成为造王者**。
18. **未经选举的上位**：通过继任链登顶 → 隐藏胜利条件"不当选也赢"：某角色赢的条件是成为"议长/副总统"等继任位，在总统出事时上位。
19. **拒绝特赦**：最终的背叛来自最亲近的人 → 终局后"特赦环节"：新总统可特赦一名被揭发者，决定其最终结局（全场最后一个高光选择）。
20. **打破第四面墙**：主角直接对观众吐露真实想法 → "独白卡"：玩家可对DM/全场说一段"内心戏"，全场必须假装没听见（欢乐向名场面机制）。
21. **"权力就像房地产，关键是位置"**：不同职位提供不同权限 → 职位即技能：党鞭/议长/幕僚长/记者/说客/金主各有专属能力。
22. **恢复党内秩序的"清洗"**：上位后清算旧账 → 胜者在每幕结束可"清算"一人，被清算者不出局但要换阵营/换身份（避免过早出局）。

## D. 可游戏化素材

### D1. 可做成机制的政治环节（20个，含机制雏形）
| # | 政治环节 | 机制雏形 |
|---|---|---|
| 1 | **隐形初选/金主晚宴** | 金主轮流"约饭"候选人，暗拍捐款；超级PAC资金无上限但必须"不协调"（候选人不能直接指挥用途，只能"暗示"——用表情包/谐音暗示，猜错即浪费） |
| 2 | **爱荷华式党团会议（站角落）** | 玩家与NPC票分站房间角落，限时游说"拉人过来"；低于15%门槛的角落必须解散并改投 → 现场拉扯名场面 |
| 3 | **超级星期二** | 多州同时开票：玩家把有限的"竞选资源"同时分配到若干州，暗置后统一揭示，比例/赢者通吃规则混合 |
| 4 | **代表票交易所** | 退选者可"释放"代表给他人，换取内阁职位/现金/政策；承诺可违背但会被记者盯上 |
| 5 | **辩论之夜** | 主持人题卡+"静音麦克风"规则：不在发言时段说话会被DM"静音"（真的不允许说话）；观众（其他玩家）用"热度牌"投票判胜负 |
| 6 | **市民大会（town hall）** | 其他玩家扮演"普通选民"提刁钻问题，问题卡上有隐藏任务（让候选人说出某个词） |
| 7 | **副总统搭档拍卖** | 候选人竞标搭档；搭档可"坐地起价"；搭档翻"背调卡"可能爆雷 |
| 8 | **党代会唱名投票** | 各州依次报票，持有"把最后一票让给家乡州"特权的角色可决定谁"跨过门槛"那一刻 |
| 9 | **竞争性党代会（第二轮）** | 首轮无人过半 → 超级代表解锁，承诺代表松绑；全场进入"密室交易"时段 |
| 10 | **党纲之争** | 各派别把议题卡塞进党纲，冲突议题需二选一；党纲决定大选中各"选民群体"好感 |
| 11 | **超级PAC与协调禁令** | PAC管理者与候选人"不能说话"，只能通过"红盒子"（公开贴在墙上的告示）传递意图；违规被抓→罚款+丑闻 |
