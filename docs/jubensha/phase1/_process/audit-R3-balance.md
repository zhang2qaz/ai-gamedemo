## 0. 结论摘要

**计数**：critical 1，major 6，共7条。

**核心判断**
1. **收账可以被提前收割**（R3-01，critical）。规则分层讲解：片头只讲"沼泽另有共赢路"，收账细则到第3期摊牌才讲（F-02④、F-13第1款）；沼泽的角色本却从第1期起就写着自己的胜利条件。卧底只认⛳18上线，以为上线是自己人；唱名中待定代表票可以用欠条买（F-18第6款）。N不设每人上限，T＝3（6人局4），一名卧底在第1–3期签给上线3张就单独构成T。推演1中，镜像觉醒生效的局里，沼泽胜率接近100%。按05自己的权重粗算，沼泽合计会从23.7%升到约38%，并且按"沼泽会不会收割"分成两峰。
2. **收账的V入口仍是R2-B05那个囚徒困境**（R3-02）。R2只给P加了"被套牢"，V照旧用主观的a决定签不签。跨阵营的V签欠条没有任何代价，跨党的忠诚V在规则上还无法被换下。反过来，P只要让V把2张欠条"质押"给自己，V入口就被一招封死。R2-M02要消除的双峰没有消除。
3. **镜像觉醒是一票否决，不是信任博弈**（R3-03）。每个卧底的选择只在对方也选"假戏真做"时才起作用，所以"按偏好投"是弱占优策略，口头背刺什么也改变不了。摊牌因此退化成查表：两人都预期出线才生效；提名人卧底遇上对面忠诚提名人时一定坚守，锁局由此产生；两人都落选时必不生效。01、04、05对这一机制的设计说明都写错了。
4. **垂帘入口几乎是占优选择**（R3-04）。只要恰好一张票上有沼泽成员，放出第9页就等于该票第三周约−15到−18分；压下则当选后惨胜，沼泽还会倒向本票。只要a大于约0.38，压下就占优。手稿印又常在沼泽手里。垂帘频率被低估，05§9.6的情景树里没有这个变量。
5. **另有三处问题**：
   - 7人局补偿只抵掉约一半结构差，备选补偿量级不足（R3-05）；
   - F0初始风向（民调差加协同）可以直接到±2～3格，成为全本最大的一次性滚雪球放大器（R3-06）；
   - 05§9.6的胜率表是拍定数，不能作为R2遗留问题的闭合依据（R3-07）。

## 1. Critical

### balance-R3-01｜critical｜收账可以被提前收割：规则知情不对称、卧底信任通道、唱名买票、单一签名人即可达T，四处叠加使沼泽结构性过强并呈双峰
- **文件/位置**：
  - 01 附录A：F-02片头第④项（"收账、垂帘、惨胜细则在第3期⑬讲"）、F-11第1、6款（每人一生4张；N计P或V亲笔签，不设每人上限；T＝3／6人局4）、F-13第1款（摊牌讲解2分钟"首次完整讲收账"）、F-16第4款（全员邮包）、F-18第6款（欠条在唱名中每张支配10票）；
  - 01§4.5第3条（"P有硬性理由拒签，沼泽只能从V和第三方手里收"）；
  - 04§2.0.2（卧底只认⛳18落款）、§4.3第4条、§3.5第3期（跟跟当场签1张欠条给钱多多，换10票拿下提名）、§6.10；
  - 02 钱多多剧情星（冻结时两位总统提名人各有至少1张亲笔欠条在他手里）、钱多多与安德福第3期决策点；
  - 05§9.3 B″结论（"P在成为P之前签的旧欠条照样计数"）、§9.5"提名人拒签一切欠条"行、§9.6。
- **问题**：
  1. **规则知情不对称**。片头的欠条模块只讲"签发、二选一兑现、认签名不认人"，不讲"当选总统或副总统的欠条凑满T张，沼泽共赢、总统本人判负"；这一条要到第3期摊牌讲解时才讲。沼泽成员的角色本必须写明自己的胜利条件，所以他们第1期起就知道欠条是收账的筹码。其余6人在第1、2期签欠条时，并不知道这些欠条将来会让自己"被套牢"。
  2. **卧底的信任通道零成本**。卧底只认⛳18落款的指令（04§2.0.2），以为上线是本阵营的人。上线可以在指令卡里以"替你运作背书、超级星期二、待定代表"为由要欠条。对卧底来说，这是"交给自己人"，感知成本为零。
  3. **唱名就是收割场**。
     - 8人局每党都有1名沼泽各支配10张待定代表票；7人局大象党、6人局两党的第二轮，待定票全由沼泽独占；
     - 欠条兑现①可以强制立据人支配的10票；
     - 04§3.5里，跟跟就是签1张欠条给钱多多拿下提名的。
     候选人就是将来的P或V。
  4. **单一签名人即可达T**。N不设每人上限：一名卧底在第1期给上线2张、唱名时再签1张，就单独凑满T＝3。6人局T＝4，正好是一个人的全部欠条。02钱多多的剧情星还在奖励这种提前布局。
  5. **"拒签"来得太晚**。01§4.5和05§9.5说"P有硬性理由拒签"，这只在P已经知道规则之后才成立。B″承认旧欠条照样计数，却把它当作特色，没有评估它的规模。

#### 推演1（8人局，镜像觉醒生效局：沼泽在第3期讲解之前完成收割）
- **第1期走廊**：
  - 钱多多给高文的第1张指令卡（标准版）写："超级星期二我替你在孤星州运作，签两张欠条给我做凭证。"
  - 安德福给跟跟的写法相同。
  - 两名卧底按"只认⛳18"的铁律各签2张，交给上线。此时规则书只讲到"欠条可以兑现投票和投放"。
- **第3期唱名**：
  - 大象党：完全照04§3.5，跟跟再签1张给钱多多，换他手里的10张待定票。
  - 驴友党：设春季爆冷牌抽到"落后者25/领先者15"，高文首轮差几票过线，他向安德福签1张，换10张待定票。
  - 唱名结束后，沼泽袋中有高文亲笔3张（钱多多2张、安德福1张），跟跟亲笔3张（安德福2张、钱多多1张）。
- **摊牌（唱名之前）**：两人都预估双方大概率出线，按R3-03的偏好表都放"假戏真做"，觉醒生效。蓝票总统＝高文（转为驴心），红票总统＝跟跟（转为象心），两票表里一致，对公开调查免疫。
- **终局**：
  - 不论哪张票当选，P的亲笔欠条都已≥3＝T，收账必然成立：当选的P被套牢判负，他阵营的其余2人惨胜，沼泽共赢。
  - 沼泽第三周不必押任何一边，还可以同时向两边收钱，承诺"保持中立"。
- **两名卧底何时察觉**：第3期摊牌讲解时，他们才第一次听到收账与被套牢。规则既没有收回欠条的程序，沼泽也不会卖回；冻结前唯一能把欠条消掉的是持有人兑现，而持有人正是沼泽。
- **规模估算**：
  - 05§9.6给"生效"35%。凡生效局中沼泽完成了上述收割，沼泽胜率接近100%。
  - 即使只有一半桌次的沼泽这样做：沼泽合计≈23.7%＋35%×50%×(100%−14%)≈38.7%，越过F-12第8款20–30%的上限。
  - 分布是"会收割的桌次接近100%，不会的约14%"，正是R2-M02要消除的双峰。
  - 不生效局里，落选的卧底常以副手身份上票：高文、麦克的剧情星都要求"F0第6步时本人在任一张提名票上（含跨党）"。他手里那3张旧欠条，同样让本票一旦当选就收账成立。

- **为什么重要**：
  - 收账是沼泽的主路。沼泽的胜负应当来自终局的谈判与背刺，而不是来自"别人当时还不知道规则"。复盘时，被套牢的总统一定会指出："我第1期签那张欠条时，规则书根本没告诉我它能让我判负。"
  - 这违反核心承诺"每一刀都有理由，复盘讲得通"，也违反"强弱悬殊"禁忌。

- **修复**（不新增规则模块）：
  1. **规则一次讲全**。片头欠条模块（F-02③）加一句规则书原文（不涉沼泽人数，符合01§2.9）：
     > "终局冻结时，当选总统或副总统亲笔签、握在沼泽成员手里的未兑现欠条凑满3张（6人局4张），沼泽共赢，签字的总统本人判负。"

     同步修改以下各处：
     - 01§8.1"欠条"行、04§6.10；
     - F-02第④项删去"收账细则在第3期讲"；
     - F-13第1款的讲解改为"复述"。
  2. **每名立据人计入N最多2张**。F-11第6款改为：N＝min(P签,2)＋min(V签,2)＋P发出的国务卿任命书（≤1）；T不变（8/7人局3，6人局4）。同步修改05§3.10、§7.1。效果：
     - 8/7人局，收账必须P与V（或P与国务卿任命书）都出过血；
     - 6人局必须P签2张、V签2张；
     - 一名卧底被上线收割，最多贡献2张。

     "旧账总是要还的"这个主题保留：P在初选期为买待定票签出的欠条仍然计数，只是不能单独定胜负。
  3. **卧底角色本加一句提示**（不新增规则）。在02两名卧底第1册"上线"段与⛳18指令卡模板上印："欠条认签名不认人，交给谁都可能被转手。"
  4. **外测记录项**：
     - 每局第1、2期每人签出的欠条数与首位持有人；
     - 冻结时N由哪些签名人构成；
     - 第3期讲解之前签出的欠条在最终N中的占比（目标≤1/3）。

## 2. Major

### balance-R3-02｜major｜收账的V入口仍是R2-B05的囚徒困境：跨阵营V零成本、跨党忠诚V无法换下、P一招"质押"即可封死，双峰未消除
- **文件/位置**：
  - 01 附录A：F-11第6款、F-12第3款、F-03第1、2句、F-14第3款；01§4.5第3条；
  - 02 辣椒、高文、麦克的剧情星（"F0第6步在任一张提名票上（含跨党）"）、02§5.3（6人局把跨党搭档列为忠诚者的唯一选项）；
  - 05§9.2结果X、§9.3′C的F4走廊、§9.5"提名人拒签一切欠条"行、§9.7第16条（沼泽第三周囤钱"保留"）。
- **问题**：
  1. **V的取舍仍由主观的a决定**。V签欠条：本票当选时，自己从"胜"降为"惨胜"；不签：保留"胜"。沼泽第三周握有全场最多的现金（A″：沼泽11、驴心8、象心3），足以单独决定引爆点州。A″结果X中，钢铁州沼泽贡献14分，最终差值D＝−11。于是两位V之间重现R2-B05的囚徒困境，见推演2。R2只把P的a硬化了，V的a没动。
  2. **跨阵营V签欠条零成本**。V与P不同心（F0宣布"貌合神离"）时，本票当选，他的阵营本来就判负，签欠条对他没有任何代价，还能向沼泽换钱去投对面。剧情星设计又在主动制造这种V：02里三名候选人的剧情星都奖励"在任一张票上"，6人局还要求跨党搭档。
  3. **跨党忠诚V无法被换下**。P如果误选了对面阵营的忠诚者当副手（例如6人局，辣椒在跟跟与麦克之间猜错，选了麦克），麦克胸牌是大象党、真阵营是象心，公开调查只会读出"一致"，发动者反被罚3资金（F-14第3、4款）。按F-03第2句，确凿曝光就只剩他本人自曝一条路。这名零成本的签名人，在规则上没有办法被移出提名票。
  4. **反向的一招封死**。搭档谈判时，P要求V把2张欠条签给P本人：P持有这2张，冻结时它们不在沼泽袋里。V只剩2张，8人局单靠V凑不到3张，同阵营的V对此没有任何损失。熟练桌次会把V入口压到接近0。
- **结论**：新手桌（V不懂防守、跨阵营V多）收账显著高于15%，熟练桌接近0，R2-M02要消除的双峰原样保留，只是从P挪到了V身上。

#### 推演2（8人局，常规3:3，两票都"政策协同"：两位V的囚徒困境）
- **局面**：摊牌不生效，两名卧底都落选。
  - 蓝票：辣椒＋梅（协同）；红票：麦克＋琳达（协同）。两票协同互相抵消，初始民调差2，风向为0。
  - 第二周后两票各锁一州，钢铁州"胶着"（与A″同型）。
  - 沼泽第三周可用约11资金，外加每人每轮1枚站台。按A″，这笔投入足以单独翻转钢铁州。
- **报价**：沼泽向两位V各开价："签3张欠条给我们，第三周的钱和站台全押你们这张票。"
- **胜率粗估**：两边都没得到沼泽支持时各0.5；独得沼泽支持约0.7，对面独得时约0.3。

  | 梅＼琳达 | 琳达签 | 琳达不签 |
  |---|---|---|
  | **梅签** | 沼泽已两边稳收账，可保持中立：梅得0.5a | 沼泽押蓝：梅得0.7a |
  | **梅不签** | 沼泽押红：梅得0.3 | 0.5 |

- **结论**：
  - 琳达签时，梅签的条件是0.5a＞0.3，即a＞0.6；琳达不签时，梅签的条件是0.7a＞0.5，即a＞0.71。
  - a＞0.71：签是占优策略，两位V都签，沼泽两边各握3张，**100%共赢**，当选的P被套牢。
  - 0.6＜a＜0.71：协调博弈，要么都签，要么都不签。
  - a＜0.6：没人签，收账只能靠其他入口。
  - a的取值完全由玩家主观决定（规则只说惨胜"不得评MVP、不得计大胜"），结果是双峰。
  - 若P在搭档谈判时先要走V的2张欠条（问题第4条），这个矩阵就不存在，收账接近0：这是另一峰。

- **修复**：

- **问题**：
  1. **为什么是否决投票**：只有两人都放"假戏真做"才生效。所以某一名卧底的选择，只在对方也放"假戏真做"时才影响结果；对方坚守时，他放什么都一样。因此"按自己的偏好投"是弱占优策略：想换就放假戏真做，不想换就坚守。
  2. **"背刺"不改变任何结果**。口头答应"假戏真做"、信封里坚守，与当面说"我要坚守"的结局完全相同。这是一个全票通过制的否决投票，不存在囚徒困境，也不存在信任问题。
  3. **决策退化为查表**（附表）。卧底真正要估计的只有一个变量："对方能不能出线"。
  4. **锁局的来源**：提名人卧底遇到对面党由忠诚者出线时，他会否决（S2、S3）。不生效局里锁局应占多数，而交叉只在卧底误判提名时才出现。05§9.6"交叉15%、两锁40%"的权重与此不符。
