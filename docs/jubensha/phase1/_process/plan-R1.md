**F-03 临阵换将（唯一口径，七句）**

3. 窗口：F0第6步、F2十月惊奇执行完毕后；一律以窗口开启时的当前真阵营判定。
4. 表决：表决人＝该提名票所属党的全体胸牌成员，不含被曝光者、不含身在另一张提名票上的人；同意数≥⌈表决人数÷2⌉即通过；欠条不得强制本表决。

6. 补副手：出现副手空缺时，由（新）总统提名人当场指定一名合格玩家（年龄合格、不同州、非跛脚鸭、不在另一张提名票上，可跨党），被指定者不得拒绝。
7. 被换下者成为独立参选人，获3枚分票标记：每轮可公开放1枚在本轮开放、未锁票的州，使他被换下的那张票在该州−2，每州全场最多1枚；换将后DM撤回旧组合的协同风向并重新宣布协同，此外没有任何风向代价。
