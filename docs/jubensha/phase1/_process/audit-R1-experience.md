# 《摇摆！》第一轮审查 · 玩家体验、节奏与欢乐（audit-R1-experience）

> 审查视角：城限阵营本中度玩家的体验、节奏与欢乐密度。
> 审查对象（已全部完整阅读）：01-core-concept（v1基准）、02-characters-relations（v1.1）、03-truth-timeline（v1.1）、04-flow-and-mechanics（v1）、05-finale-election（v1）。
> 严重度：critical＝逻辑崩塌／游戏无法进行／阵营结构失衡／硬知识错误；major＝明显影响体验或公平、复盘时会被玩家挑出的漏洞；minor＝打磨项。
> 计数：**critical 3｜major 23｜minor 12**。按严重度排序；附录A为逐环节耗时估算，附录B为戏份与挂机核对，附录C为笑点地图。

## 总评

骨架（双层阵营、两次高潮、九页账本连续剧）是好的，但按"中度玩家一晚上玩得完、玩得懂、玩得笑"的标准，现稿有三处硬伤：
1. **时间根本装不下**：逐环节按实操估算，全本约8小时45分到9小时35分，远超8小时上限，而且排程里没有一分钟缓冲；技能、规则讲解、终局后台结算、复盘都没有时间预算。
2. **规则量与承诺严重背离**：每幕"最多新增2条规则"实际是7到17个规则模块，最复杂的终局规则只给2分30秒讲，讲解还排在玩家最疲劳的第6小时。
3. **沼泽阵营在多数对局里几乎赢不了**：第9页发布后，收账门槛4正好等于欠条上限4；第9页又几乎总会发布；坐庄和垂帘两条路都很窄。全桌25%的玩家打7个半小时，大概率白打。

另外，很多写进戏份矩阵的C位和名场面只是"有条件发生"：防御技能会把它们抹掉，可砍项会砍掉它们，初选一输就整条作废。安德福从开场到第6个半小时没有任何保底高光。

## 一、Critical

### experience-R1-01｜critical｜总时长必然超过8小时上限，全本零缓冲
- **文件／位置**：04 §1.1 总表、§1.2 第1–3期分钟表、§1.2 超时预案；05 §1.2 终局95分钟表；01 §7.1、§7.3。
- **问题**：按实操口径逐环节估算（明细见附录A），各段的真实耗时如下：第1期108–118分钟（预算95）；第2期112–122（预算95）；第3期82–95（不触发经纪人党代会）或94–110（触发，预算85）；终局123–145（预算95）；复盘35–45（预算25，出现269时只剩19）。合计约525–575分钟，即8小时45分到9小时35分，排程是470分钟。超时的系统性原因有五个：
  1. 技能没有时间槽。直播带票60秒加闭眼数拇指，连麦答两题，九秒剪辑复述后还要"全场多数认可"，对镜头说话30秒定格，代笔念卡。04 §5.2写的是"任一公开环节开始时宣布"，每期要多出4–7分钟，而且会打断原定流程。
  2. 新机制的讲解时间没有算进去。扒马褂、听证、唱名、搭档的讲解都要从环节时长里挤，只有暗标单列了讲解时间（4分钟，包含填单）。
  3. 第2、3期新闻周期的"午夜合影"没有计时（04 §1.2只列了结算、页码和片尾）。
  4. 第三周投放后"直接进入开票"（05 §3.8），主DM要拆8个信封，每个信封最多涉及8个州，这段时间一分钟都没给。
  5. 复盘25分钟只够结算，装不下盘真相（见R1-14）。
  即使执行全部可砍项（04约22.5分钟、05约8分钟），总时长仍超过8小时15分。01 §7.3写"可砍约28分钟"，与04、05的数字也对不上。
- **为什么重要**：城限店的场次是按固定时段卖的，超过8小时就会挤占下一场，或者被迫在终局腰斩。题目要求7–8小时，现排程7小时50分已经顶到上限，任何超时都直接越线。超时最先牺牲的是终局和复盘，也就是全本最值钱的两段。
- **修复方案**：以"8小时硬上限、留10分钟机动"为准，按实测口径重排。建议目标表如下（须在3车外测中计时验证）：
