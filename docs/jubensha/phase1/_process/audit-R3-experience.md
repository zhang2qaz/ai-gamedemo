# 第3轮复审：玩家体验、节奏与欢乐（experience-R3）

> 审查对象：01-core-concept.md（v1.2，R2冻结版）、02-characters-relations.md（v1.3）、03-truth-timeline.md（v1.3）、04-flow-and-mechanics.md（v1.2）、05-finale-election.md（v1.2），参照06-audit-log.md第1、2轮裁决与_process/audit-R2-experience.md。
> 视角：城限阵营本中度玩家（爱博弈、拉扯、背刺、名场面；不爱挂机、规则过载、纯算数、过早出局、强弱悬殊、硬核长推理）。
> 口径：本轮是复审，只报告critical与major，按严重度排序；编号experience-R3-xx。

## 总评

R2的体验修复大部分真正落了地：F1并行段给足8分钟并改一问一答，终局技能统一挪到F2技能段；站台写进投放单同时揭示；欠条冻结后移到F4；邮包时差消除；插播不可砍；高文落选备选星；梅主持F4.5；F0加了知识竞赛与"联姻体检报告"；第9页删掉了阵营举牌。R2-15条体验问题里，13条已闭合。

但本轮复审发现两类新问题，其中最重的一类恰恰是R2修复带出来的：

1. **镜像觉醒（R2-C01的修法）把"全本最大决策"做成了盲选**。双签规则在下注那一刻才第一次读到，摊牌前没有任何私聊窗口，两名卧底默认流程里直到摊牌之后才比对落款；单方"假戏真做"又没有任何代价。信任博弈在纸面成立，在牌桌上不成立（R3-01）。同一结构还让第3期最贵的待定票交易失去了私聊窗口（R3-04）。
2. **规则"按需才讲"造成的信息不对称与超时**：换将（F-03九句）直到F0触发时才第一次讲，而决定它结果的唱名、搭档、公开调查都在第3期就做完了；收账与"被套牢"要到第3期才讲，欠条却从第1期就能签。前者让约一半的局在F0超时（R3-02），后者是复盘时最伤公平感的"规则陷阱"（R3-03）。

另有四处体验与公平问题：三件事卡直接点名真相题答案和R5对象（R3-05）；跟跟的剧情星仍是全场唯一挂在开票结果上、且无备选的星（R3-06）；辣椒的名场面星仍要靠对手阵营多数举牌（R3-07）；禁词表的指定绰号本身就是日常词（R3-08）；第9页回应变成了计时口试且没有兜底卡（R3-09）。

**计数：critical 0，major 9。**

## 二、Major

### experience-R3-01｜major｜镜像觉醒的"信任博弈"在牌桌上是盲选：双签规则下注当刻才读到，摊牌前无任何私聊窗口，单方假戏真做零代价

- **文件与位置**：01附录A F-13第3款（"本款只印在卧底摊牌卡背面与DM手册"）、01§4.5第1条；04§1.2第3期顺序（阅读13→摊牌8→唱名10→走廊10）、§6.5第3款与"设计说明"、§7.1第3期检查表（"比对指令卡落款"排在摊牌之后的走廊）；03 T00′"开局知情：两名卧底只在第3期摊牌卡背面读到它的规则"、§6.4第43条；02§2.2"高文—跟跟"（"即使事先口头约好"）、§1.11高文与跟跟第3期三件事卡③（"赌对方也假戏真做"，在第2期片尾发放）；05§9.6（"不生效约65%"）、§9.5"卧底约好双签"。
- **问题**：
  1. **下注时才第一次知道规则**。03 T00′写明卧底只在摊牌卡背面读到双签规则；摊牌是全员隔板后同时操作3分钟、操作期不得交流。也就是说，卧底在读到"必须对方也选才生效"的同一刻就要下注，没有机会找对方确认。
  2. **摊牌前没有任何私聊窗口**。第3期顺序是阅读→摊牌，上一次走廊在第2期（约2:43–2:53），中间隔着超级星期二和40分钟饭点（禁止签欠条）。两名卧底在默认流程里互不知道对方是谁，R5的落款比对被排在摊牌之后的第3期走廊。
  3. **三份文件对"卧底何时知道双签"的口径互相冲突**：03说摊牌时才知道；02§1.11的第3期三件事卡在第2期片尾就写着"赌对方也假戏真做"；02§2.2又写"即使事先口头约好"。DM无法判断卧底在饭点前该不该知道这条规则。
  4. **单方"假戏真做"与"坚守"结果完全相同**（回执写"未生效"，公开调查同样判"不一致"），没有任何代价；而双签生效能让两人都免疫公开调查与换将。对卧底来说"假戏真做"是弱优势选项：要么被识破后无脑全选，选择失去张力；要么玩家没想明白而随手乱选，觉醒落空。05§9.6估计65%的局不生效，即约三分之二的局里，"这身驴皮我穿出感情了""驴心·这身驴皮"结局与觉醒戏份根本不发生。
  5. 上线（沼泽）在03里也不知道君子协定，R2-10修好的邮包时序因此帮不上这场决策：上线的指令无法就"要不要和对面那颗种子一起报备"给出任何意见。
- **为什么重要**：表里双层阵营是全本第一卖点，摊牌被02§4.1标为高文、跟跟"全本最大决策之一"。目标玩家要的是"拉扯、背刺"，而背刺的前提是先有约定。现在没有约定的机会，只有抛硬币；复盘时卧底玩家会说"我连另一个卧底是谁都不知道，怎么赌？"。
- **修复方案**：
  1. **规则提前到第2册**：两名卧底的第2册各加约120字"上线转述的旧规矩"——两党《互不挖角君子协定》：投诚报备须对面党同时有一人报备才被接收（其余六人同位置放等长的传闻段落，保持各册字数差≤10%）。沼泽两人的第1册写入同一条（他们继承了师父的档案），让上线能在第2期回邮里就此下指令（第3期阅读开始时送达）。F-13第3款改为"印在卧底第2册与摊牌卡背面"；03 T00′"开局知情"、02§2.2、三件事卡③统一为此口径。
  2. **第3期新增"开幕前走廊"1轮（3分钟）**，放在阅读之后、摊牌之前；时间从唱名后的走廊借（10→7分钟，2轮），总时长不变。两名卧底可以在这一轮试探对方、口述落款、互相起誓，也可以虚晃一枪后在信封里背刺——这才是04§6.5设计说明里的"信任博弈"。此轮同时承接R3-04的待定票谈判，全员都在动，不会暴露谁是卧底。
  3. **给单方"假戏真做"一个真实代价**：报备被退回的人，F0回执照常写"转换未生效"，另由DM在F0第2步私下把"你的种子提交过投诚报备、被退回"写进其上线的回执小道消息卡（上线回执卡同尺寸、同字数，不暴露其他人）。上线由此知道自己的种子想跑，可以在F0第5步前公开调查或自曝点名——"试图背叛被上线知道"本身就是纸牌屋名场面，不新增任何公开规则。
  4. 外测增加观察项：两名卧底是否在开幕前走廊相认、双签生效率（仍按25–60%验收）、单方假戏真做后上线是否报复。

### experience-R3-02｜major｜换将（F-03九句）直到F0触发时才第一次讲，而决定其结果的唱名、搭档、公开调查都在第3期做完；F0"换将3分钟"在约一半的局里必然超时

- **文件与位置**：01附录A F-02终局行"㉑换将与独立参选"及注②"换将在触发时讲"、F-01终局F0行"换将3"、F-03第4–9句、F-14（未计入F-02的22个模块）；04§2.3.5（搭档"复述1"只讲求婚）、§2.3.6（公开调查与资格诉讼5分钟，无复述时间）；05§3.2第0-6步、§3.3执行表（0.5＋1＋0.5＋0.5＋0.25＋0.25＝3分钟）、§3.3亚军排序速查与算例甲至丁、§9.2推演A″"同窗双换将"、§9.6情景树、§10.7主DM考核"F0换将全流程模拟≤4分钟"。
- **问题**：
  1. **上游决策在不知规则的情况下做出**。F-03第7句：被换下的总统由"第3期唱名最后一轮得票→唱名开始时民调→座位"排出的亚军顶上；第7句后半：顶上者与现任副手同州时副手席位空缺；第8句：新总统当场指定副手、被指定者不得拒绝；第9句：被换下者获3枚分票。这些决定了第3期每一个选择的后果——唱名第二轮把票投给谁（直接排出候补顺位）、搭档选谁（同州空缺）、钱多多改不改籍、要不要在搭档后发动公开调查。可是玩家第一次听到这些规则，是在F0第6步换将真正发生时。复盘时一定会有人说"早知道唱名的票会决定谁顶上，我就不会那样投"。
  2. **公开调查不在模块预算内**。F-14的"一致＝诬告罚3资金／不一致＝确凿曝光→可触发换将"是第3期起全员都要理解的连锁，04§2.3.6的5分钟段却没有复述时间，非持有者只能从别人的技能卡口述里拼凑规则。
  3. **3分钟执行不现实**。逐步估算单次触发：确认0.5；闭眼表决并说明谁有表决权1；念候补顺位并等跨票者当场决定回不回本党0.5–1；新总统当场挑副手（必然讨价还价）0.5–1.5；重宣协同0.25；发分票并讲分票规则0.5；再加首次讲解F-03至少1.5——合计5–6分钟。05推演A″的同窗双换将要9–12分钟。05§10.7给主DM的考核线是"≤4分钟"，本身就超过预算的3分钟。
  4. **频率不低**。05§9.6自己的情景树：不生效约65%，其中交叉15%、两锁40%、沼泽P15%，三者合计约46%的局会走到换将，另有常规局里沼泽副手被曝光的情形。缓冲余量只有3分钟，双换将局必然超时，再叠加269（8分钟从缓冲出）就突破480分钟硬上限。
- **为什么重要**：换将是终局开局最大的翻盘点，也是全本最复杂的一条规则；它若在超时与"现场才讲"中走完，会在终局第一个高潮之前就制造规则争议与疲劳。总纲禁忌"规则过载"在这里以"先做决定、后讲规则"的形式出现，比单纯规则多更伤体验。
- **修复方案**：
  1. **第3期讲"换将三句话"**：搭档段复述由1分钟扩为2分钟，讲①谁会被换（被确凿曝光、且真心与所在票不符）；②谁投票（本党胸牌成员，不含被曝光者与另一张票上的人）；③谁顶上（按今晚唱名最后一轮得票排的候补顺位；新总统当场补副手，同州者不行）。时间从两次求婚各≤4分钟改为各≤3.5分钟腾出。第3期本期新规则卡背面印《换将速查》（三句话＋候补顺位示例）。
  2. **公开调查计入模块预算**（全本23个，上限25不变），在04§2.3.6开头复述30秒：一致＝诬告罚3，不一致＝确凿曝光，F0第6步可换将。

### experience-R3-03｜major｜收账与"被套牢"到第3期才讲，欠条却从第1期就能签：六名非沼泽玩家在规则不知情下给沼泽"攒账"

- **文件与位置**：01附录A F-02片头行④（"收账、垂帘、惨胜细则在第3期⑬讲"）、F-11第6款、F-12第3款；04§1.1片头规则讲解（"冻结与收账在第3期讲"）、§2.3.1与§6.5第1款（摊牌讲解2分钟）、§6.10欠条格式与"认签名不认职位"；05§9.3推演B″"收账T＝4的可达性"第1、2条；02§2.1"辣椒—安德福"机制交互点（"她可以向安德福索要欠条"）。
- **问题**：
  1. 欠条从片头就教、第1期起就能签、白送、转卖，而且"认签名不认职位"；可是"当选总统或副总统亲笔签的欠条落入沼泽手里满3张（6人局4张），当选总统本人判负"这条规则，片头只用一句"沼泽另有共赢路，见规则卡背面"带过，细则要到第3期4:13的摊牌讲解才讲。沼泽两人从第1册就知道这条（这是他们的胜利条件），其余六人前四个小时在不知情下签欠条。
  2. 05推演B″把这种情形写成了"策略误判"：辣椒第2期、第3期签出3张欠条，"那时她觉得副手的欠条不值钱"，大选夜被套牢判负。但在真实牌桌上，这不是误判，是规则没讲。
  3. 第3期摊牌讲解2分钟要同时讲收账（P或V签、V是沼泽只计P、T＝3/4、国务卿任命书、F4冻结）、垂帘（V是沼泽＋两枚印章压第9页）、惨胜、被套牢，再加摊牌操作步骤与封口口令，约600字口播量，必然超时，而且是在饭后第一个环节，记不住。
- **为什么重要**：这是"规则层"的信息不对称，不是剧情秘密。阵营本里最伤公平感的复盘对话就是"我第1期签的那张欠条，凭什么让我当了总统还判负？"。它同时违背01§4.5第3条"所有阵营变化都不依赖DM判断，复盘时可以验算"的承诺——玩家能验算，但会觉得被规则伏击。
- **修复方案（二选一，推荐A）**：
  - **A. 提前公开**：片头欠条模块加一句，并印在每张欠条背面："⚠沼泽收账：大选夜，当选总统或副总统亲笔签、未兑现的欠条若有3张（6人局4张）在沼泽成员手里，沼泽共赢，当选总统本人判负。"片头+30秒，第3期摊牌讲解−30秒（只讲垂帘、惨胜与操作），总时长不变。措辞只写"沼泽成员"，不涉人数，符合01§2.9硬约束。
  - **B. 只计已讲之后的欠条**：收账只计欠条"立据时间"栏为第3期及以后的欠条（04§6.10欠条格式已有该栏，不新增物料）。代价是沼泽前两期的布局价值下降，需balance复核收账10–15%的目标。

### experience-R3-04｜major｜第3期最贵的交易（待定20票、退选转投、欠条指定投票）没有私聊窗口，唱名首轮只剩当众表态

- **文件与位置**：04§1.2第3期顺序、§2.3.2、§4.3第3条（待定代表团）、第4条（欠条"唱名开始前私下向DM出示"）及算例（"待定代表团是全场最贵的人情"）、§1.1饭点（禁止交易、签欠条）；02§1.11钱多多第3期①"待定票卖给谁"、安德福第3期③"副手位和待定票哪个更值钱"；05§9.7第10条（第二轮唱名触发率目标30–50%）。
- **问题**：
  1. 上一次私聊是第2期走廊（约2:43–2:53），那时超级星期二还没开标、春季信封还没抽；饭点禁止签欠条；第3期阅读结束即摊牌、即唱名。待定票的支配者（梅、安德福、琳达、钱多多）手里握着决定提名的20票，却没有任何私下要价的时段，只能凭饭桌上无约束的口头承诺，或在唱名现场当众表态。
  2. 理性的支配者会选择首轮弃权、拖到第二轮再卖（第二轮时间只有5分钟，且仍是公开场合），第二轮唱名触发率会被系统性推高，偏离30–50%的外测目标，并吃掉"第二轮未触发即省5分钟"的时间余量。
  3. 欠条兑现①"唱名开始前私下向DM出示"在时间表里没有时点：唱名开始前一刻DM正在主持摊牌封口与独白。
  4. 三件事卡给钱多多、安德福写了"待定票卖给谁""待定票哪个更值钱"，却不给他们卖的地方。非候选人在第3期最重要的C位决策被压成一次当众举手。
- **为什么重要**：04§4.3自己把待定票称作"全场最贵的人情"，纸牌屋式的"密室撬票"是第3期本该出现的名场面。没有私聊窗口，非候选人在唱名环节等于陪坐，候选人也失去了背刺对手的机会。
- **修复方案**：
  1. 与R3-01共用第3期"开幕前走廊"1轮（3分钟，阅读后、摊牌前；唱名后走廊10→7分钟，总时长不变）。此轮可签欠条、谈退选、谈待定票。
  2. 欠条兑现①在此轮交场控登记（持有人把欠条与指定内容交场控，场控写纸条交主DM），04§4.3第4条与§6.10兑现表同步改时点。
  3. 唱名首轮在待定代表团表态前加"30秒公开喊价"：DM口播"这20票，有没有人现在报个价？"——把讨价还价变成全场可看的名场面，不新增规则（报价仍无约束，签欠条才算数）。
