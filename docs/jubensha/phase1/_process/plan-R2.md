## 0. R2统一口径卡（全部修订员先读；与任何旧文冲突以本卡为准）

### 0.1 阵营与觉醒：镜像觉醒（双签生效）
1. 摊牌信封仍在第3期阅读后、唱名前；卧底仍二选一（坚守／假戏真做），放"已阅"视为坚守。
2. **只有两名卧底都放"假戏真做"时，两人同时转入胸牌政党对应阵营（高文→驴心，跟跟→象心）；任一人坚守，两人都保持原阵营。**
3. 阵营人数恒定：8人3/3/2，7人3/2/2，6人2/2/2。全本删除一切"单方觉醒""4:2""4:1""3:1"的表述与补偿（含"逆风令""隐藏少数派补偿"——均不采纳）。
4. 世界内依据（03新增）：两党总法律顾问之间有一份两头吃三十年前促成的《互不挖角君子协定》：选举年里，一方接收对方党安插者的"投诚报备"，必须以另一方同时接收一名为条件，单方报备一律退回、视同未报备。"假戏真做"卡＝本人签名的投诚报备。
5. 双签细则只印在卧底摊牌卡背面与DM手册；公开规则书只写"卧底可选坚守或假戏真做，结果以回执为准"，不写人数、不写双签。
6. 回执（F0第2步）只告诉本人：选假戏真做者收到"转换已生效"或"转换未生效"；选坚守者收到"阵营不变"。
7. 7人局麦克公开补偿（按角色，不泄露隐藏信息）：开局＋3资金（原有）；F0开幕收入＋6（他人＋3）；终局每轮可放2枚站台；背调、律师函（原有）。"高文开局知道麦克是象心"保留为剧情信息，不再称"补偿"。
8. 6人局F-15第3款改写见01节F-15。

### 0.2 换将（F-03 R2，九句；全局只有一个窗口）
- 窗口只剩**F0第6步**。删除"F2十月换将"（窗口、4分钟缓冲、相关台本与裁决）。公开调查时段相应改为"第3期搭档仪式结束后至F0第5步结束"。
- "合格"＝年龄合格、非跛脚鸭、不是本局任何被换下的独立参选人、不是"已被确凿曝光且当前真阵营与本票所属党不对应"的人、不在另一张提名票上。
- 表决人不足2人时，身在另一张提名票上的本党胸牌成员恢复表决权；仍为0人视为通过。
- 补总统按"亚军排序"（最后一轮得票→唱名开始时民调→座位），跨票亚军可选择回本党；排完无合格者则换将不执行、原票保留。副总统提名人不再"自动顶上"，只按排序参与。
- 同票双曝光：先总统后副手、表决人相同；两张票都触发先蓝后红。
- 全文以01节F-03为准。

### 0.3 欠条与收账（单一口径）
1. **冻结时点：F4全图投放沙漏倒完时**，全员同时交回第三周投放信封与本人欠条袋。此后欠条不得新签、转让、兑现。F3不再有"欠条冻结装袋"步骤。
2. 兑现①（指定投票）**不适用于269唱票**；269中不得使用欠条，无拆袋程序。兑现②（终局指定投放）可指定任一张票，包括立据人的对手票（规则卡明写）。
3. 收账：N＝冻结时沼泽成员欠条袋中、由**当选总统P或当选副总统V**亲笔签名、未兑现的欠条张数（V本人是沼泽成员时只计P签的）＋沼泽成员持有的P发出的国务卿任命书（最多1张）。**T＝3（8/7人局）、4（6人局）**；第9页发布不改变T。漏装未交者不计。
4. 钱多多剧情星在冻结封存时（F4投放结束）判定。

### 0.4 沼泽三路、惨胜与"被套牢"
1. 坐庄：P是沼泽（不变）。垂帘：V是沼泽且第9页已顺延（顺延门槛见0.5，已结构上可达）。收账：N≥T。
2. **垂帘成立（P非沼泽）→P的阵营全员"惨胜"**；**收账成立→P本人评级"负（被套牢）"，P阵营其余成员"惨胜"**；两者同时成立按收账处理。
3. 惨胜：不得评MVP、不得计"大胜"、个人结局卡用"被套牢"版。
4. 设计目标（外测验收、05推演验证）：沼泽（含共赢）20–30%，其中坐庄≤5%、垂帘5–10%、收账10–15%；不得呈双峰。
5. 沼泽谈判筹码：资金（开局最富）、待定代表票、副手位、手稿印（压页的关键第二章）、交权书副本、匿名捐款、兑现②、269令牌。
