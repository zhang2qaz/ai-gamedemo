- 新的执行缺口集中在四处：
  1. **终局高潮的"最后一公里"没有执行程序**：F5开票要报"现场票/邮寄票"绝对值，而速算只产出差值D；F6拆欠条袋拆谁、按什么顺序没写。

  3. **"全员同构"仍有两个漏口**：上线手写留言卡不可能"约150字、差≤10%"；草根核点的走位当众暴露最穷者。
  4. **场控与单DM的岗位表仍有错位**：第3期走廊场控三线并行；单DM替代包漏项；考核表把场控的活考在主DM身上。

## 1. Major

### operability-R3-01｜major｜F5开票要报"现场票／邮寄票"的蓝红绝对值，但速算只产出差值D；"开票表"没有制作程序、执行人和时间
- **文件与位置**：05 §3.1.5☑（"场控速算用差值D"，六格只算差）；§5.2（每州先报"现场票：蓝X，红Y"，再报"邮寄票：蓝＋A，红＋B，最终X'比Y'"）；§13物料"开票表1"；§3.8.1 F4.5（场控只做"第三周速算"）；§10.3计时表（无开票表一项）；01 F-01、§9.2。
- **问题**：
  1. 播报与锁票只需要D，所以R2把速算压成"差值六格、单州10秒"。但开票脚本要的是每州蓝、红两侧各自的"现场"（三周投放＋站台×2－攻击）与"邮寄"（倾向＋风向冻结值＋背书×3＋事件、分票、第9页）四个绝对数，且要跨三张周表累加、套用锁票冻结值与飓风减半。这张表全本没有谁做、何时做、怎么做。
  2. 唯一可做的时段是F4.5（6分钟），场控在这里已经要完成第三周速算（≤5分钟）；F5开票期间场控又要在状态板加总比分、预开核对押宝单。8州×4个数×3周的累加挤不进任何一段。
- **为什么重要**：开票是全本第一次高潮，"海市蜃楼"完全依赖现场/邮寄的拆分。表没出来，主DM只能对着差值临场心算，既慢又可能报错数字（违反"DM不改任何数字"），高潮当场冷掉。
- **修复方案**：
  1. 05§3.1.5的预印周表在每州两栏下各加一个"站台/攻击/背书"小格，场控抄数时顺手记**本周该州蓝、红的现场小计与背书小计**（只抄不算，单州多10秒）。
  2. 新增预印"开票表"（8行×6列：现场蓝、现场红、邮寄蓝、邮寄红、合计、归属），**第一、二周播报后**由场控把已锁票州整行填好（锁票州此后不再变）；F4.5只填未锁票州，每州一行三格相加。
  3. 05§10.3计时表增"F1、F2播报后：开票表锁票州行"；"F4.5：开票表未锁票州行"。F-22第3款场控实操"第三周8信封速算≤5分钟"改为"第三周速算＋开票表≤6分钟"，并在外测逐车计时。
  4. 若外测F4.5超时，备选：开票脚本只报"现场票领先方"与"邮寄票后最终比分"，现场票不报具体数字（台词改"现场票：红方领先！"），场控每州只需现场差与最终差两个数。

### operability-R3-02｜major｜第3期走廊里场控三线并行：开8只摊牌信封并更新机密册、坐镇公示台、办理匿名捐款；觉醒时更换两只封袋的动作可被旁观
- **文件与位置**：04 §2.3.4（"场控在本时段于隔板后开摊牌信封、更新机密册（考核≤6分钟）"）；§2.0.2公示台（"场控坐镇"，资金赠予记账、手稿印存根补登）；§5.2钱多多「匿名捐款」（"走廊中，经场控私下办理"）；F-13第4款；04 §9.1"觉醒卡……觉醒时替换对应封袋内容"；F-22第3款。
- **问题**：
  1. 第3期走廊（10分钟）恰是搭档谈价、欠条与资金往来最密集的一段，公示台排队最长；同一时间场控要在隔板后完成≤6分钟的开封与机密册更新，还要接钱多多的匿名捐款信封。R2-08只把冲突从唱名挪到了走廊。
  2. 双签生效时，场控要在机密册里**只对两页**做"取出原卡、放入觉醒卡"的额外动作；不生效时没有这个动作。场控在主场里操作，耗时差与翻页位置可被旁观者看见，等于提前泄露"觉醒生效"以及大致是哪两页。
- **为什么重要**：觉醒是否生效是终局前最重要的暗信息（F0回执只告诉本人）；同时公示台漏登会让资金赠予、手稿印流转与机密册"印章流转"页对不上（F-22第4款要求零失误）。
- **修复方案**：
  1. 第3期走廊**公示台关闭**，资金赠予改为当面交付、双方在"走廊赠予单"上签名投入钱钱委员会票箱（与欠条存根同流程），场控在新闻周期结算时补登；匿名捐款本期改在插播时段前1分钟由场控统一收。04§2.3.4、§2.0.2各加一句"第3期例外"。
  2. 开封必须在**主场外**（私聊空间或屏风后）进行；机密册对**8页全部**执行同一套动作：取出封袋、放回一张卡、封口贴"第3期已核"贴纸，不论是否觉醒，耗时一致。04§6.5第4条、F-13第4款写入。
  3. 场控实操考核"摊牌开封与机密册更新≤6分钟"增加"8页动作同构"评分项（任一页动作不同即不合格）。

### operability-R3-03｜major｜欠条兑现②"强制投放"仍无法唯一执行：卡怎么到立据人手里、何时截止、与"每轮≤3州"及已投另一张票的钱冲突、改记从哪一行扣、罚−1还是−2，都没有写死
- **文件与位置**：01 F-11第3、4款；04 §6.10兑现表②；05 §3.10②、§3.1.4投放单"强制投放卡编号"栏、§8.3第26条、§8.6第49条、§10.6单DM替代表第1行；F-09第4款（每轮≤3州）、F-20第8款（扣减顺序）。
- **问题**：
  1. **递交路径空白**：规则只写"持有人到公示台出示，场控发强制投放卡""立据人本轮须夹入信封"。卡发给谁？若发给持有人，持有人可能不转交或在最后几秒才转交；立据人可能正在另一个私聊区。#49"领了卡但没夹入"的罚则以"领了卡"为前提，可"没领到"怎么办没有规定。
  2. **无截止**：终局"走廊投放合一"＝两轮3分钟＋封信封2（F4为1）分钟，公示台全程开放。持有人可在封信封最后10秒发卡，立据人来不及改投放单，按#49直接被改记并民调−1，等于欠条附赠一次免费罚分。
  3. **与≤3州冲突**：立据人已填满3州，强制州是第4州时，是作废第3行、还是强制州不计入3州上限？无规定。
  4. **"本轮该州不得给另一张票投放"的已投资金**：立据人在强制州原本给另一张票投了5，DM"改记"是只补足2（#49），还是把5全部改给指定票，剩下的3退还、作废还是计入？无规定。
  5. **罚则二义**：信封资金不足2时，按05§3.10是"未执行→改记＋民调−1"，按F-11第4款可能是"两项都无法履行→民调−2"。
  6. **单DM局**：替代表写"强制投放卡预印、持有人自取并在登记簿签名；DM在新闻周期结算时核对签名"。终局没有新闻周期；持有人自取后欠条由谁撕毁未写，若持有人是沼泽成员，可"兑现"之后仍把欠条留在袋里计入收账。
- **为什么重要**：兑现②是设计内的"书面背刺"，也是A″推演里改写奶酪州的关键动作；每个空白都会在终局当场引发争执，且直接影响收账计数与州胜负，复盘时必被挑出。
- **修复方案**（写入F-11第3款②并同步04、05）：
  1. 强制投放卡为**两联**：场控当场撕下欠条（兑现即撕毁，留半张存档），在两联上写州与票；上联交持有人留证，下联由**场控本人在下一次沙漏翻转时当众放到立据人面前**（翻沙漏是全场统一时点，立据人无需到场）。
  2. **签发截止**：每轮第2个3分钟沙漏翻转之前；此后公示台不受理兑现②。这样立据人至少有3分钟改单。
  3. 强制州**不占**"每轮≤3州"名额；单州上限5仍适用（指定票≥2，另一张票0）。
  4. 立据人在强制州给另一张票投的钱**全部改记到指定票**；若改记后指定票仍不足2，按F-20第8款行序从其他行先蓝后红抽足2；仍不足则按现有资金执行到0为止，**民调−1**，不再另判−2。F-11第4款"−2"只用于①指定投票失效且持有人放弃改选②的情形，写明二者不叠加。
  5. 单DM局：强制投放卡仍由DM签发（持有人到DM处出示，DM撕欠条后放卡），删除"自取"。

### operability-R3-04｜major｜欠条冻结时刻与F4"封信封1分钟"互相矛盾：沙漏倒完即交，还是封完再交？封信封期间能否签、转、兑现欠条没有唯一答案
- **文件与位置**：01 F-11第5款（"F4全图投放沙漏倒完时，全员同时交回第三周投放信封与本人欠条袋"）；01 §9.2 F4行、05 §1.2 F4行与§3.8（"两轮3分钟沙漏＋1分钟封信封……沙漏倒完时全员同时交回"）；F-12第7款（钱多多剧情星按冻结封存时判定）；05 §9.2推演X（琳达在F4走廊签第3张）。
- **问题**：同一段里既写"两轮沙漏＋1分钟封信封"，又写"沙漏倒完时同时交"。若沙漏倒完就交，1分钟封信封无处安放；若封完再交，这1分钟内是否还能签欠条、转让欠条、发强制投放卡，规则沉默。A″推演的胜负恰好取决于V在最后时刻签不签第3张，收账判定对冻结时刻极其敏感。
- **为什么重要**：收账是沼泽三条路之一，钱多多剧情星也挂在同一时点；冻结时刻一旦可争，F6清点时必有人主张"那张是在封信封期间签的"。
- **修复方案**：F-11第5款改为："F4第2个3分钟沙漏倒完＝**欠条冻结时刻**：此刻起不得新签、转让、兑现欠条，不得签发强制投放卡；随后1分钟只用于封投放信封、把手中所有已签欠条装袋写名封口；场控喊'交'时投放信封与欠条袋同时交回。"01§9.2、05§1.2、§3.8、§3.10、§10.2 F4台本同步；DM在第2个沙漏翻转时口播"最后3分钟，沙漏倒完欠条冻结"。

### operability-R3-05｜major｜F6"欠条袋清点"没规定拆哪几只袋：只拆沼泽袋会在"其余6袋同时翻卡"前提前点名沼泽；8袋全拆当众逐张核对，5分钟装不下
- **文件与位置**：05 §7.4第4步（"沼泽俱乐部的会员们，请清点你们的账。场控当众拆开F4封存的欠条袋，逐张核对P或V的签名"）、第6步（"其余6个封袋同时翻卡"）、〔设计〕（"一张一张地摆欠条"）；§1.2 F6 5分钟；01 §9.4；F-22第3款"欠条袋封存与F6清点≤3分钟"。
- **问题**：
  1. 冻结时全员8只欠条袋都交了（F-11第5款）。第4步只说"拆开欠条袋"，没说拆谁的。若只拆两只，第9页被压下的局里全场此刻才第一次知道沼泽是谁，而且是在第6步"同时翻卡"之前，第二次高潮的节奏被提前拆掉。
  2. 若8只全拆，全员手里P、V签的欠条与第三方持有关系当众摊开，"一张一张摆"8袋最多32张，远超第4步的时间，也泄露与胜负无关的私人交易。
  3. P本人是沼泽（坐庄）时第4步无意义，P空缺（两院僵局）时也不需要，判定流程没写跳过。
- **为什么重要**：F6是全本第二次高潮，第4步是收账"被套牢"的公开定罪时刻；拆袋口径不定，DM要么泄露、要么超时。
- **修复方案**：
  1. **F5开票期间**，场控在主场外拆开**全部8只**欠条袋，按机密册欠条台账核对，把"沼泽成员袋中、P或V亲笔签、未兑现"的欠条与国务卿任命书取出，装入一只"收账信封"（另装一只"不计入"信封作复盘备查），其余欠条原样封回。P、V在F5结束前才确定，场控按开票进程预分两套（蓝胜／红胜），开票结束取对应一套。
  2. 第4步改为："DM拆开收账信封，一张一张摆出计入的欠条，报N与T"——**不说这些欠条来自谁的袋**。第6步翻卡后，持有人自然揭晓。
  3. 判定流程第4步前加："P是沼泽或无P时跳过本步。"场控实操"欠条袋封存与F6清点≤3分钟"改为"F5期间预清点≤5分钟＋F6摆放≤1分钟"。

### operability-R3-06｜major｜独立参选人的"分票"何时放、怎么放没有写：公开实物放置允许看图后手，与站台"写在投放单、播报前同时揭示"的R2原则冲突
- **文件与位置**：01 F-03第9句（"每轮可公开放1枚在本轮开放、未锁票的州"）；05 §3.1.3（"分票……公开放置，不占行动次数"）、§3.3第6步、§8.1第10条（两名独立参选人"先放者有效"）；§3.1.4投放单样张（无分票栏）；§3.1.3〔因果〕（站台改写在投放单上，"消除后放者看图再放的后手优势"）。
- **问题**：
  1. 分票的放置窗口没有起止：走廊中任何时刻？封信封期间？投放信封收走之后、速算之前？F4最后一轮在信封交回后是否还能放？无规定。

### operability-R3-07｜major｜"全员同构"只管到信封，没管到卡面：上线手写留言卡不可能满足"约150字、差≤10%"，⛳18卡与小道消息卡外观不同，F0回执与第1期球童信封都在无隔板的公开场合拆读
- **文件与位置**：01 F-13第6款（回执两卡"每张约150字，全员字数差≤10%"；卧底②为"上线留言卡（沼泽在第3期回邮中所写）"）；F-16第3、4款（同构清单只列信封与袋，不含卡面）；04 §2.0.2全员邮包（上线"于隔板后填写空白⛳18卡"）、§2.1.6（第1期球童信封在走廊第1轮开始时发）、§9.2（"⛳18空白指令卡"与"小道消息卡""无回复卡"分列）；05 §3.2第0-2步（只写"拆""收"，未要求隔板；对比第0-1步收入信封写明"隔板后拆"）。
- **问题**：
  1. 上线留言是沼泽玩家现场手写，长度从"稳住"到写满不等，也不可能控制在150字，F-13第6款的等长要求对卧底②天然失效。
  2. 手写卡与印刷卡、印着⛳18小旗的指令卡与小道消息卡，卡面一眼可辨。第1期球童信封在走廊开始时、F0回执在主桌上公开拆读，邻座余光就能看到"他手里那张是手写的／有面小旗"。
  3. 沼泽未回复时卧底拿到"无回复"卡，非卧底拿到小道消息卡，两种卡的版式是否一致也没规定。

- **修复方案**：
  1. F-16第3款同构清单增加**卡面**：球童信封、回邮、回执内所有卡一律同尺寸、同卡背、**同正面版式**——上方印刷区（约120字：小道消息／终局提示／报备回执正文），下方统一留一块"手写区"（约30字）。非卧底的卡手写区由场控在装封时用同色笔写一句预定节目台词；卧底的卡手写区由场控**誊抄**上线的留言（上线原卡留存场控处，不直接转交）。⛳18只印在印刷区一角的"落款位"，非卧底卡同位置印节目台标，尺寸相同。
  2. "无回复"不再单独成卡，改为场控在手写区写"本期无新指令"，与其他卡同版。
  3. 05§3.2第0-2步、04§2.1.6补"一律在隔板后拆读"；第1期球童信封改在走廊开始前30秒全员隔板后拆读、读完放回信封收回（与回执同构）。
  4. 场控实操考核新增"回执与邮包装封（含誊抄、选版）"一项，见R3-10。

### operability-R3-08｜major｜草根捐款执行链仍漏底：写数时点与第2期道歉费、先见之明、九秒剪辑付费的先后未定；场控走到最低者座位核点，当众点出全场最穷的人
- **文件与位置**：01 F-09第2款；04 §2.0.1第2条、§2.0.3第1步（②写数在前，"第2期另有⑤道歉费由场控统一收付"在后）、§2.2.2第7步（道歉费与先见之明在新闻周期结算时收付）、§2.2.6第1步；§3.5推演（第3期草根给高文，隐含"道歉费先到账、再写数"）；§1.1第二次进广告（"前5分钟强制休息"）；F-10九秒剪辑（新闻周期属公开环节，可在写数后付1资金）。
- **问题**：
  1. 第2期新闻周期结算里，04§2.0.3把"写数"排在第②步、"道歉费"排在第⑤步；按此顺序钱多多写0（道歉费未到账）应得草根，而§3.5推演按"先收道歉费再写数"给了高文。同一局两种结果。写数之后新闻周期里仍可能发生九秒剪辑付费，"上一期结束时"的金额又会变。
  2. "场控在进广告／饭点第1分钟到最低者座位隔板后私下核点"：全场只看场控走到谁那里，就知道谁最穷；并列最低时场控走两处，同样暴露。资金是F-09第3款明定的隐藏信息。
  3. 第二次进广告前5分钟是"强制休息"，最低者可能离座，核点无法在第1分钟完成。
- **为什么重要**：草根是唯一按资金发放的银行收入，判错就是给错人；"谁最穷"是终局买票、收欠条时的关键暗信息。
- **修复方案**：
  1. F-09第2款写死顺序："新闻周期最后一步（片尾之后）全员写数"；04§2.0.3把写数从第1步移到第6步之后，道歉费、先见之明、剪辑付费都在其前完成。
  2. 核点改为**抽查同构**：场控每次核点固定走**3个座位**（最低者＋掷骰决定的2人），每处停留30秒、动作相同；被抽中的非最低者也确认"金额与纸条一致"。谎报偏低者罚则不变。
  3. 第二次进广告核点改在"后5分钟读终局通用本"开始时进行（全员在座）。04§1.1、F-09第2款同步。
