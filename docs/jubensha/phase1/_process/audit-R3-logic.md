## 一、Major

### logic-R3-01｜major｜01 F-04第2、4、6款、F-05注；03 §2.3第9条"为什么是任意两枚"；04 §6.8第4条及因果自检；02 §0.4⑦、§2.1辣椒—麦克
- **问题**：刹车条款写的是"三枚印章中任意两枚同盖一张申请书"，全本没有任何一句禁止同一个人同时持有并盖两枚。辣椒印、麦克印不可转让，但手稿印可以买卖、可以在盲盒里拍到。于是辣椒或麦克只要拍到（或买到）手稿印，就能一个人在DM面前压两格，独自顺延第9页（或第7、8页）。这与以下论断直接矛盾：04§6.8第4条"至少要有一位见证人愿意和手稿印持有人或另一位见证人坐到同一张桌前"、04§6.8因果自检"任何人都无法独自压页"、03§2.3"他只要求三个本不该合作的人里至少两个学会合作"、02§0.4⑦同句。而且这条路径并不罕见：①04§3.5推演里辣椒对手稿盒出价4、麦克出价2，本来就会去抢；②6人局手稿盒特意贴了律所寄存标签，"两名印章持有人能认出第三枚印章在哪只盒里"（04§8.2）；③8人局琳达第1期"私聊暗示不追究"，她可以合法地在走廊里叫麦克去抢手稿盒。
- **为什么重要**：第9页的"两人同桌盖章"是全本走心点前的名场面，也是05§9.6垂帘5–10%概率估算的前提（"压下要两名持章人中至少一名忠诚见证人主动买保险"）。一人独控时，"最不可能的同盟"不再需要发生，沼泽也只需说服一个人；同时世界设定"三个人里至少两个学会合作"在复盘时站不住。
- **修复**：
  1. F-04第2款补一句："一份申请书上的两枚印章须由**两名不同的持卡人**各自本人盖章；同一人同时持有两枚印章时，只能用其中一枚。"F-04第6款"无效"情形加"两枚出自同一人"。
  2. 03§2.3第9条合同原文同步写成"任意两位不同的持章人"，并在"为什么是任意两枚"后补："他防的正是有人把两枚攥在一只手里——那等于没设刹车。"
  3. 04§6.8第4条与因果自检、05§3.7第3-1步、02§0.4⑦与§2.1辣椒—麦克"同桌即可"同步改为"两名不同持章人"；04§2.1.4盲盒"决策点"补一句"见证人拍到手稿印也不能一个人压页，只能拿它当筹码换人"。
  4. 05§9.6不需重算权重，但在§9.7加一条外测观察："见证人持有手稿印的局，压下率是否异常偏高"。

### logic-R3-02｜major｜03 T00′、§2.9第2、3条、§6.4第43条；05 §3.2.1〔因果〕、§8.2第14条；01 F-13第3、6款；02 琳达A、安德福A、钱多多A
- **问题**：R2为镜像觉醒新增的世界依据《互不挖角君子协定》有五处因果断裂：
  1. **退回不等于没看过**：03§6.4第43条写"单方投诚报备会被本党（胸牌政党）法律顾问退回、视同未报备"。可"投诚报备"本身就是一份认罪书（"我是对面派来的"），收件方法律顾问拆开读过才能退回。高文单方报备后，驴友党法律顾问已经知道自己的建制派领跑者是大象党卧底，按常理当晚就会动手；规则却让他和坚守者"在档案上没有区别"（§2.9第3条），F0也不会因此换将。
  2. **琳达就是接收方**：琳达公开身份是"大象党首席律师"，T00′又写她"知道协定存在"。跟跟的报备交给"胸牌政党（大象党）法律顾问"，按字面就落在琳达手里。8人局里琳达会在摊牌夜知道"跟跟是驴心卧底、且他想投诚"，与F-13第6款"回执只告诉本人"、04§6.5"觉醒结果DM永不公开"冲突，也让她的「背调」变得多余。
  3. **调查者凭什么看得到**：§2.9说公开调查要查"两党法律顾问办公室的报备记录"。梅是驴友党通讯总监，查跟跟要看**大象党**的保密报备；琳达查高文要看**驴友党**的；6人局律所调查令则要律所去看两党的。这份协定是"不公开的君子协定"，三者都没有调阅权。
  4. **该知道的人不知道**：T00′写协定是两头吃"为保护种子"促成的，但安德福、钱多多（继承了种子网络的两个弟子）的开局知情里都没有它。弟子不知道师父为种子设的唯一护栏，说不通；他们知道的话，走廊里又会多一句"你单方投诚会被退回"的真实筹码，角色本必须写明。
  5. **未生效者的动机空白**：选了假戏真做、回执写"转换未生效"的卧底，规则让他继续为旧阵营赢，但02、04、05都没有给出这张回执上的世界内理由（只写"对应终局段落"）。玩家复盘必问："我都交了投诚书，凭什么还替原来那边卖命？"
- **为什么重要**：这是R2唯一的critical修复（镜像觉醒）在世界里的全部依据，也是公开调查"一致／不一致"、也就是确凿曝光和换将的来源。本格要求"一切可用现实逻辑解释"，这一层是复盘时最可能被深挖的地方。
- **修复**（只改设定文字，不动规则）：
  1. T00′改为**中立托管**：协定指定一位两党共同信任的托管人（NPC，例："退休大法官老秤砣的公证处"），投诚报备一律**密封交托管人**，不交任何党的法律顾问；托管人只在**两份密封报备同时到齐**时同时拆封并通知两党，否则**原封退回、不拆封**。这样"退回＝没人看过"，§2.9第3条成立。
  2. 03、02明确：大象党**总法律顾问**是NPC（与琳达不是同一人），琳达是"首席选举律师"，不经手报备，她"知道协定存在"保留。
  3. 协定增设"查询附则"：提名产生后（党代会搭档仪式结束起），每个政党在一个选举年里可向托管人**查询一次**"某人名下是否有已生效的交换"，托管人只答"有／无"；8人局两党分别由琳达（大象党）与梅（驴友党全国委员会通讯总监，作为本党授权查询人）行使，7人局由麦克代大象党行使。这一附则同时解释了公开调查的三件事：为什么"全场1次"、为什么只能在搭档仪式后、为什么DM只答一致／不一致（另两类纸——旧登记与资金线——是公开或半公开档案，调查员本来就查得到）。
  4. 安德福、钱多多A层各补一句："你知道师父三十年前促成过一份《互不挖角君子协定》，单方投诚会被原封退回——种子想跑，必须两颗一起跑。"
  5. 回执"转换未生效"卡（F-13第6款）写入世界内理由，例："托管处把你的报备原封退回，附言'对方无人同步'。没人看过它，你还是原来那个人——而在这个选举年，只有原来那边还认你。"02高文、跟跟第3期段落同步。

### logic-R3-05｜major｜03 §1.1"世界设定·两套暗号的来源"；04 §6.1第1条及因果自检；02 §1三星通用口径④、跟跟A⑦
- **问题**：暗号的世界来源与"谁会哪套"对不上：
  1. 象心暗号＝"大象党元老俱乐部的口令。元老子弟从家里学来，党的法律顾问圈常年替元老们办事，也都会（麦克、琳达由此学到）"。按这个来源，一个以局外人身份参加初选的播客主（麦克）会，而在大象党里"一步步干了22年，从州议员到联邦参议员"、当了七年现任副总统的跟跟（02跟跟因果核验）却不会。这是全场资历最深的大象党人，世界内没有任何理由被元老俱乐部排除在外。
  2. 驴心暗号＝青年团入团口令，"停用后外人只当是老党员的怀旧梗"。照字面，外人听过这句话，那它就谈不上暗号；象心玩家、麦克这样的政治播客主都可能知道。
  3. 规则侧（04§6.1）又写定跟跟只会驴心暗号、象心阵营只有麦克、琳达、高文和沼泽会象心暗号；"卧底能接上本阵营暗号、接不上对面暗号"是R3、R4的铺垫之一（02§3 R3③、R4）。世界依据一旦被追问，这两条铺垫就不成立：跟跟应当两套都会，和沼泽一样。
- **为什么重要**：暗号是全程阵营推理的第一工具（01§3.4第2条），"能接上暗号的可能是沼泽、不能百分百放心"是全本唯一的规则书提醒。如果卧底按世界逻辑也该两套都会，玩家会质疑"为什么只有沼泽能冒充"；跟跟这个设定更是最显眼的一处，复盘一问就破。
- **修复**：
  1. 03暗号设定把象心暗号的范围收窄并补一句羞辱梗："元老俱乐部只收**元老世家子弟**和替世家打官司的律所圈；改登记入党的人一律算'外来户'。跟跟当了七年副总统，俱乐部的门他一次也没进过——金大嗓的伞他可以撑，元老的口令他没资格听。"这同时强化跟跟"半步"的人设与羞辱线。
  2. 驴心暗号末句改为"停用后只在老团员之间当暗语流传，外人从没听过"，删去"外人只当是怀旧梗"。
  3. 02跟跟秘密A补一句"你从没被请进大象党元老俱乐部，你不会他们的口令"；04§6.1因果自检补"为什么跟跟不会象心暗号"一问一答。

### logic-R3-06｜major｜03 T16遗嘱附条款、T19、§8.1"规则物不是事件"①、§2.9；04 §6.3因果自检、§8.1；02 辣椒、麦克"6/7人局"；05 §9.8
- **问题**：6人局"律所调查令"的世界依据（R2-M23新设）有四处断裂：
  1. **条件与结果无因果**："起草律师回避本案时，律所向两位印章见证人各提供一次调查"。琳达在8人局里的「背调」是她作为大象党律师的本职工作，与她是不是合同起草人无关；"起草人回避"推不出"见证人需要一次调查"。
  2. **与两头吃的原则相悖**：调查结果能把没有投诚的种子判为"不一致"、确凿曝光并触发换将。两头吃一面在第9页写"名字我带走了""选边的机会留给种子自己"（03§3.12），一面又在遗嘱里亲手给两个见证人一件能揭穿种子的工具，动机自相矛盾。
  3. **律所无权调阅**：§2.9规定调查要查"两党法律顾问办公室的报备记录"，守口如瓶律所是私人律所，没有调阅两党保密报备的途径（与R3-02第3点同源）。
  4. **时窗与送达**：遗嘱给的调查委托第1期之前就送到了辣椒、麦克手里（与印章通知信同一信封），世界内凭什么要等到第3期搭档仪式之后才能用？同一信封里委托书的措辞也没有定稿，若写明"见证人""回避""本案"，会在第1期就把刹车条款的存在提前透露给两名持章人（K2本应在第2期午夜才公开）。
- **为什么重要**：6人局里这两张调查令是唯一的破锁工具，F-15第3款"6人局保底"整条成立都靠它；它也是03§8.1登记的"随人数变化的世界事实"，必须经得起推敲。
- **修复**（与R3-02的"查询附则"合并处理）：
  1. 删除遗嘱附条款，6人局调查令改为**协定查询权的本党授权**：按R3-02第3条，每党在提名后有一次托管查询权，由本党全国委员会在党代会当夜指定一名查询人行使。8/7人局驴友党指定梅、大象党指定琳达（7人局由麦克经琳达代查）；6人局琳达（NPC）因另一桩案件的利益冲突回避本选举年党务，梅（NPC）被派驻大选计票监督组，两党改为各指定本党一名"见证人兼候选人"——辣椒、麦克——代行一次。随人数变化的世界事实只剩"党代会当夜指定了谁"，与两头吃无关。
  2. 道具改为两党总部各自寄出的"党内查询授权书"，在第3期阅读时随球童信封发放（不再与印章通知信同封），卡面只写"提名产生后，可向协定托管处查询一次'某人名下有无已生效的交换'"，不出现"见证人""刹车""本案"。
  3. 03§8.1、T16、T19、04§6.3与§8.1因果自检、02辣椒与麦克"6/7人局"、05§9.8同步改写；8.1"唯一随人数变化的世界事实"清单相应更新。

### logic-R3-07｜major｜03 §8.1"7人局"、§8.2第3、5、6、9行；02 麦克"6/7人局"、§5.1；04 §6.3因果自检、§8.2删琳达表
- **问题**：7人局"世界不变，只换牌桌"，琳达作为NPC仍是大象党首席律师、象心、麦克的假离婚合伙人，开局握着：跟跟三十年前的驴友党青年团档案与合影（K9、K14）、刹车条款与"第三枚印章随手稿拍卖"（K2、K3，2月16日后可合法披露）、第18洞那句"他们来了"（K11碎片）。8人局里这些信息由琳达玩家决定给不给麦克；7人局里琳达是NPC，03只规定了"麦克打电话请琳达查一次"，却没有规定她**为什么不把其余信息告诉麦克**：
  1. 第1、2期麦克在大象党初选里与跟跟死斗，而他的合伙人手里正握着能当场打掉跟跟的旧档案；

### logic-R3-08｜major｜03 T07"两头吃怎么知道的"；对照03 §3.10第9页名录、01 §2.7、§3.3第9页
- **问题**：T07写"金大嗓竞选团队的副法律顾问是**沼泽俱乐部的会员**，看到过备忘录初稿"，以此解释两头吃为什么知道琳达压档。可第9页名录（截至Y−2年12月）写的是"主席：游游·两头吃　会员：'老底'安德福、钱多多"，01§2.7也写沼泽由两个弟子接管，F-05规定"名录上的人视为确凿曝光"。两处不能同时为真：要么名录漏了人，要么T07的线人不是会员。
- **为什么重要**：第9页名录是终局的确凿曝光来源、梅的真相题答案（"沼泽是哪两个人"），也是"两边都是我的人"结构（师父＋两徒＋两颗种子）的定义处。复盘时DM讲到"琳达的沉默是怎么被师父知道的"，一句"副法律顾问是会员"就会被玩家追问"那第9页为什么只有两个人"。
- **修复**：T07改为"金大嗓竞选团队的副法律顾问是两头吃三十年的老客户、欠过他人情（不是俱乐部会员），看到过备忘录初稿，后来跟终稿一对，附录不见了，顺口告诉了老头"；同时在03§3.12或§2.8补一句"俱乐部只有会员三人；外围的客户、线人、欠人情的人遍布两党，都不在名录上"，明确名录与外围网络的区别。

### logic-R3-09｜major｜03 T07、§3.8第7页正文、§6.4第30条；02 琳达A③；01 §3.2#4（R2-M29修复引入）
