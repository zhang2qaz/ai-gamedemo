### 1.2 核心机制逐条拆解

**机制①：自我介绍 → 才艺展示 → 打赏/竞拍（开场破冰经济）**
- 怎么运作：女性角色上台表演节目，争取男性角色口袋里的"银票"打赏；男性角色按各自任务竞拍女性角色的表演道具。[已证实·游民星空/搜索摘要"女性玩家需要进行才艺展示，男性玩家根据自己的任务竞拍女性玩家的表演道具"]
- 玩家决策：表演方决定怎么"卖"自己（演技、讨好、示弱、点名某个金主）；出价方决定钱给谁、抢哪件道具。任务不同，同一件道具对不同人的价值也不同。
- 为什么好玩：开场就逼大家开口、上台，社交破冰和经济分化在同一个环节完成；"每个人都有小秘密"，所以打赏和竞拍本身就在暴露信息。[已证实·"大家都有自己的小秘密，努力争取最高的打赏就对了"]

**机制②：前期道具决定终局能力（前后勾连）**
- 怎么运作：前期竞拍拿到的道具在最后的机制环节很重要，测评明确提醒"前期一定要努力获得道具"。[已证实·游民星空测评]
- 玩家决策：前期是抢道具还是攒银票？终局道具的具体功能前期不透明，带有赌的成分。[多源推断]
- 为什么好玩：开场的欢乐环节有了策略分量，不会沦为"表演完就没用"的过场；整本"都在为最后的机制做铺垫"。[已证实·测评原话"会感觉到整篇都在为最后的机制做铺垫"]

**机制③：人人皆有罪（全员凶手结构）**
- 怎么运作：复盘资料显示，7个角色每人都在剧中杀过NPC（例如：葛山杀莫老家主、莫来杀徐百万、马逍遥杀陈柔儿、余飘飘杀阿桃、阿無杀葛明、江时一杀兔娘、陈铁花杀齐书书和徐百万）。每个角色都有明面身份和暗面身份（如江时一明面是长安神医，暗面是凉山余党、铁将之子）。[已证实·找复盘/搜索摘要]
- 玩家决策：盘凶时不是在找"唯一凶手"，而是在处理"人人都有把柄"的局面：保谁、卖谁、自己怎么脱罪。
- 为什么好玩：消解了"凶手玩家孤立无援"的痛点，每个人都有隐藏动机，适合欢乐阵营本"弱推理、强博弈"的取向。

**机制④：终局大机制——"监狱打斗 + 威望值，最高的一男一女出狱"**
- 怎么运作：所有人都因杀人被捕，在监狱里完成打斗，最后威望值最高的一男一女可以出狱。[已证实·搜索摘要"所有人均因为杀人遭捕，要在监狱里完成打斗，最后威望值高的一男一女可以出狱"]
- 补充：时长约40分钟 [已证实·游民星空测评"将近40分钟"]；机制中会出现"未知剧情"，未知剧情会改变规则 [已证实·测评"在机制中会有未知剧情，未知剧情会给规则带来一些变化"]；需要"计算对方的情况" [已证实]。
- 玩家决策：结盟围攻谁、自己的威望值怎么保、道具什么时候用；"一男一女"的名额限制让男女两条赛道各自内卷，又必须跨性别合作。
- 为什么好玩：前面积累的所有东西（道具、银票、仇恨、秘密）在这里集中兑现；未知剧情防止玩家提前算死。
- 细节缺口：打斗具体的回合规则、威望值的增减公式、未知剧情有哪些，公开资料都没查到。[未查到]

**机制⑤：DM一人分饰两角 + 带动玩家入阵营**
- 测评称"本子很吃DM的热场能力，需要扮演俩个角色，要带动玩家进入阵营里的角色"。[已证实·搜索摘要引述测评]

**前作《青楼》的机制（旁证，可移植性高）**
- 大爷选伎、掷千金博美人、私聊消耗"酒力点"、拍卖环节。[已证实·知乎/搜索摘要]
- 地图搜证：在地图里选三个地点搜证，每人有行动点，可以深入线索；**每人可使用一次毁坏线索或捏造线索**。[已证实·搜索摘要"可以改线索"、"对线索进行毁坏、清理、捏造"]
- 魔石验身：三人同时验身，好人多于坏人亮绿光，坏人多于好人亮红光。[已证实·搜索摘要]
- 终局：最后两人可以离开。"好人+好人奏效，好人+坏人不奏效，坏人+坏人奏效"（对组合结果的判定）。[已证实·搜索摘要]
- 打架环节被评为"剧本最有意思的机制"。[已证实]

**好评**

- 适合朋友聚会、新手和进阶玩家，玩家不会中途下线。[已证实·游民星空"玩家也不会下线"]

**差评**

- 金钱收获差距很大，玩家之间收益悬殊。[已证实]
- 剧情偏薄，凶案线索集中在线索卡里，略杂乱；和一代相比新鲜环节不多。[已证实]
- 很吃DM热场能力。[已证实]

### 1.5 设计精神提炼（供移植）
1. 开场用"表演换钱"一次性完成破冰和经济分化。
2. 前期获得物 = 终局武器，让每个欢乐环节都带策略分量。
3. 人人有罪，所以人人有动机、人人有把柄。
4. 终局"名额制出线"（一男一女），制造跨阵营合作与同赛道内卷。
5. 终局中途插入"未知剧情/规则突变"。
6. 反面教训：终局规则必须讲清楚、数值必须直观（血量优于威望值）、经济差距要有兜底。

### 1.6 移植到美国竞选题材的转化方案（7条）

**转化1：筹款晚宴·"金主见面会"（对应：才艺展示+银票打赏+竞拍道具）**
- 玩法：第一幕开场，所有"想参选的人"轮流上台做60秒"竞选宣言/电视广告模仿秀"；扮演金主、超级PAC、游说者的玩家用"竞选美元"现场打赏。之后拍卖"背书卡"（工会背书、福音派背书、科技巨头背书、播客之王专访、退役将军站台等），这些卡在终局大选中各有加成。
- 关键改造：不按性别分"表演方/出钱方"，按"候选人线/金主线"分；8人局里按身份区分谁上台、谁撒钱，避免性别刻板化，也方便反串。
- 吸取教训：为保证没有人在开场就破产，规定每人保底筹到一笔"小额捐款"（Small Donors），以此兜底经济差距。

**转化2：黑料档案"人人有罪"（对应：全员凶手结构）**
- 玩法：用"丑闻/违法交易"代替"杀人"，保持欢乐基调、本格可解释。每个角色都有一份别人掌握的"对手研究档案"（Oppo File），里面写着真实发生过的违规（偷税、婚外情、收受外国游说、AI换脸、内幕交易等），因果链必须严丝合缝。
- 中段节点"国会听证会/特别检察官调查"：全员都会被查，比的是谁更会"切割、甩锅、交易豁免"，而不是推唯一凶手。

**转化3："提名出线名额"终局（对应：一男一女出狱）**
- 玩法：党内初选阶段，每个党最终只能有"一位总统候选人+一位副总统搭档"出线。出线规则用直观的"党内支持率"（看得见的数值条），不用抽象威望值。被淘汰的人不出局，转为"金主/幕僚/媒体"继续影响大选（避免过早出局）。
- 吸取教训：数值用"票数"或"民调百分比"，比"威望值"直观得多。

**转化4："十月惊奇"事件卡（对应：终局未知剧情改变规则）**
- 玩法：终局大选中，DM在预设时间点翻开"十月惊奇"卡（如"候选人病历泄露""深度伪造视频疯传""飓风登陆摇摆州""外国干预调查"）。每张卡都由前面玩家的行为触发，并改变一项结算规则。触发条件写在DM手册里，保证因果可追溯，不是天降随机。

**转化5："AI深度伪造"一次性技能（对应：前作的毁坏/捏造线索）**
- 玩法：每位玩家整场有一次机会"伪造一条爆料"或"删除一条证据"（对应删帖、律师函、AI伪造）。被识破会触发"造假丑闻"惩罚。DM手册规定所有伪造品的物理标识（如卡角暗记），保证复盘时可以追溯。

**转化6："联合民调"三人同验（对应：前作的魔石验身）**
- 玩法：任选三人做一次"联合民调/测谎"，只公布"这三人里忠于A党的人数是否过半"（绿/红），不公布具体是谁。既能给阵营推理提供信息，又不直接点破身份。

**转化7："搭档组合"判定（对应：前作"好+好奏效、好+坏不奏效"）**
- 玩法：总统候选人和副总统搭档组成"ticket"时，暗阵营组合决定加成：同一真实阵营的搭档有"政策协同"加成；暗阵营不同的，在终局触发"搭档内斗"事件（副手背刺/泄密）。这天然制造"选搭档"环节的高张力拉扯。

### 2.2 核心机制逐条拆解

**机制①：三幕循环"公聊 → 私聊 → 战斗"**
- 怎么运作：全程3幕，每一幕都按公聊、私聊、战斗的顺序进行。[已证实·多处一致]
- 为什么好玩：节奏固定、可预期，中度玩家很快能掌握；公聊立人设、私聊做交易、战斗做结算，三种体验轮流出现，不会长时间单调。

**机制②：双资源"兵力（攻击）+ 粮草（血量）"**
- 怎么运作：兵力代表攻击力，粮草代表血量。[已证实]
- 推断：吕布技能写有"空过不扣粮"，可见其他人空过（不行动）会扣粮草，也就是"不动也有成本"。[多源推断·由吕布技能反推]
- 为什么好玩：两个数值就讲清了"能打多疼"和"能扛多久"，理解成本极低；"空过扣粮"逼人行动，防止有人挂机苟活。

**机制③：回合内三类行动自由组合**
- 怎么运作：自己的回合可以行动或不行动；行动分为"移交物品、进攻他人、使用技能"，三项可以全做或任选，顺序自定。[已证实]
- 玩家决策：先给盟友送物资再打人，还是先打人再放技能，顺序本身就是策略。

**机制④：线索卡＝军需兑换券，可跨幕留存，有截止期**
- 怎么运作：搜证得到的线索卡下方印有"1000兵力"或"XX粮草"，可以在每幕私聊阶段找主持人兑换；可以留到下一幕再换；**第三幕私聊结束后不再兑换**。[已证实·复盘摘录原文]

**机制⑤：交易硬约束"一换一，不得赠予、偷抢"**
- 怎么运作：私聊阶段可以拿手中任意卡牌和别人交换，用来调整兵力和粮草；**不能赠予、偷抢，只能用自己的一张卡换他人的一张卡**。[已证实·复盘摘录原文]
- 为什么好玩/为什么重要：防止"抱团把资源全部倾倒给一个人"的平衡崩溃；每笔交易都要讲条件，自然产生谈判。

**机制⑤-b："移交物品"作为回合内行动**
- 注意：回合内"移交物品"和私聊阶段"一换一"可能是两套规则（私聊交换受限，战斗回合可以移交）。公开资料不足以确认两者关系。[未查到·存疑]

### 2.6 移植到美国竞选题材的转化方案（8条）

**转化1："竞选周"三段循环（对应：公聊→私聊→战斗）**
- 玩法：每一幕分三段。"电视直播/公开辩论"（公聊，全员发言、互相点名）→"密室交易/走廊政治"（私聊，限时轮转）→"新闻周期结算"（攻击、投票、民调变动）。全本重复3–4次，每次叠加新规则。

**转化2：双资源"弹药 + 民调"（对应：兵力+粮草）**
- 玩法：用"媒体弹药"（攻击：攻击广告、爆料、播客炮轰）和"民调支持率"（血量）两个数值。攻击别人花弹药、扣对方民调；民调归零不出局，只是变成"跛脚鸭"，换一套能力继续玩。
- 再加"新闻周期惩罚"：一轮里没有任何公开动作的候选人，民调自动-1（"不上头条就被遗忘"），逼人行动。

**转化3：回合行动三选一/多选（对应：移交/进攻/技能）**
- 玩法：每个"竞选周"每人可以做以下任意组合：①转移资源（捐款、转让背书卡）；②投放攻击广告；③发动角色技能。顺序自定。

**转化4："筹款支票"兑换期限（对应：线索卡兑换军需）**
- 玩法：搜证得到的"线索/文件"同时是"支票"，背面印有金额或弹药值，可以在任意一幕的私聊阶段向DM（扮演FEC联邦选举委员会官员）兑现。大选日前最后一个私聊阶段之后失效（法律梗："申报截止日"）。
- 效果：弱推理玩家也有搜证动机，搜证变成抢资源；早兑现会暴露财力，晚兑现可能作废。

**转化5："对价交易"规则（对应：一换一不能赠予）**
- 玩法：私聊阶段的卡牌交易必须"一换一"（Quid Pro Quo梗），不能单方面赠送。直接捐款只能在"筹款"行动中进行，并且会公开记账（对应"竞选财务申报公开"）。这样既防止抱团倾倒资源，又自然产生讽刺笑点。

**转化6：专属道具 + 条件彩蛋（对应：吕布与貂蝉等）**
- 玩法：每个角色带一件专属道具（例如候选人的"第一狗狗"、播客主的"千万订阅金麦克"、游说者的"小黑本"）。达成特定条件时触发彩蛋：
  - "第一狗狗"被别人拿来做政治道具，主人触发"爱狗之怒"，对此人攻击翻倍；
  - 一人同时被全场每人至少攻击过一次，触发"全民公敌"，转入"悲情牌"，民调回弹；
  - 记者把同一条黑料第三次换个标题发出，触发"标题党之王"奖励。
- 每个彩蛋的触发条件都写进角色本暗示里，兼顾公平和惊喜。

**转化7：党籍（表）+ 真实效忠（暗）（对应：表阵营+隐藏阵营）**
- 玩法：明面阵营是两党（如"驴党/象党"的谐音化名）；暗面效忠是金主、外国游说集团、个人野心或"建制派深层网络"。中期开放"换党/独立参选"窗口，暴露时机就是核心博弈。

**转化8：辅助型角色（对应：甄姬辅助）**
- 玩法：设计1–2个"辅助位"（如竞选经理、民调专家），技能是给别人加成。辅助位的胜利条件是"押中赢家并成为其幕僚长"，保证不爱正面冲突的玩家也能赢、有高光。

- 玩法：每人胜利条件二选一达成即胜：①自己（或自己扶持的人）入主白宫/进入内阁；②自己所属的真实阵营（暗阵营）在大选中获胜。另设"个人KPI"作为额外得分（MVP评比用），保证败方阵营的人也有个人高光。

**转化2："押注大选"投资环节（对应：投资试水）**
- 玩法：金主/超级PAC类角色可以把资金押在多个候选人身上对冲（真实政治里的"两边下注"）。押注在每幕结束时按民调变化浮动结算，终局按当选结果翻倍或清零。押注记录公开或半公开，制造"你到底押的谁"的猜疑。

**转化3："黑料直播间·扒马褂"（对应：爆料互撕）**
- 玩法：中段设置"深夜脱口秀/有线新闻连线"环节。任何人可以花弹药公开一条他人黑料，被爆者有30秒"狡辩时间"，并可以请一位"嘴替"帮腔；全场投票"洗白/锤死"，结果影响民调。
- 黑料互相咬合：A的黑料里藏着B的不在场证明，B为了自保必须替A圆谎，形成"被迫同盟"。

**转化4："技能＝人设＝黑料"（对应：黄大力雷管、孟小星举报）**
- 玩法示例：
  - 退役网红州长的技能"深度伪造"（他自己就是靠AI换脸起家的）；
  - 记者的技能"匿名信源"（每幕可匿名向DM举报一条黑料，DM在下一轮新闻中播出）；
  - 游说者的技能"小黑本"（每局两次，让一名议员的一张背书卡失效）。
- 每个技能都能在剧情里找到"为什么他会这招"的因果，满足"逻辑严谨"的要求。

**转化5："摇摆州竞标"（对应：合作竞标）**
- 玩法：七个摇摆州各自是一次"联合竞标"：同阵营玩家可以合并出资，出价最高的阵营拿下该州选举人票；也可以"假合作真不出钱"。竞标采用暗标（信封出价），开标瞬间就是名场面。

**转化6："选举人团地图"终局大机制（对应：转战全球各洲大对抗）**
- 玩法：终局在一张美国地图上进行。安全州直接按阵营归属分配，摇摆州逐一争夺，每州有"议题偏好"（关税/移民/医保/加密货币/AI）。玩家用手中的背书卡、弹药、资金和事件卡竞夺，最后统计到270票即胜。DM实时记账，这正是"终局对DM能力有明确要求"的落点。

**转化7："贿赂NPC"（对应：前作贿赂DM角色）**
- 玩法：DM分饰"党主席""有线新闻大亨""州务卿（计票）"等NPC，玩家可以私下"游说/贿赂"。NPC的反应写进DM手册的固定价目表，保证公平可复现，同时留给DM即兴表演空间。

**转化8：万物可交易、不可偷抢（对应：《搞钱》基石规则）**
- 玩法：作为全本最高规则写在规则卡第一条：所有卡（证据、黑料、背书、选票承诺、内阁职位承诺）都可以交易；不可偷、不可抢、不可看他人手牌；口头承诺不具约束力（允许背刺），但写成"白纸黑字的协议卡"并由DM公证后，具有机制约束力（违约触发"违约丑闻"）。由此形成"口头结盟随时可背刺、书面契约要付代价"的两层信任体系。

**附：结局文案做成笑点（对应：《回锅肉也有春天》）**
- 每个角色准备"当选/落选/入狱/当上播客主"等多分支结局小剧场，文案要讽刺、好笑，在复盘时由DM朗读。

## 5. 品类通用规律：城限欢乐阵营本

### 5.1 发行形式与定位常识
- 独家：一城一家；城限：一城约3–5家；盒装：不限量。城限价格常见2000–3000元，盒装一般低于700元。品质上"独家 > 城限 > 盒装"是行业普遍认知，但不绝对。[已证实·游民星空、知乎行业文]
- 行业经验："时长在初始设计时就要卡死：盒装4.5小时，城限6小时，因为机制本最怕等待时间过长。"[已证实·CSDN《机制本创作指南》摘要]
  - **对本项目的提示**：7–8小时已经超出城限机制本的常规时长，必须用"多幕多机制轮换 + 零挂机设计"支撑，否则疲劳风险高。[多源推断]

### 5.2 常见结构（以本次研究的作品为样本归纳）
| 段落 | 常见做法 | 样本 |
|---|---|---|
| 开场破冰 | 别出心裁的自我介绍、才艺表演、选人/打赏 | 青楼2、搞钱2、青楼 |
| 前期积累 | 拍卖/竞拍、投资、搜证换资源 | 青楼2、搞钱2、水镜八奇 |
| 中期冲突 | 黑料爆料/撕逼、凶案（弱推理）、阵营分组 | 搞钱、搞钱2、青楼2 |
| 阵营成形 | 分组/站队/表暗阵营揭示，可变阵营 | 搞钱、水镜八奇、青楼2 |
| 终局大机制 | 打斗/竞标/地图对抗/名额出线，常含"未知剧情"翻转 | 青楼2、搞钱2、水镜八奇 |
| 结局与复盘 | 分支结局、彩蛋、MVP | 搞钱2、拆迁 |
（结构归纳：[多源推断]）

### 5.3 经济系统常见范式
1. **单一货币 + 道具**（银票、亿元钞票）：开场按角色差异发放，用于打赏、竞拍、贿赂。[已证实·青楼2、搞钱]
2. **双资源对抗**（攻击/血量）：用于终局战斗类机制。[已证实·水镜八奇]
3. **资源券化**：线索卡兼作资源兑换券，有兑换期限。[已证实·水镜八奇]
4. **资产卡**：可以被技能摧毁（雷管）。[已证实·搞钱2]
5. **交易规则是经济平衡的关键**：要么"万物可交易但不可偷抢"（搞钱），要么"一换一、不得赠予"（水镜八奇）。前者自由度高、欢乐，后者更平衡、防倾销。[已证实]
6. **兜底机制**：欢乐本差评常见"金钱差距很大"（青楼2），需要设计保底收入或"穷人逆袭"通道。[已证实·差评；对策为推测]

### 5.4 互动机制常见形态
| 机制 | 常见做法 | 设计要点 | 可信度 |
|---|---|---|---|
| 投票 | 多数决；少数派受罚（囚徒困境） | 投票前私聊拉票是乐趣主体；匿名/实名会改变博弈 | [已证实·拆迁] |
| 竞拍 | 明拍（才艺打赏）、暗标、盲盒拍 | 道具价值因人而异，才有竞争 | [已证实·青楼2、孤城] |
| 交易 | 万物可交易 / 一换一 | 明确禁止偷、抢、偷看 | [已证实] |
| 结盟 | 口头结盟随时可破 | "不到最后都不一定是盟友"本身就是卖点 | [已证实·搞钱] |
| 卧底/隐藏阵营 | 表阵营+暗阵营 | 暴露时机是核心博弈 | [已证实·水镜八奇] |
| 转阵营 | 可选阵营、中途站队 | 需要给转换代价，防止全员涌向强势方 | [多源推断] |
| 身份验证 | 三人同验（只给汇总结果） | 给信息但不点破 | [已证实·青楼] |
| 证据操纵 | 毁坏/捏造线索，每人一次 | 需要可追溯标记，避免复盘对不上 | [已证实·青楼；标记为推测] |
| 贿赂NPC | DM扮演NPC接受贿赂 | 高欢乐，但要有价目表以保证公平 | [已证实·搞钱；价目表为推测] |
| 彩蛋 | 特定条件触发额外奖励 | 名场面制造器 | [已证实·水镜八奇] |

### 5.5 终局大机制常见形态
1. **乱斗/打斗型**：回合制攻防，双资源，最后存活或排名决胜（水镜八奇、青楼系列）。[已证实]
2. **名额出线型**：数值最高的N人"出狱/离开/当选"（青楼2"一男一女出狱"、青楼"两人离开"）。[已证实]
3. **竞标/拍卖型**：阵营合资竞拍最终标的（搞钱"医疗养生产业园"）。[已证实]
4. **地图区域争夺型**：多区域分别结算（搞钱2"转战全球各洲"）。[已证实·存在；细则未查到]
5. **全员投票型**：多数决定结局（拆迁）。[已证实]
6. **规则突变**：终局中途插入未知剧情/事件，改变规则（青楼2）。[已证实]
- **本项目建议**：美国大选天然适合多段复合终局：初选（名额出线）→ 党代会/搭档（组合判定）→ 摇摆州（竞标+地图）→ 十月惊奇（规则突变）→ 大选夜（选举人团计票）。[设计建议，非原作事实]

### 5.6 常见翻车点及规避方法
| 翻车点 | 证据 | 规避方法 |
|---|---|---|
| 终局规则讲不清，"不知道要干什么" | 青楼2差评 [已证实] | 终局规则卡单页化；DM手册附"30秒口播版规则"；先跑一轮示范回合 |
| 数值抽象、爽感不足 | 青楼2"建议威望值改血量" [已证实] | 用直观数值（票数、民调%、血量）；用实体筹码/计分轨展示 |
| 经济/收益悬殊 | 青楼2 [已证实] | 保底收入、追赶机制（落后者获得"悲情牌/草根捐款"） |
| 技能超模、角色强弱悬殊 | 水镜八奇（孙坚、袁绍超模）[已证实] | 每个技能做数值验算和多轮实测；强技能加使用次数/代价限制 |
| 翻车率高（DM或玩家一失误就崩） | 水镜八奇 [已证实] | 保姆级DM手册（搞钱2经验）；关键节点设"DM校验表"和兜底规则 |
| 战斗/回合单调 | 水镜八奇 [已证实] | 每一幕加一条新规则或新地形，事件卡打破重复 |
| 朋友抱团导致5打2、8虐1 | 知乎行业文 [已证实] | 阵营归属由剧本暗定 + 隐藏阵营 + 双路径胜利，弱化"现实好友自动结盟" |
| 挂机/摆烂 | 知乎行业文 [已证实] | "不行动就扣民调"（借鉴空过扣粮）；被淘汰者转职继续玩 |
| 过早出局 | 品类共识 [多源推断] | 民调归零变"跛脚鸭"或"转职幕僚/金主"，绝不让人坐冷板凳 |
| 阵营与剧情割裂 | 行业文"阵营设计与剧本剧情的割裂是最大问题" [已证实] | 每个阵营归属、技能、黑料都必须有剧情因果；做因果链审校表 |
| 读本压力大 | 水镜八奇 [已证实] | 角色本分幕发放；关键信息加粗或做成"任务卡"；单幕阅读不超过20分钟 |
| 抄袭/IP风险 | 水镜八奇 [已证实] | 全原创命名与设定；真实政治人物只做讽刺映射 |
| 太吃DM | 青楼2 [已证实] | 写清DM能力画像；提供台词脚本、计分表和复盘脚本 |
| 时长过长导致疲劳 | 行业经验"城限6小时" [已证实] | 7–8小时必须"机制轮换+中场休息+高能节点均匀分布" |

### 5.7 核心玩家画像（城限阵营本中度玩家）的验证
- 搞钱2"机制简单、比拼心理博弈"适合新手，但核心玩家打分偏中（6.5）[已证实]；水镜八奇机制深、阵营强，被称"封神"，但也有翻车高、读本压力大的问题 [已证实]。
- **结论**：本项目的甜区在两者之间：规则用"搞钱级易懂"，深度用"水镜级可深挖"，开场体验用"青楼级强破冰"。[多源推断]

### 5.8 DM能力要求（品类经验）
- 通用：吃透剧本、控场带节奏、沉浸式演绎；脱稿控场；心理承受力、应变能力强。[已证实·知乎、新浪]
- 有观点认为专业DM应"至少能完整背诵流程、能脱稿带本，有200场以上带本经验"（个别来源，标准偏高）。[已证实·单一来源]
- 机制本特有：分饰多个NPC（青楼2）[已证实]；实时记账、结算、计算 [多源推断]；在规则突变时口径一致地裁定 [多源推断]。
- **本项目终局大机制DM硬性要求的建议方向**：①能同时管理地图计分板和多方暗标；②能一人分饰3个以上NPC并即兴回应贿赂；③能按手册条件准确触发"十月惊奇"；④能在规则争议时10秒内依据裁定表作出判决；⑤有丰富的热场与主持能力（模仿新闻主播、辩论主持）。[设计建议]
