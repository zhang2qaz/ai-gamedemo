## 2. 世界观设定

### 2.1 时间
虚构的"**20XX年·第六十届大选年**"。映射2024–2026年前后的美国：两党极化、摇摆州决定一切、超级PAC和亿万金主主导资金、播客主比电视台更有影响力、AI深伪随手可得、关税/移民/AI监管/加密货币/医保补贴吵成一锅粥。
现任总统**金大嗓**（大象党，"关税大王"，NPC，只在背景和DM播报中出现）任期届满、不能连任，**两党都要重新初选**——这是一个"开放席位"年，所以人人都觉得自己有机会。

### 2.2 地点与舞台
- **骑墙大酒店**：位于**钢铁州**（映射宾夕法尼亚，最大摇摆州）首府铁锅城。酒店老板是一位已故说客的基金会，向两党免费提供场地，口号是"**两党都欢迎，账单都一样**"。
- 为什么全年的大事都发生在这里：钢铁州是本届"引爆点州"（谁拿下谁大概率当选），两党都把关键活动放在这里抢镜头。这符合真实惯例：党代会和重要集会会优先放在摇摆州。
- **时间跨度**：全本跨越一个完整大选年，分为五个"夜晚"，每幕都是同一家酒店的不同夜晚：
  1月·新年筹款晚宴 → 3月·超级星期二之夜 → 8月·党代会之夜 → 10月·辩论与十月惊奇 → 11月·大选夜。
  这个结构和竞品《大选日》（只发生在大选当天）做出明确区分。

## 3. 本格核心事件（轻推理）

### 3.1 发生了什么（玩家开局看到的表象）
第一幕筹款晚宴的午夜，叉叉网账号"@老游说不死"发布了**两头账本第1页**，内容是在场某人的真实黑料。此后每到一个政治大日子的午夜（超级星期二、党代会、十月惊奇、大选前夜），都会再发1–2页。全场第一反应是"**我们中间有人在泄密**"，于是互相指控、互相甩锅。

| 时间 | 事件 | 为什么 |

### 3.3 它如何驱动阵营对抗，而不是变成烧脑盘凶
- **账本页＝弹药**：每页发布后，相关角色要当场"狡辩"（扒马褂环节），其余人投票洗白/锤死，结果直接改民调。
- **停发码＝终局武器**：凑齐三段并按正确顺序输入的人，获得"**账本控制权**"：可以压下一页、调换发布顺序，或**用深伪替换一页**（有被鉴定拆穿的风险）。三段密码分散在驴心、象心和公开拍品中，任何阵营都拿得到，但都要交易。
- **第9页＝定时炸弹**：它会在大选前夜曝光沼泽的卧底网络。沼泽最想压住它，卧底最怕它，忠诚派最想用它。围绕"谁控制第9页"，三个真阵营在第三、四幕必然正面碰撞。

## 4. 阵营结构

### 4.1 双层阵营总览（8人）

**结构对称性**：每个政党内部恰好是"1名忠诚候选人＋1名对面卧底候选人＋1名忠诚幕僚＋1名沼泽"。两党的初选因此都是"**忠诚派 vs 卧底**"的内战，而两场初选的结果组合，决定了大选是"真对决"还是"左右手互搏"。

### 4.2 胜利条件与计分
**主目标（阵营胜利，决定输赢）**
- **驴心胜**：当选总统的**真阵营**是驴心——不论他挂的是哪个党的旗。
- **象心胜**：当选总统的真阵营是象心。
- **沼泽胜**：满足其一即可。① 当选总统或副总统的真阵营是沼泽；② 当选总统签给沼泽成员的"**白房子欠条**"≥3张。
  - 走路径②时，沼泽与当选方**共赢**，但当选方的胜利降级为"**惨胜**"（结局演绎不同，MVP计分−2）。所以签欠条有真实代价，不是白送。

**个人目标（政治遗产分，决定MVP与"虽败犹荣"）**
- 每人3条个人目标，每条2分；另有彩蛋分（1–3分）和DM颁发的高光分（最佳狡辩/最佳背刺/最佳演讲，各1分）。
- 阵营胜利者中遗产分最高者为**MVP**；阵营失败者遗产分≥5，获得"**虽败犹荣**"个人结局（例如落选后当上播客主、出回忆录）。保证输的一方也有高光。

### 4.3 隐藏阵营 / 卧底 / 转阵营机制
1. **卧底候选人**：定型（驴友党里的象心）和跟跟（大象党里的驴心）。他们知道自己是卧底，却不知道自己的上线其实是沼泽。
2. **沼泽**：知道两名卧底的身份，信息优势最大；但人数最少、没有天然的总统候选人，而且第9页账本会在大选前夜自动曝光他们。
3. **策反信**（每个真阵营1张）：在第三幕"策反窗口"内，可以私下交给某人。对方接受后，由DM替换其真阵营卡；原阵营不会收到通知。
   - **限制①（防一边倒）**：不能把人策反进"当前势力领先的真阵营"。势力由DM按"该阵营成员持有的代表票＋民调"在后台计算，被拒时DM只说"船满了"，不说原因。
   - **限制②（有代价）**：被策反者保留原有个人目标，并新增一条"叛徒目标"；若新阵营最终失败，被策反者遗产分−2。
4. **卧底觉醒**（专属于两名卧底）：当卧底确认自己的上线是沼泽时（来源可以是账本页、上线自己承认、背调结果），可以在一次"觉醒"中三选一：**坚守**原真阵营 / **投靠**沼泽（受限制①约束）/ **自立**——转为"孤狼"，只有自己当选总统才算胜利，但获得一次性技能"**反咬上线**"（公开上线的真阵营，DM确认真伪）。
5. **换旗**（表阵营变更）：党代会前，任何人可以公开换党。代价：清空已获得的代表票，失去1张背书；收益：获得对方党副总统提名资格。

### 4.4 为什么这套结构没有必胜策略、没有造王者
- **双锁不是稳赢**：驴心如果同时拿下两党提名（辣椒＋跟跟），大选看似"左右手互搏"，但象心和沼泽仍可以在第四幕用"真身曝光→临阵换将"把其中一位换下（见第9节）。
- **沼泽不是造王者**：沼泽要赢必须拿到欠条或亲自上位。它支持谁，是一笔有对价的生意，而不是"随便选个人让他赢"。签了欠条的一方会把把柄交给沼泽，沼泽可以拿欠条"催债"。
- **卧底不是工具人**：每名卧底都有觉醒和自立选项，上线随时可能被反噬。
- **转阵营不会滚雪球**：限制①让策反只能流向弱势方，天然是翻盘通道而不是锦上添花。

### 4.5 6/7人适配思路（细则见第5节末尾）
- **核心6人**：辣椒、定型、安德福、麦克、跟跟、钱多多。真阵营恰好是驴心2/象心2/沼泽2，而且每个政党里各有一名驴心、象心、沼泽，是最纯粹的三方拉扯。
- **可删2人**：梅·独家（驴心）、琳达·背调（象心）。两人是忠诚幕僚位，删除后由预写的"迁移表"把其关键信息与道具转给NPC或公开拍品。
- **7人**：删琳达（或删梅，二选一，镜像处理），被删一方的真阵营获得补偿包。

## 5. 八个角色

> 格式说明：名字均为"绰号·谐音姓/人设词"，中文玩家一眼能记、能喊。无一使用真实政治人物姓名。技能统一遵循"技能＝人设＝黑料"原则（借鉴《搞钱2》黄大力"雷管"对应其炸化粪池黑料的做法，[已证实]）。

### ① 辣椒·冲冲（核心位）
- **命名梗**：辣＝敢说，冲冲＝冲锋＋冲动。全场最好喊的名字。
- **年龄/公开身份**：33岁，驴友党众议员，靠"一边炒菜一边骂政敌"的直播爆红，挑战本党建制派。
- **隐藏秘密**：①直播用的"自家厨房"其实是租来的影棚，爱犬"选票"也是粉丝寄来的（她以为是粉丝）；②她第一次竞选的"草根小额捐款"里有四成来自同一家空壳公司——两头吃。
- **真阵营**：驴心（忠诚）。可能变化：被策反或在第9页曝光后动摇。
- **个人目标**：赢得驴友党提名或成为任一党副总统提名人；在辩论中获得全场最高掌声；查清"是谁在暗中资助我"。

## 9. 终局大机制：「摇摆之夜」

### 9.1 地图与胜负
- **选举人团**总数538，过270当选。为平衡改为对称安全票：驴友党安全州**222**、大象党安全州**222**，余下94票为摇摆区：
  钢铁州19、桃子州16、烤肉州16、轮胎州15、仙人掌州11、奶酪州10、骰子州6、**玉米州蓝点区1**（映射内布拉斯加按选区分票，"一个城市选区决定总统"）。哪一组拿到48张摇摆票即当选。
- 每州印一个**议题偏好**（钢铁州＝关税、轮胎州＝工会、桃子州＝医保、仙人掌州＝移民、骰子州＝赌场工会、奶酪州＝农业、烤肉州＝AI监管、蓝点区＝城市年轻人），与背书卡匹配。
- **注意：选举人团只决定"哪组搭档当选"，阵营胜负还要看第五步"真身揭晓"。**

### 9.2 五个阶段（100分钟）
**① 规则补全＋换将窗口（10分）**
- DM用"30秒口播版规则"讲清本阶段，并先跑一个示范州。
- 如果某提名人的真阵营已被确凿公开（账本页、背调、卧底自曝），其所在政党的成员可发起"**临阵换将**"表决：本党过半同意，由副手或初选亚军顶上；被换下者可以第三党身份独立参选，不能进辩论（门槛梗），但可以参加州争夺，用来分票。

**② 电视辩论（25分）**
- DM扮演吵架委员会主持人，手握"**关麦铃**"。两组总统候选人进行三轮：开场陈述（1分钟）→ 互怼（每人2次30秒，可召唤一位"嘴替"）→ 结辩（1分钟）。副手可以插话一次。
- 非候选人各持"场外事实核查"卡一张，可当场举牌质疑一句话，DM裁定真假，说假话者民调−1。
- 全员匿名投票"谁赢了辩论"：胜方获得3枚**动量**，负方1枚（真实依据：辩论通常只改变1–3个百分点）。

**③ 十月惊奇（10分）**
- DM按手册翻开**2张由前因触发的事件卡**，每张都对应前几幕的某个行为，确保因果可追溯：
  - 有人用过深伪卡 →「深伪恐慌」：本轮所有攻击须先付1资金送照妖镜鉴定；
  - 钱多多在押宝网单注超过10 →「押宝网操纵调查」：他所支持的那组搭档在下一轮暗标中打八折；
  - 交权书复印件已出现 →「第18洞真相」（R8）：安德福民调−3，沼泽全员公开身份；
  - 都没触发 → 抽"飓风登陆仙人掌州"等中性事件，该州本轮暗标作废、重新竞标。
- 账本控制权持有人在此阶段决定剩余账本页的发布顺序，或用深伪替换其中一页。

**④ 摇摆州争夺（40分，三轮）**
- 第一轮·阳光带：桃子、烤肉、仙人掌、骰子（49票）。
- 第二轮·铁锈带：钢铁、轮胎、奶酪（44票）。**第二轮结束＝大选前夜**，第9页账本自动发布（除非已被控制者压下）。若曝光沼泽网络，所有含沼泽成员的搭档在第三轮全部州−3。
- 第三轮·加时：蓝点区（1票）＋前两轮中差距≤2点的州（"重新计票州"重新竞标）。
- **每轮流程**：走廊私聊5分钟 → 全员同时执行2个行动（任意组合）：
  - **暗标**：信封里写"州＋搭档"，放入资金。任何人都可以给任何一组搭档投钱，**卧底和沼泽的暗中支持就在这里**；
  - **驻扎**：把自己的棋子放进某州，为指定搭档＋2。棋子公开可见，所以这是"公开站队"；
  - **攻击**：打出黑料卡，指定某州某组搭档−3；
  - **技能/动量**：放置动量（每枚＋2）或发动技能。
- **结算**：DM与场控逐州开信封，州得分＝暗标＋驻扎＋背书匹配＋动量＋民调差修正−攻击。高者拿下全部选举人票；平局时民调高者胜。
- **策反选举人**：全场限一次，只能在无约束法律的骰子州使用，花10资金使1张选举人票改投。成功后立即触发"不忠选举人丑闻"，使用者民调−3（真实依据：最高法院已裁定州可惩罚或替换不忠选举人，所以设计成高成本、仅限一个州）。

**⑤ 大选夜开票＋真身揭晓（15分）**
- DM以新闻主播口吻按时区顺序报票，最后报蓝点区。
- **269:269**：进入"众议院加时赛"（真实依据：宪法第十二修正案，众议院按州代表团每州一票选总统）。每名玩家代表若干州代表团，公开唱票一轮，过半者当选，平票再由参议院选出的副总统代理总统。
- 当选总统、副总统当众翻开真阵营卡，DM宣布阵营胜负；沼泽清点欠条。

## 11. 自评

### 11.1 最强的3点
1. **表里双层阵营的对称结构**：每个政党内部都是"忠诚派＋对面卧底＋沼泽"，两场初选天然变成内战，大选天然变成"你确定赢的是你的人吗"。拉扯来自结构本身，不靠DM煽动。6人核心版仍保持完整的三方对称。
2. **转阵营有方向、有代价、有翻盘意义**："船满了"规则只允许策反流向弱势方，叛徒有额外目标和失败惩罚，卧底觉醒提供三选一。转阵营变成翻盘通道，而不是滚雪球通道。
3. **本格事件是阵营对抗的燃料**：死人开关的因果链完整、现实可解释，从"谁在泄密"的撕逼开始，到"谁控制第9页"的三方争夺收束。推理只占约15%，产出全部是武器和身份信息。
