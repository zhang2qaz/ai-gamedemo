# 概念方案 B ·「机制博弈派」——《白房子大甩卖》

> Ascham工作室 · 城限 · 欢乐向阵营机制本 · 本格 · 8人标准（7/6人适配）· 目标时长约7.5–8小时
> 设计主轴：**全本共用一套"四币一命"资源经济（钱·料·情·声 + 人气）**。开场打赏的每一块钱、听证会翻出的每一张黑料、党代会签下的每一张欠条，最终都要在大选夜换成选举人票。
> 研究依据：三份研究报告均已读完（research-references / research-politics / research-players-production）。文中凡写"借鉴自某作品"的条目，都只引用报告里标为[已证实]或[多源推断]的内容；标为"推测"的条目只当作我们自己的灵感，不当作原作事实。

## 1. 剧本名 · 卖点 · 宣传语

**备选剧本名**
1. **《白房子大甩卖》**（首选）——"白房子"即白宫的欢乐化名。整本的核心笑点和机制都是"白宫是可以买的吗？"，剧名本身就是讽刺。
2. **《二百七》**——到270张选举人票就赢，硬核、好记，适合做海报大字。
3. **《驴象撕不停》**——直白的欢乐撕逼感，适合盒装下沉版本备用。

**一句话卖点**
8个政坛戏精在同一家酒店里过完一整个大选年：开场打赏、中场爆料、党代会卖票、大选夜开标，前面每一笔交易都会在选举人团地图上兑现。

**宣传语**
- "在沼泽大酒店，没有永远的盟友，只有没兑现的欠条。"
- "你投出的每一票，都有人提前付过钱。"
- "这届选举很干净——钱都洗过了。"

## 2. 世界观设定

### 2.1 时间
虚构的"20XX年"，对应现实里下一个总统大选年。现任总统**沃克·软软**（大象党，两届任满，不能再选）以"宣布关税后48小时内必撤回"闻名，华尔街专门编了"软软指数"。白宫没有在任者参选，是一场**开放席位**的混战。

时代议题全部虚构化后照搬：关税反复横跳、医保补贴到期、移民执法、币圈与AI的超级PAC、AI深伪广告（钱钱委员会因3:3僵局管不了）、长播客取代电视辩论、媒体执照战。

### 2.2 地点与舞台：沼泽大酒店
- 首都"大沼泽特区"（"排干沼泽"梗）的百年老酒店，政客、说客、金主、记者都住在这里。
- **为什么一整年的事都发生在同一家酒店**：现任政府的"省钱部"出台新规，要求联邦相关活动统一在"政府协议酒店"举办以节约开支。结果两党党代会被安排在同一家酒店的东、西两个宴会厅，同一晚开幕，中间只隔一个自助餐区。这条规定本身就是笑点，也让"两党玩家同场互动"有了现实逻辑。
- **游戏时间跨度**：一个大选年，压缩成在酒店里度过的4个夜晚：
  - 第一幕：1月·开年金主晚宴（隐形初选）
  - 第二幕：3月·超级星期二之夜 + 钱钱委员会紧急听证
  - 第三幕：7月·两党党代会同夜开幕
  - 终局：9–11月·辩论、十月惊奇、大选夜（酒店顶层"选举夜派对"）

### 2.3 政党与势力（欢乐命名）
| 势力 | 映射 | 人设 |
|---|---|---|
| **驴友党**（蓝） | 民主党 | 爱结伴、爱开会、爱远方；口号"驴友出发！" |
| **大象党**（红） | 共和党 | 体大、稳、记仇；口号"象来如此！" |
| **沼泽俱乐部**（隐藏势力） | 华盛顿建制派+游说网络 | 不站队，只收欠条。谁当选都无所谓，只要新总统欠它的人情 |
| **钱钱委员会** | 联邦选举委员会 | 3:3永远打平，外号"平局委员会"；本作中由DM扮演主席 |
| **《滑溜溜》** | 政治八卦网站 | 记者佐伊供职的网站 |
| **《吼吼三小时》** | 头部长播客 | 前两个半小时在聊外星人和冷水澡 |
| **美国梦加油站** | 超级PAC | 名字很正义，资金来自石油和"鹰币"（一种迷因币） |
| **关心关心老百姓** | 501(c)(4)黑钱组织 | 捐款人：未披露 |

### 2.4 当前局势
- 两党都没有现成的接班人，初选是乱战。大象党内，建制派党鞭想当"造王者"，播客主持人想"吼进白房子"；驴友党内，稳健派州长和网红众议员互不相让。
- 七个摇摆州（钢铁州、桃子州、烤肉州、轮胎州、仙人掌州、奶酪州、骰子州）加上玉米州的"蓝点区"，一共94张选举人票，两党基本盘各222张。**谁先拿到48张摇摆票谁赢；47:47就是269平，交给众议院。**
- 超级PAC"美国梦加油站"号称手握**1亿美元**，准备砸向大象党提名人。这笔钱是全年最大的变量。

### 2.5 为什么这几天是命运转折点
1. **开放席位**：没有在任者，谁都有机会，所以谁都敢押上全部身家。
2. **一亿美元在开年晚宴上"失窃"**：这笔钱的去向决定整个大选年的资金格局，也撕开了每个人在晚宴上的小动作。
3. **省钱部的同酒店规定**：两党第一次在同一个屋檐下开党代会，"隔着自助餐区挖墙脚"成为可能。

## 3. 本格核心事件：消失的一亿（轻推理）

### 3.1 发生了什么（玩家开局时知道的表层）
开年金主晚宴当晚20:00–21:00，"美国梦加油站"存放竞选资金的**硬件钱包"金钥匙"**从创始人钱多多的礼服内袋里消失，链上余额清零。第一幕结尾，钱多多当众宣布"一亿被盗"，并指控"驴友党的黑客"。

### 3.2 真相骨架（完整因果链，每一环都能回答"为什么"）
| 时间 | 事件 | 为什么 |
|---|---|---|
| 两周前 | 鹰币暴跌90%。PAC账面上的"1亿"实际只剩**1000万**；钱多多早就挪用PAC资产给自己的石油生意做抵押 | 迷因币计价的PAC本来就不稳；挪用是他的老毛病 |
| 晚宴前 | 钱多多决定**自导自演一场盗窃**：钱包"被盗"，就没人能查出1亿早已不存在；他还能找"大保险同盟"索赔1亿的"数字资产盗窃险"，再借受害者身份在大象党内收割同情捐款 | 一箭三雕：掩盖挪用、骗保、博同情 |
| 19:40 | 钱多多把装着金钥匙的礼服交给衣帽间，并把**取衣牌和PIN码**交给说客雷米，约定20:30把钱转到他的离岸地址 | 雷米是他的老牌说客，转账由别人操作，他自己就有不在场证明；酬劳是一张"钱多多欠条" |
| 19:45 | 两人在露台确认计划，钱多多说了一句"今晚它会丢"。这句话被吼吼放在露台栏杆上的播客麦克风录了下来 | 吼吼当晚在露台录"金主晚宴吐槽特辑"，麦克风一直开着 |
| 20:05 | 雷米凭取衣牌取出钥匙，在洗手间走廊用笔记本**导出了钱包的全部交易记录**（证明1亿早已缩水） | 雷米是沼泽俱乐部的大管家，习惯给每个客户留一份"保险" |

| 20:31 | 贝蒂手机弹出"到账1000万"的通知，正在旁边的盖文瞥到了屏幕 | 501(c)(4)的银行账户绑定了她的手机 |
| 20:35 | 雷米把钥匙塞进宴会厅鹰形冰雕的喙里 | 钥匙上有他的指纹，带在身上危险；冰雕第二天就会被处理掉 |
| 20:45 | 安德福一直在点人头，他看到雷米在冰雕前停留过久，便用蛋糕刀撬出了钥匙 | 党鞭的本能：别人藏起来的东西一定值钱。他要的不是钱，而是钱多多和雷米两个人的把柄 |
| 20:40–20:50 | 乔安娜在宴会厅直播，背景里拍到了"冰雕喙部反光"和"安德福拿着蛋糕刀" | 她在直播"金主晚宴有多奢侈"，镜头恰好朝向冰雕 |
| 20:10 | 佐伊在洗手间走廊拍到雷米在操作笔记本 | 她在跟踪雷米，想挖"说客收买记者"的稿子 |
| 21:00后 | 钱多多按计划"发现失窃"，一查链上，钱去了一个陌生地址，不是自己的离岸账户 | **自导自演的盗窃，被真的盗了**。他不能报出真实去向，否则会暴露1亿早就不存在 |

**三问（推理目标）**：
- Q1：钥匙现在在谁手上？（安德福）
- Q2：钱去了哪里，到底有多少？（1000万，进了"关心关心老百姓"；"1亿"从来不存在）
- Q3：谁策划了"失窃"？（钱多多自导；雷米截胡）

### 3.3 它如何驱动阵营对抗，而不是变成烧脑盘凶
- **真相就是钱**：那1000万是全局唯一一笔"无主资金"。第二幕听证会上，三问答对得越多，这笔钱被冻结后按"追缴款"分给揭发方的份额就越多。如果没人查清，这笔钱会作为黑钱留给沼泽俱乐部，在终局变成一波匿名攻击广告。玩家查案的动力是抢钱，不是解谜。
- **人人有点小动作**（移植《青楼2》"人人皆有罪"的精神，罪行降级为丑闻）：每个人在晚宴上都干过一件见不得光的事，所以每个人提供证词时都要掂量：说出真相会不会顺带暴露自己？
- **证据本身就是筹码**：线索卡背面印着金额（移植《水镜八奇》"线索卡=军需兑换券"），可以拿去换钱，也可以扣着要挟别人，也可以卖给想灭口的人。

### 3.4 推理的占比与形态
- 推理约占总时长**10–12%**，集中在第二幕的"酒店搜证+钱钱委员会听证会"（约40分钟），终局复盘时再补全。
- 形态是**三道选择题，不是开放式盘凶**：每题有3–4个公开候选答案，各阵营在听证会上举牌作答。答对即得资源，答错扣人气。
- 已知结论有容错：Q1靠乔安娜的直播回放加安德福自己的心虚就能锁定，Q2、Q3需要两到三张线索交叉。推理弱的玩家可以靠"买证据""跟票"参与，不会挂机。

## 4. 阵营结构

### 4.1 阵营总览（8人）
| 明面党籍 | 角色 | 真实阵营 |
|---|---|---|
| 驴友党 | 乔安娜·不服、盖文·不乱 | 驴友阵营 |
| 驴友党 | 贝蒂·稳稳 | **沼泽俱乐部（卧底）** |
| 大象党 | 雷霆·吼吼、钱多多 | 大象阵营 |
| 大象党 | 安德福·老底 | **沼泽俱乐部（卧底）** |
| 无党派 | 雷米·两头吃（游说者） | **沼泽俱乐部（大管家）** |
| 无党派 | 佐伊·快门（记者） | **第四权（独立，可被收购）** |

明面上是3 : 3 : 2，真实结构是**2 驴友 + 2 大象 + 3 沼泽 + 1 记者**。
- 沼泽俱乐部采用"单线联系"：雷米认识贝蒂和安德福，**贝蒂和安德福互不知道对方也是沼泽成员**。所以沼泽人数虽多，内部却有猜疑，也存在被反向策反的空间。
- 两党各藏着一个卧底，"党内谁是自己人"是贯穿前三幕的悬念。

### 4.2 胜利条件与计分（双路径，移植《搞钱2》"自己上市成功或站在胜利队伍中"的精神）
每人终局得分 = **阵营分（0或4分）+ 个人目标分（每项1分，共3项）+ 彩蛋分（0–1分）**。
**个人胜利**：阵营胜利，**或**个人目标完成≥2项。**MVP**：全场最高分。

| 阵营 | 主目标（达成即全员+4） |
|---|---|
| 驴友阵营 | 驴友党总统候选人赢得大选（≥270，或在众院条件性选举中胜出） |
| 大象阵营 | 大象党总统候选人赢得大选 |
| 沼泽俱乐部 | 大选结束时，**当选总统签出的欠条中有≥3张握在沼泽成员手里**；或任一沼泽成员当选总统/副总统 |
| 第四权（佐伊） | 终局"全真相头条"答对三问中至少两问，且本人未被"收购"；被收购则改为与收购方阵营同胜负 |

- **沼泽是"第三极"**：它不和两党抢票，而是和两党抢"新总统欠谁的"。所以两党玩家在拉票时会主动给出欠条，越想赢越要给，沼泽就越可能赢。这是"金主双押""说客佣金"在阵营层面的体现。

### 4.3 隐藏阵营 / 卧底 / 转阵营机制
- **倒戈卡**（每人1张，全场只在第三幕末的"倒戈窗口"可用）：秘密交给DM，即可改投另一个真实阵营。代价是交出一半美元给原阵营的公共竞选基金（"违约金"）。主要设计给两位卧底：贝蒂可以真正倒向丈夫，安德福可以改投大象（比如他发现吼吼更有希望时）。普通玩家也能用，但会损失个人目标分（个人目标与原阵营绑定）。
- **收购记者**：第三幕两党提名人可竞价"收购"佐伊当新闻秘书。被收购后她加入该阵营，记者技能保留，但"全真相头条"失效。她也可以拒绝所有报价，坚持独立。
- **落选转职**：初选落败的人不出局，转任"竞选经理"或"超级PAC操盘手"，保留全部资源，并获得一个新的终局技能（移植《青楼2》"名额出线"，同时消除过早出局的问题）。

### 4.4 8人分配
如4.1表所示：**驴友明面3人（含1卧底）、大象明面3人（含1卧底）、无党派2人**。每党都有"1个候选人型 + 1个操盘型 + 1个金主/幕僚型"，初选就有内部竞争。

### 4.5 7人 / 6人适配思路（第5节末附角色级迁移表）
- **7人：删佐伊**。她的线索迁移到乔安娜的直播回放和DM扮演的NPC"滑溜溜主编"；"收购记者"改为"收购媒体台"（拍卖NPC电视台的终局声量加成）。真实结构变为2驴 + 2象 + 3沼泽。沼泽主目标提高到"≥4张欠条"作为补偿。
- **6人：再删钱多多（NPC化）**。他按DM手册里的固定策略表行动（"永远押民调第二的人""收到2张欠条就交出一条情报"），核心事件因果不变（自导自演仍由他完成）。为保持平衡，**安德福的卧底身份取消**，改为纯大象阵营（个人目标保留"成为副总统"），真实结构变为2驴 + 2象 + 2沼泽（雷米、贝蒂），即研究报告推荐的2 + 2 + 2。
- 数值按"每人X份"线性缩放：摇摆州数量、初始美元总量、背书卡数量都随人数调整（详见第8节）。
