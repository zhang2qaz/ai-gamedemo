# 概念方案 B ·「机制博弈派」——《白房子大甩卖》

> Ascham工作室 · 城限 · 欢乐向阵营机制本 · 本格 · 8人标准（7/6人适配）· 目标时长约7.5–8小时
> 设计主轴：**全本共用一套"四币一命"资源经济（钱·料·情·声 + 人气）**。开场打赏的每一块钱、听证会翻出的每一张黑料、党代会签下的每一张欠条，最终都要在大选夜换成选举人票。
> 研究依据：三份研究报告均已读完（research-references / research-politics / research-players-production）。文中凡写"借鉴自某作品"的条目，都只引用报告里标为[已证实]或[多源推断]的内容；标为"推测"的条目只当作我们自己的灵感，不当作原作事实。

## 1. 剧本名 · 卖点 · 宣传语

**备选剧本名**
1. **《白房子大甩卖》**（首选）——"白房子"即白宫的欢乐化名。整本的核心笑点和机制都是"白宫是可以买的吗？"，剧名本身就是讽刺。
2. **《二百七》**——到270张选举人票就赢，硬核、好记，适合做海报大字。
3. **《驴象撕不停》**——直白的欢乐撕逼感，适合盒装下沉版本备用。

**一句话卖点**
8个政坛戏精在同一家酒店里过完一整个大选年：开场打赏、中场爆料、党代会卖票、大选夜开标，前面每一笔交易都会在选举人团地图上兑现。

**宣传语**
- "在沼泽大酒店，没有永远的盟友，只有没兑现的欠条。"
- "你投出的每一票，都有人提前付过钱。"
- "这届选举很干净——钱都洗过了。"

## 2. 世界观设定

### 2.1 时间
虚构的"20XX年"，对应现实里下一个总统大选年。现任总统**沃克·软软**（大象党，两届任满，不能再选）以"宣布关税后48小时内必撤回"闻名，华尔街专门编了"软软指数"。白宫没有在任者参选，是一场**开放席位**的混战。

时代议题全部虚构化后照搬：关税反复横跳、医保补贴到期、移民执法、币圈与AI的超级PAC、AI深伪广告（钱钱委员会因3:3僵局管不了）、长播客取代电视辩论、媒体执照战。

### 2.2 地点与舞台：沼泽大酒店
- 首都"大沼泽特区"（"排干沼泽"梗）的百年老酒店，政客、说客、金主、记者都住在这里。
- **为什么一整年的事都发生在同一家酒店**：现任政府的"省钱部"出台新规，要求联邦相关活动统一在"政府协议酒店"举办以节约开支。结果两党党代会被安排在同一家酒店的东、西两个宴会厅，同一晚开幕，中间只隔一个自助餐区。这条规定本身就是笑点，也让"两党玩家同场互动"有了现实逻辑。
- **游戏时间跨度**：一个大选年，压缩成在酒店里度过的4个夜晚：
  - 第一幕：1月·开年金主晚宴（隐形初选）
  - 第二幕：3月·超级星期二之夜 + 钱钱委员会紧急听证
  - 第三幕：7月·两党党代会同夜开幕
  - 终局：9–11月·辩论、十月惊奇、大选夜（酒店顶层"选举夜派对"）

### 2.3 政党与势力（欢乐命名）
| 势力 | 映射 | 人设 |
|---|---|---|
| **驴友党**（蓝） | 民主党 | 爱结伴、爱开会、爱远方；口号"驴友出发！" |
| **大象党**（红） | 共和党 | 体大、稳、记仇；口号"象来如此！" |
| **沼泽俱乐部**（隐藏势力） | 华盛顿建制派+游说网络 | 不站队，只收欠条。谁当选都无所谓，只要新总统欠它的人情 |
| **钱钱委员会** | 联邦选举委员会 | 3:3永远打平，外号"平局委员会"；本作中由DM扮演主席 |
| **《滑溜溜》** | 政治八卦网站 | 记者佐伊供职的网站 |
| **《吼吼三小时》** | 头部长播客 | 前两个半小时在聊外星人和冷水澡 |
| **美国梦加油站** | 超级PAC | 名字很正义，资金来自石油和"鹰币"（一种迷因币） |

### 2.4 当前局势
- 两党都没有现成的接班人，初选是乱战。大象党内，建制派党鞭想当"造王者"，播客主持人想"吼进白房子"；驴友党内，稳健派州长和网红众议员互不相让。
- 七个摇摆州（钢铁州、桃子州、烤肉州、轮胎州、仙人掌州、奶酪州、骰子州）加上玉米州的"蓝点区"，一共94张选举人票，两党基本盘各222张。**谁先拿到48张摇摆票谁赢；47:47就是269平，交给众议院。**
- 超级PAC"美国梦加油站"号称手握**1亿美元**，准备砸向大象党提名人。这笔钱是全年最大的变量。

### 2.5 为什么这几天是命运转折点
1. **开放席位**：没有在任者，谁都有机会，所以谁都敢押上全部身家。
2. **一亿美元在开年晚宴上"失窃"**：这笔钱的去向决定整个大选年的资金格局，也撕开了每个人在晚宴上的小动作。
3. **省钱部的同酒店规定**：两党第一次在同一个屋檐下开党代会，"隔着自助餐区挖墙脚"成为可能。

## 3. 本格核心事件：消失的一亿（轻推理）

### 3.1 发生了什么（玩家开局时知道的表层）
开年金主晚宴当晚20:00–21:00，"美国梦加油站"存放竞选资金的**硬件钱包"金钥匙"**从创始人钱多多的礼服内袋里消失，链上余额清零。第一幕结尾，钱多多当众宣布"一亿被盗"，并指控"驴友党的黑客"。

### 3.2 真相骨架（完整因果链，每一环都能回答"为什么"）
| 时间 | 事件 | 为什么 |
|---|---|---|
| 两周前 | 鹰币暴跌90%。PAC账面上的"1亿"实际只剩**1000万**；钱多多早就挪用PAC资产给自己的石油生意做抵押 | 迷因币计价的PAC本来就不稳；挪用是他的老毛病 |
| 晚宴前 | 钱多多决定**自导自演一场盗窃**：钱包"被盗"，就没人能查出1亿早已不存在；他还能找"大保险同盟"索赔1亿的"数字资产盗窃险"，再借受害者身份在大象党内收割同情捐款 | 一箭三雕：掩盖挪用、骗保、博同情 |
| 19:40 | 钱多多把装着金钥匙的礼服交给衣帽间，并把**取衣牌和PIN码**交给说客雷米，约定20:30把钱转到他的离岸地址 | 雷米是他的老牌说客，转账由别人操作，他自己就有不在场证明；酬劳是一张"钱多多欠条" |
| 19:45 | 两人在露台确认计划，钱多多说了一句"今晚它会丢"。这句话被吼吼放在露台栏杆上的播客麦克风录了下来 | 吼吼当晚在露台录"金主晚宴吐槽特辑"，麦克风一直开着 |
| 20:05 | 雷米凭取衣牌取出钥匙，在洗手间走廊用笔记本**导出了钱包的全部交易记录**（证明1亿早已缩水） | 雷米是沼泽俱乐部的大管家，习惯给每个客户留一份"保险" |
| 20:30 | 雷米转账，但收款方**不是钱多多的离岸地址，而是"关心关心老百姓"**。这个501(c)(4)组织的名义董事是贝蒂，实际控制人是雷米 | 沼泽俱乐部要的是一笔不留名的黑钱。客户本人在策划"被盗"，事后只能吃哑巴亏，不敢报真实去向 |
| 20:31 | 贝蒂手机弹出"到账1000万"的通知，正在旁边的盖文瞥到了屏幕 | 501(c)(4)的银行账户绑定了她的手机 |
| 20:35 | 雷米把钥匙塞进宴会厅鹰形冰雕的喙里 | 钥匙上有他的指纹，带在身上危险；冰雕第二天就会被处理掉 |
| 20:45 | 安德福一直在点人头，他看到雷米在冰雕前停留过久，便用蛋糕刀撬出了钥匙 | 党鞭的本能：别人藏起来的东西一定值钱。他要的不是钱，而是钱多多和雷米两个人的把柄 |
| 20:40–20:50 | 乔安娜在宴会厅直播，背景里拍到了"冰雕喙部反光"和"安德福拿着蛋糕刀" | 她在直播"金主晚宴有多奢侈"，镜头恰好朝向冰雕 |
| 20:10 | 佐伊在洗手间走廊拍到雷米在操作笔记本 | 她在跟踪雷米，想挖"说客收买记者"的稿子 |
| 21:00后 | 钱多多按计划"发现失窃"，一查链上，钱去了一个陌生地址，不是自己的离岸账户 | **自导自演的盗窃，被真的盗了**。他不能报出真实去向，否则会暴露1亿早就不存在 |

**三问（推理目标）**：
- Q1：钥匙现在在谁手上？（安德福）
- Q2：钱去了哪里，到底有多少？（1000万，进了"关心关心老百姓"；"1亿"从来不存在）
- Q3：谁策划了"失窃"？（钱多多自导；雷米截胡）

### 3.3 它如何驱动阵营对抗，而不是变成烧脑盘凶
- **真相就是钱**：那1000万是全局唯一一笔"无主资金"。第二幕听证会上，三问答对得越多，这笔钱被冻结后按"追缴款"分给揭发方的份额就越多。如果没人查清，这笔钱会作为黑钱留给沼泽俱乐部，在终局变成一波匿名攻击广告。玩家查案的动力是抢钱，不是解谜。
- **人人有点小动作**（移植《青楼2》"人人皆有罪"的精神，罪行降级为丑闻）：每个人在晚宴上都干过一件见不得光的事，所以每个人提供证词时都要掂量：说出真相会不会顺带暴露自己？
- **证据本身就是筹码**：线索卡背面印着金额（移植《水镜八奇》"线索卡=军需兑换券"），可以拿去换钱，也可以扣着要挟别人，也可以卖给想灭口的人。

### 3.4 推理的占比与形态
- 推理约占总时长**10–12%**，集中在第二幕的"酒店搜证+钱钱委员会听证会"（约40分钟），终局复盘时再补全。
- 形态是**三道选择题，不是开放式盘凶**：每题有3–4个公开候选答案，各阵营在听证会上举牌作答。答对即得资源，答错扣人气。
- 已知结论有容错：Q1靠乔安娜的直播回放加安德福自己的心虚就能锁定，Q2、Q3需要两到三张线索交叉。推理弱的玩家可以靠"买证据""跟票"参与，不会挂机。

## 4. 阵营结构

### 4.1 阵营总览（8人）
| 明面党籍 | 角色 | 真实阵营 |
|---|---|---|
| 驴友党 | 乔安娜·不服、盖文·不乱 | 驴友阵营 |
| 驴友党 | 贝蒂·稳稳 | **沼泽俱乐部（卧底）** |
| 大象党 | 雷霆·吼吼、钱多多 | 大象阵营 |
| 大象党 | 安德福·老底 | **沼泽俱乐部（卧底）** |
| 无党派 | 雷米·两头吃（游说者） | **沼泽俱乐部（大管家）** |
| 无党派 | 佐伊·快门（记者） | **第四权（独立，可被收购）** |

明面上是3 : 3 : 2，真实结构是**2 驴友 + 2 大象 + 3 沼泽 + 1 记者**。
- 沼泽俱乐部采用"单线联系"：雷米认识贝蒂和安德福，**贝蒂和安德福互不知道对方也是沼泽成员**。所以沼泽人数虽多，内部却有猜疑，也存在被反向策反的空间。
- 两党各藏着一个卧底，"党内谁是自己人"是贯穿前三幕的悬念。

### 4.2 胜利条件与计分（双路径，移植《搞钱2》"自己上市成功或站在胜利队伍中"的精神）
每人终局得分 = **阵营分（0或4分）+ 个人目标分（每项1分，共3项）+ 彩蛋分（0–1分）**。
**个人胜利**：阵营胜利，**或**个人目标完成≥2项。**MVP**：全场最高分。

| 阵营 | 主目标（达成即全员+4） |
|---|---|
| 驴友阵营 | 驴友党总统候选人赢得大选（≥270，或在众院条件性选举中胜出） |
| 大象阵营 | 大象党总统候选人赢得大选 |
| 沼泽俱乐部 | 大选结束时，**当选总统签出的欠条中有≥3张握在沼泽成员手里**；或任一沼泽成员当选总统/副总统 |
| 第四权（佐伊） | 终局"全真相头条"答对三问中至少两问，且本人未被"收购"；被收购则改为与收购方阵营同胜负 |

- **沼泽是"第三极"**：它不和两党抢票，而是和两党抢"新总统欠谁的"。所以两党玩家在拉票时会主动给出欠条，越想赢越要给，沼泽就越可能赢。这是"金主双押""说客佣金"在阵营层面的体现。

### 4.3 隐藏阵营 / 卧底 / 转阵营机制
- **倒戈卡**（每人1张，全场只在第三幕末的"倒戈窗口"可用）：秘密交给DM，即可改投另一个真实阵营。代价是交出一半美元给原阵营的公共竞选基金（"违约金"）。主要设计给两位卧底：贝蒂可以真正倒向丈夫，安德福可以改投大象（比如他发现吼吼更有希望时）。普通玩家也能用，但会损失个人目标分（个人目标与原阵营绑定）。
- **收购记者**：第三幕两党提名人可竞价"收购"佐伊当新闻秘书。被收购后她加入该阵营，记者技能保留，但"全真相头条"失效。她也可以拒绝所有报价，坚持独立。
- **落选转职**：初选落败的人不出局，转任"竞选经理"或"超级PAC操盘手"，保留全部资源，并获得一个新的终局技能（移植《青楼2》"名额出线"，同时消除过早出局的问题）。

### 4.4 8人分配
如4.1表所示：**驴友明面3人（含1卧底）、大象明面3人（含1卧底）、无党派2人**。每党都有"1个候选人型 + 1个操盘型 + 1个金主/幕僚型"，初选就有内部竞争。

### 4.5 7人 / 6人适配思路（第5节末附角色级迁移表）
- **7人：删佐伊**。她的线索迁移到乔安娜的直播回放和DM扮演的NPC"滑溜溜主编"；"收购记者"改为"收购媒体台"（拍卖NPC电视台的终局声量加成）。真实结构变为2驴 + 2象 + 3沼泽。沼泽主目标提高到"≥4张欠条"作为补偿。
- **6人：再删钱多多（NPC化）**。他按DM手册里的固定策略表行动（"永远押民调第二的人""收到2张欠条就交出一条情报"），核心事件因果不变（自导自演仍由他完成）。为保持平衡，**安德福的卧底身份取消**，改为纯大象阵营（个人目标保留"成为副总统"），真实结构变为2驴 + 2象 + 2沼泽（雷米、贝蒂），即研究报告推荐的2 + 2 + 2。
- 数值按"每人X份"线性缩放：摇摆州数量、初始美元总量、背书卡数量都随人数调整（详见第8节）。

## 5. 八个角色

> 命名规则：**"英文名 + 中文谐音/绰号姓"**，喊出来就知道这人是干嘛的。所有角色均为虚构，只做气质映射，不对应任何真实政治人物。
> 技能设计遵循"技能 = 人设 = 黑料"（移植《搞钱2》"黄大力雷管"的精神：技能本身就是梗，并且在剧情里有"他为什么会这招"的因果）。

### ① 乔安娜·不服（Joanna Bufu）——驴友党·网红众议员
- **命名梗**："不服"，被怼必回、谁都不服。外号"小辣椒"。
- **年龄**：32
- **公开身份**：大苹果州众议员，直播起家，每天开播骂金主。
- **隐藏身份/秘密**：①她和"死对头"吼吼合开了一家"吵架有限公司"，两人在播客上的对喷是**写好剧本的流量生意**，广告分成五五开；②她当晚的直播是"未来是我们的"AI超级PAC赞助的，而她公开主张严管AI。
- **阵营**：驴友阵营（可能被吼吼拉进跨党"民粹联盟"，用倒戈卡转大象）。
- **个人目标**：①赢得驴友党总统或副总统提名；②终局前公开揭穿一名沼泽成员；③"吵架有限公司"的秘密直到复盘都没被曝光（或由她自己主动公开换取人气）。

### 7.1 第一幕 · 开年金主晚宴（隐形初选）100′

2. **60秒竞选广告模仿秀**（25′）：每人上台用60秒推销自己（候选人拍竞选广告，记者做开场播报，说客做"客户产品推介"）。台下所有人用美元打赏，打赏公开进行。打赏最高的两人各获声量+2。

### 8.1 资源种类

### 8.2 关键规则
- **万物可交易，不可偷、不可抢、不可看别人手牌**（借鉴《搞钱》"不可以偷、不可以抢，但所有东西都可以交易" [已证实]）。
- **卡换卡必须一换一**，钱可以单方面给但DM会公开记账，也就是"竞选财务申报"（借鉴《水镜八奇》"一换一、不得赠予" [已证实] 防倾销；公开记账是我们的讽刺改造）。**欠条是唯一可以白送的东西**，因为人情本来就是白送的。
- **欠条兑现**（三选一，由DM强制执行）：①某次投票按持有人意愿投；②交出一张持有人指定类型的卡；③在一个指定摇摆州的暗标中至少投入2M。每张欠条只能兑现一次。口头承诺没有约束力，欠条有。
- **新闻周期惩罚**：每幕结算时，本幕没有任何公开动作（打赏、爆料、发言、投票都算）的人，人气-1（借鉴《水镜八奇》由吕布技能反推的"空过扣粮" [多源推断]）。
- **跛脚鸭**：人气降到0时，不出局，变成"跛脚鸭"：不能再被爆料，获得1张"悲情牌"（终局任一州+3），不能获得提名。
- **追赶机制**：每幕开始，人气≤3的人额外获得2M"草根捐款"。

### 8.4 终局怎么兑现（转化链）
- **钱** → 摇摆州暗标分数（1M = 1分）
- **声** → 摇摆州暗标分数（1声量 = 2分），或辩论胜负
- **料** → 在某州"投放攻击广告"，令对手在该州-2分（十月惊奇阶段打出时-4分，越晚越狠，但提前投票锁定的州免疫）
- **情** → 强制对方投钱、投票或交卡；同时是沼泽俱乐部和钱多多的胜利计数器
- **背书卡** → 议题匹配的州+3分
- **人气** → 提名人人气 ÷ 2（向下取整）= 该党在每个摇摆州的基础分
- **党纲** → 与州议题偏好一致的每项+2分

**设计意图**：开场打赏多拿的2M，可能就是终局烤肉州差的那2分。所有资源都有去处，前面的每一个决定在大选夜都能找到对应的那一票。

- 全场非辩手举"热度牌"判胜负：胜方声量+3、人气+1；负方人气-1。

### 9.3 F2 竞选周 ×3（每轮15′：公开造势3′ → 密室私聊6′ → 暗标6′）
- **第1轮**：钢铁州、奶酪州、骰子州；**第2轮**：桃子州、仙人掌州；**第3轮**：烤肉州、轮胎州、玉米州蓝点区。
- **暗标**：**每一个玩家**（不只是提名人）都可以往任意州的"蓝信封"或"红信封"里投钱和声量。卧底可以暗中往对方信封里投钱，沼泽可以两边都投，这就是"两边押"在终局的形态。投入时在DM处登记姓名，但开封时只公布总数（选举夜复盘时公开明细，"黑钱开盒"）。
- **州得分** = 提名人人气÷2 + 党纲匹配（每项+2）+ 背书卡匹配（每张+3，每州最多2张）+ 信封里的钱（1M=1分）+ 声量（1个=2分）+ 搭档协同（+1）− 攻击广告（每张料−2）。
- **民调提示**：每轮暗标后，副DM算分，主DM只播报"某州红方领先 / 蓝方领先 / 胶着（差≤3）"，不报具体数字。
- **提前投票锁票**：播报后，领先方可花3M锁定该州，锁定后免疫十月惊奇和后续攻击广告。但民调只是提示，"胶着"的州锁不锁是一场赌博。

### 9.4 F3 十月惊奇（由前因触发，不是天降随机）
DM在第2轮暗标后核对"触发表"，满足条件的事件卡依次翻开（最多3张）：
| 触发条件 | 事件 | 效果 |
|---|---|---|
| 听证会上Q2无人答对 | **匿名攻击广告** | 沼泽俱乐部（由雷米决定）获得等同未追缴款的"攻击额度"，可投放到第3轮任一州 |
| 韭菜录音仍未公开 | **录音泄露** | 持有者可选择现在公开：大象方第3轮所有州−3，除非全场投票认定"这是AI深伪"（钱多多彩蛋的触发点） |
| 有一组搭档真实阵营不同 | **搭档内斗** | 该搭档可秘密把本方第3轮信封里至多5M挪到对方信封 |
| 盖文的假发尚未曝光 | **大风户外集会** | 盖文选择当众摘下（触发"秃然真诚"）或被风吹掉（人气−2） |
| 金钥匙仍在安德福手中 | **钥匙拍卖** | 安德福可当场把钥匙卖给任何人；持有者在选举夜可出示钥匙，令钱多多或雷米人气−3 |
| 任一提名人人气≥8 | **认知测试** | 该提名人须30秒内背出DM念的5个词，失败则人气−2 |
（借鉴：《青楼2》"机制中会有未知剧情，未知剧情会给规则带来变化" [已证实]。改造为"条件触发、DM手册可追溯"，保证因果。）

### 9.5 F4 选举夜 → F5 众院决战 → F6 特赦
- **逐州开封**：DM按"现场票（基础分+钱）→ 邮寄票（声量+背书+党纲）"的顺序报分。大象方往往前半段领先、后半段被追回，这就是"红色海市蜃楼"的讽刺。
- **重新计票**：分差≤1的州，落后方可付3M请律师，翻一张"重计卡"（−1 / 0 / +1 / +2）。
- **269平 → 众院决战**：每名玩家按当前人气获得"州代表团票"（人气即票数），公开投票选总统；欠条可在此强制兑现。副总统另由声量最高的两人中按声量总和多数选出。**总统和副总统可能来自不同阵营**，这也是一种结局。
- **特赦大会**：当选总统可以特赦一名被坐实黑料的人（复盘时决定其结局小剧场），这是全场最后一个选择题。

### 9.6 胜负判定顺序
1. 先定总统归属（≥270或众院决战结果）→ 驴友 / 大象阵营胜负；
2. 清点当选总统签出、握在沼泽成员手里的欠条（≥3张，7人局≥4张）→ 沼泽胜负（与两党胜负**可以并存**）；
3. 佐伊宣读"全真相头条"（三问答对≥2且未被收购）→ 第四权胜负；
4. 每人核对个人目标与彩蛋，算总分，评出MVP。

### 9.7 DM能力画像与硬性要求
**画像**：主持过≥10车阵营 / 机制本、有实时计分经验、有主持或表演底子的成熟DM；能"先裁后议"；本作须先作为玩家完整玩一次、观摩一次、在带本老师监督下主持一次，之后才能独立开本。

**硬性要求（DM手册首页）**
1. **双DM配置**：终局必须是"主DM（主持 + 表演）+ 副DM / 场控（计分 + 计时 + 信封）"。单DM开本时，必须使用预印的"州得分自动表"（只做整数加减）。
2. **一人分饰≥5个NPC**：嗯嗯新闻主播、拍卖师、平局委员会主席、脱口秀主持人、辩论主持人，开本前完成声线和道具试演。
3. **5分钟结算**：每轮暗标须在6分钟内完成登记、算分和民调播报。
4. **触发表零失误**：十月惊奇触发条件须在终局前用"DM核对单"逐条打勾，不得临场新增事件。
5. **30秒裁决**：规则争议依"书面规则 > 手册FAQ > 不破坏已发生事实 > 不让任何一方获得规则外收益"的顺序裁定，当局不翻案。
6. **信息隔离**：信封明细、倒戈卡、欠条兑现只能私下核对，公开时只报结论。
7. **复盘能力**：能脱稿讲清"消失的一亿"完整因果链和8条反转的铺垫位置。

## 11. 自评

### 11.1 最强的3点
1. **一套经济贯穿全本**：钱、料、情、声、人气从开场打赏一路流到大选夜暗标，每个环节都在"积累或消耗终局筹码"，没有"玩完就作废"的过场环节。这正是机制博弈派的主张，也直接解决了品类里"阵营与剧情割裂"的老问题。
2. **核心案件即资源争夺**：消失的一亿用"三道选择题"代替盘凶，推理只占约10%，却决定了全局唯一一笔无主资金的去向。不擅长推理的玩家也能靠买证据、跟票分到钱。
3. **欠条与沼泽俱乐部的双层信任**：口头结盟可以随便背刺，欠条却由DM强制执行。沼泽靠收集欠条取胜，两党越想赢越得签欠条，于是"给不给欠条"成了全场最微妙的拉扯，背刺和结盟都有了理性依据。

### 11.2 最大的3个风险及应对
| 风险 | 表现 | 应对 |
|---|---|---|
| **规则与资源过载**（中度玩家最怕） | 五种资源 + 欠条兑现 + 暗标公式，可能让人"不知道要干什么"（《青楼2》终局差评 [已证实]） | ①每幕只引入一种新资源，第一幕只用钱和声；②全部资源做成实体（筹码、卡、麦克风徽章、计分轨），不需要记数；③终局公式在超级星期二完整预演过一次；④每人发"本幕我能做的3件事"小卡 |
| **终局算分负担与翻车率** | 8个州 × 两色信封 × 多项加成，单DM极易算错（《水镜八奇》"翻车率高" [已证实]） | ①强制双DM / 场控；②预印"州得分自动表"，只做整数加减；③背书卡每州上限2张、料每州上限2张，限制计算项；④外测中统计结算用时，超过6分钟就删减加成项 |
| **数值失衡与滚雪球** | 钱多多资金过多；沼泽3人且可两边押，可能过强；欠条可能滚雪球 | ①人气起点和"不能当候选人"压制钱多多；②沼泽单线联系，内部互不知情，倒戈卡可以策反；③每人只有5张欠条（物理上限），每张只能兑现一次；④追赶机制（草根捐款、悲情牌、跛脚鸭不出局）；⑤外测要求各阵营胜率落在40%–60%，6/7人局各至少2车，并跑数值模拟 |

**附注**：7.5–8小时超出城限机制本的常规时长（研究报告记录的行业经验是城限约6小时 [已证实]）。本方案的应对是：三段循环保证每40分钟换一次形式，三次休息与饭点均匀分布，反转按"第二幕3个、第三幕3–4个、复盘1个"分布高潮。DM手册中每幕标注"超时可砍"的子环节（扒马褂可缩至20′，党纲可改为DM公布）。
