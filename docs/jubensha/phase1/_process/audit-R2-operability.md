## 0. 总体判断
- R1的五个critical（换将口径、6人局地图、摊牌物理泄露、球童递送、出示禁令）**主体都已落实**，冻结表F-01～F-22让DM第一次拿到了单一口径。本轮没有发现"游戏无法进行"级别的问题。
- 但R1的修复引入了一批**新的执行缺口**，集中在四处：
  1. **冻结、补位、补副手三条新规则的边界没封口**：冻结后的欠条在269里能不能用、补副手能不能把刚被换下的人再指定回来、十月换将窗口能不能重投、初选亚军平票或零票怎么算，DM都得临场发明规则。
  2. **场控一个人被同时排进两个地方**：第3期唱名（开摊牌信封＋没人计票）、终局并行段（后台速算＋公示台开着＋闭眼举牌没人记名）。
  3. **"全员同构"只做了一半**：回执卡卧底150字、其余人一句话，读完时间不同；收入信封金额不同，厚度不同；手稿印交易写上公开公示板。
  4. **R1声称已执行、但正文里找不到的东西**：表层秘密清单、打赏小目标正文、三件事卡（04 R-11写"已执行（02）"，02里没有）；《换人数检查表》（04§8.2引用，全本不存在）；单DM替代包只有一句话。
- 不属于本视角、但须提醒：05§9.4、§9.6第11条"两名卧底同向觉醒致4:2火力悬殊、驴心胜率＜20%"仍标为"R2待处理"，属阵营结构问题，请平衡审查组定级。本报告不计入统计。

## 1. Major

### operability-R2-01｜major｜回执卡"卧底150字、其余人一句话"，读完时间不同，F0当场暴露两名卧底（R1-03修复不完整）
- **文件与位置**：01 附录A F-13第6款；04 §6.5第6条；05 §1.2 F0第②步、§3.2第0-2步、§10.2 F0台本"同时拆、读完同时交回"；04 §9.4回执卡。
- **问题**：
  - 回执卡尺寸、信封都同构了，但内容长度不同构：卧底卡是"本人选择对应的终局段落（≤150字）"，其余人是"已收悉＋一条通用小贴士"。
  - 台本要求"读完同时交回"。150字要读30–40秒，一句话5秒读完。非卧底读完抬头等人，还在低头读的两个人就是卧底。
  - 第3期摊牌同样没有"统一封口"口令：非卧底把三张"已阅"随手塞完，卧底还在犹豫，只靠押宝单的填写时间掩护。
- **为什么重要**：R1把这一类泄露定为critical（C05），要求"信封厚度、撕封声、交还动作都不暴露"。现在动作一致了，时长没一致，等于在F0协同宣布之前白送两名卧底的身份；第5、6页只是旁证，这里却是肉眼可见的确认。
- **修复方案**：
  1. 回执卡全员等长：非卧底卡改为同样约150字的"终局个人提示"（本角色的终局小目标、一句角色独白、一条规则提醒），字数差≤10%，与F-16第3款"同期各册字数差≤10%"同一口径。
  2. 回执改为**定时读**：DM喊"拆"，计时45秒，喊"收"，全员同时交回；规则书删掉"读完同时交回"。
  3. 摊牌信封同样加口令：3分钟操作期内一律不得封口，DM喊"封口"后全员同时封、同时交。
  4. 写入F-13第2、6款与05§3.2第0-2步；外测时请第三人只看动作盲猜卧底，命中率不高于随机。

### operability-R2-02｜major｜F3冻结后欠条全部封袋，但269唱票、F4兑现②仍要用欠条；兑现会不会扣减收账计数，三处写法不一
- **文件与位置**：01 F-11第3、5、6款；04 §6.10"冻结""收账计数"；05 §3.7第3-5步、§3.10、§6.3第269-2步、§7.1"收账数N"、§8.5第41条、§8.6第48条。
- **问题**：
  1. F-11第5款：冻结后"不得新签、转让；持有人仍可在F4申请兑现②"，没有提兑现①。05§6.3却写"欠条兑现①可以指定某枚令牌的投向"，F-11第3款也把"269唱票"列为兑现①的对象。269发生在F5，此时所有欠条都封在场控手里的袋子里，持有人连欠条都拿不到。
  2. 收账N写"未兑现的欠条张数（按冻结封存时计）"。F4兑现②、269兑现①都发生在封存之后：被兑现的那张算不算？"按封存时计"读作"算"，"未兑现"读作"不算"。05§3.10另写"沼泽每兑现一张，就少一张收账的筹码"，与"按封存时计"相反。
  3. 拆袋取欠条的动作没有程序：在哪里拆、谁看得见袋里其余欠条、拆完怎么重封，均未写。
- **为什么重要**：269本身就是全本最依赖欠条的场景（1824式交易、国务卿任命书计入收账）。DM现场只能二选一裁决，而两种裁决直接决定"沼泽收账成立／惨胜"与否，属于胜负判定的歧义。
- **修复方案**（写入F-11第5、6款，05§3.10、§6.3、§7.1同步改）：
  1. 冻结后允许两种兑现：F4的②、269唱票的①。持有人向场控申请，场控在隔板后拆开**该持有人本人**的欠条袋，只取出所指欠条，当场撕毁，其余放回重封并签名，全程不展示袋内其余欠条。
  2. 收账N统一为："F6清点时，沼泽成员欠条袋中仍在的、P亲笔签的欠条张数"。兑现过的欠条已撕毁，自然不计。删掉"按冻结封存时计"这一括注，改为"冻结后不得新增"。
  3. 钱多多剧情星"按F3冻结封存时判定"保留：场控在F3第5步收袋时当场核对钱多多的袋子并记入机密册，之后的兑现不影响剧情星。

### operability-R2-03｜major｜换将"补副手"的合格条件漏了三种人：刚被换下的独立参选人可以被原票再指定回来；无合格人选时无裁决
- **文件与位置**：01 F-03第6、7句；05 §3.3 DM执行步骤第4步、§8.1第2、6条；04 §4.5第2条。
- **问题**：F-03第6句的合格条件只有"年龄合格、不同州、非跛脚鸭、不在另一张提名票上，可跨党"。按字面：
  1. **刚被换下的人本人**不在任何提名票上、年龄州籍都合格，总统提名人可以当场把他指定回副手位，换将表决等于作废；他手里还同时握着打这张票的3枚分票标记。
  2. **其他已确凿曝光、真阵营与本票不对应的人**（例如已被公开调查为"不一致"的沼泽成员）也能被指定，下一个窗口又要再换一次。
  3. **"被指定者不得拒绝"**：独立参选人可能被强行拉回票上，失去分票身份。
  4. 6人局场上只剩6人，两张票占4人、独立参选人1人，常常只剩1名候选人；此人同州或是跛脚鸭时，**无合格人选**，没有规定。
- **为什么重要**：换将是破锁的唯一出口（01§4.5第2条）。补副手一旦能回填，象心/驴心破锁的成果可以被总统提名人一句话推翻，DM在4分钟的F0第6步里必须临场立法。
- **修复方案**（F-03第6句改写，05§8.1增列第14、15条）：
  1. 补副手的合格条件增加两项："不是本次或此前被换下的独立参选人"；"不是已确凿曝光、且当前真阵营与本票所属党不对应的人"。
  2. 场上无合格人选时，副手位空缺；空缺的票不受影响，只是F6"V视为空缺"，垂帘不可能成立。
  3. 速查例写入05§8.1：6人局蓝票辣椒＋安德福，安德福被换下后，辣椒只能在高文（若不在红票上）中指定；高文不合格则副手空缺。

### operability-R2-04｜major｜十月换将窗口能否重投、能否处理F0表决失败的旧曝光，冻结表与05写法冲突
- **文件与位置**：01 F-03第3句（"窗口：F0第6步、F2十月惊奇执行完毕后"）、§4.4第6条；05 §1.2 F2、§3.6.1（"如果F0之后又出现了新的确凿曝光，开放十月换将"）、§12.1修订#3。
- **问题**：
  1. F-03第3句是无条件的两个窗口；05§3.6.1把F2窗口限定为"F0之后出现新的确凿曝光"才开。
  2. 由此产生两种局面没有唯一裁决：①某人第3期被曝光，F0表决没通过，F1又有人被曝光，F2开窗时能不能对旧的那位**再表决一次**？②F0表决没通过、F0后也没有新曝光，F2是否还开窗？
  3. 同一张票上F0表决失败后，表决人有没有"一事不再理"，也没写。
- **为什么重要**：F2换将要从缓冲里扣4分钟，开不开、对谁开，直接影响胜负与时长；按冻结表"附录A优先"读，每局都要开窗，与05的"省4分钟"设计矛盾。
- **修复方案**（二选一写死，建议A）：
  - A：F2窗口**只**在F0结束后出现新的确凿曝光时开放，且只表决新被曝光者；F0已表决过的人不再表决（"党代会决议不复议"）。F-03第3句改为"窗口：F0第6步；F2十月惊奇执行完毕后（仅限F0之后新出现的确凿曝光）"。
  - B：F2窗口固定开放，凡当前确凿曝光且不对应者都可再表决一次；时长从缓冲固定扣4分钟，F-01缓冲表同步改。

### operability-R2-05｜major｜"初选亚军"在平票、零票（退选）、亚军本人已被曝光时没有唯一结果，6人局"辣椒破锁后自己接任"的保底路径可被劫持
- **文件与位置**：01 F-03第5句、F-15第3款（"换将时由初选亚军（即本人）顶上"）；05 §3.3第3步、§8.1第5条；04 §4.3第2条（退选转投）、§4.4（第二轮黑马）。
- **问题**：05§8.1第5条定义为"最后一轮得票次多、当前合格、不在另一张提名票上的本党胸牌成员，否则顺延"。仍有三处没有唯一结果：
  1. **并列次多**：第二轮出现黑马时，原候选人与黑马可能同票；首轮两人都为0票的非候选人也"并列"。
  2. **零票是否算"得票"**：候选人唱名前退选、把票转给对手，他在最后一轮是0票。按"得票次多"读，他可能根本不算亚军，直接落到"由本票副总统提名人顶上"——6人局里本票副手常是沼泽成员（推演B′蓝票副手就是安德福）。F-15第3款承诺的"忠诚候选人破锁后自己顶上"就此失效，C03"无沼泽劫持"的修复被绕开。
  3. **"当前合格"未定义**：是否排除已确凿曝光、且真阵营与本票不对应的人？若不排除，换上来的亚军可能当场又满足换将条件。
- **为什么重要**：这是换将七句里唯一还需要DM判断的一步；6人局的阵营保底路径整个挂在它上面。
- **修复方案**（F-03第5句加一段排序规则，05§8.1第5条同步）：
  1. 亚军排序：本党胸牌成员（含退选者、非候选人）按"最后一轮得票"降序；同票按唱名开始时民调降序；再同按座位从DM左手起顺时针。零票者照样参与排序。
  2. "合格"＝年龄合格、非跛脚鸭、不在另一张提名票上、不是"已确凿曝光且当前真阵营与本票不对应"的人。
  3. 补一个6人局速查例：辣椒唱名前退选转投高文，高文当选后被调查令曝光，亚军按上述排序仍是辣椒（0票，民调最高的合格成员），F-15第3款成立。

### operability-R2-06｜major｜7/6人局待定代表"首轮自动投本党民调高者"，两人民调相同时没有规定，而这正是常态
- **文件与位置**：01 F-18第3款、F-15第1、2款、§4.6表；04 §4.3第3条、§8.1表；05 §9.7。
- **问题**：
  - 四名候选人开局民调一律为5（F-09第1款），各种加减都是±1、±2，同党两名候选人在唱名时民调相同的概率很高。
  - 自动投票的20票足以决定是否过46票门槛，但"民调相同"怎么投，全本没写；同一节里春季初选写了"民调相同各20"，超级星期二写了"再平则对半"，偏偏这一处没写。
  - "民调高者"取哪个时点（春季信封预算用的第2期末，还是唱名开始时）也没写。
- **为什么重要**：6人局两党、7人局大象党每局首轮都会走这条规则，DM临场裁定会直接决定提名人。
- **修复方案**：F-18第3款补一句："以唱名开始时民调为准；两人民调相同时，待定代表团20票对半，各10票。"04§4.3第3条、§8.1表同步。

### operability-R2-07｜major｜盲盒"每人最多拍得1盒"的分配写了两套互相矛盾的算法，第三枚印章归谁可能有两种答案
- **文件与位置**：04 §2.1.4规则第3、4条。
- **问题**：规则第4条前半句是"若某人在多盒都是最高价，只得其出价最高的一盒"，后半句是"按A→C顺序逐盒结算"。两者会给出不同结果。
  - 例：甲出价A盒5、B盒9；乙出价A盒4、B盒8。
  - 按前半句：甲拿出价最高的B盒（9），A盒顺延给乙（4）。
  - 按"A→C逐盒"：先结A盒，甲最高，甲得A（5）；再结B盒，甲已得盒，B顺延给乙（8）。
  - 手稿印可能在A，也可能在B，归属完全取决于DM选哪种读法；成交价也不同。
- **为什么重要**：第三枚印章是第9页刹车的关键，盲盒是5分钟内必须当众开标的环节，没有唯一算法就没有唯一结果。
- **修复方案**：改为一种确定算法，写成规则书原文：
  1. 把全场所有出价（不含0）从高到低排成一列；同价按民调低者在前，再同抽签。
  2. 从最高的一笔开始逐笔处理：该盒未成交、出价人未得盒，即成交；否则跳过。
  3. 处理完毕仍未成交的盒流拍，按背书流拍同样处理（送资金最少者）。
  4. DM手册附上例题与开标表（3列×8行），上岗考核加一道盲盒开标题。
