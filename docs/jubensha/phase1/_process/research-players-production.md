> 项目：Ascham工作室 · 城限欢乐阵营本 · 美国大选题材（6–8人，7–8小时）
> 版本：v1.0　｜　资料截止：2026-10-04　｜　用途：给后续"核心设计 / 人物 / 机制 / 分幕写作 / DM手册 / 物料"各环节提供可执行的行业基准与验收线
> 可信度说明：本文件的公开数据来源有限（见文末"来源"），大部分条目属于**行业惯例/从业经验归纳**，标【惯例】；有公开报道支撑的标【有出处】；数值类（页数、成本、时长）均为**设计建议区间**，不是行业统一标准，后续以内测数据为准。

## 0. 一页结论（给后续阶段直接用）

1. **核心玩家要的是"每个人都有高光 + 每一刀都有理由"**：欢乐和阵营是体验，严谨因果是信任。背刺必须"事后能复盘出动机"，否则欢乐会变成"被策划耍了"。
2. **挂机是第一杀手**：7–8小时本，任何玩家连续无事可做超过15分钟就会掉分；"出局"必须设计成"换个身份继续玩"。
3. **规则分段教学（即用即教）**：单次规则讲解≤10分钟；终局大机制规则在前几幕用"小机制"提前预演。
4. **阅读总量控制**：全程阅读≤100分钟，第一幕≤30分钟，后续每幕≤15分钟；角色本单人总字数建议1.2万–1.8万字。
5. **弹性人数采用"6核心 + 2可删"结构**，可删角色的关键信息必须有"替代承载者"，删人时数值表同步缩放。
6. **终局对DM是硬门槛**：需要"主持人 + 计分员"双角色能力（推荐双DM或DM+场控），DM手册必须附**裁决优先级原则**和**常见争议FAQ**。
7. **城限物料要"能拍照"**：选举人团大地图、竞选徽章/帽子、头条报纸、当选证书，是传播截图的主要来源。
8. **验收硬指标**：外测满意度≥8.5/10、各阵营胜率落在40%–60%、每个角色在"最想再玩的角色"投票中都有人选、实际时长偏差≤±30分钟、因果审计表零漏洞。

## A. "城限阵营本中度玩家"画像

### A1. 人群素描【惯例】

| 维度 | 描述 |
|---|---|
| 年龄/身份 | 主体22–35岁，城市白领、学生党后期、自由职业；公开报道显示剧本杀用户以26–30岁为最多【有出处】 |
| 游玩经验 | 累计约30–150个本；玩过5个以上机制/阵营本；对"城限""独家""盒装"差别有认知 |
| 组车方式 | 熟人车+拼车混合；常有1–2位"车头"（组局人），车头的评价决定整车口碑 |
| 消费 | 能接受长本较高客单价（城限长本人均通常明显高于盒装，公开报道中城限/独家人均约138–258元区间，长机制本更高【有出处，需随城市浮动】） |
| 能力 | 能理解中等复杂度规则（约3–5个子系统），会做简单的收益权衡，但不愿意记账算数 |
| 社交属性 | 爱"演"、爱"嘴"、爱"拉扯"；对"互相坑"有高容忍度，前提是复盘时能笑着讲出来 |
| 审美 | 对排版、道具手感、沉浸布景有要求；会拍照发小红书/朋友圈/群聊 |

### A2. 他们爱什么

1. **个人高光（C位时刻）**：每人至少有1–2个"全场看着我"的时刻（演讲、揭发、关键一票、反水）。
2. **博弈拉扯**：信息不对称下的谈判、承诺、试探；"我信你，但我留了一手"。
3. **有理由的背刺**：背刺最好来自角色本身的秘密目标或往事，而非"策划强行塞任务"。
4. **阵营归属感 + 个人小目标的冲突**：阵营要赢，但我个人还有私心——这是最好玩的张力。
5. **可翻盘**：落后方有"孤注一掷"的翻盘工具（但需付出代价），领先方有"压力"。
6. **公开结算的仪式感**：开票、揭榜、宣誓、颁奖，像综艺决赛。
7. **复盘"原来如此"**：多层身份/关系反转在复盘时被串起来，"原来你从第一幕就在演我"。
8. **名场面可复述**：玩完能用一句话讲给朋友听（"我用一张假录音把搭档送进了监狱然后当了他的副总统"）。

### A3. 他们恨什么（=常见差评来源）

| 痛点 | 典型表现 | 设计对策 |
|---|---|---|
| 挂机 | 别人在谈判/表演，我没事做；"出局"后当观众2小时 | 并行任务；出局→换身份（说客/记者/选民代表）；闲置时有"押注/情报交易"可玩 |
| 规则过载 | 开场讲规则20分钟、规则书10页 | 即用即教；规则卡单页化；先玩小机制再上大机制 |
| 纯算数/记账 | 每轮算资金、算加成、算比例 | 计算交给DM/计分板；玩家只做"选哪个"不做"算多少"；数值用整数小数字 |
| 角色强弱悬殊 | 有人是工具人、边缘位；有人一人带全场 | 戏份矩阵（见D5）；每个角色都有"独有能力"和"独有秘密" |
| 滚雪球 | 第二幕领先就锁定胜局 | 领先惩罚（曝光度/被围攻）、落后补偿、终局权重高于前期 |
| 运气定胜负 | 最后一个骰子/抽卡决定总统 | 随机只用于"事件"，不用于"判定胜负"；随机结果玩家可应对 |
| 逻辑不自洽/强行反转 | "其实你是他失散多年的兄弟"毫无铺垫 | 每个反转必须有≥2处前置伏笔（因果审计表） |
| 机制与剧情两张皮 | 小游戏和故事无关，像在玩桌游 | 每个机制=剧情中一个政治动作（筹款=金主晚宴，投票=党团会议） |
| 拖时长/水时间 | 用线索缺失或无意义环节凑时间 | 时长来自"有选择的回合"，不是来自等待 |
| 社死过度 | 强制反串尬演、强制唱跳 | 社死任务分级、可用"代价"拒绝 |
| 过时梗/低俗梗 | 网络旧梗、地域/性别歧视笑点 | 讽刺制度与权力，不嘲笑群体；梗以剧本内生梗为主 |
| 说教/立场输出 | 剧本明显站队某真实党派 | 双方阵营都荒诞、都有理；只讽刺"政治游戏本身" |
| 结局DM暗箱 | "DM判你输" | 胜负条件公开可算；裁决有书面原则 |

### A4. 中度玩家 vs 其他人群（定位用）

| | 新手 | **中度玩家（核心）** | 硬核机制玩家 |
|---|---|---|---|
| 规则承受 | 1–2个子系统 | **3–5个子系统，单个讲解≤10分钟** | 多子系统、喜欢深度最优解 |
| 计算 | 不算 | **只做比较与取舍，不做复杂运算** | 愿意算期望值 |
| 推理 | 怕推理 | **轻推理可，长推理不爱** | 可接受 |
| 期待 | 好玩、热闹 | **拉扯、高光、名场面、反转、仪式感** | 策略深度、平衡性 |
| 风险 | 规则听不懂 | **挂机、强弱悬殊、逻辑漏洞** | 数值漏洞被利用 |

> 设计口径：**规则面向中度玩家，深度留给愿意挖的人**（隐藏的组合策略、可选的高风险玩法），但不挖也能玩得开心。

### A5. 对城限本的期待

| 方面 | 期待 |
|---|---|
| 制作 | 排版精致、字号舒适、角色本有人物立绘/照片风插画；纸张手感明显优于盒装 |
| 物料 | 实体筹码/假钞、版图、卡牌、密封信封、徽章/胸牌、选票、可写擦计分板；"能摸、能拍、能留念" |
| 沉浸 | 装扮建议（西装/领带/竞选帽/星条风围巾）、BGM与音效清单、DM扮演NPC、开场仪式（宣誓/党旗） |
| DM | 熟练、会演、控场稳、计分不出错；终局"像综艺主持" |
| 复盘 | 真相时间线+人物关系图+每个角色的"高光回顾"+数值公开（谁在哪一步改变了局势） |
| 纪念 | 结算证书/头条报纸/角色卡可带走（城限店常用"可带走小物"提升好评） |

### A6. 口碑传播点（截图/名场面/梗）

1. **截图类**：选举人团大地图最终染色（"红蓝地图"→ 虚构化成本作的两色）、"当选头条报纸"、竞选海报、角色名牌合照。
2. **名场面类**：电视辩论（含"禁词"惩罚）、党代会提名演讲、副总统搭档"联姻"仪式、十月惊奇爆料、大选夜开票直播、败选演讲。
3. **梗类**：角色口头禅、名字谐音梗、"政策抽签"的荒诞政策、DM播报的"突发新闻"。
4. **反转类**：阵营卧底身份揭晓、"你一直以为的盟友其实是对方金主"、复盘时的"真正操盘手"。
5. **可复述金句**：每个角色给1句"签名台词"，印在角色卡背面，鼓励玩家在高光时刻喊出来。

### A7. 常见差评原因（排序，按经验频率）

1. 挂机/戏份少（"我全程打酱油"）
2. 时长注水（"8小时有3小时在等"）
3. 规则太绕、DM讲不清/算错分
4. 结局随机或一边倒
5. 反转牵强、逻辑漏洞
6. 物料不全/缺件/与描述不符（城限尤其敏感）
7. 笑点尬、社死强迫
8. 阅读量太大
9. 角色性别/反串处理不当（反串角色体验差）
10. 题材"擦边"或说教

## B. 欢乐本笑点制造技法清单（附美国竞选题材示例）

> 原则：**笑点来自"规则内的荒诞"和"人物的反差"，不来自对真实人群的嘲弄**。讽刺对象=权力游戏、媒体、金主、官僚程序本身。所有名字虚构化，不得使用真人姓名。

| # | 技法 | 要点 | 美国竞选题材示例 |
|---|---|---|---|
| 1 | **人设反差** | 外在身份与内在癖好对立 | 强硬"铁腕党鞭"私下是星座占卜爱好者，每个重大决定都要先查当日运势；"环保斗士"候选人的私人飞机里程全场第一 |
| 2 | **谐音/绰号命名** | 名字自带人设、好喊 | "钱多多"（超级PAC金主）、"嘴替·白"（新闻发言人）、"翻车·王"（危机公关）——名字本身就是笑点和记忆点 |
| 3 | **表演任务** | 有明确时长/格式的小表演 | 30秒"竞选广告"现场演绎（必须包含一个吉祥物和一句不可能兑现的承诺） |
| 4 | **即兴议题** | 随机抽题即兴发言 | 辩论抽题卡："你如何看待把感恩节火鸡纳入联邦保护名单？"——限60秒，答完全场举牌打分 |
| 5 | **禁词/口癖惩罚** | 规则制造口误 | 电视辩论中禁说"我"字/禁说对手名字，违者民调-1；或每次说"Make…"要付1筹码给"版权方" |
| 6 | **公屏/播报** | DM以新闻主播身份插播 | "突发！据本台独家消息，某候选人的狗在社交媒体上关注了对方阵营……"——用"快讯卡"统一格式朗读 |
| 7 | **DM扮演NPC** | DM换声线/道具扮演 | DM戴墨镜扮"神秘金主"、拿麦克风扮"深夜脱口秀主持人"、扮"一位摇摆州的中年选民"接受拉票（选民有离谱诉求：要求修好他家门口的路灯） |
| 8 | **荒诞政策抽签** | 政策卡含正经+离谱 | "全国统一时区""给猫投票权""关税加到地球以外"；玩家必须用正经口吻为抽到的政策辩护 |
| 9 | **夸张数值/播报** | 民调数字离谱 | "最新民调：候选人好感度 -300%，误差范围 ±400%"；用于制造"媒体不可信"的讽刺 |
| 10 | **前置埋梗·后置引爆** | 第一幕埋，终局爆 | 第一幕某角色随口说"我这辈子不会再踏进某州"，终局该州恰好是决胜州，必须去拉票（自带社死） |
| 11 | **信息错位** | 两人对同一件事理解相反 | 两位幕僚都以为对方是自己阵营的卧底，在密谈中互相"掩护"对方，复盘时笑翻 |
| 12 | **实名公开投票** | 公开举手制造尴尬 | 党团会议"站队"环节：必须走到自己支持的候选人身后排队，"站错队"当场社死 |
| 13 | **拍卖/竞价狂热** | 限时叫价 | 拍卖"黄金时段广告位""某网红播客的独家访谈"；DM当拍卖师用快嘴节奏带气氛 |
| 14 | **黑料互曝** | 有代价的爆料 | "黑料卡"打出需朗读标题，如《某候选人被拍到在快餐店点了沙拉——选民质疑其亲民形象》 |
| 15 | **伪造/深伪** | 纸质版"合成录音"文稿 | DM朗读"合成录音稿"，目标玩家需当场"辟谣"，全场投票信不信；纸质道具可做"文字录音截图" |
| 16 | **道具外观** | 视觉笑点、可拍照 | 一次性竞选帽、过大的支票牌、"提词器"卡（字很小）、假新闻报纸头版 |
| 17 | **社死任务（分级）** | 轻/中/重三级，可拒绝 | 轻：向对手鞠躬致敬；中：为对手写一句赞美标语；重：唱一句"竞选主题曲"。拒绝=付代价（资金/民调） |
| 18 | **"官僚程序"讽刺** | 规则本身荒诞 | 想发言须先"填表申请发言权"，表格上有一栏"请说明本次发言是否会被引用" |
| 19 | **复盘颁奖** | 搞笑奖项 | "最佳翻脸奖""年度金句奖""最昂贵的一票""最不像卧底的卧底" |
| 20 | **签名台词** | 每人一句口号 | 角色卡背面印口号，鼓励在高光时刻喊出，成为该局的梗 |

**笑点安全边界（写进DM手册）**
- 不针对种族、宗教、性别、残障、地域群体开玩笑；不使用真实政治人物姓名与可识别肖像。
- 社死任务一律可"花代价拒绝"，并在开场告知；反串角色的表演任务不以"性别反差"为笑点。
- 涉及枪击、暴力事件等真实创伤题材，不作为笑点素材。

## C. 6–8人弹性人数设计技法

### C1. 基础结构推荐【惯例 + 本项目建议】

- 以8人满配为标准，采用 **"6个核心位 + 2个可删位"**：
  - **核心位**：承载主线因果、终局候选人/操盘手、阵营骨架，不可删。
  - **可删位**：有完整个人线和笑点，但其"关键信息"在剧情中有**替代承载者**（线索/NPC/另一角色也知道）。
- 阵营骨架建议（示例，仅供核心设计参考）：

| 人数 | 结构建议 | 补偿手段 |
|---|---|---|
| 8人 | 3（阵营甲）+ 3（阵营乙）+ 2（中立/摇摆/第三方） | 标准数值 |
| 7人 | 3 + 3 + 1（保留更有"终局影响力"的中立位） | 中立位获得被删位的一项能力或资源；中立位胜利条件微调 |
| 6人 | 3 + 3（中立位NPC化，由DM按策略表执行）或 2 + 2 + 2 | NPC的资源/票数折算为公共池；各阵营资源同比缩放 |

> 注意：7人时出现奇数时，**不要强行让两个阵营人数不等而不补偿**；若必须3v4，较少一方需获得"信息优势"或"终局票权加成"，并经数值模拟验证胜率。

### C2. 五种技法

1. **删角色（Cut）**：删掉可删位；其独有线索改由"替代承载者"持有（预先在DM手册写好"删人迁移表"：哪条信息→转给谁/哪张卡）。
2. **合并角色（Merge）**：把两个角色的身份合并给一人（例如"竞选经理"兼任"首席筹款人"）。前提：两者的**动机方向一致、时间线不冲突、不在同一场景对话**；合并后提供"合并补丁页"。
3. **NPC化（NPC-ify）**：被删角色以NPC形式存在，由DM执行**固定策略表**（例如"始终把票投给当前民调第二名""收到≥3筹码就交出情报"），保证可预测、不偏袒。
4. **阵营人数补偿（Compensate）**：资源量、票数、行动次数、特殊能力按人数缩放；建议做"人数×参数"总表。
5. **机制参数缩放（Scale）**：州的数量、选举人票总数、筹码总量、拍卖物数量、胜利阈值随人数调整；尽量用"每人X份"的线性规则，DM无需临场算。

### C3. 删减验收清单

- [ ] 删人后**每条主线因果仍闭合**（用因果审计表逐条核对）
- [ ] 删人后**每位剩余玩家仍至少有2条对手戏**（关系矩阵检查）
- [ ] 删人后各阵营胜率仍在40%–60%（数值模拟）
- [ ] 删人后**笑点担当仍在**（不要把唯一的喜剧位设成可删位）
- [ ] 删人后终局候选人数量与结构不变（或有明确替代方案）
- [ ] 删人说明能在DM开本前5分钟完成调整（不得要求DM改写大量材料）

### C4. 常见坑

1. **关键线索断裂**：被删角色恰好持有某个反转的唯一证据 → 必须做迁移表。
2. **只改人数不改数值**：资源总量不变导致人均资源暴涨、节奏变快、时长不足。
3. **合并后动机打架**：一个人同时要"保护A"又要"扳倒A"，玩家困惑。
4. **NPC化变成DM偏袒**：DM临场决定NPC行为→玩家质疑公平；必须用公开或封存的策略表。
5. **奇数阵营失衡**：3v4没有补偿。
6. **删掉"情感/反差"位**：剧情只剩权谋，失去走心反差点。
7. **反串体验差**：反串角色被设计成笑料对象；反串应只换性别称呼，不改核心体验。
8. **删人后某角色无对手戏**：其主要互动对象被删，变成边缘位。
9. **删人方案未测**：只测了8人车，6人车首发即翻车 → 外测中至少安排2车7人、2车6人。

## D. 7–8小时长本节奏曲线

### D1. 注意力管理原则【惯例】

- **单环节≤40分钟**，超过就切换形式（公聊↔私聊↔表演↔结算）。
- **每45–60分钟一个小高潮**（揭秘/播报/投票结果/背刺），**每2小时一个中高潮**，**最后90分钟大高潮**（终局大机制）。
- **规则即用即教**：每幕只教当幕用到的规则；终局规则拆成"前几幕的预演+终局开场的补全"。
- **"公开—私密"交替**：公开环节（表演/投票）提供热闹，私密环节（私聊/交易）提供拉扯，交替进行避免疲劳。
- **疲劳低谷放阅读，高峰放对抗**：饭后30分钟是低谷，适合轻阅读+轻机制，不要放规则教学。
- **出局不离场**：任何淘汰都转化为新身份（记者、说客、选民代表、媒体评论员），保有投票/爆料权。

### D2. 推荐节奏表（以7.5小时为例，含饭点）

| 时间 | 环节 | 形式 | 能量 |
|---|---|---|---|
| 0:00–0:20 | 开场：选角、装扮、世界观（DM播报"大选年开幕"） | 公共 | 中 |
| 0:20–0:50 | 第一幕阅读（≤30分钟） | 个人 | 低 |
| 0:50–1:00 | 自我介绍+签名台词 | 表演 | 中↑ |
| 1:00–1:45 | 第一幕机制（小机制，教会核心货币/谈判） | 机制+私聊 | 中高 |
| 1:45–2:00 | **小高潮①**：第一次公开结算+突发新闻 | 公共 | 高 |
| 2:00–2:10 | 休息 | — | — |
| 2:10–2:25 | 第二幕阅读（≤15分钟） | 个人 | 低 |
| 2:25–3:25 | 第二幕机制（结盟/交易/曝料） | 机制+私聊 | 高 |
| 3:25–3:40 | **中高潮①**：第一次大反转（身份/关系） | 公共 | 很高 |
| 3:40–4:20 | **饭点**（40分钟；饭间可保留"非正式私聊"） | 自由 | 低 |
| 4:20–4:35 | 第三幕阅读（≤15分钟，饭后轻阅读） | 个人 | 低 |
| 4:35–5:20 | 第三幕机制（初选/党代会类，含表演） | 表演+投票 | 中高 |
| 5:20–5:30 | 休息 | — | — |
| 5:30–5:40 | 终局规则补全（≤10分钟） | 公共 | 中 |
| 5:40–7:00 | **终局大机制**（竞选：辩论/十月惊奇/大选夜） | 全员 | 极高 |
| 7:00–7:10 | **大高潮**：开票、选举人团揭晓、宣誓/败选演讲 | 仪式 | 峰值 |
| 7:10–7:30 | 复盘：真相时间线、反转串联、颁奖、合影 | 公共 | 中高（情绪落点） |

> 可伸缩段：第二幕机制、第三幕机制、终局各预留±10分钟弹性；DM手册须标注"超时时可砍的子环节"和"提前时可加的子环节"。

### D3. 阅读量控制

| 项 | 建议 |
|---|---|
| 阅读速度假设 | 剧本杀场景下玩家理解性阅读约300–400字/分钟 |
| 第一幕 | ≤30分钟 → 约6,000–9,000字（含人物小传、关系、目标、首幕规则摘要） |
| 后续每幕 | ≤15分钟 → 约3,000–4,500字 |
| 全程阅读 | ≤90–100分钟（占总时长约20%） |
| 单人总字数 | 约1.2万–1.8万字（不含公共规则书） |
| 公共规则 | 单页规则卡化；每个子系统1张卡，正面规则、背面例子 |
| 均衡 | 各角色首幕字数差≤20%，避免有人读完干等 |

### D4. 防挂机设计

- **并行轨道**：公聊时，非发言者可进行"押注"（押谁赢辩论）、"情报黑市"（交换线索卡）。
- **闲置任务**：每幕给每人1个"副目标"（例如"让某人说出某个词"），在空档推进。
- **私聊时长上限**：每轮私聊限时（如3分钟），DM有沙漏/计时器；避免两人长谈其余人干等。
- **出局重生**：落选者转任"媒体/说客/选民代表"，拥有关键终局权力（例如影响一个摇摆州）。

### D5. 戏份均衡（戏份矩阵）

建议在核心设计阶段建表，后续每次修订都要更新：

| 角色 | 幕1 C位 | 幕2 C位 | 幕3 C位 | 终局 C位 | 决策点数 | 对手戏数 | 独有能力 | 独有秘密 | 反转次数（施/受） |
|---|---|---|---|---|---|---|---|---|---|
| 角色1 | ✓ | | ✓ | ✓ | ≥6 | ≥3 | 1 | ≥1 | 1/1 |
| … | | | | | | | | | |

**均衡验收线**：
- 每人全程C位时刻≥2次，其中至少1次在终局。
- 每人每幕≥1个有意义的决策点（选择会影响结果）。
- 每人与≥3名其他角色有直接关系线，其中≥1条为"反转关系"。
- 外测中，每个角色都至少1次被投为"本局最想再玩的角色"，且无角色连续多车被评为"最无聊"。

## E. 终局大机制对DM的能力要求（行业惯例）与城限培训

### E1. 能力维度与硬性要求（建议写进DM手册首页）

| 维度 | 具体要求 | 本作硬性门槛建议 |
|---|---|---|
| 主持 | 规则讲解清晰、有示范；能用"新闻主播/拍卖师/辩论主持"三种口吻推进 | 规则讲解≤10分钟，讲后能用3个问答确认理解 |
| 计分 | 实时、准确、公开；能处理多资源（资金、民调、选举人票） | 能独立使用计分表在5分钟内完成一轮结算；建议配**计分员/场控** |
| 控场 | 控时（沙漏/计时器）、控发言（防一人霸场）、控私聊（时长与次数） | 能按分钟级流程表运行，误差≤±30分钟 |
| 表演 | 扮演≥3个NPC（金主、主播、选民），声线/道具区分 | 首次上车前完成NPC台词试演 |
| 临场裁决 | 规则缝隙、玩家"骚操作"、计分争议 | 依据书面**裁决优先级**快速裁定（见E2），30秒内给结论 |
| 氛围 | BGM切换、音效、仪式感（开票、宣誓） | 熟记BGM清单与切换点 |
| 节奏 | 判断场子冷热，能砍/加子环节 | 熟悉"可砍/可加"清单 |
| 公平 | 不剧透、不偏袒、信息隔离（私密卡不外泄）、NPC按策略表执行 | 不允许临场改变胜负条件 |
| 复盘 | 能串起全局因果，回应"为什么"类追问 | 能脱稿讲清主线时间线与每个反转的伏笔位置 |

**DM能力画像（推荐）**：主持过≥10车阵营/机制本；对公开计分和实时结算有经验；有一定表演/主持基础；遇到玩家争议时能"先裁后议"；本作需完整玩过一次（作为玩家）+观摩一次+在带本老师监督下主持一次后方可独立开本。

### E2. 裁决优先级原则（模板）

1. **书面规则** > DM手册FAQ > DM临场判断。
2. 规则未覆盖时：**按"不破坏已发生事实"、"不让任何一方获得规则外收益"、"偏向更有戏剧性但不改胜负判定的方案"**依次判断。
3. 裁决一旦作出当局不翻案，复盘时可解释。
4. 涉及胜负的争议，DM公开说明依据；涉及私密信息的争议，DM私下核对后公布结论不公布内容。

### E3. 双DM/场控建议

- 终局建议"**主DM（主持+表演）+ 场控/副DM（计分+计时+物料）**"；单DM开本时需使用"自动化计分表"（预印格子、只需打勾/填数），并把计算步骤降到"加减整数"。

### E4. 城限店家如何培训DM【惯例】

1. **发行方提供**：DM手册（含逐字台词与流程表）、讲解视频/线上培训、计分表模板、FAQ、物料检查表。
2. **带本**：首批城限店通常由发行方或认证老师"带本/首车带教"，店家DM观摩或跟车。
3. **店内流程**：DM先作为玩家体验完整一局 → 观摩一局 → 内部车试主持 → 正式开本。
4. **考核**：规则问答（≥10题）、计分实操（给定局面完成结算）、NPC试演、裁决情景题（≥5个争议场景）。
5. **持续支持**：发行方建立城限店家群，收集FAQ与勘误，定期发布"版本补丁"（规则澄清/物料补件）。

## G. 优质剧本"从0到发行"标准创作流程

> 公开报道提及的典型周期：约3个月创作+约2个月测本，并通过展会/线上平台对接店家【有出处】。本作因机制复杂，建议预留更长测试期。

| 阶段 | 关键动作 | 产出物 | 验收标准 |
|---|---|---|---|
| 1. 立项 | 定品类、人数、时长、题材、目标人群、竞品分析、发行形式（城限） | 立项书（一页纸卖点+目标人群+竞品对比+预算） | 一句话卖点清晰；与竞品差异≥2点；预算与定价可行 |
| 2. 核心设计 | 阵营结构、胜利条件、核心循环、终局机制雏形、核心反转 | 核心设计文档（GDD）、阵营/胜负条件表、终局流程图 | 胜负条件可计算且公开；能用纸面"推演一局"跑通 |
| 3. 故事与人物 | 世界观、主线、人物小传、关系网、反转与伏笔 | 故事大纲、人物卡、关系矩阵、**因果审计表**、戏份矩阵 | 每个反转≥2处伏笔；关系矩阵每人≥3条关系线；无"孤岛角色" |
| 4. 机制设计 | 各幕小机制、货币体系、事件卡、终局规则 | 规则书初稿、卡牌清单、数值表 | 规则单个子系统讲解≤10分钟；每个机制对应一个剧情动作 |
| 5. 分幕剧本撰写 | 各角色分幕剧本、公共文本、线索卡文本 | 全角色分幕本初稿 | 字数符合D3；各角色首幕字数差≤20%；时间线一致 |
| 6. DM手册 | 主持稿、计分手册、FAQ、删减方案、复盘稿 | DM手册初稿 | 新DM凭手册可独立开本（盲测） |
| 7. 物料设计 | 物料清单、卡牌/版图草图、BOM | 物料清单、原型（打印版） | 物料与规则一一对应；单套BOM在预算内 |
| 8. 数值模拟 | 表格推演、简单脚本模拟（多次随机局）、极端策略测试 | 模拟报告、平衡调整记录 | 各阵营胜率40%–60%；无"必胜策略"；落后方翻盘率合理（建议15%–30%） |
| 9. 内测 | 工作室内部车（建议≥3车，含7人/6人各1车） | 内测记录（计时、挂机点、规则疑问、逻辑漏洞） | 跑完全流程；无阻断性规则漏洞；时长偏差≤±45分钟 |
| 10. 外测 | 合作店家/玩家公开车+私车（建议≥10车，覆盖不同DM、人数、城市） | 问卷数据、DM反馈、名场面记录 | 满意度≥8.5/10；时长偏差≤±30分钟；挂机投诉率低；每角色都有"最想再玩"票 |

### G1. 本项目特别要求的"严谨性"工具

1. **因果审计表**：每个事件列"起因 → 行为人 → 动机 → 证据/伏笔位置 → 谁知道 → 何时揭晓"，逐条核对无矛盾。
2. **信息分布表**：每条关键信息"谁在第几幕知道"，防止有人"不该知道却知道"或"该知道却没信息"。
3. **时间线总表**：所有角色行为按时刻排列，检查同一人不能分身、行为先后合理。
4. **反转审计**：每个反转标注"前置伏笔×2+复盘解释1句"，复盘稿必须能一句话讲通。
5. **删减一致性**：7人/6人方案下重跑以上四张表。

## H. 对本项目的落地建议（汇总）

1. 终局"竞选总统"拆为若干子环节（如初选/党代会/辩论/十月惊奇/大选夜），**前几幕用小机制预演其规则**，终局只补10分钟规则。
2. 胜负条件建议"阵营胜利 + 个人目标"双层计分：阵营决定"谁当选"，个人目标决定"谁是最大赢家"，使背刺有收益、但不破坏阵营体验。
3. 计算全部交给DM/场控和预印计分表；玩家只做"选择"。
4. 每个角色设计：1个独有能力 + 1个独有秘密 + 1句签名台词 + ≥1次反转（施或受）。
5. 出局者转任"媒体/说客/选民代表"，持有终局关键权力。
6. 可删位不放唯一笑点担当、不持唯一反转证据。
7. 物料重点投入"可拍照物"：选举人团大地图、头条报纸、当选证书、竞选徽章。
8. 笑点围绕"权力游戏的荒诞"，双方阵营同样被讽刺，避免立场输出。
9. DM手册首页写明终局DM硬性门槛，并推荐双DM开本。
10. 外测必须覆盖7人、6人车与不同水平的DM。
