# 第2轮复审：玩家体验、节奏与欢乐（experience-R2）

> 审查对象：01-core-concept.md（v1.1）、02-characters-relations.md（v1.2）、03-truth-timeline.md（v1.2）、04-flow-and-mechanics.md（v1.1）、05-finale-election.md（v1.1），参照06-audit-log.md第1轮裁决与_process/audit-R1-experience.md。
> 视角：城限阵营本中度玩家（爱博弈、拉扯、背刺、名场面；不爱挂机、规则过载、纯算数、过早出局、强弱悬殊、硬核长推理）。
> 口径：本轮只报critical与major；按严重度排序。编号experience-R2-xx。

## 总评

第1轮的大方向修复确实落了地：总时长表闭合到457＋23，终局三次结算都配了并行台前节目，摊牌前移且全员同构，安德福有了四期保底C位，防御技能不再吞掉狡辩，复盘扩到35分钟，第二次广告有了真休息。体验面最致命的"规则讲解2分30秒""第3期末25分钟陪坐""副手挂机"三项都已解决。

但复审发现四类问题：

1. **R1遗留的结构性失衡没有处理**。05§9.6第11条自己承认"两名卧底同向觉醒造成4:2火力悬殊、少数派胜率估计低于20%"，却列为"R2待处理"；06§1.6同时写着"遗留critical：0"，两处自相矛盾。按卧底的理性决策，同向觉醒不是小概率事件，而是均衡解（见R2-01）。这是本轮唯一的critical。
2. **时间表只是在纸面上闭合**。逐环节估算，片头、第1–3期与终局都有没进预算的"微步骤"（每期新模块的讲解、写资金纸条、快讯卡、邮包、终局技能），中位估算约495分钟，仍会突破480的硬上限（R2-02、R2-03、R2-04）。
3. **R1的部分修复引入了新问题**：插播时段被列为"纯表演可砍项"，砍掉的却是四个人的收益（R2-11）；全员邮包让沼泽在摊牌前只能下达第1期写好的指令（R2-10）；第9页的"放出代价"把全本唯一的走心点变成了党派计分举牌（R2-08）。
4. **终局是全本拉扯的高潮，私聊却只剩三轮**，站台规则还会制造"拖到最后一秒抢图"的僵局（R2-06、R2-07）；F3冻结欠条后，沼泽高概率提前判死（R2-09）。

计数：critical 1，major 14。
