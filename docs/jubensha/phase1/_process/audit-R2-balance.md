## 0. 结论摘要

**计数**：critical 3，major 6，共9条。

**五个核心判断**
1. **觉醒仍会制造4:2，而且现在是"纯协调博弈"**：两名卧底只要最终落在同一阵营，就能形成4:2；对任一卧底，给定对方的选择，"和对方同阵营"都是最优反应，偏离只会回到3:3，没有背叛诱因。上线（沼泽）知道两名卧底、每期都能写指令卡，R5对卡也从第1期起就可能，协调渠道现成。05§9.4自评4:2时少数方胜率<20%，05§9.6第11条把它列为"R2待处理"，06第1轮却记"遗留critical 0"（R2-01）。
2. **7人局与6人局是这一问题的放大版**：7人局高文单方面"假戏真做"就是驴心4:象心1，这是唯一的严格均衡；6人局可落到3:1，F-15第3款"任何一方不存在开局后无路"不成立（R2-02、R2-03）。
3. **"押不到已成形的领先者"并不成立**：超级星期二胜者当场公布，春季信封是第2期末公开民调的确定函数，摊牌时90票里的70票承诺代表已可算出（R2-04）。
4. **沼泽三条路退化成一条**：垂帘要两名分属两阵营的印章持有人同盖，结构上几乎必被否决；坐庄罕见；收账T＝2成为唯一主路径，而它的强弱完全取决于提名人怎么看"惨胜"，所以胜率是双峰的（R2-05）。冻结后F4兑现②的计数口径又自相矛盾（R2-06）。
5. **两处放大器**：风向每格实为"所有未锁票州各+1"，三次闭眼举牌按阵营人数分风向，放大人数差（R2-08）；驴心一侧的银行收入技能比象心一侧每局多约19资金（R2-09）。另有一处换将新漏洞：亚军在另一张票上时，破锁会把总统提名送给沼泽副手（R2-07）。

## 1. Critical

### balance-R2-01｜critical｜觉醒二选一是"纯协调博弈"：两名卧底同阵营的4:2是共同最优，有现成协调渠道，且无任何破解工具
- **文件/位置**：01 §4.4第4条、§4.5第1条、附录A F-13第3款、F-12第8款；02 §2.2"高文—跟跟"机制交互点；04 §6.5"设计说明"；05 §9.4、§9.6第11条；06 §1.6"遗留critical 0"。
- **问题**：
  1. **人数＝火力**。终局每名成员都带来：一份"单州单轮≤5"的投放额度（约10–14资金）、每轮1次公开站台（+2）、每轮1次攻击（−3/−3/−4）、三次闭眼举牌各1票（R2-08）。粗算每人约25–30分摇摆分。05§9.4自评：4:2时少数方"两个分支都低于20%"。
  2. **2×2的结构**（H＝高文，G＝跟跟；H坚守＝象心、H假戏真做＝驴心；G坚守＝驴心、G假戏真做＝象心）：
     - (H坚,G坚)：驴3:象3；(H假,G假)：驴3:象3；(H坚,G假)：**象4:驴2**；(H假,G坚)：**驴4:象2**。
     - 对H：G坚时，H假让他从3人方移到4人方；G假时，H坚让他留在4人方。G同理。**每个人的最优反应都是"和对方落在同一阵营"**，两个4:2都是纯策略均衡；从4:2单方偏离只会回到3:3，没有背叛诱因。这不是囚徒困境，而是协调博弈（附表A，按提名结果展开）。
  3. **协调渠道现成**：
     - 上线（沼泽）开局就知道两名卧底及其上线（03§5.2 K4/K5），每期都能写指令卡（F-16第4款），一句"跟跟也是自己人，摊牌时你选X"即可完成协调；
     - R5对卡从第1期邮包起就可能（03§5.1 K6）；
     - 02§2.2原文提示两人"可以约好同时'假戏真做'或同时'坚守'"，而这两种恰恰是3:3组合。设计文本没有意识到真正有利可图的协调是"一坚一假"。
  4. **即使不沟通也会相关**：落选概率高的卧底，觉醒只决定"押哪个阵营"，两人都会押同一个"看起来更强"的阵营，结果同样是4:2。05§9.4按五五开独立选择估"4:2约占一半"，但它是协调均衡，实际频率只会更高。
  5. **没有破解工具**：公开调查和换将只作用于提名票成员。不在票上的卧底，其阵营归属任何工具都碰不到；破锁也只换总统人选，改不了4:2（05推演A′破锁后仍是2对4，驴心两个分支都输）。
  6. 01§4.5第1条"押不到已成形的领先者"、04§6.5"两个选项各自在不同提名结果下更优"，都只分析了"谁当提名人"，漏掉了"阵营人数"这一主效应。
- **为什么重要**：这是8人标准局的核心阵营结构。4:2局约占一半甚至更多，被抛下的两人从第3期开头起胜率不足20%，正是目标玩家最讨厌的"强弱悬殊、过早无望"。06把它记为"不计为遗留问题"是错误的。
- **修复（推荐方案A，不新增规则模块）**：
  - **A. 镜像觉醒（双签生效）**：F-13第3款改为"只有两名卧底**都**放'假戏真做'时，两人同时转入胸牌政党对应阵营；任一人坚守（含'已阅'），两人都保持原阵营"。
    - 结果：阵营人数恒为8人3/3/2、7人3/2/2、6人2/2/2。
    - 觉醒变成真正的信任博弈：想"表里一致、免疫调查"的提名人卧底，需要说服对方一起换；对方可以口头答应、信封里坚守（书面不可见、口头无约束），背刺空间仍在。
    - 回执只告诉本人"转换已生效／未生效"，他能推知对方的选择，但信息只留在两名卧底之间。
    - 同步改：01§4.4第4条、§4.5第1条；04§6.5设计说明；02§2.2"高文—跟跟"一栏改为"两人必须同时选假戏真做才会一起换边"；05§9.4、§9.6第11条改为"已处理"。
  - **B. 若坚持单方觉醒（备选，须三条同时上）**：
    1. 每轮每州每张票的投放合计上限10，超出部分按信封拆开顺序作废并私下退还（压缩人数优势）；
    2. F0回执给人数≤2的真阵营（驴心或象心）每名成员一张"+5资金券"（全员回执都放一张券，面值+0或+5，读完交回）；
    3. 落选卧底的"假戏真做"只在其F0第6步位于提名票上时生效，否则视为坚守。
  - **验收**：外测统计"4:2局"占比≤15%（方案A应为0）；少数方胜率≥25%。

### balance-R2-02｜critical｜7人局：高文单方面"假戏真做"即成驴心4:象心1，这是唯一的严格均衡；现行补偿约等于一名成员的十分之一
- **文件/位置**：01 §4.6"7人"行、附录A F-15第1款、F-21；02 §5.1"阵营平衡"行；04 §3.2、§8.1；05 §9.7。
- **问题**：
  1. 7人局的基础结构是驴心3（辣椒、梅、跟跟）对象心2（麦克、高文）。2×2：
     - (H坚,G坚)：驴3:象2；
     - (H假,G假)：驴3（辣椒、梅、高文）:象2（麦克、跟跟）；
     - (H坚,G假)：象3:驴2；
     - (H假,G坚)：**驴4:象1（只剩麦克）**。
  2. 对高文：G坚守（默认"已阅"即坚守）时，H假让他从2人方跳到4人方，收益巨大；G假时两边都是3人，无差异。对跟跟：H假时，G坚（4人方）严格优于G假（2人方）。所以**(H假,G坚)＝4:1是唯一的严格均衡**，(H坚,G假)只是弱均衡。
  3. F-15的补偿"高文开局知道麦克是象心"，恰好让高文算清"象心这边只有我和麦克"，反而推动他跳船。
  4. 补偿只有麦克+3资金。按R2-01的口径，一名成员约25–30分，+3资金约3分。即使在不跳船的2:3里，象心也只补回约十分之一人。

### balance-R2-03｜critical｜6人局可落到3:1，F-15第3款"任何一方不存在开局后无路"不成立；05推演B′已自认"一对三"
- **文件/位置**：01 §4.6"6人"行、附录A F-15第2、3款；04 §8.2"提名人的忠诚搭档"；05 §9.3结论、§9.7。
- **问题**：
  1. 6人局的基础是驴心{辣椒、跟跟}、象心{麦克、高文}、沼泽2。2×2：
     - (H坚,G假)：**象3:驴1（只剩辣椒）**；
     - (H假,G坚)：**驴3:象1（只剩麦克）**。
     - 与R2-01同理，两者都是协调均衡。上线指令卡与R5对卡同样可用，6人局里两名卧底还是唯一彼此的"同类"，协调更容易。

     - 象心3人赢下大选；
     - 沼泽向红票总统提名人收到3张欠条（6人局T＝3），惨胜共赢；
     - 结局是象心3人＋沼泽2人共5人"获胜"，辣椒一人判负。这正是R1 C14要消除的局面。
  4. 6人局另有一个跨党票漏洞：辣椒用调查令破锁，反而会把提名送给沼泽（推演见R2-07）。
- **为什么重要**：6人局是常见的缺人开法。一名玩家从第3期开头就在结构上无路可走，是目标玩家明确列出的禁忌（过早出局、强弱悬殊）。
- **修复**：
  1. 采纳R2-01方案A，6人局阵营恒为2/2/2。
  2. F-15第3款改写为有条件的表述："在镜像觉醒下，每个真阵营终局恒有2人；忠诚候选人可用调查令破锁；破锁时若初选亚军在另一张票上，按R2-07修复执行。"
  3. 05§9.3结论删去"三个阵营各有可行路径"，或在方案A下重做推演B′。

## 2. Major

### balance-R2-04｜major｜摊牌时提名结果已可推算：超级星期二胜者当场公布，春季信封是公开民调的确定函数
- **文件/位置**：01 §4.5第1条（"卧底押不到已成形的领先者，只能凭第2期的局势赌"）、附录A F-18第1、2款、F-12第8款；04 §4.1.4–4.1.5、§4.2；02 §1高文、跟跟第3期"不知道提名结果时下注"。
- **问题**：
  1. 承诺代表的两个来源都是公开的：
     - 超级星期二三州"只报胜者"，但各州代表票数公开（冲浪12、孤星10、烤肉8），30票归属当场可知；
     - 春季60票按"第2期结束时民调"25/15/待定20分配。民调是公开状态板上的数，所以春季分配饭前就能算出。
  2. 摊牌时，90票里70票的去向已经确定，只剩20票待定代表未知。04§4.2的算例中，摊牌前全场就能算出辣椒45、高文25，跟跟38、麦克32。卧底在"几乎知道谁会出线"的情况下下注。
  3. 叠加R2-01，卧底可以同时押"人数"和"提名"。F-12第8款"卧底最终阵营＝第2期末民调领先者阵营≤60%"的验收线几乎不可能达到。这条指标本身也不清楚：领先者若是卧底，他的阵营正取决于本人的选择。
- **为什么重要**：01§4.5把"前移摊牌"列为"没有必胜策略"的第一条理由，而它建立在一个不成立的前提上。
- **修复**：
  1. 春季初选加入DM侧随机，不新增玩家规则。饭点时，DM按两党各自的第2期末民调差，从对应的"春季爆冷牌"小牌堆里各抽1张，封进春季信封：
     - 民调差0–1：抽20/20、25/15、15/25各2张中的1张；
     - 民调差≥2：抽高者25/低者15四张、20/20两张中的1张。
     - 民调仍然有用，但结果不能精确预知。
  2. 春季信封与超级星期二结果维持在唱名时最后开封；DM饭点期间不得在场内谈论春季结果。
  3. 01§4.5第1条改为"摊牌时首轮只有约三成代表票（待定20加春季浮动）不确定"，不要再写"押不到"。
  4. F-12第8款指标改为可测口径："两名卧底最终同阵营的局占比≤20%"（与R2-01联动）。

### balance-R2-05｜major｜沼泽三路径退化：垂帘结构性关闭、坐庄罕见、收账强弱取决于"惨胜"的主观估值，胜率双峰
- **文件/位置**：01 §4.1沼泽行、§4.5第3条、附录A F-05注、F-11第6款、F-12第3、6款；05 §3.7〔平衡〕、§9.2分支Y、§9.3"盖章动机"、§7.3；02 钱多多剧情星。
- **问题**：
  1. **垂帘几乎不可能出现**。压下第9页需要辣椒印、麦克印同盖，而两人的阵营永远相反（辣椒驴心、麦克象心，都是忠诚者）。
     - 只有一张票上有沼泽时，放出等于给那张票"第三周所有未锁票州−3"，对面的印章持有人必定拒绝盖章；
     - 两张票都有沼泽时，−3互相抵消，两位总统提名人都宁可放出，免得自己惨胜（F-05注本身就是这样论证的）。
     - 所以压下必须有一方违背本阵营利益。05推演A′分支Y里辣椒盖章"没有给自己换来任何东西"，推演B′写"垂帘基本关闭"，都是在自认这一点。
  2. **坐庄**要靠第二轮黑马过46票，或者在亚军缺位时由副手顶上（R2-07的漏洞），常规局罕见。
  3. **收账（T＝2）成了唯一主路径，但它的强弱由一个规则没有定义的量决定**：提名人怎么看"惨胜"。见推演3。
  4. 双峰的结果：惨胜被当作"阵营还是赢了"时，沼泽几乎必然共赢；被当作"等于输"时（05推演A′中跟跟"算得清"），沼泽只剩背刺转让一条路，约10–15%。F-12第8款的目标20–30%恰好落在两峰之间。这是R1 B-06（"常规15–25%、套路80%以上"）的变体，没有消失。

#### 推演3（8人局，3:3，两张票都表里一致）：沼泽"卖支持"
- **局面**：蓝＝辣椒＋梅，红＝麦克＋琳达，协同风向互相抵消。第一周播报后，三个州"胶着"。
- **报价**：沼泽两人（十月冲刺后合计约18资金）分别找两位总统提名人："签2张欠条，F2和F4两轮我俩的钱全投你"。
- **粗估胜率**：基准各50%；独得沼泽支持约75%；两边都签，沼泽对冲后约50%。
- 设惨胜的效用＝a×胜。以麦克为例：
  - 辣椒不签时，麦克签的收益0.75a，不签0.5，签的条件是a>2/3；
  - 辣椒签时，麦克签的收益0.5a，不签0.25，签的条件是a>1/2。
- **结论**：
  - a>2/3时，"签"是占优策略，两人都签，沼泽持有双方各2张，收账100%成立。这是提名人之间的囚徒困境，由沼泽坐收。
  - a<1/2时，没人签，收账只能靠背刺转让。
  - 规则只说惨胜"不得评MVP、评级低一档"，a完全由玩家主观决定，同一套规则在不同车次会落在两个极端。

- **修复**：
  1. **写死惨胜的代价，让a变成可预期的数**：
     - 收账成立时，**P本人**评级为"负（被套牢）"，P所在阵营的其余成员为"惨胜"；
     - 垂帘成立时，P所在阵营全员"惨胜"。
     - 这样P本人有硬性理由不签第2张；队友手里P的欠条仍可能被转让给沼泽，"书面背刺"照常存在。
  2. **给沼泽一条P无法单方面封死的经营路**：收账计数改为"P或V亲笔签名、未兑现"的欠条合计（V本人是沼泽成员时只计P），T＝3（8/7人局）、4（6人局）。这样沼泽自荐副手、向副手要欠条都有了价值。
  3. **承认垂帘是稀有结局**：在01§4.5第3条、05§3.7〔平衡〕里写明"垂帘需要一方违背阵营利益或被收买，设计频率≤5%"，不再把它算作三条常规路之一。
  4. **外测拆分统计**：坐庄、垂帘、收账各自的成功率，以及每局P签出的欠条数。目标：收账12–20%、垂帘≤5%、坐庄≤5%，合计（含共赢）20–30%。

### balance-R2-06｜major｜冻结后F4仍可兑现②，与"按冻结封存时计"和"沼泽每兑现一张就少一张"三处口径互相矛盾
- **文件/位置**：01 附录A F-11第3、5、6款；04 §6.10"冻结""沼泽收账计数"；05 §3.10（"沼泽每兑现一张，就少一张收账的筹码"）、§7.1收账数N、§8.6第48条。
- **问题**：
  1. 三处说法互相冲突：
     - F-11第6款：N按"冻结封存时计"、"未兑现"；
     - F-11第5款：冻结后"持有人仍可在F4申请兑现②（场控取出撕毁）"；
     - 05§3.10：沼泽每兑现一张就少一张。
     - 沼泽在F4兑现一张P的欠条后，F6清点时这张算不算，三处给出两种答案。
  2. 这不是措辞问题：
     - 若按封存时快照计数，沼泽可以在F4"一票两用"：强制立据人投放，同时照样计入收账；
     - 而兑现②可以指定"为指定的提名票"，包括立据人的对手票。例如沼泽持有红票P的2张欠条和蓝票P的1张，F4用蓝票P那张强制他在钢铁州给红票投2，并且本轮不得在钢铁州投蓝票，从而直接帮红票赢下收账对象。
  3. 收账判定是F6第二次高潮的核心。口径不一会让DM当场裁决，复盘时必然起争议。
- **为什么重要**：直接决定沼泽胜负和惨胜与否，是"所有因果可验算"承诺的反例。
- **修复**：
  1. F-11第6款改为："N＝F6清点时仍在欠条袋中、未兑现的……；F4经兑现②取出撕毁的欠条一律不计"。05§7.1、§3.10，04§6.10同步改。
  2. 兑现②保留"可指定任一张票"（这是设计内的书面背刺），但在规则卡上明写"可以指定对手票"，免得被当作漏洞。
  3. 05§8.6第48条（漏装欠条）一并改为"不计入收账；F4兑现②后同样不计"。

### balance-R2-07｜major｜换将补位新漏洞：初选亚军在另一张票上时由副手顶上；跨党票下表决人可能只剩沼泽一人，破锁反把提名送给沼泽
- **文件/位置**：01 附录A F-03第4、5句、F-15第3款；05 §3.3表决门槛速查、§8.1第5条；02 §5.3（6人局推荐"辣椒＋跟跟"跨党驴心搭档）；04 §8.2。
- **问题**：
  1. F-03第5句：亚军不合格（含在另一张提名票上）时，由本票副总统提名人顶上。8人局和6人局的驴友党初选都只有两名候选人，落选者一旦成了对方票的跨党副手，本党就"再无人选"，副手自动升任总统提名人。
  2. F-03第4句：表决人不含"身在另一张提名票上的人"。跨党副手所在的原党，表决人会被削到只剩1人，而这1人可能就是本票的沼泽副手。
  3. 6人局推荐的忠诚跨党搭档（02§5.3"辣椒＋跟跟"）正好落进这个坑。

#### 推演4（6人局，(H坚,G坚)，未采纳镜像觉醒也成立）
1. **提名**：驴友党高文出线，辣椒落选；大象党跟跟出线，麦克落选。
2. **搭档**：蓝＝高文＋安德福；红＝跟跟＋辣椒（驴心跨党，政策协同+1，02§5.3的推荐组合）。

  3. 同步改F-15第3款与05§3.3速查表、§8.1第5条。
