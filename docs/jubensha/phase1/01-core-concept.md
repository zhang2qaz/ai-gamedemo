## 0. 决策说明

### 0.1 基底：方案C（阵营拉扯派）
1. 目标客群是城限阵营本中度玩家，最难后补的是阵营骨架。四份方案里，只有C的"表里双层阵营"能让拉扯、结盟和背刺从结构本身长出来。它的6人核心版仍是驴心2/象心2/沼泽2，两党各有一人，删人最干净。
2. 终局采用"先开票定谁当选，再翻卡定谁赢"，有两次高潮，其他方案没有这一层。
3. C的毛病（信息泄漏、规则过载、DM黑箱、第9页提前剧透、资金失衡、欢乐不足）都能靠删减和改写成公开规则修好。反观D要补一整套阵营，A要拆长桌会，B要换掉核心案件，都是大改甚至重做。三位评审中两位推荐C，C总分也最高（98.5）。

### 0.3 修复的评审问题
- **P0信息泄漏**：忠诚者开局互不知情，各自只拿到本阵营的"接头暗号"。规则书和宣传都不公开各真阵营的人数。沼泽两人两套暗号都会，可以冒充，所以对暗号永远不能百分百放心。
- **三人同验**：改为"联合民调"，跨党任选3人，DM只回答"这3人里有没有沼泽"，不涉及卧底。背调到第三幕才能用，所以卧底最早在第三幕被确认。
- **规则瘦身**：全本只保留资金、民调、黑料、背书、欠条五种资源。契约卡并入欠条。删除策反信、换旗、策反选举人、明暗钱手续费、动量和人人一张的深伪卡。
- **小黑屋和"船满了"**：阵营变化只保留"卧底觉醒"一种，只有两名卧底能用，转向哪边在规则里写死。觉醒和全员交信封同步处理，DM不再需要在后台维护势力值。
- **停发码**：改为"三枚见证人印章"，凑齐就能用，没有排列谜题。效果只有一种：把一页账本顺延到大选之后。全场只能用一次，不能调换顺序，也不能替换内容。
- **死人开关的现实逻辑**：九页账本两年前就加密发到了五家媒体的邮箱，解密钥匙由律所保管。所以卖家删不掉，平台删帖也没用，法院也几乎不会对真实文件下发表前的禁令。
- **第9页提前剧透**：第9页只曝光沼泽名录和一封写给辣椒的信，不点名任何卧底。
- **宪法年龄**：辣椒34岁，生日1月19日，就职日前一天满35。全员的年龄和州籍都已核对（见第5节）。
- **资金量级**：初始资金定在6–15，每人每州每轮最多投放5。
- **沼泽双保险**：走副总统路径时，第9页必须已被压下；走收账路径时，只计当选总统亲笔签的欠条，第9页一旦发布，门槛+1。
- **欢乐密度与幕僚高光**：每幕设一个固定的表演产笑环节，每人一个专属道具梗。梅有终局专属的"终极特稿"，琳达有"律师团"。
- **其他**："终身党员卡"改为选民登记记录加一张合影；飓风改到烤肉州；卧底网络的归属写清楚：它是两头吃的旧体系，由两个弟子继承。

### 0.4 放弃的创意
- **A的47秒录音和长桌会**：长桌会的胜利条件在结构上过宽，两名独行者到终局无事可做，基调也偏沉重。
- **B的"消失的一亿"**：链上转账和币价都是公开的，掩盖、骗保、匿名截胡三个动机都站不住；五种货币加八项公式也超出中度玩家的承受力。
- **D的提词器门和寄生胜利**（庄家、笔杆子、流量）：纸牌屋味最弱，寄生条件容易躺赢。由玩家担任主持人会抢DM的戏，所以贾不睡改为DM扮演的NPC。
- **C自带的部分机制**：策反信、"船满了"、换旗、策反选举人、账本控制权（压页、调序、深伪替换）、第三轮差距≤2的州重新竞标、押宝技能。这些要么是黑箱，要么增加规则负担，要么会让一个人决定胜负，一律删除或改写。

## 2. 世界观

### 2.1 时间
虚构的"20XX年·第六十一届大选年"，映射2028年，底色取自2024–2026年的真实政治生态：两党极化，关税反复横跳，医保补贴到期，币圈和AI超级PAC大把砸钱，AI深伪广告无人监管（钱钱委员会3:3僵持），播客比电视台更有影响力，刚经历史上最长的政府停摆。现任总统**金大嗓**（大象党，NPC）两届任满，不能连任，还在卖"第三届"纪念帽。这是一个**开放席位年**，人人都觉得自己有机会。

### 2.2 地点与舞台
- **骑墙大酒店**：位于钢铁州首府铁锅城，钢铁州是本届的"引爆点州"。酒店属于已故说客两头吃的遗产基金会，口号是"两党都欢迎，账单都一样"。
- **为什么一整年的大事都在这里**：深夜脱口秀《今夜不睡》与酒店签下了全年的"大选特别季"；停摆期间穹顶山暂停对外开放，听证会只好借用酒店宴会厅；两党都想在引爆点州抢镜头。
- **五个夜晚，四期节目**：1月·新年筹款晚宴 → 3月·超级星期二之夜 → 8月·两党党代会同夜开幕（东西两厅，中间只隔一个自助餐区）→ 10–11月·辩论夜与大选夜（终局）。

### 3.4 轻推理的定位
- **占比约12%（约50分钟）**，有三种形态：
  1. **第二幕"谁是泄密者"听证（15分钟）**：线索包括00:00:00的时间戳（当时全员都在直播镜头前）、第3页里的客户名、琳达的保密义务，以及辣椒和麦克手里来历不明的印章。先按投票结果执行处罚，再揭晓真相。
  2. **全程的阵营推理**（核心乐趣）：可用的信息有接头暗号、联合民调、第5和第6页、背调、上线指令卡的落款格式、搭档协同判定。
  3. **真相题**：每人一题，在大选前夜第9页发布之前暗中提交，答对得1星。
- **和阵营对抗的关系**：推理的产出是武器，比如换将的证据、特稿的目标、印章的去向，它不直接决定阵营胜负。推不出来也不会卡住流程，只是少一件武器。

## 4. 阵营结构

### 4.1 阵营与胜利条件
| 真阵营 | 主目标（决定输赢） |
|---|---|
| **驴心** | 当选总统的真阵营是驴心，不管他挂的是哪个党的旗 |
| **象心** | 当选总统的真阵营是象心 |
| **沼泽** | 满足任一即胜：①**坐庄**：当选总统是沼泽成员；②**垂帘**：当选副总统是沼泽成员，且第9页已被印章压下；③**收账**：沼泽成员手里握有当选总统亲笔签的欠条≥3张（6人局≥2张）。第9页一旦发布，收账门槛+1；已经兑现的欠条不计入。收账成立时，沼泽与当选方共赢，当选方降为"惨胜" |
| **孤狼**（只能由觉醒产生） | 本人当选总统。此时驴心和象心都判负，沼泽只能靠收账共赢 |

### 4.3 计分关系
- **阵营结果**：胜／惨胜（收账成立时当选方的结果）／负。
- **个人三星**：★剧情目标；★真相题；★名场面任务（由DM当场判定，并记在状态板上）。
- **最终评级**：阵营胜且≥2星为**大胜**；阵营胜为**胜**；**惨胜**；阵营负但拿满3星为**虽败犹荣**（有专属结局彩蛋）；其余为**负**。
- **MVP**：阵营获胜者中星数最多的人；星数并列时，由全场投票选"最佳表演"。

### 4.4 隐藏阵营与阵营变化规则
1. **胸牌公开，信封保密**。规则书只写"真阵营有驴心、象心、沼泽三种"，不写人数，宣传语也不提卧底的数量。
2. **接头暗号**只能在私聊里用。沼泽两人会两套暗号（是三十年来听卧底汇报学会的），可以冒充任何一方。
3. **联合民调**（第二幕，可砍）：每个党各申请一次，跨党任选3人，DM只回答"有没有沼泽"。
4. **背调**（琳达专属，第三幕起可用，全场1次）：DM回答"此人的真阵营和胸牌上的政党是否一致"。可以私下发动，也可以公开发动；公开发动就算"确凿曝光"。
5. **卧底觉醒**（第三幕末的"摊牌信封"）：**全员都要交一个信封**。两名卧底可以在信封里放三选一卡：**坚守**；**假戏真做**（转为所在政党对应的真阵营，即高文转驴心、跟跟转象心，剧情星改为"让新阵营赢"）；**孤狼**（只有本人当选总统才算胜，获得一次性技能"反咬上线"：当众指认上线，由DM确认其真阵营）。不放卡就视为坚守，其他人一律放空白卡。DM在中场休息时处理，开终局时私下回执。
6. **搭档组合判定**（摊牌之后结算，移植《青楼》的组合判定）：总统提名人和搭档的真阵营相同时，DM公开宣布"政策协同"，风向向该票推1格；不同时，DM宣布"貌合神离"。这句宣布本身就是情报。
7. **临阵换将**（终局开场）：如果某位提名人的真阵营已被确凿曝光（本人自曝、公开背调或孤狼反咬），本党成员过半数（含半数）同意即可换将，由本党投票在副手和初选亚军中选一人顶上。被换下的人以独立身份参选，拿到3枚"分票"标记，每用一枚，原政党的票在该州−2。
8. **不设策反信，不设换旗**。允许跨党搭档，代价是终局开场风向向对方推1格，叛党者也失去本党换将时的投票权。
9. **口头承诺没有约束力，欠条由DM强制兑现**：口头背刺免费，书面背刺要付代价。

### 4.5 为什么没有必胜策略
- **双锁可以破**：两党提名人同属一个真阵营时，另一方可以用背调或逼对方自曝，再走换将翻盘；卧底觉醒是第二个翻盘口。
- **沼泽信息最多，但人数最少**，也没有天然的候选人。第9页会在大选前夜自动曝光它，逼它在第三、四幕冒险：抢印章、抢副手位、收欠条。
- **觉醒方向公开，而且只能转向所在政党**。两名卧底同时暗中选择，构成囚徒困境，不会单向滚雪球。所有阵营变化都不依赖DM判断，复盘时可以验算。
