## 1. 一页纸总纲

### 1.1 剧本名与副标题
**《摇摆！》**——副标题「**两边都是我的人**」

### 1.2 一句话卖点
每到政治大日子的午夜，叉叉网上就多一页账本——发帖的人，可能就坐在你旁边。8个政客从初选骗到大选，最后才发现：赢下白房子不难，难的是确认赢下来的是不是你的人。

- 主宣传语："**你支持的候选人，可能也在支持你的对手。**"
- 店家口播："8个人，2个党，3种心，1张选票。从初选骗到大选，从队友骗到上线。"

### 1.3 定位卡

| 项 | 内容 |

### 1.4 核心体验承诺（对玩家的三句话）
1. **每一刀都有理由**：背刺来自"胸牌政党／真阵营"双层结构和角色秘密，复盘时每一刀都讲得通、可验算。
2. **每个人都有C位，全程无人出局**：每人至少一页账本要当众狡辩、一个专属名场面任务；初选落选转任竞选经理、民调归零变"跛脚鸭"，终局人人投放、站台、攻击。
3. **大选夜两次高潮**：先开票，定谁当选（打得好）；再翻真阵营卡，定谁赢（看得准）。

### 1.5 三条设计红线（全本贯彻）
- **本格**：唯一的"神秘泄密者"是死人开关式的定时公开托管合同，每一环都有起因、行为人、动机、证据、知情人、揭晓时点（03）。
- **欢乐**：笑点来自规则内部的荒诞、人设反差、DM播报和每期固定表演关；全本只有一个走心点、一个细思极恐点。
- **合规**：不用任何真实政治人物姓名；两党同等讽刺；不嘲笑任何群体；不拿真实创伤事件做笑料。

## 2. 世界观速览（5行）

1. 虚构的"第六十一届大选年"（映射2028，底色取2024–2026真实生态：极化、关税反复、币圈与AI超级PAC、深伪无人管、史上最长停摆），现任总统金大嗓（大象党，NPC）两届任满——**开放席位年**，人人都觉得自己有机会。
2. **驴友党**（爱开会）对**大象党**（体大、记仇），中间是不站队只收账的跨党金主网络**沼泽俱乐部**；一切都发生在钢铁州铁锅城的**骑墙大酒店**："两党都欢迎，账单都一样。"
3. 一个月前，跨党超级说客**游游·两头吃**（NPC）在第18洞读一张卡片时心脏病发作去世；今年起每个政治大日子的午夜，账号"@午夜账房"就贴出一页《账本》（共九页），全场都以为"我们中间有人在泄密"。
4. 【DM机密】泄密者不是人：两头吃生前买下"定时公开·不可撤销至尊版"托管，九页账本早已加密发进五家媒体邮箱，钥匙在律所，他一停止签"生存确认"就逐页发布；三枚"见证人印章"中两名不同持章人同盖可顺延第7/8/9页之一。
5. 【DM机密】把他逼死的是两个弟子——驴友党党鞭安德福与大象党金主钱多多。他们继承了老头30年前"两边都是我的人"计划埋下的两名卧底，今年要从"收账"升级为"坐庄"：让自家人直接拿下白房子。

## 3. 阵营结构、初始归属与胜利条件速查（DM机密）

- **胸牌（公开）**：驴友党／大象党，决定你挂在哪张提名票上。
- **真阵营（保密）**：驴心／象心／沼泽三种。真阵营卡不发给玩家，由DM机密册封袋保管；玩家只在角色本正文里读到自己的心。规则书与宣传**不公开各阵营人数**（F-16）。
- **结构公式（8人）**：每党4人＝忠诚候选人＋对面派来的卧底候选人＋忠诚幕僚＋沼泽成员。

### 3.4 唯一的阵营变化：卧底觉醒·猎鹿版（F-13）
- 第3期阅读后、唱名之前，全员同构拆"摊牌信封"；两名卧底二选一：坚守／假戏真做（世界内＝向公证处递投诚报备，预缴保证金3资金）。
- **两人都选假戏真做才双签生效**：两人同时转入胸牌政党对应阵营，并对公开调查免疫；**任一人坚守则两人都不变**；单方假戏真做被退回、没收3资金。阵营人数恒定（8人恒为3/3/2）。
- 双签规则（《互不挖角君子协定》）自第2期起写进两名卧底的第2册，公开规则书只写"结果以回执为准"。

### 3.5 破锁工具（两边对称，F-14）
