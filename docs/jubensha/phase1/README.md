## 1. 一页纸总纲

### 1.1 剧本名与副标题
**《摇摆！》**——副标题「**两边都是我的人**」

### 1.2 一句话卖点
每到政治大日子的午夜，叉叉网上就多一页账本——发帖的人，可能就坐在你旁边。8个政客从初选骗到大选，最后才发现：赢下白房子不难，难的是确认赢下来的是不是你的人。

- 主宣传语："**你支持的候选人，可能也在支持你的对手。**"
- 店家口播："8个人，2个党，3种心，1张选票。从初选骗到大选，从队友骗到上线。"

### 1.4 核心体验承诺（对玩家的三句话）
1. **每一刀都有理由**：背刺来自"胸牌政党／真阵营"双层结构和角色秘密，复盘时每一刀都讲得通、可验算。
2. **每个人都有C位，全程无人出局**：每人至少一页账本要当众狡辩、一个专属名场面任务；初选落选转任竞选经理、民调归零变"跛脚鸭"，终局人人投放、站台、攻击。
3. **大选夜两次高潮**：先开票，定谁当选（打得好）；再翻真阵营卡，定谁赢（看得准）。

### 1.5 三条设计红线（全本贯彻）
- **本格**：唯一的"神秘泄密者"是死人开关式的定时公开托管合同，每一环都有起因、行为人、动机、证据、知情人、揭晓时点（03）。
- **欢乐**：笑点来自规则内部的荒诞、人设反差、DM播报和每期固定表演关；全本只有一个走心点、一个细思极恐点。
- **合规**：不用任何真实政治人物姓名；两党同等讽刺；不嘲笑任何群体；不拿真实创伤事件做笑料。
