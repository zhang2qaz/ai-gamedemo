### 0.2 统一术语（规则书第0页照印）
- **公开环节**：直播间、扒马褂、听证、唱名、搭档仪式、资格诉讼、新闻周期，以及终局的辩论、广告、开票。走廊政治不是公开环节。
- **公开动作**（用于"新闻周期惩罚"判定）：在公开环节**主动**做出的行为，即打出卡牌、发动技能、作为表演者完成表演、在拍卖中举价、发起诉讼或提案。被点名的作证和全员举牌**不算**。
- **黑料攻击**：①扒马褂中被打出的黑料卡；②账本页发布后的锤/洗表决；③终局的"攻击"行动（以05为准）。凡技能写"对黑料攻击生效"，只认这三种。九秒剪辑、连麦、资格诉讼都**不是**黑料攻击。
- **投票**：由场控记入《投票记录表》的表决，包括举牌（锤/洗、听证、联合民调党内表决、辩论胜负）、书面选票（收视率、责任认定）、唱名中玩家支配的代表票、换将投票、269加时投票。闭眼竖拇指（直播带票）属于打赏，**不是**投票。
- **确凿曝光**：某人的真阵营被以下三种方式之一当众确认：本人亮出真阵营卡；公开背调的结果由DM宣读；孤狼「反咬上线」由DM确认。口头自称不算。
- **全民靶子**：每幕开始时民调最高的人（并列则全部是），本幕受到的黑料攻击伤害+1。在状态板上挂靶子牌。
- **银行**：遗产基金会/钱钱委员会/照妖镜/律所收款，统一由场控管理的筹码盒，可以无限找零。

## 2. 第1–3期分幕规则

### 2.0 三个跨期通用程序（每期都会用到，只讲一次）

#### 2.0.1 开幕收入（第2、3期阅读开始时由场控发放；第1期的初始资金已含此项）
1. **小额捐款**：每人+3资金。
2. **草根捐款**：上一期新闻周期结束时民调最低的人（并列全给）额外+2资金。
3. **跛脚鸭同情捐款**：民调为0的人+3资金（与草根捐款可叠加，见第7.3节）。
4. **新黑料卡**：每人从本期角色本封底附袋取出1张黑料卡（第2、3期各1张；终局以05为准）。
5. **全民靶子**：场控在状态板上把靶子牌挂到当前民调最高者名下。
- 因果自检：小额捐款是现实中大选年持续流入的小额网络捐款；草根捐款对应"被骂得越惨，支持者捐得越多"的现实规律，也是对《青楼2》"收益悬殊"差评 [已证实·研究报告1.4] 的追赶机制。

#### 2.0.2 走廊政治（通用私聊规则）
- **时长**：每轮3分钟，沙漏计时；每轮之间不留换场时间，沙漏倒下即开始下一轮。
- **场地**：东厅、西厅、自助餐区、露台四个区，每个区同时只能有一组谈话，一组最多3人。谁和谁走到一起是公开的，谈话内容是私密的。
- **邀约**：任何人可以邀请任何人；被邀请者可以说"下一轮"或拒绝。连续两轮没有人邀请、也没有邀请别人的玩家，第三轮由DM指派一组（防挂机，见第7节）。
- **公示台**：场控坐镇。资金赠予在这里记上"钱钱委员会公示板"；欠条在这里盖章生效；卡牌交易在这里登记一换一（登记卡名不登记内容）。走廊期间随时可以来办。
- **上线指令卡**：第2、3期第1轮走廊开始时，安德福、钱多多各可以把一张预印"⛳18"落款的指令卡（正文≤30字，自己手写）交给场控，场控以"球童送球"的方式私下递给各自的卧底（安德福→跟跟，钱多多→高文）。卧底可以用一张无落款的回执卡回复，同样由场控递送。第1期的指令卡预印在卧底的第1册里。
  - 因果自检：凭什么——这是两头吃三十年的旧通道，卧底只认⛳18落款的指令，这是他们入行第一天被教的"防伪"规则（以03为准）；为什么不当面说——钱多多和高文是"跨党无交集"的关系，两人在走廊里同进一个区就会被全场看见，书面通道是唯一不留公开痕迹的办法；为什么不换落款——卧底会把落款变化当作被冒充的信号，拒不执行。这也正是R5的铺垫：两名卧底对比指令卡时，会发现落款一模一样。
- **接头暗号**：见第6.1节。
- **DM动作**：翻沙漏、喊"换场"；盯住"一组最多3人"；记录谁连续两轮没动；处理技能申请。
- **裁决**：①走廊里的口头承诺没有任何效力；②有人偷看别人的角色本或卡牌，立即民调−2，被偷看的人可以要求其交出1张自己指定的卡（移植《搞钱》"不可偷、不可抢"，研究报告标注为已证实）；③走廊中不能发动任何"公开环节限定"的技能。

#### 2.0.3 新闻周期（每期最后一个环节）
按以下顺序执行，场控逐项打勾：
1. **惩罚检查**：本期没有任何公开动作的人，民调−1（"空过扣粮"精神，研究报告2.2标为多源推断）。
2. **民调夹紧**：把所有民调截在0–10之间；民调为0者翻成跛脚鸭（第7.3节）。
3. **草根预登记**：记下当前民调最低者，下期开幕发草根捐款。
4. **十月惊奇检查表**：DM按05的触发表逐项打勾（例如钱多多匿名捐款次数、喊深伪成功次数），**只记不翻**。
5. **午夜**：全员起立面向"镜头"（DM手机），DM倒数"3、2、1"，00:00:00拍一张合影，场控当场打印或投屏留档。**这张合影是第2期听证的关键线索**：账本每次发布时，全员都在镜头前。
6. **账本页发布**：DM扮演叉叉网，朗读本期的账本页（正文以03为准），进入**账本审判**。
7. **片尾**：贾不睡念下期预告，发下一张"本期我能做的3件事"卡。

#### 2.0.4 账本审判（每张账本页发布后执行一次）
1. DM朗读账本页，当事人可以先用10秒"深呼吸"。
2. 当事人**狡辩60秒**。可以用台词模板卡（见下）；也可以选择**沉默是金**，即不狡辩直接进入表决，表决时锤的伤害−1（社恐兜底）。
3. 当事人以外的全员同时举牌"锤／洗"。账本页**不能喊深伪**：五家媒体同时持有原件，照妖镜不受理。
4. 多数锤：当事人民调−2（全民靶子−3）。多数洗：当事人民调+1。平票：不变。
5. 技能窗口：琳达「律师函」可以在第2步之前宣布抵消（仅当事人是大象党成员）；高文「稳如发胶」对本期第一次黑料攻击自动生效，此时跳过表决。
- **台词模板卡·账本审判（示例）**：
  - "我承认我（账本内容），但请大家想一想，（反问一句）？"
  - "这件事有三个版本：我的版本、他们的版本，和真相。今天我只讲第一个。"
  - "如果这也算黑料，那在座各位（说出一个全场人人都有的毛病），请举手。"
- 借鉴来源：《搞钱2》"多人版《扒马褂》，各种圆谎笑到飙泪"的爆料互撕 [已证实·研究报告3.2]。

### 2.1 第1期 · 新年筹款晚宴（1月，95分钟）

**故事节点**：两头吃的遗产基金会在骑墙大酒店办新年筹款晚宴，《今夜不睡》全程直播。两党候选人轮流上台拍竞选广告、抢金主；基金会按遗嘱拍卖背书和遗物。午夜，"@老游说不死"贴出两头账本第1页。具体日期以03为准（本文件建议定在1月19日，见第10节R-01）。

**阅读量与内容要点**（第1册，6000–8000字，23分钟；各角色字数差≤20%，以02为准）：
- 人设、公开身份、签名台词、道具梗；
- 秘密（分"可以说的、不能说的、可以卖的"三栏）；
- 关系速查表（对其余7人的表面关系一句话）；
- 第1期任务：打赏小目标1个、拍卖意向提示1条；
- 开局资源与技能卡（技能卡单独印，不进正文）；
- 卧底：第1张上线指令卡（预印）；沼泽：两套暗号与两名卧底的名单；其余人：本阵营暗号。
- 字数控制：所有机制性内容一律做成卡片，正文只写故事和动机。

#### 2.1.1 自我介绍（4分钟，全员）
- 规则：按座位顺时针，每人25秒，说三样东西：名号、公开身份、签名台词。必须说出签名台词，DM当场判定"台词到位"（只要说出就算）。
- DM动作：贾不睡口吻串场，例如"感谢发胶哥，发型和他的政见一样稳定"。
- 社恐兜底：可以只念签名台词卡，不算失败。

#### 2.1.2 竞选广告与公开打赏（18分钟，全员）
**参与者**：4名候选人（辣椒、高文、麦克、跟跟）各拍一条60秒竞选广告；4名非候选人（梅、安德福、钱多多、琳达）各做一条30秒"赞助商口播"。按身份分工，不按性别（移植《青楼2》"才艺表演抢银票"的精神，研究报告1.2标为已证实；本作把"男撒钱、女表演"改为"人人既表演也打赏"）。
**步骤**：
1. 准备（2分钟）：每人从道具箱拿一件道具，看一眼自己的"广告/口播模板卡"。
2. 表演顺序：口播与广告交替，顺序为钱多多→辣椒→琳达→麦克→梅→跟跟→安德福→高文（高文压轴，拍"暴雨中发型不乱"，DM持喷壶）。
3. 每条表演结束后有**30秒打赏窗口**：任何人可以把资金筹码放进表演者面前的打赏碗，并大声报"某某打赏N"。场控同步记上公示板。
4. 打赏限制：每人在本环节的打赏总额**最少1、最多6**；不能打赏自己；打赏只能在打赏窗口内进行。
5. 全部表演结束后，**收视率投票**（书面，2分钟）：每人写一张选票，选出最佳广告和最佳口播各一个（都不能选自己）。
6. 结算：最佳广告民调+2，第二名民调+1；最佳口播民调+1、资金+2（由银行支付）。并列者全部获得该名次的奖励。
7. **打赏小目标**结算：每人第1册里有一个秘密的打赏小目标（以02为准，下附示例）。完成者在本环节结束时向场控出示角色本对应段落，从银行领2资金（"税务抵扣"）。
**打赏小目标示例**（正文以02为准，设计原则：目标本身会暴露一点立场，延续《青楼2》"打赏和竞拍本身就在暴露信息" [已证实·研究报告1.2]）：
| 角色 | 示例目标 |
|---|---|
| 钱多多 | 你给驴友党候选人的打赏总额＝你给大象党候选人的打赏总额，且双方各≥2 |
| 安德福 | 跟跟收到的打赏总额高于麦克 |
| 梅 | 辣椒的打赏收入全场第一 |
| 琳达 | 打赏麦克，同时当众说一句"真抠门" |
| 辣椒 | 打赏一位大象党成员（"我连敌人都请喝汤"） |
| 高文 | 打赏钱多多的口播（"老朋友，总要捧场"） |
| 麦克 | 打赏琳达，并说一句拉丁文 |
| 跟跟 | 你的打赏总额不超过全场最低的那个人（"永远比别人低半步"） |

**决策点**：花钱换人情、完成小目标，还是攒钱留给背书拍卖？给谁打赏，就是在向谁示好，全场都看得见。
**资源流动**：打赏是玩家之间的转移，总量不变；银行流出＝收视率口播奖2＋小目标每人2。
**名场面**：DM用喷壶喷高文，他要保持发型说完广告词；钱多多同时给两党打赏，DM追问"你到底押谁"。
**台词模板卡·竞选广告**："我是（名号），我批准了这条广告。我出生在（州），我相信（一个大词）。我的对手说（对手的口头禅），我只想说：（签名台词）。"
**社恐兜底**：可以只念模板卡，时长不足60秒也算完成；但不能拿收视率前两名之外的奖励。
**DM动作**：控时（每条表演举倒计时牌）；喷壶；串场吐槽；监督打赏窗口。
**边界裁决**：①打赏不足1的人，环节结束时强制从其资金中扣1，打赏给其上家（防挂机）；②资金不足6的人，打赏上限就是其全部资金；③收视率选票写了自己，作废。

#### 2.1.3 背书明拍（12分钟，全员）
**拍品**：8张背书卡（6人局6张，见第8节）。每张卡面印：机构名、所在州、议题、终局效果"与本州议题匹配时，为一张提名票+3"（终局效果以05为准）。终局地图海报从第1期起就挂在墙上，选举人票数公开。
**拍卖顺序**（由小到大，压轴最贵）：蓝点区·《肉肝三小时》专访 → 骰子州·币圈兄弟会 → 奶酪州·牛肉玉米联合会 → 仙人掌州·边境牧场主协会 → 轮胎州·工会大锅饭 → 烤肉州·代码与芯片协会 → 桃子州·退休老爷车俱乐部 → 钢铁州·钢铁工人联合会。
**规则**：
1. 英式明拍，起拍价2，每次加价≥1，口头举价。DM喊"一次、两次、成交"，每次间隔约2秒，落锤成交。
2. 成交者把资金交给银行（遗产基金会），领卡。
3. **每人在本环节最多拍得2张**（防止钱多多以15资金扫场）。拍得的卡此后可以按交易铁律一换一转手，转手不受2张限制。
4. 起拍价无人应价即流拍。全部拍完后，流拍卡按原顺序以起拍价1再拍一次；仍然流拍的，免费发给当前民调最低者（并列时由DM按座位顺时针从靶子下家起发）。
5. **烤肉州背书的提前用途**：第2期超级星期二中，烤肉州是三个初选州之一；持有者可以把这张卡亮给任一候选人，使其在烤肉州初选中+2（见第4.1节）。这让一部分前期道具在中期就有用，延续《青楼2》"前期竞拍拿到的道具在最后的机制环节很重要" [已证实·研究报告1.2]。
**决策点**：钢铁州19票的背书最值钱，但它排在最后，前面花光了就抢不到；烤肉州卡有两次用途。
**名场面**：DM切换拍卖师口吻，"这位先生出价5，是在为工人阶级发声吗？"
**DM动作**：拍卖师；报价；落锤；提醒"每人最多2张"。
**边界裁决**：①同时喊同一价，以DM先听到的为准，DM无法分辨时由出价者中民调低者得；②已经拍得2张的人举价，视为无效，不罚；③出价超过本人现有资金，视为无效并民调−1（"空头支票"）。
- 因果自检：凭什么一家基金会能拍卖"背书"？——背书卡是各团体领袖与两头吃签过的"站台约定"，两头吃死后约定随遗产归基金会，遗嘱写明拍卖给出价最高的政客，收入归基金会（以03为准）。为什么团体不自己选人？——它们本来就是两头吃"两边都押"的客户，宁可让价高者拿走，自己两头不得罪。

#### 2.1.4 遗物盲盒暗拍（6分钟，全员）
**拍品**：三只外观相同的盲盒A、B、C。公开的拍卖目录只列三件遗物的名称，不说明哪只盒装哪件：①回忆录手稿（附律所寄存物一件）；②第18洞记分卡；③播客耳机。盒内实际内容（以03为准，本文件建议）：
| 盒 | 内容 | 作用 |
|---|---|---|
| 装手稿的盒 | 回忆录手稿（节选卡）、**第三枚见证人印章**、律所通知信（不说明用途） | 印章三缺一的最后一枚；手稿持有人在终局"回忆录节选"事件中有决定权（以05为准） |
| 装记分卡的盒 | 第18洞记分卡（同组四人名单，含两头吃、安德福、钱多多、跟跟）＋黑料卡2张 | R8铺垫 |
| 装耳机的盒 | 播客耳机，标签写"老G专用"＋黑料卡1张 | R2与钱多多真相题的铺垫 |
**信息不对称**：三只盒子的封箱胶带各不相同，玩家可以看、不可以碰。角色本里有人认得胶带（例如梅认得自己打包手稿时用的《灰老太报》蓝胶带；麦克和钱多多认得蛋白粉赞助商的贴纸；以02为准）。这移植的是《孤城》"盲盒式拍卖"的信息差 [已证实·研究报告第4节]。
**规则**：
1. 每人领一张暗标单，可以对任意几只盒子各写一个出价（整数，可写0），出价总和不得超过本人现有资金。
2. 场控收单后同时开标。每只盒子由出价最高者得，按自己的出价付给银行。
3. 平价：民调低者得；仍平则抽签。
4. 一人可以拍得多只盒子。
5. 得盒后**当场开盒**，但只有得主能看盒内物品；印章是实体卡，持有情况不公开。
**决策点**：手稿盒里有什么用处不明的"律所寄存物"——值不值得赌？
**DM动作**：念拍卖目录；开标；监督只看不碰。
**边界裁决**：暗标单写错（总和超过资金），按从A到C的顺序截断到资金上限。
- 因果自检：为什么第三枚印章随手稿一起拍卖？——v1设定"手稿持有人等于出价最高的人，这是说客式的幽默"；具体动机以03为准。为什么琳达不当场说出寄存物的用途？——她的保密义务到两头吃死后满60天为止，第1期仍在保密期内（见下条）。

#### 2.1.5 琳达的保密期（第1期专用规则）
第1期中，琳达不得以任何方式（公开发言、私聊、纸条、暗示）透露定时公开合同的内容，包括刹车条款和印章的用途。有人向DM举报并且能**说出她透露的具体内容**，DM核实属实，即判琳达"被吊销执照"：她立刻失去全部技能，持续到本局结束。举报不实，举报人民调−1。第2期开幕起保密期届满，此后不受限制。7人和6人局没有这一条。

#### 2.1.6 走廊政治（15分钟，5轮）
按第2.0.2节执行。第1期没有指令卡递送（卧底的第1张指令卡已经在角色本里）。
**本期典型决策**：找本阵营的人对暗号；用欠条换背书卡；有人想买印章，但持有人还不知道印章是干什么用的。

#### 2.1.7 新闻周期（17分钟）
1. 结算（3分钟）：按第2.0.3节第1–4步；本期所有人都做过表演，惩罚通常不会触发。
2. 午夜合影（2分钟）：全员入镜，00:00:00。
3. **第1页发布与教学版扒马褂**（8分钟）：DM朗读第1页（对象辣椒，正文以03为准），先用1分钟讲解账本审判的四步，然后实跑一遍：辣椒狡辩60秒，其余人举牌。这一页是九页里最温柔的一页（R7伏笔）。

### 2.2 第2期 · 超级星期二之夜（3月，95分钟）

**故事节点**：超级星期二多州同日开票。账本第1页引发轩然大波，钱钱委员会因停摆借不到穹顶山，只好借酒店宴会厅召开紧急听证，传唤全部在场者。当晚，两头吃去世满60天后的第一个政治大日子，琳达的保密义务已经届满（日期以03为准）。午夜，第2、3页同时发布。

**阅读量与内容要点**（第2册，≤3500字，15分钟）：
- 第1期发生了什么（按角色视角写，各人看到的不同）；
- 本期新线索：每人1–2条，用于听证（例如钱多多知道"至尊版"产品的设计、琳达知道刹车条款）；
- 新黑料卡1张、超级星期二州情速览卡（三个州的代表票数）；
- 卧底：本期是否收到上线指令卡（由沼泽玩家在走廊第1轮决定，见第2.0.2节）；
- 第2期"三件事"卡。

#### 2.2.1 扒马褂直播间（20分钟，全员）
**参与者**：全员轮流做"爆料人"，被爆料的人做"当事人"，其余人做陪审。
**黑料卡**：每张卡印有编号（H01–H40）、**当事人姓名**、一句话黑料、一句"圆谎提示"（给当事人用）。黑料卡只能打给卡上写的那个人。每名角色名下的黑料卡中，**恰好有1张是深伪**（AI伪造，事情没有发生过），真伪表只在场控手里，正文以03为准。
- 因果自检：为什么会有深伪黑料？——世界观设定AI深伪广告无人监管（钱钱委员会3:3僵持），开盒智能"一句话开盒你"的产品就在市面上流通；角色本里的黑料来路都是"有人塞给你的"，持有人自己也不知道真假。为什么当事人知道真假？——事情发没发生过，本人最清楚。这就是本环节的信息差：**持卡人不知道真假，当事人知道**。
**出牌顺序**：从当前民调最低者开始，顺时针一圈，每人轮到时选择：打出1张黑料卡，或空过。只走一圈。
**单次爆料结算**：
1. **爆料**：爆料人用模板朗读卡面（20秒）。模板："据可靠消息，（当事人）曾经（卡面内容）。我不评论，我只是转发。"
2. **技能窗口**：当事人若是大象党成员，琳达可以宣布用「律师函」抵消，此卡作废；若当事人是高文且这是他本期第一次受到黑料攻击，「稳如发胶」自动生效，此卡作废。作废的卡进入DM档案，爆料人不受罚。
3. **当事人三选一**：
   - **狡辩**：60秒圆谎，然后陪审表决。
   - **认罪换豁免**：说出"我认"。当事人民调−1，并从自己手中挑1张黑料卡交给爆料人（手里没有就付给爆料人1资金）；本环节内此后不能再被爆料。
   - **喊深伪**：当事人付1资金给银行（照妖镜鉴定费），场控查真伪表，DM宣读结论。**是伪造**：此卡作废，当事人民调+1，爆料人民调−1，场控在十月惊奇检查表上记"喊深伪成功"+1。**是真的**：DM宣读"照妖镜鉴定结论：大概率是真的"，当事人只有30秒狡辩，然后陪审表决，锤的伤害+1。这就是"说谎者红利"的反面：喊冤被打脸（移植本项目旧方案B）。
4. **陪审表决**：除爆料人和当事人外，全员同时举牌"锤／洗"。**按表演投，不按真相投**——陪审只判"这段圆谎能不能说服观众"。
5. **结算**：多数锤，当事人民调−2（全民靶子再−1，喊深伪被打脸再−1）；多数洗，当事人民调+1，爆料人民调−1（"造谣反噬"），麦克若在"粗人人设"有效期内被洗白，额外+1；平票，无事发生。无论结果，打出的卡都进入DM档案，不回到任何人手里。
**限制**：每人每次扒马褂最多被爆料2次；跛脚鸭不能被爆料；已认罪者本环节免疫。
**决策点**：打不打、打谁、打哪张（可能是深伪）？被打时是硬扛、认罪还是赌一把喊深伪？
**资源流动**：黑料卡减少约5–8张；民调在玩家之间重新分配；银行收入=喊深伪费用。
**名场面**：真黑料被当事人喊成深伪，照妖镜宣布"大概率是真的"后的30秒狡辩。
**台词模板卡·狡辩**："首先，这不是我；其次，就算是我，也是（一个高尚的理由）；最后，各位扪心自问，（反问）？"
**社恐兜底**：可以选"认罪换豁免"跳过表演，代价是民调−1，没有额外惩罚。
**DM动作**：主持人口吻；计时；查真伪表；宣读照妖镜结论；在投票记录表上记录陪审举牌。
**边界裁决**：①打出的卡写的不是被指定的当事人，此次爆料无效，爆料人民调−1；②喊深伪时资金为0，不能喊；③两个技能（律师函、稳如发胶）对同一张卡同时可用时，稳如发胶优先自动生效，律师函不消耗；④当事人是跛脚鸭，此卡不能打出。
**借鉴来源**：《搞钱2》"爆料互撕＝多人版《扒马褂》，圆谎笑到飙泪" [已证实·研究报告3.2]；"认罪换豁免""喊深伪"来自本项目旧方案B，非参考作品。

#### 2.2.2 "谁是泄密者"听证（15分钟，全员）
**场景**：DM戴上钱钱委员会主席的名牌（"本委员会3:3，所以今天只听不判……不对，今天要判"）。
**步骤**：
1. 开庭（1分钟）：DM宣读传票，"账本第1页于00:00:00发布，本委员会要查明是谁泄密"。
2. 出示公开线索（2分钟）：①第1期午夜合影（发布那一刻全员都在镜头前）；②叉叉网的公开说明："@老游说不死"账号注册于两年前，注册方为"老游说不死有限公司"；③开盒智能"定时公开·不可撤销至尊版"的公开广告单页，广告词"连我们自己都删不掉"。玩家手中的私有线索（钱多多知道产品机制，琳达知道合同，辣椒、麦克手里有来历不明的印章）由各人决定是否拿出来。
3. 证词（5分钟）：每人20秒，"那晚午夜我在……"，可以指控别人。证词是强制的，不算公开动作。
4. 自由质询（3分钟）：任何人可以向任何人提问，DM主持，每问每答不超过15秒。
5. **责任认定投票**（1分钟）：书面选票，选项为任一在场玩家，或者"不是在场的人"。不能弃权。
6. **按票执行，不按真相执行**（1分钟）：得票最多的若是一名玩家，认定其为泄密者：民调−2，罚款2资金交给银行（不足则扣光）。多名玩家并列最多：每人民调−1、罚款1。"不是在场的人"得票最多或与最高者并列：无人受罚。
7. **R1揭示**（2分钟）：DM问琳达"律师，你有什么要说的吗？"琳达有10秒决定是否当众公开合同（公开即算她的公开动作，民调+1，"律师的诚信"）；她不公开，DM即扮演律所朗读公告。两种方式公开的内容相同（以03为准），至少包括：账本是两头吃生前设定的定时公开，律所按合同发布，任何人都删不掉；**刹车条款**：三枚见证人印章同盖一份申请书，可以把一页尚未发布的账本顺延到大选之后，全场只能用一次；印章已寄给辣椒、麦克，以及回忆录手稿的持有人。
8. **蒙冤补偿**：被认定的泄密者民调+3、退还罚款；每一个投票给他的人付给他1资金"道歉费"（没有资金则民调−1代替）；每一个投"不是在场的人"的玩家从银行领1资金（"先见之明"）。
**决策点**：要不要说出自己知道的线索（说出来可能暴露自己的秘密）？要不要趁机冤枉对手？
**名场面**：全场合力冤枉一个人，结果发现泄密者是一台定时器，所有投错票的人排队给他道歉付钱。
**台词模板卡·道歉**："我为我的投票道歉。这一块钱，不代表我错了，代表我有钱。"
**DM动作**：主持听证；出示三件公开线索；收选票、唱票；扮演律所朗读公告；监督道歉费。
**边界裁决**：①有人在第5步前就公开说出"是定时公开"，不影响流程，仍按票执行；②琳达在10秒内没有开口，视为不公开；③被认定者若是跛脚鸭，民调不再下降，但罚款照扣，补偿照发。
**借鉴来源**："按票执行、不按真相执行"的责任认定投票来自本项目旧方案D；"多数决＋少数派受罚"的投票张力参考《拆迁》 [已证实·研究报告第4节]。
- 因果自检：律所为什么在今天发公告？——保密期届满，且律所作为合同执行人被国会听证点名，按惯例必须声明自己"只执行合同"，以免被认定为泄密方（以03为准）。为什么律所公告点名辣椒和麦克？——印章是律所亲手寄出的，寄件记录本来就在律所；第三枚随手稿进了拍卖，律所不知道拍到谁手里。

#### 2.2.3 联合民调（8分钟，可砍）
**参与者**：两党各自的全体成员（按胸牌分党）。
**规则**：
1. 每党在本期最多申请一次，免费。两党同时进行：驴友党进东厅，大象党进西厅，各2分钟。
2. 党内商定3个名字，**必须同时包含两党的人**（可以包含本党成员）。商定方式：党内举牌表决，记入投票记录表；平票时由党内民调最高者决定。
3. 一党代表把名单交给DM。DM在结果卡上写"有沼泽"或"没有沼泽"，扣着交回；该党全体成员同时翻看。DM不说明是谁，不涉及卧底。
4. 结果只有申请党的人看过。对另一党，可以如实转述，也可以撒谎。
**决策点**：选谁进名单？本党的沼泽成员会想方设法把自己排除在外。
**借鉴来源**：《青楼》"三人同时验身，好人多于坏人亮绿光，坏人多于好人亮红光" [已证实·研究报告1.2]，本作改为只回答"有没有沼泽"。
**DM动作**：发结果卡；在状态板记录两党各查了谁。
**边界裁决**：党内只剩1人时（例如其余人都被换出），此人独自决定；名单只含一党的人，DM退回重填，计时不停。
- 因果自检：凭什么一个"民调"能查出沼泽？——游戏化处理：《灰老太报》和押宝网联合做的"金主关系穿透调查"，能查出谁收过沼泽俱乐部的会员费，查不出谁是卧底，因为卧底从没交过会员费（以03为准）。

#### 2.2.4 走廊政治（12分钟，4轮）
按第2.0.2节执行。第1轮开始时递送上线指令卡。本期典型决策：印章持有人开始被围堵；超级星期二前的资金拼盘；对暗号、交换联合民调结果（真真假假）。

#### 2.2.5 超级星期二暗标（12分钟，全员）
完整规则见**第4.1节**。时间分配：讲解与填单4分钟（第一次暗标，讲细一点）→ 收单1分钟 → 逐州开标6分钟（DM按冲浪州→牛仔州→烤肉州顺序，每州先开驴友党再开大象党）→ 公布代表票累计1分钟。
**DM动作**：新闻主播口吻开票；场控按换算表算代表票。
**定位**：这是终局"州得分"暗投的完整预演（移植本项目旧方案B），玩家在这里第一次体验"暗中把钱投给别党的人"。

#### 2.2.6 新闻周期（13分钟）
1. 结算（2分钟）：第2.0.3节第1–4步。**印章状态**：从本期起，三枚印章同盖一份申请书，即可在任何一期新闻周期开始前，向DM（律所）提交顺延申请，见第6.8节。
2. 午夜合影。
3. **第2页**（4分钟，当事人麦克，正文以03为准）：账本审判。R2揭示：麦克是名校哲学博士，和琳达的五年骂战写在同一份商业合同里。**粗人人设彩蛋从这一刻起永久失效。**
4. **第3页**（4分钟，当事人钱多多）：账本审判。页面写出"至尊版"的第一位客户是"老游说不死有限公司"。这个名字和辣椒小额捐款里的空壳公司同名，是R7的玩家手中铺垫。
5. 片尾（3分钟）：快讯；发第3期"三件事"卡；宣布饭点规则（不得交易）。
**台词模板卡·麦克专用**："没错，我是博士。博士也是粗人——粗通哲学的粗。"
**台词模板卡·钱多多专用**："我卖的锁，把我自己锁住了。这说明什么？说明产品质量过硬！"
**第2期DM动作总表**：主持扒马褂；查真伪表；扮演钱钱委员会和律所；主持联合民调；超级星期二开票；两次账本审判；在状态板记录：代表票、印章持有人、联合民调结果、喊深伪成功次数、匿名捐款次数。
**第2期产出**：超级星期二代表票格局；刹车条款公开、印章争夺开始；第一批"谁可能是沼泽"的情报；麦克人设翻车。

### 2.3 第3期 · 同夜党代会（8月，85分钟）

**故事节点**：两党党代会同夜在骑墙大酒店开幕，驴友党在东厅，大象党在西厅，中间只隔一个自助餐区。春季初选已经全部结束，代表票格局已定，今晚唱名、提名、选搭档。午夜，第4、5、6页发布；两名卧底在散场后必须做出选择。

**阅读量与内容要点**（第3册，≤3000字，12分钟）：
- 3月到8月之间发生了什么（春季初选、各人的经历）；
- 春季初选代表票：DM在阅读开始时公布（按第4.2节计算，饭点期间已预算好）；
- 新黑料卡1张；唱名台本卡（每人负责宣读1–2个州的唱名词）；
- 卧底：两名卧底各自读到一段"我开始怀疑上线"的独白，以及摊牌三选一卡（**坚守／假戏真做／孤狼**，夹在第3册封底，单独密封）；
- 琳达：背调技能本期解锁的提示；
- 第3期"三件事"卡。

#### 2.3.1 唱名投票·首轮（8分钟）
完整规则见**第4.3节**。东西两厅交替唱名：DM在两厅之间来回跑，每念完东厅一个州就转到西厅，制造"同夜开会"的喧闹感。
**名场面**："伟大的冲浪州，冲浪板和发胶的故乡，骄傲地投出12票给——"（停顿，DM敲锣）。
**台词模板卡·唱名**："主席先生／女士，（州名），（一句吹嘘本州特产的话）的故乡，骄傲地将（N）票投给（候选人）！"
**社恐兜底**：唱名词可以照卡念；不想念的人可以把唱名卡交给DM代念，不扣分。

#### 2.3.2 经纪人党代会（10分钟，仅首轮有党无人过半时开；可砍）
完整规则见**第4.4节**。两党都已产生提名人时跳过，节省的10分钟并入走廊（多开3轮）或提前进入搭档环节。

#### 2.3.3 走廊政治（12分钟，4轮）
按第2.0.2节执行。第1轮开始时递送上线指令卡。本期典型决策：提名人挑搭档，搭档人选开价；两名卧底找机会私下对比指令卡的落款（R5）；沼泽抢副手位。

#### 2.3.4 搭档与背调（12分钟）
完整规则见**第4.5节**（搭档）与**第6.3节**（背调）。时间分配：先手提名人求婚≤4分钟 → 后手提名人求婚≤4分钟 → 联姻仪式2分钟 → 背调窗口2分钟。

#### 2.3.5 资格诉讼（5分钟）
完整规则见**第4.6.3节**。本期最多审一案。没有人起诉时，此5分钟并入新闻周期。

#### 2.3.6 新闻周期（14分钟）
1. 结算（2分钟）：第2.0.3节第1–4步。
2. 午夜合影。
3. **第4页**（当事人梅）→ **第5页**（当事人高文）→ **第6页**（当事人跟跟），各3.5分钟，依次账本审判。第5、6页只是**旁证**：改党籍和跨党捐款都能解释，狡辩空间要留足（正文以03为准）。
4. 片尾（1.5分钟）：贾不睡："今晚的提名人，明早还是今晚的提名人吗？我们进广告。"——不，先别进，还有一件事。
**台词模板卡·高文专用**："二十年前我就在这里，二十年后我还在这里，发型没变，心也没变。"（他自己知道这句话哪一半是假的。）
**台词模板卡·跟跟专用**："年轻时谁没站错过队？我后来站到了正确的一边——站在总统身后半步。"

#### 2.3.7 摊牌信封（12分钟，全员）
完整规则见**第6.5节**。时间分配：DM讲解3分钟（对全员讲同一套话，不提卧底人数）→ 全员在隔板后同时填写4分钟 → 场控收信封1分钟 → DM用2分钟独白收尾（"今晚每个人都交了一封信。有的信是空白的，有的信不是。"）→ 缓冲2分钟。
**第3期DM动作总表**：公布春季初选；主持唱名（两厅来回）；必要时主持经纪人党代会；主持搭档仪式；处理背调；扮演九老会；三次账本审判；收摊牌信封。状态板记录：两张提名票、搭档州籍与年龄核验、背调结果（及是否公开）、确凿曝光名单、觉醒结果（广告期间填）。
**第3期产出**：两组提名票；觉醒结果；协同判定；卧底首次被确认的可能。
