## 1. 终局总览

### 1.1 一句话
**《今夜不睡·大选特别季》最终期：先开票，定谁当选；再翻卡，定谁赢。**
终局浓缩了大选年最后六周（Y年9月底到11月7日大选夜）。本格口径：日期以03为准，本文件只用三个硬节点：第一场总统辩论之夜、十月、大选日（Y年11月7日，周二，即"十一月第一个周一之后的周二"）。

### 1.3 两次高潮的设计意图
| 高潮 | 时刻 | 揭示什么 | 为什么要分两次 |
|---|---|---|---|
| **第一次：开票**（F5） | 1:23–1:31 | 谁当选总统 | 这是**表层**的输赢，全场都能看懂。红色海市蜃楼让领先者在开票途中换手，制造"看票"的紧张感。这一刻大家欢呼或哀嚎的对象是**胸牌**（驴友党或大象党） |
| **第二次：翻卡**（F6） | 1:31–1:35 | 当选者的**心**属于谁；沼泽有没有收到账 | 这是**里层**的输赢。刚才欢呼的人可能当场判负，刚才哀嚎的人可能是赢家。"两边都是我的人"在这一刻兑现 |

〔设计〕第一次高潮奖励"打得好"，第二次奖励"看得准"。玩家在F1–F4的每一笔暗投，都同时押在这两次高潮上：钱投给哪张**票**，决定第一次；那张票上站的是哪颗**心**，决定第二次。所以本格和推理在终局并不是附属品，它决定了钱该往哪里投。

### 1.4 每个阶段的核心决策
| 阶段 | 核心决策 | 谁最纠结 |
|---|---|---|
| F0 | 要不要自曝？要不要换将？换谁？ | 被确凿曝光的提名人所在党；卧底 |
| F1 | 辩论里要不要冒险点名对手；暗投时是"公开站台挺自己票、暗中投对面"，还是表里一致 | 卧底、沼泽 |
| 午夜 | 锤还是洗：锤死提名票上的人会推风向，但锤的可能是自己人 | 全员 |
| F2 | 惊奇怎么接；**终极特稿发不发、点谁**；换不换将；锁哪个州 | 梅、提名人 |
| F3 | 三枚印章凑不凑：压下第9页，保谁、放过谁 | 辣椒、麦克、手稿持有人、沼泽 |
| F4 | 最后的钱：投、攻击、还是留3块钱重计 | 全员 |
| F5 | 重计付不付；269时令牌卖给谁、换什么官 | 令牌持有人 |
| F6 | 无（结算）；复盘才开始算账 | — |

〔防挂机〕终局没有人出局。不在提名票上的玩家照样投放、站台、攻击，在辩论和广告里当评委，手持刁钻问题卡。被换下的人以独立身份参选，手里有3枚分票标记。269加时中，令牌按投放额发放，任何人都可能变成造王者。
