### 0.3 规则书措辞（宪法与选举硬知识，供角色本引用）
- **同州搭档**：规则书写作——"**【规则书简化说明】**宪法第十二修正案规定，选举人投票时，总统票和副总统票至少有一票要投给不是本州居民的人。所以同州搭档并不违宪，但这个州的选举人不能把两票都投给这组搭档，在势均力敌时可能导致副总统无人过半、改由参议院选出。为了省掉这层计算，本游戏简化为：**同州的两人不能组成一张提名票**。"钱多多花2资金"改籍"，对应的是现实里候选人在提名前把选民登记迁到另一州的做法（以04/05为准）。
- **269平局**：规则书写作——"现实中由新一届众议院在得票前三名中选总统，**每州代表团一票，须得到过半数州（26州）**；参议院在副总统得票前两名中选副总统，每位参议员一票，须全体参议员过半数（51票）。到就职日众议院仍未选出总统时，由已选出的副总统当选人代理总统。本游戏用'州代表团令牌'模拟这一过程（详见05）。"
- **副总统主持计票**：规则书写作——"副总统以参议院议长身份主持国会联席会议计票，职责只是程序性的：开启证书、宣读结果。2022年《选举计票改革法》已把这一点写进法律，副总统无权拒绝或改动任何一州的结果。"这就是跟跟「礼仪之锤」彩蛋的法理来源。
- **年龄资格的时点**：规则书写作——"宪法要求总统'年满三十五岁'。通行理解是在就职时满35岁即可，参议院也有当选时未满龄、到宣誓时满龄即可就任的先例。"琳达的资格诉讼正好卡在这个问题上：她主张"选举人12月投票时辣椒只有34岁"。这是一个有学术争论、实际上会输的诉讼，与v1"诉讼只伤民调，不改变资格"一致。

### 0.4 NPC游游·两头吃：动机档案（回应总策划问题1）
> 本节只写人物动机和决策逻辑，用来回答"他为什么这样设计死人开关"。涉及的事件和日期都是建议值，以03为准。账本正文以03为准。

**基本信息**：Y−79年生，Y−1年12月18日在第18洞倒下，享年78岁。早年确诊心脏病，身边人都知道他"随时可能走"。信条："沼泽只收账，不坐庄。"他有一家只用来办私事、从不走沼泽账的公司：**老游说不死有限公司**。小狗"选票"、辣椒第一次竞选的钱、死人开关的合同，都走这家公司【修订#3】。

**① 两年前他发现了什么**
两个弟子起草了交权书，附件是一份"坐庄路线图"：1月拿筹款晚宴做资金池；3月以前用麦克的"博士加假离婚合同"把他打出初选，保跟跟出线；10月用辣椒的"影棚厨房加黑钱小额"让她出局；8月锁定两张提名票，最好再把自己人塞进副手位；11月不管谁赢，赢的都是沼泽的人。草稿是在骑墙大酒店商务中心打印的，而酒店是两头吃的产业，打印日志直通他的邮箱（发现途径以03为准）。

**② 为什么不直接清理门户**
| 看似更简单的做法 | 他为什么不做 |
|---|---|
| 曝光两个弟子 | 说客唯一的武器就是曝光，但三十年的每一笔两头交易，对手方都是他自己。在世时曝光弟子，等于自首 |
| 把两颗种子收回来 | 卧底网络是他亲手设计的单线结构："师父→弟子→种子"。跟跟只认安德福，高文只认钱多多，两颗种子根本不知道他是谁。切掉弟子，种子要么断线，要么被弟子带着一起暴露。他舍不得这两颗种子 |
| 当面摊牌，用把柄威慑 | 一旦摊牌，钱多多手里的技术和安德福手里的党鞭权力足够让他们两年内把局改掉。威慑只能拖延，拖不过他的心脏 |
| 自己活着守到大选 | 他知道自己可能等不到大选年。他需要一个**在他活着时什么都不做、他死了或下台时也照样运转**的东西 |

结论：他要的是一个**跟他本人的在位状态绑定的、只对准这一届大选的保险**，而不是报复。

**③ "被夺权"在机制上如何触发**
- 合同要求每周一本人到律所当面签"生存确认"，律所只认本人到场，不接受代签或委托。签了就顺延一周。
- 被夺权有两种可能：①他被迫交权，此后自愿不再去签。一个被逼下台的说客失去了全部保护，被拉去当替罪羊是迟早的事，他宁可同归于尽。②他被胁迫继续签。合同里有一句"胁迫暗语"：签字时如果说"今天果岭很慢"（平时说"今天果岭很快"），律所立即启动发布日程。弟子不知道开关存在，所以这条从没用上，但它堵住了"把老头软禁起来逼他签"的漏洞。
- 死亡与被夺权按同一种情况处理：他一死，弟子就会接管沼泽，坐庄计划就会启动。对开关来说，这两件事是同一件事。
- **只对准Y年**：漏签后，律所不立即发布，而是按"Y年政治日历"逐页发布。合同在Y+1年1月20日正午到期，到期后由律所销毁钥匙。如果他平安熬过这一年，什么都不会发生。【修订#4：v1只写"签了就顺延"，没有写到期日和胁迫条款】

**④ 为什么分九页、为什么一页一页地滴**
说客的老规矩："一次全倒是新闻，一页一页滴是连续剧。"九页一次性发出去，只能占一天的新闻周期；分九次发，就有九个新闻周期，每一次都恰好落在坐庄计划的一个关口上。

**⑤ 为什么是这个顺序：三条原则**
1. **打疫苗（第1、2页）**：路线图里打算拿来致命一击的两颗子弹，是辣椒和麦克的旧事。他抢先把这两件事放出来，而且只放最轻的那一层：辣椒那页只写影棚和"匿名寄来的狗"，不写钱从哪儿来。时间选在离大选最远、伤害最小的时候：辣椒那页离大选还有近十个月，麦克那页赶在超级星期二投票结束后的午夜。另一层是说客的定调术，"谁先说，谁定调"：由一个死人用温和的口吻说"他其实是博士"，比由对手说"他欺骗粉丝五年"轻得多。所以即使04把第2页的发布时点放在第2期开场，这条逻辑照样成立。到了十月，"旧闻不是新闻"，弟子的子弹就打空了。这就是"他最疼的人第一个被曝光"的原因：**曝光得越早，伤得越轻。**
2. **先让他们怕，再告诉他们是我（第3页）**：第1页发出后，他故意留出一个半月，让全场、尤其是两个互相提防的弟子彼此猜疑"谁在泄密"。等到超级星期二，第3页才亮出机关：至尊版的第一位客户就是"老游说不死有限公司"。这一页的作用是终止猎巫、保护无辜者，同时告诉弟子"删不掉"。
3. **剥洋葱，从外到内（第4–9页）**：第4–6页（工具人梅、两颗种子的旁证）放在党代会午夜，也就是提名已经产生之后。他不拦种子登顶，而是让种子先长到最高处，再让全世界看见它的根，逼种子自己选边。第7、8页（掩护者琳达、操盘手安德福）放在第一场辩论的午夜，正好在两张提名票当面对决的时候切断操盘线。第9页（沼泽名录）放在大选前夜：越早公开，弟子越有时间重组。第9页不点名种子，因为"名字我带走了"，选边的机会留给种子自己。

**⑥ 为什么挂在政治大日子**
九个发布时点，就是路线图上弟子自己定下的九个关口。"你们每走一步，我都在同一天跟你们对一次账。"第1页挂在就职日倒计时一年的零点，这是最早的"一年后谁宣誓"的时刻（v1"每到政治大日子的午夜"不变，具体日程以03为准）。

**⑦ 为什么设刹车（三枚印章）**
他担心自己算错，某一页误伤无辜，比如第9页那封信可能在大选前夜毁掉辣椒。所以他留了一次反悔的机会，但只交给三个"永远坐不到一张桌前"的人：辣椒、麦克，以及出价最高的手稿持有人。想压下一页，先学会合作。

**⑧ 交权书背面那行字**
v1写的是"交权书原件背面"。本文件建议改为：**两年前那份交权书草稿的背面**。他发现草稿后，在背面写下"我早知道是你们。开关不是为了报复，是为了让你们记得——账，总是要还的"，锁进保险柜，死后随遗物到了律所，复盘时由DM出示。这样"早知道"三个字是字面意义上的早知道，也避免了"心脏病发作的人还在写字"的漏洞【修订#5】。第18洞那天他读完交权书原件，只说了一句"你们终于来了"，就倒下了。跟跟听见了这句话（见跟跟档案）。
