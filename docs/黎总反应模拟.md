## 黎总反应模拟

前提：对美国业务不熟，对投入极度谨慎，又非常想要真正的成功，控制欲强，事无巨细。

### 一、他拿到方案后的第一个小时

他不会先看 Big Idea。他会翻到钱的表，先找三个数：这次要批多少、最坏亏多少、什么时候回来。然后他会把 58 万和 42.3 万加在一起，说"一百万美金"。

接着他会问四句话，几乎一定按这个顺序：

1. **"58 万是谁算出来的？每一项的报价单在哪？"** 他要看到首发店的租约报价、微仓的合同、车队的价格。没有报价单的数字，他会当成拍脑袋。
2. **"6,000 台是怎么来的？去年一台没卖过，凭什么？"** 他会盯着 1,448 和 6,000 的差距，认为 6,000 是为了让账好看。
3. **"纽约开店？谁去管？你人在哪？"** 他会立刻想到他看不见、管不到。
4. **"原来的方案不是说 2029 年才回本吗，现在怎么变 2028 年了？"** 他会怀疑数字被改过。

### 二、他会说的话，和话背后的意思

| 他说 | 他的意思 | 怎么接 |
|---|---|---|
| "先把亚马逊做起来再说，别搞这么多花样。" | 我只懂看得见的渠道，花样等于失控。 | 不辩论。给他单台账：亚马逊每台 69 美元，纽约 222 美元，同一台货。问他要 69 还是 222。 |
| "Smeg、Marshall 是人家的牌子，我们是新牌子。" | 我不信我们能做到人家的样子。 | 承认。Smeg 用了 30 年，我们只借它的方法，不借它的结果。目标方案里限量版只占 1,100 台，不是全部。 |
| "联名要给人家版税，凭什么？" | 我不愿意分利润给别人。 | 算给他看：899 美元的版本给 10% 版税还剩 373 美元，599 美元的不给版税只剩 69 美元。 |
| "纽约一小时送达，出了事谁负责？" | 我怕美国的法律和赔偿。 | 微仓商业租约、货物保险、产品责任险，三份文件的报价一起给他。 |
| "这个 1977 大停电，美国人真的在乎吗？" | 我不了解美国文化，不敢赌。 | 不要解释文化。给他看三件事的 50 周年都在 2027 年，然后说：这是免费的。 |
| "万一预售卖不掉，定金要退，怎么办？" | 我怕丢脸。 | 预售目标 500，闸门 300。不到 300，第二期不放，首批照常走亚马逊。最坏损失第一期 14.5 万。 |
| "分三期可以，但每一期我要签字。" | 我要控制权。 | 给。闸门本来就是为他设计的。把每期的放款条件做成一页纸，他签。 |
| "这么多事，你一个人干得了吗？" | 我不放心你，也不放心我看不到的人。 | 给责任表。每个装置一个负责人，每周一个数。他每周一收到一张表。 |
| "工厂这边我来安排，产能没问题。" | 这是我的地盘，别教我。 | 只要一句书面确认和一个日期。 |

### 三、他会卡在哪三件事上

1. **58 万本身。** 他的参照系是国内，国内 58 万美金能开十家店。他会反复砍：店能不能不租、车队能不能不要、公关能不能自己做。要准备一个 40 万的缩减版：店改 6 个月、活动砍到 8 个、公关砍到 4 万，销量按 4,500 台算，经营打平。他砍完有台阶下，方案还站得住。
2. **纽约开店这件事。** 他会说"先不开店，线上做"。但没有店就没有 drop，没有 drop 就没有排队，没有排队就没有内容。要让他明白店是内容工厂，不是零售点。用 Apple 的话说：店是最贵的广告，也是最便宜的。
3. **他看不见。** 他会要求每天汇报，要看每一笔开支。给他一个周报模板，固定每周一发，内容只有数字：卖了多少、花了多少、下周要花多少。比他开口要之前先给。

### 四、他最后会怎么决定

- **CES 42.3 万，会签。** 场地已经付了，他没有退路。但他会要求制作费再压，运营费不超过 8 万。
- **纽约计划第一期 14.5 万，大概率会签。** 条件是每一项有报价单，他每期签字。
- **第二、三期，他不会现在承诺。** 他会说"到时候看"。这正是闸门的设计。不要逼他现在批 58 万。
- **工厂产能承诺，他会口头答应，书面拖。** 要在 CES 前拿到书面的，否则预售不敢开。

### 五、三条原则

1. **先给账，再给故事。** 他对故事免疫，对单台账不免疫。所有创意都翻译成每台多赚多少钱。
2. **每一笔钱都有报价单和退出条件。** 他怕的不是花钱，是花出去收不回来又不知道为什么。退出条件写得越清楚，他批得越快。
3. **让他赢。** 分期放款、每期签字、周报、工厂产能由他拍板。他要控制，就把控制点设计成不伤害方案的地方。
