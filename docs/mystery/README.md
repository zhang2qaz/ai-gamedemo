## 🦖 给小学生的《恐龙蛋失踪之夜》

**怎么玩**：打开网址 → 点「恐龙蛋失踪之夜」那张卡片 → 输入名字 → 「创建房间」，把房间号发给一起玩的人。两个人就能开始（必须有人演一鸣和小米）；第三、四个人可以演大壮、朵朵，没人演的时候电脑替他们回答问题。

- **故事**：博物馆"小小讲解员过夜营"，四个三年级学生睡在恐龙大厅里。22:30 停电十分钟，灯亮以后，展柜盖得好好的、锁也锁着，6800 万岁的恐龙蛋化石却不见了。没有人受伤，也没有吓人的情节。
- **真正的剧本杀玩法**：玩家中间可能藏着一个"**隐藏者**"——真正拿走恐龙蛋的人，只有他自己知道（电脑演的营员和大人也有嫌疑）。隐藏者可以说谎、可以抢先拿走线索、可以把怀疑引到别人身上；其他人是**侦探**，不能说谎，但可以守着自己的秘密（说"这是我的秘密"）。开场会把这些规则讲清楚。
- **推理**：湿沙坑上的鞋印、黑暗里只看得见的夜光手环、监控录像和配电箱的时间、谁和谁在一起……把几条证据链拼起来，排除不可能的人。里面有一个专门的陷阱，只看表面就会冤枉好人。
- **博弈**：
  - 🪙 **工具拍卖**：每人 10 个金币，同时出价拍手电筒、放大镜、紫外线灯（能照出真蛋）、讲解员徽章。最高价一样，谁也拿不到；剩下的金币最后每 4 个换 1 分。隐藏者也会出价。
  - 🤫 **秘密时刻**（第二轮搜线索之前）：侦探要不要公开自己的秘密卡？不公开（卡片和嘴上都不说），最后加 2 分，但守秘密的人被投一票扣 1 分；公开了，大家更快抓到隐藏者，每个侦探都能拿团队奖。隐藏者可以公开一张"假的秘密卡"。
- **最后**：侦探投票回答 4 个问题（谁拿的、蛋在哪、为什么、停电是怎么回事）；隐藏者把自己的一票投给别人，侦探们投错得越多，隐藏者得分越高。然后看每个人的结局、真相复盘（时间线、三条证据链、每个人的秘密、博弈复盘）和分数，侦探按分数拿金 / 银 / 铜牌。
- 每段字旁边都有「🔊 读给我听」；打开「自动朗读」后，新的内容会自动读出来。

## 最简单的玩法（不用懂代码，Mac 电脑）

1. 点这个链接下载游戏：<https://github.com/zhang2qaz/ai-gamedemo/archive/refs/heads/claude/trump-era-murder-mystery-ypz5xa.zip>，下载好后双击解压。
2. 打开解压出来的文件夹，双击 **「开始剧本杀.command」**。
   - 第一次会多等几分钟（自动下载、准备游戏），之后每次大约十几秒。
   - 准备好后，浏览器会自动打开游戏页面；黑色窗口里会写着给其他玩家用的地址。
3. 你在浏览器里输入昵称、点「创建房间」；其他玩家（和你连同一个 Wi‑Fi）用手机或电脑打开黑色窗口里写的地址，输入房间号加入。
4. 玩完了，关掉黑色窗口即可。

如果第一次双击时提示"无法打开，因为无法验证开发者"：在文件上**右键 → 打开 → 再点「打开」**；如果还是打不开，打开「系统设置 → 隐私与安全性」，往下拉，点「仍要打开」。以后直接双击就行。
如果提示电脑没有安装 Node.js，它会自动打开下载页：下载「LTS」版安装包装好，再双击一次「开始剧本杀.command」。

## 怎么开一局

剧本杀走的是自定义服务器 `server.ts` 上的 WebSocket（路径 `/ws-mystery`），所以要用它启动，**`npm run dev`（`next dev`）不带联机，开不了房**。

```bash
npm install
npm run start:mp          # 先 next build，再用 tsx server.ts 启动（默认端口 3000）
# 本地开发（热更新）：DEV_MODE=1 npx tsx server.ts
```

1. 玩家甲打开 `http://<服务器地址>:3000/mystery`，输入昵称，点「创建房间」，拿到 4 位房间号。
2. 把房间号（或带 `?room=房间号` 的链接）发给另外 2–3 个人，他们输入昵称加入。首页也有入口卡片。
3. 每人选一个角色：曼迪、伊森、乔安三个角色必须有人演；第四个人来了就演普雷斯顿（三人局时普雷斯顿由电脑扮演，可以向他问话）。
4. **人到齐了再点「准备好了，开始」**：所有人都准备好就会马上开局，开局以后就不能再有人加入了。

部署到 Render 见上文的按钮（`render.yaml`）；部署到 Railway 时，`railway.json` 已经是 `npm run build` + `npm start`（即 `tsx server.ts`），不需要额外配置。可选环境变量 `HOME_PATH=/mystery`：打开首页直接跳到剧本杀。

建房、加入失败按来源 IP 限流。转发头（`X-Forwarded-For`）客户端可以伪造，所以默认只认 TCP 对端地址；Railway 上会自动信任它的代理，`render.yaml` 里也已设好 `TRUST_PROXY=1`。如果你部署在别的反向代理（Nginx 等）后面，请设置环境变量 `TRUST_PROXY=1`（取 `X-Forwarded-For` 最右一跳，即代理追加的地址），否则所有玩家会被当成同一个 IP；只有当代理会覆盖写入 `X-Real-IP` 时才用 `TRUST_PROXY=real-ip`。

## 电脑 DM 做什么

- **推进流程**：每个环节都有倒计时；所有人都点「继续 / 读完了 / 结束搜证 / 讨论完毕」就提前进入下一环节，时间到了也会自动推进。
- **保管秘密**：每个人只收到自己能看的剧本、线索和私聊结果。别人的手牌、暗标、私下递交的推理和现金余额，服务器都不会发给你；搜查点在报文里也只是一串随机编号；别人搜了你够不着的地方（专属点、还没解锁的点），你只会知道他去了哪个地点。记录按每个人各自编号，你的视图没变化时也不会给你推送，所以从报文的编号或推送次数里也看不出别人做了什么私密操作。剧情文字只在服务器上，前端代码里没有任何人名与真相（有测试把关）。
- **裁定**：搜证扣行动点、NPC 问话、案卷判分、拍卖结算、终局每轮的结算与结局，全部由服务器按规则判定。
- **掉线恢复**：断线后刷新页面或重新打开，会凭本机保存的身份自动回到原座位，进度不丢。同一身份在另一个窗口登录时，旧窗口会被顶下线。服务器每 30 秒检测一次连接，手机休眠、切网后的"假在线"会被及时识别。
- **离开房间**：在大厅里离开会让出座位，别人可以补位（大厅里掉线超过 1 分钟的座位也可以被补上）；开局后离开，座位会保留，之后在本设备打开本页，入口处会出现「回到房间」；点「放弃这局」会通知服务器（大厅里让出座位，开局后告诉其他人你不会再回来了），断网时点的离开 / 放弃会在连上后自动补发。暂离着一局时直接创建或加入别的房间，成功进入新房间后等同于放弃那一局（其他人会收到通知；加入失败则什么都不放弃）。同一设备开了第二个窗口时，旧窗口会被顶下线，入口页可以「在此窗口继续」（同一台设备只能记住一局，所以这时不能在旧窗口里另开新局）；各窗口的入口页会随时跟着另一个窗口的进退自动更新。
- **防误操作**：与阶段绑定的操作（准备、搜证、出价、下令等）带着当时的阶段编号，双击或网络迟到的操作不会落到下一阶段；公开、交出线索、递交案卷跨阶段都有效，不受影响。离线时点的按钮不会被缓存补发，会直接提示"没有发出"。

## 一局的流程

| 环节 | 时长 | 你要做的事 |
|---|---|---|
| 序幕 · 大选之夜 | 5 分钟 | 了解背景 |
| 第一幕 · 八方豪宴 | 15 分钟 | 读自己的剧本 |
| 自我介绍 | 7 分钟 | 轮流用语音或文字向大家介绍自己（可以隐瞒） |
| 21:30 · 慈善拍卖 | 7 分钟 | 用现金暗标竞拍四件道具，它们会在终局派上用场（最高价有人一样，就被维克多截走） |
| 第二幕 · 两点四十分 | 15 分钟 | 继续读剧本 |
| 噩耗 | 5 分钟 | — |
| 搜证一 · 03:20 | 18 分钟 | 8 点行动点：搜现场、问 NPC，决定公开、私藏，还是交给某一个人；可以私下递交「案卷」换酬金 |
| 交锋一 | 12 分钟 | 互相盘问 |
| 第三幕 · 04:15 | 10 分钟 | 新的剧本与线索 |
| 搜证二 · 04:30 | 15 分钟 | 6 点行动点 |
| 交锋二 | 12 分钟 | 互相盘问 |
| 盘凶 · 向 DM 交底 | 20 分钟 | 回答 9 道题，每答对一题得分并领酬金（超时未交视为放弃作答） |
| 终局 · 警长的名单 | 约 20 分钟 | 每位玩家和普莱斯医生各一排格子，每轮交一份证据给警长：指向谁就给谁填一格；中途普莱斯会找每个人私下谈交易（只有一个人接受，他就保这个人、再告这个人点名的人）；06:00 格子满了的人被带走 |
| 06:00 · 破晓之前 | — | 结局、计分、真相复盘 |

进入终局后，先有一页规则说明（可以点「🔊 读给我听」），所有人都点「我看懂了」才开始；之后「📖 规则」也可以随时展开。

## 代码在哪

| 路径 | 内容 |
|---|---|
| `app/mystery/` | 页面入口与样式 |
| `components/mystery/` | 客户端界面（大厅、剧本、搜证、拍卖、终局、结局） |
| `store/mysteryStore.ts`、`lib/mystery/client.ts` | 客户端状态与联机（自动重连、断线恢复） |
| `lib/mystery/hub.ts`、`lib/mystery/protocol.ts` | 服务端多房间中枢与消息协议 |
| `engine/mystery/core.ts` | 通用剧本杀引擎（纯函数，即 DM） |
| `engine/mystery/scenarios/swing-state/` | 《摇摆州》剧本内容与终局机制（**含剧透，只在服务端加载**） |
| `engine/mystery/scenarios/museum-night/` | 《恐龙蛋失踪之夜》剧本内容与算分（**含真相，只在服务端加载**） |
| `engine/mystery/scenarios/index.ts`、`engine/mystery/engine.ts` | 上线的剧本列表；每个房间开房时选定一个剧本 |
| `engine/mystery/scenarios/meta.ts` | 无剧透的标题与简介（两个故事），客户端只允许引用这一个剧本文件 |
